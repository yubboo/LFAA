# Web 应用

Web 应用只负责 Vite 服务、页面挂载和 Cordis 插件装配。共享三栏 Shell、一级/二级侧栏、搜索和活动入口、模式菜单、可固定的应用入口、本地项目列表、外观设置和左下角用户菜单由 `@lfaa/ui-layout` 提供。

项目登记和会话数据保存在本机 Host。侧栏和聊天右侧工作台可进入内置 Git 与代码审查。

```powershell
pnpm lfaa web
```

开发服务器绑定本机地址，并由 Vite 选择可用端口。

## 项目对话与 Git

首次在已绑定且可用的项目中发送消息时，Host 会在模型执行前为项目主目录准备本地 `.git` 和初始基线。内置 Git 审查使用该仓库查看差异和恢复文件。初始化失败会显示在本轮执行记录中。

模型请求遇到短暂连接中断或持续输出推理时，如果当前请求尚未发出正文或工具调用，Host 会在该轮时限内重试一次，并沿用此前已完成的工具结果。
