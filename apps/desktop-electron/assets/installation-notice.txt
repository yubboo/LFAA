LFAA 安装与本机运行须知

安装 LFAA 前，请阅读以下说明。选择“我同意”表示你确认这些安装与运行行为；选择拒绝会取消安装，不会安装 LFAA。

1. 安装范围
安装向导允许选择仅当前 Windows 用户或本机所有用户；安装程序按向导所选范围把 LFAA 桌面程序和随包提供的本机运行组件写入你选择的目录。

2. 本机服务
启动桌面端时，LFAA 会在本机启动控制端与 Daemon 进程，桌面窗口通过本机地址连接它们。使用模型服务、更新检查或用户主动配置的联网功能时，应用仍可能访问相应网络服务。

3. 数据与日志
桌面设置和诊断日志保存在当前 Windows 用户的应用数据目录。LFAA 运行数据默认保存在安装目录的 data 文件夹；安装目录不可写时会使用当前用户应用数据目录。已有的数据目录设置优先，安装不会自动迁移或合并已有数据。

4. 可选桌面操控
桌面版包含电脑操控组件，默认关闭。用户只有在设置中主动启用后，Agent 才能通过现有工具权限流程请求鼠标、键盘或屏幕观察操作。

5. 卸载与数据
卸载会移除程序文件，但会保留安装目录中的 data 数据；用户应用数据目录中的设置、日志或另行选择的数据目录不会由此安装步骤自动清理。需要彻底移除数据时，请先确认其中没有 Minecraft 实例、存档或其他个人文件，再自行选择对应目录处理。

本须知用于说明安装与本机运行行为，不构成额外软件许可或对网络服务、数据目录内容的保证。
