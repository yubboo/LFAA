# Python 临时脚本

放 Agent 与本地排查用的一次性 Python 脚本：布局测量、截图裁剪、批量数据处理等。

## 规矩

- **不入库**：本目录除这份说明外都被 `.gitignore` 忽略。
- **命名**：`<用途>.py`（如 `measure-shell.py`），一个脚本只做一件事，文件头写一句用途与运行方式。
- **产物进 `shots/`**：截图、裁剪图、对比图一律写到 `../shots/`，不要留在本目录或仓库根目录。
- **一次性脚本任务结束就删**：跑完这一次就没用的，Agent 直接删掉，不需要再问。
- **会复用的留下**：判断标准是「换个页面、换个视口还要再跑一遍」——四栏测量、截图裁剪对照这类留下，下次改参数直接跑。
- **长期工具走 `scripts/`**：需要 npm script、需要维护、需要进 CI 的东西，改名进 `scripts/` 并补文件头与脚本条目。

## 运行

```bash
python Python/measure-shell.py
```

脚本只读页面与截图时可以自由跑；要写仓库文件时，先确认写的是 `shots/` 或临时目录。
