## 1. 标签右键菜单

右栏标签栏任意标签右键弹出，动作按标签类型给出，全部是真实实现：

| 菜单项 | 适用范围 | 行为 |
| --- | --- | --- |
| 关闭 | 全部 | 与标签上的 × 相同；关掉最后一个内容标签时右栏按既有规则收起 |
| 关闭其他标签页 | 全部 | 保留右键的那个标签，其余逐个关闭；有浏览器组时只保留目标浏览器页 |
| 关闭右侧标签页 | 全部 | 按标签栏当前视觉顺序关闭右侧全部标签 |
| 关闭所有标签页 | 全部 | 关闭文件 / 辅助 / 子智能体 / 审查 / 浏览器标签，随后回到空态「新标签页」 |
| 复制文件路径 | 文件标签 | 复制绝对路径到剪贴板 |
| 复制网址 | 浏览器标签 | 复制当前页 URL |
| 新建标签页 | 全部 | 与标签栏「＋」相同 |

- 批量关闭显式使用「不收起右栏」的关闭入口，避免关到一半整栏消失；关闭全部后由空态占位补回「新标签页」。
- 「关闭右侧」按标签栏渲染顺序（文件 → 辅助 → 子智能体 → 审查 → 浏览器）计算，而不是按创建时间。
- 不做「固定标签 / 置顶到侧边栏」：当前没有 pin 模型，宁可缺席也不做假菜单项。

## 2. 快捷键注册表

- 契约：`WorkbenchShortcutContribution`（`packages/ui/layout/contract`）= `id / group / title{zh,en} / description{zh,en} / defaultKeys / run`。
- 注册：`workbench.registerShortcut(contribution)`，返回注销函数；动作与界面按钮共用同一实现，没注册的动作不会出现在设置页，也不会响应按键。
- 快照：`WorkbenchSnapshot.shortcuts` 由注册项 + 用户键位覆盖合并而来；右键菜单的键位提示与设置页读同一份数据。
- 分发：Shell 只保留一个全局 `keydown`，按注册表匹配键位后调用 `workbench.runShortcut(id)`；`Esc` 固定关闭浮层 / 收起移动端抽屉，不参与改键。
- 持久化：`localStorage` 键 `lfaa:shortcut-bindings:v1`，值为 `{ [actionId]: string | null }`；缺失用默认，`null` 表示主动清除。
- 输入栏动作（听写 / 中止 / 推理强度）由组件通过 `composer-commands` 命令总线登记处理函数，插件层只注册快捷键，不把工作台服务一路传进输入栏。

### 已注册动作（22 项）

| 分组 | 动作 | 默认键位 |
| --- | --- | --- |
| 全局 | 搜索 / 活动 / 显示隐藏左二栏 / 显示隐藏右栏 / 最大化右栏 | `Ctrl+Alt+K` / `Ctrl+Alt+U` / `Ctrl+←` / `Ctrl+→` / `Ctrl+Alt+M` |
| 导航 | 键盘快捷键 / 打开设置中心 / 打开资料库 | `Ctrl+Alt+/` / `Ctrl+Alt+,` / `Ctrl+Alt+L` |
| 会话 | 新聊天 / 归档 / 置顶 / 标记未读 / 中止回复 / 语音听写 / 选择推理强度 | `Ctrl+Alt+N` / `Ctrl+Alt+Shift+A` / `Ctrl+Alt+Shift+P` / `Ctrl+Alt+Shift+U` / `Ctrl+Alt+X` / `Ctrl+Alt+V` / `Ctrl+Alt+R` |
| 右栏 | 打开终端 / 变更审查 / 侧边提问 | `Ctrl+↓` / `Ctrl+Alt+G` / `Ctrl+Alt+S` |
| 右栏 | 新建标签页 / 关闭当前标签 / 下一个 / 上一个 | `Ctrl+Alt+B` / `Ctrl+Alt+W` / `Ctrl+Alt+PageDown` / `Ctrl+Alt+PageUp` |

- **三栏开合用方向直觉键位**：`Ctrl+←` 左二栏、`Ctrl+→` 右栏、`Ctrl+↓` 终端（终端当前是右侧工作台里的标签页，不是底部独立面板）。浏览器不保留裸 `Ctrl+方向键`，页面能收到；输入框内仍然保留按词移动光标——全局监听在编辑区内只放行 `Ctrl+Alt` 组合。
- 其余动作走 `Ctrl+Alt(+Shift)` 命名空间（理由写在 `shortcut-defaults.ts` 顶部）：`Ctrl+<字母>` / `Ctrl+Shift+<字母>` 会被 Chrome/Edge 截走，`Alt+Shift(+字母)` 是 Windows 输入法切换，`Ctrl+Alt+方向键` 会被显卡驱动当成屏幕旋转。
- 默认键位唯一来源是 `DEFAULT_SHORTCUT_KEYS`：注册表、悬停提示、右键菜单提示都从它取值，改一处即可全链路同步，不再有「提示写死旧键位」。
- 输入框里放行 `Ctrl+Alt` 组合（打不出字符、不会抢输入），所以听写 / 推理强度 / 中止在输入栏里也能用；单键与纯 `Ctrl` 组合仍交给输入框。
- 浏览器标签级动作只在工作台挂载时出现于设置页（面板内的标签快捷键），「新建标签页」已提升到插件级，工作台收起时也能用且会先展开工作台。
- 参考清单里的「显示智能伙伴（Alt+Win+P）」在本产品没有对应功能，不做占位快捷键。

## 3. 悬停提示

- 所有绑定了快捷键的入口都带同款胶囊气泡：左二收起/展开、右侧菜单栏开关与最大化、新建标签页、语音听写、选择推理强度、发送、用户菜单里的「设置」等；文案与键位徽章都读注册表，改键后提示同步。
- 气泡用 portal 渲染到 `body`，按触发元素位置自动落在上方或下方：顶栏按钮改到下方，避免被窗口边缘裁掉；贴视口左右边缘时自动内收。
- 搜索与活动沿用左二工具栏的 `ToolbarTip`（同款深色胶囊），键位同样从注册表读取。

## 4. 设置中心「键盘快捷键」

- 位置：设置中心 → 个人 → 键盘快捷键（`settings:shortcuts`），目录项只登记已接入页面；`Ctrl+Alt+/` 可直达。
- 行式布局：动作名 + 说明在左，键位芯片在右；芯片右侧是清除（×）与「恢复默认」，页头提供「全部恢复默认」。
- 录制：点键位芯片进入录制，`Esc` 取消，`Backspace` 清除，其余组合键保存；录制期间捕获阶段拦截按键，不会同时触发全局动作。
- 冲突：与其它动作重复时就地提示「与「X」相同，请换一个组合」，不写入。
- 搜索：按中英文动作名、说明与键位过滤。
