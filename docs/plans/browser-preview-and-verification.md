# 浏览器预览与定向验收修复

状态：**已实施**。负责人已确认按 A1 修复浏览器工具与右侧工作台联动。

## 目标与交互

- 用户要求打开预览时，主 Agent 调用 `browser_present`。当前标签符合目标时直接展示，需要访问其他地址时导航一次。显式打开独立于后台跟随偏好。
- 多步排查或验收委派浏览器子智能体。验收任务包括目标页面、具体操作、预期结果和结束条件。子智能体复用当前标签，以真实点击和滚动验证交互。主 Agent 根据已授权范围和可复现证据修改代码，复验受影响步骤。
- 自动操控期间右栏显示同一个 Playwright 页面。步骤更新按动作去重，预览状态读取不触发重载。对话步骤展示操作结果，验收截图可以单独查看。

## 文件与契约

- `core/agent` 的 `agent-context.ts`、`think-round.ts` 区分预览与验收。`core/subagent` 的 `browser-subagent.ts` 与调度服务传递定向任务和真实工具结果。
- `core/browser` 注册 `browser_present`，为截图和视觉检查提供会话范围的证据标识。证据放在有限容量的宿主缓存，随宿主生命周期释放。`core/tools` 和 `core/session` 扩展可选步骤结果字段，旧会话继续读取。证据 HTTP 路由使用会话和证据标识查找截图。
- `client/ui-chat` 的 `agent-workbench-sync.ts`、`chat-store.ts` 和右栏 workbench 接收显式打开与浏览器操作状态，浏览器步骤卡显示结果和截图链接。`client/ui-browser` 复用现有 CDP 画面和人工接管，并把 iframe 重载交给显式刷新。
