## 实现摘要

1. **`ChatAnchorBar.tsx` / `ChatAnchorBar.module.css`**：
   - 新增 `buildTurnAnchors(messages)` 将消息列表按 `user` + 配对 `assistant` 聚合为轮次锚点数据（含用户标题、助手回复摘要、时间 `HH:mm`）。
   - 在聊天工作区左侧垂直居中渲染水平刻度条，支持当前可见轮次高亮（`tickActive`）、macOS Dock 风格悬停波浪放大（`tickDist0` / `tickDist1` / `tickDist2`）。
   - 悬停刻度时在右侧弹出液态玻璃预览卡片（`previewCard`），展示用户提问标题、书签切换按钮（`添加书签` / `取消书签`）、助手回复预览以及 `N of Total` 与时间戳页脚；窄屏（`<= 900px`）自动隐藏以免遮挡正文。
2. **`ChatWorkspace.tsx` / `ChatWorkspace.module.css`**：
   - 为 `.root` 添加 `position: relative` 作为刻度条定位容器。
   - 在每条 `.userRow` 挂载 `data-turn-anchor={msg.id}`，并在 `.scrollArea` 滚动时实时计算当前可见轮次 `activeTurnIndex`。
   - 接入 `<ChatAnchorBar />`，点击刻度通过 `scrollIntoView({ behavior: 'smooth', block: 'start' })` 平滑跳转至对应对话轮次。
