# DEV-000446｜滚动条改成共享强调色胶囊滑块，设置中心接入 ScrollArea

  - **外观基线收进主题层**：新增 `packages/ui/theme/client/scrollbars.css`，由主题包客户端入口副作用引入。全局 `::-webkit-scrollbar` 定为 10px 槽位（`--scrollbar-size`）、透明轨道、3px 透明边框 + `background-clip: padding-box` 的 4px 内嵌圆角胶囊；Firefox 走 `@supports not selector(::-webkit-scrollbar)` 内的 `scrollbar-width/scrollbar-color`，标准属性不会在 Chromium 生效。`app.css` 删掉原来的滚动条块（含 `var(--color-accent, #e66aa8)` 这种写死回退），只留一行指向说明。

## 关键设计

- **平滑过渡**：预览内每个元素对 `background-color` / `color` / `border-color` 做 260ms 过渡，切换取样是"颜色渐变过去"而不是整块淡入淡出；`prefers-reduced-motion` 下关闭。

- **两条轴分开标记**：模式卡与预设卡各自 `active`，点击 `mode:*` 只换明暗，点击 `preset:*` 应用整套配色，不会互相覆盖。
- **取样抽成纯函数**：`theme-tiles.ts` 的 `buildThemeTiles()` / `sampleOfPreset()` 不依赖 DOM，便于单测与复用。
