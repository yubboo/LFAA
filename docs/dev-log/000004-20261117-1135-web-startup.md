## 风险、回滚与遗留问题

- 风险：`pnpm-workspace.yaml` 允许 `esbuild` 安装脚本，这是 Vite/tsx 工具链所需的单包构建授权；其余包仍由 pnpm 拦截。
- 回滚办法：移除本轮新增的 `apps/cli`、`apps/web`、`packages/ui/layout` 文件，恢复本日志列出的根配置和说明文件；保留已有菜单与前序日志。
- 遗留问题：当前只有静态四栏 Shell，没有真实 workspace 数据、业务插件插槽、拖拽尺寸、折叠或持久化；应用退出信号的交互表现仍可在后续桌面化时进一步验证。
- 生成物：`pnpm install` 创建被忽略的 `node_modules/`；`pnpm run build` 创建被忽略的 `apps/web/dist/`。
- Git 状态及提交：`F:\lfaa` 不是 Git 仓库；未初始化、未提交。
- 本轮有无用户可见变化、是否新增 updata-log：新增可启动 Web 页面及四栏空工作区，已新增对应 `updata-log`。
