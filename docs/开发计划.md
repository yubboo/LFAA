# LFAA 当前开发计划

本页只保留仍有效的主线、已知缺口和排序方法，不重复记录每项任务的实施细节。进行中任务及最新状态见 [PROMPTS 任务索引](PROMPTS.md)；任务合同是具体范围与验收证据的唯一入口。

## 当前主线

1. **先完成进行中的合同。** 依据索引状态继续任务，修复真实问题，按合同验收；不把源码存在、构建成功或旧报告写成端到端完成。
2. **保持唯一 Owner。** 新增应用和节点能力时，沿现有 Settings、Session、Permission、领域服务与 Daemon 合同接入，不建立平行权限、数据或执行体系。
3. **补齐应用和画布接入。** 运行时应用注册及内部应用市场尚未实现；系统画布仍需接入 Minecraft、SteamCMD 等 App 的真实节点目录和执行能力。
4. **按目标平台交付。** 当前 Windows x64 Electron 为桌面主线；macOS、Linux 与 Android 尚未交付。各平台须完成独立构建、安装、权限和实际运行验收。

## 排序原则

- 优先级依次考虑安全与数据正确性、核心流程可用性、可靠性与性能、后续能力扩展。
- 先解决已确认的用户问题和进行中合同，再开始依赖它们的新能力。
- 每个目标拆成可验证结果；对 UI、Provider、Daemon、桌面或设备的要求，使用对应宿主实测。
- 计划和合同描述目标，不构成实现、发布或操作授权。未知或未测项目明确保留。
