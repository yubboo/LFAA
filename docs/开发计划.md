## 当前主线与真实边界

LFAA-Harness 以第一方插件、Profile/Bundle 和 Cordis 生命周期装配通用 Agent 与领域 App。模型按目标选择已接入工具，手动与 AI 共用领域/权限/节点 Owner，不写死流程替代模型决策。Windows Electron 是桌面主线；macOS、Linux 与 Android 仍需独立平台交付。

- Session：JSONL 权威、恢复与工具中断保护已接入；正文缓存、列表工作量和超长会话消息分页已实现。分页现为单次异步流式完整哈希链校验，不再双扫或同步阻塞；单页仍遍历完整日志，轻量索引、压缩/沉降和真实长会话性能测量待治理。
- Settings：共享类型/默认值与严格写入校验已收敛；旧值兼容读归一化保留，不重置偏好。
- Agent 与 MCP：AI Work 沿用模型驱动工具循环；用户配置的本机 stdio MCP 可按 App 提供真实工具，MCP 文本/图像结果能回到下一轮 Provider 请求。超过 64 项的 MCP 工具目录使用分页发现、单工具 schema 按需读取与原 schema 校验后的统一派发；官方 REA 6.7.0 Windows 连接预设和证据优先 Skill 已进入源码/Bundle，REA Skill 可由 `plugins.disabledSkillNames` 单项停用，账户连接仍需用户在设置中心添加。Computer-Use MCP 受 computerControl.enabled 与现有 permissions.mode 双重约束；本机进程使用 shell:false、有界参数和桌面环境变量白名单，并在 Run 租约结束时回收。207 项合成协议回归已验证搜索、schema、校验与调用；真实 REA npm MCP、Provider 视觉请求、目标程序和桌面操作仍未验收。
- 本机电脑/游戏操作：Windows Electron `desktop` 与仅绑定 loopback 的本机 CLI `web` Profile 使用 LFAA 自有 CUA 提供屏幕观察和有界鼠标/键盘动作，受账户 `computerControl.enabled` 与 `permissions.mode` 控制。模型仍理解自然语言并选择工具；用户明确要求启动且名称清楚时，可一次调用危险启动工具的 `query` 入口，Owner 在一次有界发现中校验并启动唯一高置信匹配，避免先搜索再启动及重复发现。歧义、低置信、无结果或扫描受限时不启动；需要选择时仍可搜索候选并用本轮 ID 启动。发现覆盖 Windows 登记来源、Steam 与有界便携 EXE 查找；命中已登记应用时跳过便携扫描，否则最多检查 16 个磁盘根、1400 个目录、24000 个目录项、5 层、2.5 秒和 80 个候选。不做无界全盘扫描或同目标重复查询。启动后观察核验。个性化游戏推荐仅统计本 Control Plane 进程内、由 LFAA 发起的 Steam 游戏启动请求；Steam 外部账户数据、游戏时长和 LFAA 外活动不接入。真实 Provider、桌面安装版和启动效果仍待实机验收。
- AI Work 浏览器预览台：已接入认证 Browser API、按账户/Session 隔离的系统 Edge/Chrome 上下文、同页截图/文本/元素/JSON 检查与受限 Agent Tools；可选 Tabbit Provider 走安装时的稳定 LocalAgent CLI，仅在用户明确连接后列举标签，选择精确标签后读取页面。设置中心保存 `browserUse.enabled`（Agent 工具开关，默认关闭）、`enabledProviderIds`（已连接浏览器，默认空）和 `showFullUrl`（默认关闭）；隔离浏览器不要求 computerControl，Tabbit 个人会话还要求既有 `computerControl.enabled`，所有 Agent 动作统一经过 `permissions.mode`。页面数据/截图不落会话记录。2026-10-21 既有实页记录确认隔离 Edge 页面预览和 Browser 设置状态；本轮回归、构建及内置浏览器检查详见任务合同 167。真实 Tabbit 操作、个人 Edge/Chrome Profile 镜像（当前未接入）、Desktop WebView 与帧时间仍待后续验收；默认隔离浏览器不继承个人登录态。
- 本机精确路径是通用发现之外的可选快捷入口：用户明确提供 Windows `.exe` 绝对路径时，本机电脑 Owner 直接校验并以 `shell:false`、无参数启动，复用 `computerControl.enabled` 与 `permissions.mode`；不要求用户必须知道安装目录，启动后仍要观察核验。
- 三种权限模式：`请求审批`仍逐项等待；`替我审批`只对同一账户、App、工具版本、风险和目标范围的明确批准累计两次后自动记忆，并支持首次批准时主动记忆和设置中心撤销；`完全访问`在当前目标内不逐项审批。真实 Provider 与桌面交互待实机验收。
- 执行：Shell 与运维槽隔离、Electron IPC 卸载和 Tauri 兼容路径的 stdin/IPC 有序退出已改造；长安装仍占用运维槽，Tauri 实际桌面退出未验收。
- Minecraft、写作、资料库与工作流：以现有领域合同为准；AI Work 已可通过 `packages/workflow/tool-workflow` 发现、保存、运行和跟踪现有工作流，但可执行领域节点目前仍只有 Minecraft 适配器，不能宣称全部 App 可执行或 DSH 能力全量完成。
- Connectivity：保留已有单一 App、EasyTier 节点安装/运行/状态和路由合同；玩家网关、完整邀请/语音/协作与真实跨网验收仍是目标。
- AI 漫剧：项目/剧本/角色场景参考图/分镜、导入媒体、可编辑时间线片段和白模相机状态按账户写入本机项目文件；所选角色/场景图随 OpenAI Images Edit、Ark Seedream 与 Ark Seedance 请求发送。视频使用独立设置中心账户、模型和生成参数，由 Ark 异步任务生成并由 AI Video Owner 保存真实任务状态和下载后的 MP4；应用运行时有本机服务轮询，页面重开可恢复。项目媒体库支持音视频图片，时间线含视频/音频/字幕轨道、预览与浏览器原生导出；白模导演台和主动开启的手机取景器已接入源码。模型目录存在不代表服务商已开通视频能力；没有真实请求前不宣称 Provider 已验收。项目与图片/视频任务已进入 `aivideo` Agent Tools 和统一 Permission。浏览器编码/音画同步、设备相机/权限、桌面、现场 Provider 与后台恢复须分开验收。
