# 文档语言维护

[English](README.md) · [文档目录](../README.zh.md)

新专题使用英文 `name.md` 与中文 `name.zh.md` 配对，首段互链；同一提交同步更改会影响操作、参数、Owner 或验收条件的内容。项目根 README 继续作为中文入口，英文入口为 `README.en.md`。

现有中文权威文件保持唯一原路径。英文专题是相同职责的操作指南或导读，不另建版本日志、架构事实或任务合同。历史审计、旧合同与用户提供的提示词资料保留原语言；不把未翻译记录标成已翻译。

移动文档须更新相对链接。归档中历史绝对路径是当时证据，既不指定当前 checkout，也不继承访问、清理、重启或发布授权。修改前始终解析当前仓库根目录。
