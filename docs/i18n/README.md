New topics pair English `name.md` with Chinese `name.zh.md` and link to each other. Update behavior, parameters, owners and acceptance criteria in both versions together. The root README remains the Chinese entry; `README.en.md` is the English entry.

Existing Chinese authorities retain one original path. English guides do not create separate release logs, architecture authorities or task contracts. Historical audits, contracts and supplied prompt materials remain in their original language; untranslated records are identified as such.

Update relative links when moving documents. Historical absolute paths describe earlier checkouts, not the current physical location or authorization to access, clean, restart or publish anything. Resolve the current repository root before acting.
