## 1. 背景与待解决的痛点

结合负责人实机验收反馈及参考界面截图，当前首版右侧面板存在四类明显体验问题：

1. **顶部未对齐且套娃严重**：`ContextPanel` 顶部占位为静态“右侧上下文”，内部又套了一层“工作详情”卡片与 `← 打开文件 / ← 内置浏览器` 二级返回条，未像左/中顶栏那样直接作为右工作区标签栏水平对齐。
2. **辅助信息污染主视图**：“工作区上下文”常驻压在右栏底部，无论看代码还是看浏览器都会被它截断高度，缺乏类似 IDE 最右边的独立图标菜单栏来收纳与按需展开辅助工具。
3. **代码查看简陋**：点击对话中的“已编辑 / 已读取文件”后仅在小盒子中展示简陋灰块，缺少 VS Code 风格全高标签页、路径面包屑、精确行定位高亮、右侧文件树联动高亮以及行内 `+` 批注提问。
4. **内置浏览器被关在小方框内且交互受限**：浏览器画面被缩在 1280×800 的小预览图盒里，上方标题冗余、下方被“工作区上下文”与输入框挤占；缺少多标签页切换、视口自适应清晰分辨率、直接滚轮与键盘直输、Network 状态查看等真浏览器操控体验。

## 2. 已讨论确认的核心选型

经与负责人对齐，明确以下三条设计基准：

1. **代码查看器定位**：仅需 VS Code 风格**只读查看 + Diff 对比 + 精确行定位 + 行内 `+` 批注发送给 Agent**（保持轻量快速，暂不引入重型编辑器或全量写盘保存）。
2. **右侧结构排布**：采用「**右工作区全高 Tab + 可折叠右辅助栏（文件树 / 上下文 / 任务 / 子智能体等）+ 最右图标轨**」，展开文件树即可形成“左代码 + 右文件树”联动，收起时全幅空间让给浏览器或代码阅读；原有“审查 / 打开文件 / 终端 / 浏览器 / 侧边提问 / 扩展 / 工作详情”全部保留，一项不省。
3. **内置浏览器操控引擎**：沿用并升级 **Playwright 多标签本机 Edge/Chrome 会话流**（视口动态匹配面板宽高、直接鼠标悬停/点击/滚轮/键盘直输、Console/Network 可折叠 DevTools 抽屉、一键弹/收桌面有头窗口人工接管），确保小鱼 Agent 与用户可共控同源与跨域任意站点。

## 3. 总体视觉与交互架构

### 3.1 桌面端整体布局演进

保留四栏可折叠 Shell 与左一/左二既有定位，将右侧主区升级为贴近 IDE 的三段协同结构（仍归属于 Workbench 右侧可折叠域，一键可整体收起不挤压中间聊天区）：

```text
[左一图标栏] | [左二会话/项目] | [中间聊天工作区 (顶部 WorkspaceBar)] | [右工作区: 顶部统一 Tab 栏 + 全高代码/浏览器] | [可折叠右辅助栏 (可选展开)] | [最右图标轨]
```

- **顶部齐平（`var(--topbar-height)`）**：
  - 取消 `ContextPanel` 的“右侧上下文”静态标题与 `AgentContextPanel` 内的“工作详情 / 返回总览”套娃层；
  - 右工作区顶部直接与中间 `WorkspaceBar` 水平对齐：展示打开的文件 Tab、内置浏览器 Tab、`+` 新建浏览器 Tab、关闭按钮 `×`；
  - 辅助栏顶部展示当前激活辅助视图标题与收起按钮。
- **右工作区默认与可调宽度**：
  - 保留现有 `sidebar-resize.ts` 保护机制（`MIN_CENTER_WIDTH = 360`，右栏最大可拉到 `75%`）；
  - 当打开全高文件 Tab 或浏览器 Tab 且桌面可视宽充足时，允许智能平滑扩展至合理宽屏阅读比例（如在未人工手动调窄前优先保障代码与浏览器可用视野，手动拖拽后严格尊重用户保存宽度）。
- **窄屏 / 平板兼容（`< 1024px`）**：
  - 仍沿用右侧滑出抽屉，最右图标轨在窄屏转为抽屉顶部紧凑图标切换条，不横溢、不与左抽屉同时遮挡。

### 3.2 最右侧图标菜单栏（Right Utility Rail）与辅助视图

最右边缘增加一条固定窄图标轨（桌面端宽度同左一风格紧凑图标按钮，支持键盘焦距与提示气泡），收纳并独立切换下列功能视图：

| 图标项 | 职责 | 说明 |
| --- | --- | --- |
| **工作区文件树** | 浏览项目目录、点击任意项目内文件直接在右工作区开 Tab | 自动展开并高亮当前激活文件 Tab 所属路径；切换项目或对话自动同步绑定项目 |
| **工作区上下文** | 展示 `@lfaa/workspace` 项目状态、根目录与来源 | 从主区底部彻底迁出到这里独立按需查看，不再污染代码/浏览器画面 |
| **终端与后台任务** | 接入 `@lfaa/jobs` 实时日志流、状态筛选与停止进程树 | 点击任意任务可直接看增量日志与停止 |
| **子智能体团队** | 接入 `@lfaa/subagent` 运行态、只读/读写模式与结果详情 | 支持继续追问或中止运行中子智能体 |
| **侧边提问** | 独立短问侧边助手（`/api/agent/side-ask`） | 不打断主聊天上下文的快速解释/查代码窗口 |
| **工作详情 & 设置** | 展示当前大脑模型、权限模式、记忆数、规则层数与设置入口 | 保留总览、快速跳转代码审查（`codeReview`）与扩展中心入口 |

交互规则：
- 单击当前已展开的辅助图标 → **收起右辅助栏**，把宽度全数释放给代码/浏览器；
- 单击另一辅助图标 → 切换右辅助栏内容并展开；
- 主右侧快捷触发（点击聊天文件 → 激活/打开左文件 Tab；点击 `+ → 浏览器` → 新建/聚焦浏览器 Tab）。

### 3.3 VS Code 风格代码查看器（只读 + Diff + 行定位 + 行内 `+` 批注）

- **全高铺满**：移除旧版卡片嵌套盒，占满右工作区 100% 宽高；顶部 Tab 下紧接**面包屑路径栏**（`项目名 > dir > ... > filename`）+ 右侧轻量动作条（`源码 / Diff 对比` 切换、精确行区间徽标如 `L112-145`、复制路径/定位）。
- **语法高亮与行号沟槽**：
  - 按扩展名高亮 TS/TSX/JS/JSX、Java、JSON、CSS/SCSS、HTML、YAML、Markdown、Shell、SQL 等词元，深/浅双主题均通过 `@lfaa/ui-theme` 变量配色；
  - 精确滚动与高亮：打开步骤附带 `firstLine` / 变更行或点击聊天中的 `file#L10-25` 时自动平滑滚动居中并高亮目标行区间；
  - 支持读取未在本轮编辑的项目内文件（点击文件树节点即可打开源码只读查看；如有 Git 工作区差异，可点击切入 Diff 视图）。
- **行内 `+` 批注发送给小鱼 Agent**：
  - 鼠标悬停行号左侧时显示蓝色 `+` 按钮；点击（或拖动起止行）在对应代码行下方内联展开评论卡（带当前行上下文标注、`取消` 与 `添加到对话` / `直接发送`）；
  - 提交时自动构造紧凑、可定位的引用草稿（如 `针对 path/to/file.ts#L42：...`）附加到当前会话输入框焦点并提示用户补充或一键发送。

### 3.4 全视口、真交互多标签内置浏览器

- **全高全宽铺满**：内置浏览器直接作为一个（或多个）右工作区 Tab 渲染，去掉所有外层卡片边框与“工作区上下文”占位：
  1. **Tab 栏（共用右工作区顶栏）**：展示当前所有打开的浏览器标签（图标、页面标题、加载状态、`×` 关闭），右侧 `+` 一键新建空白/本地开发页 Tab；
  2. **浏览器导航条**：`后退`、`前进`、`刷新/停止`、安全/本地徽标、**全宽 URL 地址栏**（支持直接输入域名或 `localhost:PORT`）、`视口预设`（自适应面板 / 桌面 1280×800 / 手机 390×844）、`DevTools 开关`、`人工接管开关`、`附带当前页截图与控制台异常到对话`；
  3. **主视口区域（`flex: 1` 全高铺满）**：直接渲染高清晰度实时页面画面，并承载完整真实鼠标与键盘交互；
  4. **底部可折叠 DevTools 抽屉**：分 `Console`（按日志/警告/错误筛选与清空）与 `Network`（记录请求方法、状态码、耗时与失败原因）两栏，便于用户和小鱼 Agent 共同排错。
- **Host / Client 真交互协同（`@lfaa/browser` 升级）**：
  - **多标签管理**：将 `BrowserSessionEntry` 由单 `page` 升级为单一持久化 `BrowserContext` 下的多 `tabId` 映射；支持自动捕获网页新开弹窗/链接标签并同步到前端 Tab 栏；
  - **自适应视口与 1:1 坐标**：前端通过 `ResizeObserver` 将视口容器真实 CSS 像素（带合理的最小/最大上限与防抖）同步到后端 `setViewportSize`（在“自适应模式”下画面 1:1 铺满且无缩放锯齿）；
  - **真实鼠标与键盘直输**：视口容器直接绑定鼠标左/中/右键点击、节流悬停、滚轮 `wheel` 滚动及聚焦后的键盘 `keydown` / 中文输入法 `compositionend` 文本输入；移除旧版底部显式文字小输入框；
  - **Agent 工具增强**：在既有 8 个工具基础上补充多标签切换/新建/关闭（`browser_tabs`）、悬停（`browser_hover`）与网络失败摘要（`browser_network`），保持 `BrowserUseRegistry` 会话独占锁语义不变。

## 4. 跨包契约与文件边界规划

严格遵守 `AGENTS.md` §2（Host/Client 分离、Cordis 公开契约驱动、不跨包深层导入）：

1. **`packages/ui/layout`（Shell 通用扩展契约）**：
   - `src/index.ts` & `client/workbench-service.ts`：新增右侧栏通用扩展注册契约（`WorkbenchRightToolContribution` / 右辅助栏与最右图标轨注册、清理与切换状态，以及向主右区插件开放紧凑头部/全高容器渲染开关，不直接导入 `@lfaa/chat`、`@lfaa/browser` 或 `@lfaa/workspace`）；
   - `client/components/ContextPanel.tsx` / `WorkbenchShell.tsx`：移除固定死板的卡片套娃包装，支持插件渲染全高 Tab 工作区并装配可折叠右辅助栏与最右图标轨。
2. **`packages/workspace/workspace`（只读文件树节点与项目内单文件安全读取）**：
   - `src/index.ts` & `src/http-handler.ts`：扩展按项目安全读取单个文本文件只读内容（严格校验路径处于已注册项目 `rootPaths` 内、限制最大字节与跳过二进制文件），并在 `client/` 导出通用可嵌入的轻量项目文件树组件或通过 `workbench` 暴露文件点击回调，供右辅助栏“工作区文件树”联动使用。
3. **`packages/core/browser`（多标签、真键鼠与 Network/Console 采集）**：
   - `src/types.ts`、`browser-service.ts`、`browser-tools.ts`、`http-handler.ts`：支持多 `tabId`、动态视口尺寸、鼠标悬停/滚轮/右键/键盘直输及 `network` 请求异常采集；
   - `client/browser-client.ts`、`RightBrowserPane.tsx`、`RightBrowserPane.module.css`：全高全宽铺满浏览器主区、`ResizeObserver` 自适应视口、真实滚轮/键盘事件穿透、可折叠 Console/Network DevTools 抽屉与快捷端口入口；清理大文件确保可读与双主题支持。
4. **`packages/core/chat`（右工作区统一 Tab 栏、VS Code 代码查看器与最右辅助栏装配）**：
   - `client/chat-types.ts` & `client/chat-store.ts`：统一管理右工作区 Tab 队列（文件 Tab + 浏览器 Tab，支持多开、切换、关闭、激活项目任意文件与定位目标行）；
   - `client/components/RightWorkbenchPane.tsx` & `RightCodeViewer.tsx` & `InlineLineComment.tsx` & `RightUtilityRail.tsx`：拆分实现顶部对齐 Tab 栏、VS Code 风格代码+Diff查看器（面包屑 + 行定位 + `+` 行内批注回填聊天输入框）、可折叠右辅助栏及最右图标轨。

## 5. 分期实施顺序

- **第 1 期（Shell 顶栏对齐 + 最右图标轨 + 统一 Tab 工作区骨架）**：重构 `@lfaa/ui-layout` 右栏容器与 `WorkbenchShell` 顶栏对齐，落地最右图标轨与可折叠右辅助栏，将“工作区上下文”迁出主区并保留“后台任务 / 子智能体 / 侧边提问 / 审查 / 工作详情 / 扩展”全部能力。
- **第 2 期（VS Code 代码查看器 + 行内 `+` 批注 + 文件树双向联动）**：在 `@lfaa/workspace` 补充安全项目文件只读接口与树联动，在 `@lfaa/chat` 落地全高代码查看器、路径面包屑、多语言语法高亮、精确行滚动高亮及 `+` 行内批注回填对话能力。
- **第 3 期（全视口真交互多标签内置浏览器 + 全端双主题浏览器实测验收）**：升级 `@lfaa/browser` Host 多标签、动态视口、滚轮/键盘穿透与 Network 采集，重构全高全宽浏览器 UI 与 DevTools 抽屉，最后运行全量 `typecheck`、单测、Web 构建及内置浏览器深/浅双主题桌面与窄屏实测验收，并更新常驻 `5173` 服务与文档日志。

## 6. 验收标准

1. **视觉与布局（对照图一～图八）**：右工作区顶栏 Tab 与中间栏 `WorkspaceBar` 水平对齐；代码查看器全高铺满、带面包屑、精确行定位、高亮同步右侧文件树，且支持行号旁 `+` 内联添加批注发送到对话；内置浏览器全高全宽铺满（上方多 Tab + 工具/URL 栏，下方完整可交互视口 + 可折叠 Console/Network）。
2. **功能完备性**：最右图标轨支持自由展开/收起「工作区文件树」「工作区上下文」「终端与后台任务」「子智能体」「侧边提问」「审查 / 工作详情」，原有能力零丢失。
3. **真实操控**：内置浏览器支持真实滚轮、鼠标悬停/点击、直接键盘与中文输入、多标签新建切换、桌面/手机预设、人工接管切换；小鱼 Agent 与用户可在同会话共享操作同一组标签页。
4. **工程质量**：Host/Client 隔离严格、`@lfaa/ui-theme` 深浅双主题无硬编码色值、单文件行数受控、新增与改动均附中文注释及单测，经内置浏览器实测控制台报错 0、请求失败 0 后再更新常驻 `5173` 服务与开发/更新日志。
