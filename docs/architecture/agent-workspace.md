# Agent 会话工作区

本轮修复已有会话绑定、Host 解析和应用私有文件暴露。已有聊天保留项目选择器，明确绑定后下一轮使用该项目目录。运行中或处理项目切换时保留当前工作区，避免在审批和执行中途换目录。

- Web Agent 以磁盘会话的项目绑定解析授权根目录。浏览器提交消息及审批模式，项目提示和任意根目录不作为授权来源。信任项目只是登记，聊天通过项目绑定选择本轮的执行根目录。
- 输入区的工作位置与项目栏仅在没有消息时显示。已有聊天通过输入区的 `@项目` 打开同一个选择器。
- 运行期间的权限选择通过 Host 更新本轮模式。对未结算的审批发送结束事件并按新模式重新评估，后续工具即时读取新模式。
- 默认项目外工作目录为 `~/.lfaa/workspace`。旧的 `~/.lfaa` 默认值按新目录解释，已有文件与显式配置的其他目录保留。内置文件工具和源文件预览拦截本机模型配置、凭据与会话日志；目录搜索跳过这些位置和符号链接。模型上下文列出本轮真实工作区与加载的项目规则。
- 审批仍使用 LFAA 当前会话请求。终端子进程沿用现有授权执行方式，与内置文件工具的路径限制有不同的技术边界。旧配置和密钥保持原状，单独评审凭据迁移、轮换与 OS 隔离。
- DSH 本地参考：`packages/workspace/workspace` 用会话关联持久化 workspace；`packages/sandbox/sandbox-windows-acl` 提供 Windows 子进程写入保护，未限制读取；`packages/credentials/credentials-local` 以操作系统用户权限保护私密文件，与同用户的 Agent 进程之间仍需隔离。

验收覆盖已有会话选择项目、项目外文件保护、已绑定会话的实际读取和审批写入、伪造根目录字段失效，以及浅色和深色。回滚仅撤销本轮实现，保留会话、项目文件和凭据。
