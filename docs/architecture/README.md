# 架构文档索引

## 基线

- [架构基线](overview.md)：项目技术栈、包边界、应用装配和已确认的总体决策。
- [仓库目录说明书](repository-map.md) · 当前目录树、逐文件职责与常见入口。

- [助手回复过程](assistant-timeline.md)：正文流、活动分组、运行状态与历史回看。

- [Plan 模式](plan-mode.md)：计划模式的交互、Host/Client 契约、实施顺序与验收要求。状态以文档内说明为准。

## 维护约定
