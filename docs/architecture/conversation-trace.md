# 对话流与独立轨迹方案（待评审）

## 目标与范围

以负责人提供的截图为交互参照，在现有聊天工作区提供独立的「对话 / 轨迹」切换，让自然语言流式回复保持清晰，同时可按时间查看真实 Agent 执行过程。轨迹在运行中更新，完成后可回看；不把工具轨迹藏在流式状态行中。

## 交互和数据

- 对话页保留流式正文、必要的简洁运行状态和审批操作；轨迹页按会话顺序展示用户输入、助手进展与步骤，工具行显示名称、目标、状态和可用的结果摘要。
- 选择轨迹行后查看详情：概览、参数、结果和计时；只展示当前真实记录中存在的字段。没有保存 Schema、完整参数或结果时明确提示不可用，不伪造数据或计时。运行中状态与完成、失败状态均及时更新。
- 提供轨迹搜索和简明的轮次/状态信息；桌面可并排查看列表和详情，窄屏以可返回的详情视图适配。遵循现有 Shell、双主题、本地化和键盘可访问性。
- 在项目上下文位置提供截图中的「变更」入口及新增/删除行数，点击打开现有变更审查；负责人已确认本次目标项目为 `E:\lfaa`，统计口径为当前绑定项目的 Git 工作区差异，避免误认为仅由当前会话产生。无项目、非 Git 仓库、读取失败及统计不完整时给出真实状态。统计须明确暂存、未暂存和未跟踪文件的覆盖范围，不能将截断的 diff 文本行数当作完整统计。
- 复用会话消息、`AgentStepTrace` 及现有 SSE 的快照和步骤更新，不新增第二份轨迹状态或改变事件协议；处理历史记录中缺失字段的情况，保留现有重连、去重及审批行为。
