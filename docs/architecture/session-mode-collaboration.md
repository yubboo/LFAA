# 会话模式与多 Agent 协作

## 目标和现状

将模式选择移到输入框底部权限控件附近：新会话发送首条消息前选择，发送后锁定；新会话可以重新选择。每个会话的模式真正决定可用能力，并与全局插件状态相协调。主 Agent 对可独立并行的复杂任务主动考虑派发子智能体，简单任务可直接完成，展示与执行均来自真实子运行。

当前 `ComposerScopeBar.tsx` 调用 `/api/plugins/preset` 修改全局文件，`bundle/web` 装配可选插件后 Agent 直接读取全部工具；当前会话没有模式字段。子智能体工具虽已注册，主 Agent 提示未给协作决策指引，且子智能体 write 模式当前使用 full 权限。不能仅移动按钮或仅增加提示来宣称完成。

参考本机 `E:/lfaa1/deepseek-harness`：其插件清单区分全局与 Agent 预设，新会话负责选择预设；子智能体委派有独立生命周期、结果及深度限制。LFAA 采用自身现有服务契约实现，不复制其内部目录或逻辑。

## 模式与插件契约

1. 创建会话时将选中的模式及其经过校验的能力组合存入会话记录；重启恢复同一模式。旧会话无该字段时保持既有行为并标明兼容状态，不静默推断曾经使用过的模式。
2. 用户在无消息、无运行的草稿或空会话中选择；服务端在同一会话锁内处理选择及首条消息写入，之后拒绝修改。直接调用 API、重复提交和并发首条消息也不能绕过锁定。
3. 模式是会话级组合，全局负责安装、启用和提供能力；会话仅可使用全局可用能力的交集。通过工具来源归属、会话级工具视图同时限制模型可见 schema 与实际执行；全局插件变化导致能力不可用时明确提示，不静默替换模式或越权执行。
4. 逐项核验现有标准、极简、创造、PTC 的实际能力与说明。现有 PTC 描述缺少对应实现时显示不可用及原因，不伪造程序化调用能力；其他模式仅展示真实差异。会话锁定后入口显示当前模式和原因，提示新建会话可更换。

## 子智能体

- 复杂任务存在独立调研、实现或验证时，主 Agent 优先考虑并行派发，交代明确目标、权限和交付；等待真实完成结果并汇总。简单任务或缺少独立分工时直接处理，不强制制造子智能体。工具不可用或失败时如实反馈。
- 为子任务建立可追踪的父会话与运行关联，展示实际启动、状态、步骤、结果、停止与失败；不把模拟状态当作真实运行。沿用并发与递归深度限制，主任务取消时明确处理子任务生命周期。
- 子智能体不能因 `invoke_subagent` 的 read 权限绕过父会话授权：默认只读；写入/命令须继承父运行的审批、沙箱和项目根约束，不能把 write 自动提升为 full。对现有会话与运行中途的权限变化做好测试。

## 文件边界与顺序

1. `packages/core/session`、`packages/core/memory`、`packages/core/chat/src`、`packages/core/agent/src`：会话模式持久化、空会话选择及首条消息锁定、历史兼容与并发检查。
2. `packages/extension/plugins`、`packages/bundle/web`、`packages/core/tools`：公开模式及插件来源能力契约，按运行创建受限工具视图和实际调用校验。预设不再通过全局切换冒充会话切换。
3. `packages/core/subagent`、`packages/core/agent`：协作策略、父子生命周期与权限传递；`packages/core/chat/client`：移动选择器、锁定提示和真实子任务展示。
4. 同步受影响包的双语 README、测试与开发日志。保持已存在的轨迹界面和工作树未提交修改。

## 验证、风险和回滚

风险 A1；权限边界相关变更须特别审查，任何 A2 范围变动另行提交负责人批准。测试覆盖首条消息竞争与锁定、会话隔离及恢复、旧会话、全局插件停用、模型伪造受限工具调用、子任务审批/取消/失败，并用真实页面验证模式入口、深浅主题、移动端、子任务状态与实际 Provider。不能真实验证时注明。回滚只撤销该方案实施的差异，不覆盖用户现有会话或未提交文件；新增持久字段须保持向后兼容。

## 实施与验收

- 选择器位于输入框底部。Host 在创建、改选时解析预设并保存能力组合，与首条消息写入共用会话锁。极简模式只暴露读权限的基础工具，创造模式包含产物工作所需的插件，标准模式另含子智能体。PTC 在目录中标记未接入。旧会话采用兼容路径。
- 工具按实际注册情况和会话策略交集执行。Host 全局插件仍负责工作台功能，单个会话的模式只影响该会话内的 Agent 能力。
- 火山方舟 `ark-code-latest` 实际派发两项独立子任务、等待结果并汇总。另一次运行在子任务等待 Shell 审批时取消父任务，子任务停止。模型按任务判断是否适合委派。
- Codex 内置浏览器验证真实 SSE 正文输出、完成后历史活动、文件侧栏、轨迹定位、项目绑定与变更跳转、分栏拖动、细滚动条和深浅主题。详见开发日志 DEV-000248。
