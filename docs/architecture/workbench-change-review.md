# 右侧工作台与会话反馈

- 右栏使用现有工作台标签。文件、终端和变更各有入口并独占当前视图。用户主动打开文件树时可与源文件分栏。
- 输入框底部左侧以本轮成功的文件操作记录显示变更文件与增删行数。增删行数按已保存的操作累加，列表以路径去重。点击历史回复自己的变更入口会打开对应轮次。
- 本轮变更和工作区 Git 变更均按单栏文件列表呈现。点击文件时在该行下展开，点击当前行可收起。工作区差异按文件读取，右栏整体可拖动调整宽度。
- 主运行每轮模型调用使用稳定的活动行承载真实状态。正文保持流式显示，已完成的活动和子智能体的身份、工具工作、结果保存在父消息中。
- 会话用量使用模型返回的字段。上下文占用以最近请求的实际输入和对应窗口为准，缓存比例使用同时上报输入与缓存计数的请求。
- 目标或范围有足以影响实施的歧义时，主 Agent 可发出结构化问题并结束该轮；同批工具等待用户答复。答复作为下一条会话消息继续，问题随会话保存。
- 验收包括深浅主题、右栏拖拽、单栏文件展开、流式状态、子运行记录、模型用量与澄清恢复。
