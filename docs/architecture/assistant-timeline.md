# 助手回复过程

负责人已确认六张参考图所示的交互与验收条件，并明确要求开工。A1 范围限于现有聊天消息流、会话回看和工具详情，使用 LFAA 自有主题与工作区布局。

- 运行中，顶部显示实际模型或工具阶段和经过时间。用户可见的模型正文逐段流出，同轮真实活动跟在正文之后。活动组和单条操作均可展开。审批卡在需要确认时直接显示。
- 完成后，顶部用时控制整段过程的展开。最终答复和现有交付卡片保持可见。展开过程后，进度正文和工具轨迹按原顺序列在最终答复前。
- `@lfaa/agent` 在工具轮结束正文的位置记录 UTF-16 偏移。会话消息使用可选 `progressText` 保存偏移对应的正文前缀，`content` 仍是最终答复。可选 `runDurationMs` 记录实际运行用时。步骤中的可选模型阶段和命令详情沿用步骤事件、快照和会话持久化。结束事件携带已写回的助手消息。旧记录继续读取，缺失的历史片段无法还原。
- 实施涉及 Agent 循环与运行收尾、Memory 的消息和轨迹类型、Tools 的终端结果，以及 Chat 的流消费与回复组件。命令仍经现有授权路径，详情采用有长度上限的纯文本。适用的开发与更新日志同轮补齐。
- 先验证 Host 的偏移、真实工具及退出码、会话写回，再验证 Web 流、历史回看和两级展开。内置浏览器覆盖浅色和深色，并检查刷新后的历史与窄屏展示。回滚仅撤销本轮差异，新增的可选会话字段对旧版本读写无迁移要求。
- 验收时重启用户实际访问端口的本地 Host，并以新回复的结束事件和会话 API 核对正文。Vite 的前端热更新会更新展示，Host 的流式与持久化代码在重启后加载。
- 聊天视口在接近底部时跟随流式正文、工具和输入栏带来的高度变化。主动上滚阅读历史时保持当前位置，回到底部后继续跟随。聊天和左侧会话列表的滚动条为相邻的分隔手柄预留独立操作空间。

## 活动动效与文件变更联动

负责人要求实时展开执行过程、区分创建和编辑及命令反馈，并用现有右栏打开文件记录。运行中可独立展开或收起过程。活跃工具有局部渐变，状态和图标随实际事件切换，展开及右栏切换采用短缓动并尊重减少动态效果设置。

`@lfaa/tools` 内置写入和编辑工具在成功执行后返回真实操作类型、路径和有上限的前后片段。Agent 以可选 `fileChange` 保留这些数据，随步骤事件和会话恢复。聊天 Store 用会话、消息和步骤定位选中的文件，右栏沿用现有能力面板的挂载点。旧记录可以查看原有操作详情；有项目映射的相对路径可查看当前 Git 差异。

按工具记录、Host 持久化、聊天行与右栏联动、动效的顺序实现。验收覆盖实际写入、编辑、命令、查看右栏、刷新回看、双主题和减少动态效果。回滚仅撤销对应增量；新增步骤字段对旧会话可选。

负责人补充右栏以文件标签页呈现。点击文件默认打开带行号的只读源文件，选择同一个文件复用标签并定位本次变更，标签可切换、关闭。工具栏切换本次更改与当前文件，聊天仍在工作区。读取 API 通过会话、助手消息和成功步骤定位路径，再用当前工作区授权校验，不接受浏览器提供任意文件路径。文件源文本按大小限制，超出范围或读取失败时明确提示，已保存的更改仍可切换查看。

## 工具实时进度

收到 Provider 的工具名增量时，沿用步骤事件发布准备状态。只有完整调用通过参数校验及现有审批后才进入真实执行。浏览器在同一活动组中原位更新状态，完成后按操作类型显示结果，可继续展开或打开变更文件。验收用分段的真实 SSE 请求覆盖准备、执行、会话回看和双主题。未提供工具增量的 Provider 从收到完整调用开始报告状态。

相邻工具轮之间没有新的用户可见正文时，步骤继续追加到已展开的活动组。运行中的命令摘要显示实际命令，完成后的详情保留输出及退出码。

第一轮尚无工具时，也可展开实时状态。15 秒无模型增量显示等待。Host 每个模型轮限制 45 秒静默、180 秒总时长及连续 64,000 字符的纯推理，工具参数增量计入进展。停止时保留此前已产生的可见消息和工具记录，并向客户端返回原因。
