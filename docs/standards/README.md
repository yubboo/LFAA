# 开发规范索引

这里放**当前有效规范**。

常用入口：

| 范围 | 文件 |
|---|---|
| 命名 | `NAMING.md` |
| 开发日志 | `DEV_LOGS.md` |
| 模块边界 | `MODULE_BOUNDARIES.md` |
| 导入路径 | `IMPORT_PATHS.md` |
| 安全 | `SECURITY.md` |
| 质量门禁 | `QUALITY_GATES.md` |
| 性能 | `PERFORMANCE.md` |
| 项目资源 | `PROJECT_RESOURCES.md` |
| 工作区同步 | `WORKSPACE_SYNC.md` |
| 版本 | `VERSIONING.md` |
| 打包 | `PACKAGING.md` |

规范文件名属于稳定工具接口，因此保持短英文；正文必须中文清晰。
