# 设置中心界面规范（强制）

> 状态：已实施（2026-11-24 负责人确认）。
> 适用：`settings:*` 与 `appearance` 视图，以及后续新增的任何设置页。
> 共享实现：`packages/ui/primitives/client/settings/`（`SettingsControls.tsx`、`SettingSelect.tsx`、`SettingsSurface.module.css`）。

设置页不是"功能页"，是**配置清单**。用户来这里是为了快速找到一项目前值并改掉，不是为了阅读排版作品。因此统一成一套可预测的行式结构，任何页面不得自创卡片、自创控件样式。

## 1. 一项设置占一行

- **一行一项**：名称在左，控件在右，右边缘对齐。禁止把两个不相关的设置挤进同一行。
- 名称下方可以有一句说明（ muted、单行优先）。说明是补充，不是正文；超过两行说明该设置该拆页。
- 控件形态按取值决定，不按页面喜好决定：

| 取值类型 | 控件 |
|---|---|
| 布尔 | 开关（改即生效，不配"保存"按钮） |
| 短枚举（≤ 4 项且文案短） | 分段选择 |
| 长枚举 / 需带说明 / 可搜索 | 下拉菜单（`SettingSelect`） |
| 路径 | 右侧显示截断路径 + 「更改」按钮 |
| 数值 / 短文本 | 行内输入框 |
| 会跳走的操作 | 按钮 |

## 2. 去掉最外层那层框

- **禁止**给分组加外边框、底色、圆角、阴影；页面不再套一层卡片。
- 分组之间靠**标题 + 留白**区分，不靠描边。
- 页面背景就是设置中心背景，内容和背景之间没有中间层。
- 唯一允许的分隔线是组内行与行之间的 1px 细线，且只用于"列表感"，不得回退成描边框。
- **弹窗内浮层的层级必须写在令牌层**：设置中心是覆盖工作台的弹窗（`--z-dialog`），而弹窗里的下拉菜单 Portal 到 `body`，必须用高于弹窗的 `--z-popover`。菜单层要是落在弹窗下面，触发器看着正常、选项却点不到，整页设置会表现成"所有控件都失灵"（DEV-000455）。新增 Portal 浮层一律选 `@lfaa/ui-theme` 的层级令牌，不写死数字。

## 3. 多分组、加标题、组间松组内紧

- 一页拆成若干分组，每组必须有标题；分组顺序按 **常用 → 少见 → 危险**。
- 组间留白必须显著大于组内留白（建议组间 ≈ 2rem，组内行距 ≈ 0.6rem，约 4 倍差）。
- 组内行与行贴紧，保证一屏能看到尽可能多的当前值。

### 尺寸基线

- 设置窗口：`min(76rem, 100%)` 宽 × `min(52rem, 100%)` 高，左目录 `14.5rem`；窗口比一般弹窗更大，设置项不需要靠滚动逐条找。
- 内容列：行式页 `min(100% - 3rem, 56rem)`；卡片网格类页面（如模型提供商）用 `SettingsPage size="wide"` 放宽到 `min(100% - 2.5rem, 62rem)`，让卡片多排一列。
- 卡片网格是"选择器"而不是设置分组，不受第 2 条约束（模型提供商、主题预设这类一眼比较的选项就该是卡片）。

### 主题类选择器的实时预览

- 选择"外观形态"（主题、配色、字体档）时，页面顶部放一块**实时预览**：用真实配色渲染的迷你界面，不是静态截图。
- 悬停/聚焦缩略图只驱动预览面板，**不写回真实配置**；点击（或回车）才应用。移开鼠标立即回到当前主题。
- 颜色切换走 `transition`（建议 240–280ms），不整块淡入淡出；`prefers-reduced-motion` 下关闭过渡。
- 预览与缩略图必须是同一个组件（`ThemePreview` / `ThemeGallery`），避免"缩略图和预览长得不一样"。

## 4. 删除与危险操作单独放

- 删除、清空、重置、迁移覆盖等破坏性操作**不得**混在普通设置行里。
- 单独成组放在页面最末，标题用危险色，与普通设置之间留出额外间距。
- 行内只允许出现「危险动作按钮」，不得在普通行里塞删除图标。

## 5. 表单不照搬行式布局

顺序填写、需要一次提交的表单（存储位置与迁移、模型接入、规则与记忆编辑）**不套用"左名称右控件"**：

- 上下排：标签在上，控件在下，占满可用宽度。
- 多字段纵向排列，同屏不出现左右分栏。
- 提交/取消按钮固定在表单底部，不跟随每一行。
- 表单里切回行式布局的唯一情况是"字段本身就是一次开关"。

## 6. 目录只列已接入页面

- 未接入的条目**不占目录位**，不显示"功能不可用"占位。
- 目录按用户心智分组（个人 / 集成 / 编码），与页面内部分组无关。
- 新增设置页 = 注册视图 + 目录登记 + 本规范自检，三件事同一轮完成。

## 7. 状态记忆（强制）

- 设置中心的打开状态与**当前子页**必须持久化；F5、强制刷新后回到同一子页，不得把用户踢回工作区。
- 设置中心作为弹窗时，必须记住打开前的视图与项目上下文，关闭后回到原处。
- 记忆键统一走 `packages/ui/layout/client/shell/ui-preferences.ts`，不得在组件里散写 `localStorage`。

## 8. 交付自检

1. 一屏内每行只有一项设置，控件右对齐。
2. 页面里搜不到分组级 `border` / `background` 卡片样式。
3. 组间留白 ≈ 组内留白 4 倍。
4. 破坏性操作在最后一组且用危险色。
5. 表单页是上下排，不是左右两栏。
6. 在设置里按 F5，仍停在同一个子页。
7. 深浅色主题、窄屏（≤ 760px）各看一遍。
