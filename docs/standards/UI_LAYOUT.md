# LFAA 工作台 UI 规范

> 本规范定义 Web / Desktop 共用工作台壳层的当前有效布局要求。

## 1. 总体结构

```text
左侧导航 / 会话
│
├── 可拉伸分隔条
│
中间工作区
│
├── 可拉伸分隔条
│
右侧工具 / 资源面板
```

中央工作区始终是主区域。

## 2. 视觉语言

采用 Codex / ChatGPT 类生产力工具的中性视觉语言：

```text
白
黑
中性灰
细边框
轻阴影
高可读文字
圆角控制在克制范围
```

必须同时支持浅色和深色。

禁止：

- 水墨 / 宣纸 / 山水纹理；
- 松绿 / 朱砂作为主主题色；
- 高饱和霓虹；
- 大面积装饰性渐变；
- 装饰遮挡可交互区域。

状态可以使用少量语义色，例如连接成功、刷新和错误。

## 3. 左右栏尺寸

默认：

```text
左栏：288px
最小：240px
最大：640px

右栏：360px
最小：300px
最大：760px
```

桌面模式不能只使用静态最大值。

拖动时还必须根据：

```text
窗口宽度
另一侧当前宽度
中央最小宽度
分隔条宽度
```

计算当前允许的动态最大值。

中央区目标最小可用宽度：

```text
约 520px
```

## 4. 吸附与拖动

侧栏的 `min` 同时是自动吸附边界。

当前规则：

```text
Pointer Down
→ Pointer Move 使用 requestAnimationFrame 合并
→ max 到 min 之间正常跟随
→ 一到 min 立即自动吸附为 0 / collapsed 预览
→ 不等待 Pointer Up
→ Pointer Up 只提交最终状态
```

禁止再使用独立的：

```text
96px snapThreshold
```

因为这会导致侧栏在已经低于可用最小宽度后，还继续拖一段距离才收起，和目标交互不一致。

为了避免指针停在 `min` 附近时反复开合，反向展开采用迟滞：

```text
reopen = min + 24px
```

自动吸附动画：

```text
约 150ms - 180ms
```

拖动期间不得每帧通过 React setState 重绘整棵工作台。

## 5. 输入方式

必须支持：

- Pointer 拉伸；
- 双击分隔条收起 / 展开；
- Enter 切换；
- Home 收起；
- 方向键调宽；
- Shift + 方向键加速调整。

## 6. 中间工作区

必须使用：

```css
min-width: 0;
overflow: hidden;
```

内部区域自行滚动，禁止整页水平滚动。

## 7. 响应式

- `> 1120px`：标准三栏；
- `<= 1120px`：右栏浮层；
- `<= 820px`：左右栏都浮层；
- 中央工作区始终保持可操作。

## 8. 本地状态

可以在浏览器 `localStorage` 保存：

- 左栏宽度；
- 右栏宽度；
- 左栏收起状态；
- 右栏收起状态；
- 浅色 / 深色主题偏好。

这些只属于 UI 本地状态，不是业务事实源。

## 9. 本地热插拔测试

Vite 开发桥接只读监听：

```text
.lfaa/skills
.lfaa/experts
.lfaa/plugins
.lfaa/extensions
.lfaa/mcp
```

只允许暴露资源类型、名称、相对路径、类型和更新时间；禁止暴露正文、Secret、Token 或项目外绝对路径。
