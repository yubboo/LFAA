# LFAA 工作台 UI 规范

> 本规范定义 Web / Desktop 共用工作台壳层的当前有效布局要求。

## 1. 总体结构

桌面端与 Web 端共用三栏工作台：

```text
左侧导航 / 会话
│
├── 可拉伸分隔条
│
中间工作区
│
├── 可拉伸分隔条
│
右侧资源 / Agent / Tool 面板
```

中间工作区永远是主区域，左右栏不得挤坏中央布局。

## 2. 左右栏

必须支持：

- 鼠标自由拉伸；
- 键盘调整宽度；
- 双击分隔条收起 / 展开；
- 拖到吸附阈值自动收起；
- 记住本地宽度与收起状态；
- 窄窗口不产生横向页面溢出。

默认预算：

```text
左栏：280px，范围 220px - 520px
右栏：320px，范围 260px - 560px
吸附收起阈值：128px
```

## 3. 中间工作区

必须使用：

```css
min-width: 0;
overflow: hidden;
```

内部滚动由工作区自己管理，禁止让整个页面因为侧栏宽度产生水平滚动。

## 4. 响应式

- `> 1080px`：标准三栏；
- `<= 1080px`：右栏以浮层方式打开；
- `<= 820px`：左右栏都以浮层方式打开；
- 中央工作区始终保持可操作。

## 5. 水墨视觉

视觉关键词：

```text
宣纸
墨色
留白
山水晕染
松绿
朱砂点缀
克制阴影
```

禁止：

- 高饱和霓虹；
- 大面积纯黑；
- 复杂拟物纹理影响文字清晰度；
- 装饰遮挡可交互区域。

## 6. 性能预算

侧栏拖动：

- 每帧最多提交一次宽度更新；
- 使用 `requestAnimationFrame` 合并 Pointer Move；
- 目标 60 FPS；
- 不允许拖动过程中触发整页布局错位。

收起 / 展开动画：

```text
180ms - 220ms
```

## 7. 本地热插拔测试

Vite 开发服务器允许提供只读开发桥接：

```text
.lfaa/skills
.lfaa/experts
.lfaa/plugins
.lfaa/extensions
.lfaa/mcp
```

开发桥接只允许暴露：

- 资源类型；
- 名称；
- 项目相对路径；
- 文件类型；
- 更新时间。

禁止把资源正文、Secret、Token 或项目外路径暴露给浏览器。
