# LFAA 工作台 UI 规范

## 1. 总体结构

桌面工作区：

```text
┌────────左侧栏────────┬─┬────────中间工作区────────┬─┬────右侧栏────┐
│                      │ │                           │ │              │
│                      │ │                           │ │              │
│                      │ │                           │ │              │
│                      │ ├───────────────────────────┴─┴──────────────┤
│                      │ │                真实终端                    │
└──────────────────────┴─┴───────────────────────────────────────────┘
```

关键：

- 左侧栏全高；
- Terminal Dock 只从左侧栏右边开始；
- Terminal Dock 横跨中间 + 右侧；
- 右侧栏位于 Terminal Dock 上方。

## 2. 视觉语言

参考 ChatGPT / Codex 类桌面生产力工具：

- 黑 / 白 / 中性灰；
- 细边框；
- 低对比背景层级；
- 克制圆角；
- 浅色 / 深色；
- 不使用水墨 / 宣纸 / 装饰性纹理。

## 3. 侧栏尺寸

```text
左栏 默认 288px / min 240 / max 640
右栏 默认 360px / min 300 / max 760
中央区目标最小宽度约 520px
```

动态最大值必须考虑另一侧栏与中央最小宽度。

## 4. 侧栏拖拽与吸附

```text
Pointer Move
→ requestAnimationFrame
→ max 到 min 正常跟随
→ 到 min 立即自动吸附 0
→ 不等待 Pointer Up
```

反向重新展开：

```text
min + 24px
```

分隔条：

- 只允许拖拽；
- 不叠加点击按钮；
- 不承担 Hover 展开按钮。

## 5. 侧栏 Hover 控制

控制按钮属于侧栏本身。

### 左侧栏

- 鼠标进入左栏 → 收起按钮淡入；
- 鼠标离开 → 淡出；
- 左栏已收起 → 左屏幕边缘热点淡显重新展开按钮。

### 右侧栏

- 鼠标进入右栏 → 终端按钮 / 收起按钮淡入；
- 鼠标离开 → 淡出；
- 右栏已收起 → 右屏幕边缘热点淡显重新展开按钮。

禁止把这组控件放在中间工作区顶部。

## 6. 真实 Terminal Dock

Terminal Dock 必须是可交互终端，不是日志卡片。

Web 本地开发实现：

```text
xterm.js
+ FitAddon
+ node-pty
```

行为：

- 位于最底部；
- 可拖动顶部边界改变高度；
- 可从右栏“终端”入口开合；
- 终端关闭后 PTY 会话可以在组件存活期间保留；
- 页面 / Vite 关闭时回收 PTY。

## 7. 安全

Web PTY 仅开发模式：

- Vite 绑定 `127.0.0.1`；
- PTY cwd 为项目根；
- 不自动提升权限；
- 不提供 Agent 自动执行通道；
- 正式 Agent Terminal 必须走 Tool Runtime → Policy → Permission → Rust PTY Broker。

## 8. 响应式

- `>1120px` 标准三栏 + 底部 Terminal Dock；
- `<=1120px` 右栏浮层；
- `<=820px` 左右栏浮层，Terminal Dock 作为底部层；
- 禁止整页水平滚动。
