
## 6. Runtime Home

源码不保存机器状态。

默认目录：

```text
Windows  %LOCALAPPDATA%\LFAA
macOS    ~/Library/Application Support/LFAA
Linux    $XDG_DATA_HOME/lfaa 或 ~/.local/share/lfaa
```

`LFAA_HOME` 可覆盖。

典型子目录：

```text
state/
plugins/
cache/
tmp/
logs/
```

旧 `<project>/.lfaa/state` 只允许迁移，不是新的项目资源 namespace。
