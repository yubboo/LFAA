# LFAA Minecraft 中文提示词库

本目录用于维护 Minecraft 应用的领域提示词。提示词负责约束 Agent 的理解、规划、工具选择、验证和汇报方式，不替代 Minecraft 业务服务、权限系统、Daemon Runner 或沙盒实现。

## 当前能力基线

以下提示词严格按当前 LFAA 文档中的已接入能力编写：

- 本机 Windows x64 Daemon。
- Minecraft Java Edition。
- 官方 Vanilla 服务端。
- 官方 Minecraft 版本目录与服务端工件。
- Java 环境扫描、手动 Java 路径登记、Temurin JRE 安装/卸载；旧版本无 JRE 时可回退同主版本 JDK ZIP。
- 管理员可创建实例、选择匹配 Java、启动/停止实例、查看状态和日志。
- 受支持的 `server.properties` 白名单字段修改。
- 停止中的世界安全备份。
- Minecraft 任务、日志、节点和实例状态的真实后端数据与 Socket.IO 变更通知。
- Windows AppContainer + Job Object 的实例级沙盒启动路径。

当前**不能把以下能力写成已经实现**：远程 Daemon、Linux/macOS Minecraft Runner、Bedrock、Paper/Spigot/Purpur、Fabric/Forge/NeoForge、插件/Mod 管理、交互式 PTY、完整资源监控、复杂升级迁移、世界备份恢复。

## 共同原则

1. 用户表达目标，Agent 负责分析并选择当前真实可用的工具，不把工作重新甩给用户。
2. 所有状态只相信 server/daemon 的真实结果、任务状态、日志和能力上报，不使用演示值，不猜测成功。
3. Minecraft EULA 必须单独展示并由用户明确同意；任何 AI 权限模式都不能代替 EULA 同意。
4. Minecraft 业务动作必须走现有 Minecraft 服务和 Daemon Runner；不得用 Shell 绕过业务校验、实例路径约束、配置白名单或沙盒边界。
5. AppContainer、ACL、Job Object、路径规范化或 Sandbox Host 任一关键步骤失败时必须 fail-closed，不得退回普通 `java.exe` 直接启动。
6. 已领取任务在 Daemon 中断或租约过期后不得自动重放；先重新核对真实节点与实例状态。
7. 运行中的 Minecraft 实例不得通过通用文件管理直接改实例文件。需要修改时先走 Minecraft 配置能力或按业务流程停服。
8. 当前 Minecraft Runner 不支持的生态必须明确说明“当前未接入”，不能伪造工具、任务或成功结果。

## 目录

- `开服提示词/`：部署、Java、EULA、实例生命周期、节点与沙盒、任务恢复、日志诊断、备份和未支持生态路由。
- `改文件提示词/`：实例配置读取与修改、`server.properties`、运行中实例保护、路径安全、差异验证和修改失败诊断。
