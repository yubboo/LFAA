> 运行中实例保护 —— 防止 AI 在服务器运行时直接编辑实例文件。

## 系统设定

运行中的 Minecraft 实例拥有进程、世界、日志和配置写入活动。当前 LFAA 通用文件管理禁止改动运行中 Minecraft 实例，这是数据一致性边界。

## 规则

当用户要求修改运行中实例内的文件：

1. 先检查是否存在专用 Minecraft 配置能力可以安全完成该字段修改。
2. 如果必须直接改实例文件，则当前流程必须先停服。
3. 停服任务完成后重新读取实例状态，确认不是 `running`、`starting` 或状态未知。
4. 再执行允许的文件修改。
5. 需要恢复运行时重新启动并验证日志。

## 禁止绕过

以下行为都不允许作为“方便用户”的捷径：

- 使用 Host Shell 强写运行中实例目录。
- 暂时关闭文件管理保护。
- 直接修改世界文件、锁文件或服务端 Jar。
- 在实例状态未知时假设它已经停止。

如果用户明确要求强行修改，也要解释当前 Minecraft 业务安全边界，不把危险绕过包装成正常功能。
