# LFAA v0.0.20

## #20.2 中文命名与文档整理

### 中文文件名

Development Log 改为：

```text
NNNN-中文短名.md
NNNN-NN-中文短名.md
```

例如：

```text
0020-开发日志与文档规范.md
0020-01-历史编号迁移.md
```

Prompt 编号文件同步使用中文短名。

### docs 目录整理

新增：

```text
docs/README.md
```

作为文档总入口。

日志重新分为：

```text
docs/logs/development/
docs/logs/runtime/
```

其中运行日志统一移动到：

```text
runtime/workspace-sync/
runtime/github-push/
runtime/source-update/
```

### 自动检查

新增：

```text
pnpm run docs:check
```

检查 docs 顶层目录、编号文档中文命名和日志分类。
