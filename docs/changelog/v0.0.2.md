# LFAA v0.0.2

## #3 导入路径与 Alias 优化

### 问题

随着 LFAA Monorepo 扩大，如果继续使用：

```text
../../../
../../../../
```

会导致：

- 路径难读；
- 目录重构引发大面积修改；
- AI 难以判断模块边界；
- 容易跨 Package 直接访问内部实现。

### 方案

定义三层导入：

```text
./
@/
@lfaa/*
```

其中：

- `./`：同目录 / 同小模块；
- `@/`：当前 workspace 的 `src/`；
- `@lfaa/*`：真实 pnpm workspace package。

同时：

- `../../` 及以上禁止；
- `@lfaa/package/src/internal/*` 禁止；
- 新增自动检查脚本；
- TS workspace 增加本地 tsconfig Alias。
