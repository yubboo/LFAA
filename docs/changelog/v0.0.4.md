# LFAA v0.0.4

## #5 同步日志目录优化

### 问题

`.lfaa-local/sync-logs/` 属于隐藏开发目录，不符合 LFAA “文档和开发留痕按 docs 分类可发现”的治理原则。

### 方案

改为：

```text
docs/logs/workspace-sync/
```

实际运行日志：

```text
*.log
```

作为本机开发留痕：

- 不参与版本镜像 diff；
- 不被同步删除；
- 默认不提交 GitHub。

目录说明 `README.md` 仍属于正式项目文档。
