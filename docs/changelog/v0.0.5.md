# LFAA v0.0.5

## #6 GitHub 一键推送脚本修复

### 问题

首次初始化 Git 时，控制台显示 Git 帮助页：

```text
usage: git ...
```

而不是执行：

```text
git init
```

### 根因

PowerShell 函数使用 `$Args` 作为参数名，与 PowerShell 自动变量冲突。

### 修复

改为：

```text
Invoke-Git -GitArgs @("init")
```

并按同步脚本设计标准重构整个 GitHub Push 流程。

### 新流程

```text
治理检查
→ 检测 .git
→ 首次自动 git init
→ 检查 Git Identity
→ 检查 origin
→ 实际 Git 文件变化检测
→ 彩色 ADD/MOD/DEL/REN 列表
→ git add -A
→ staged 文件列表
→ 用户自定义 Commit 名称
→ Commit 确认
→ pull --rebase（如远程已有 main）
→ Push 确认
→ git push
→ 本地 Push 日志
```
