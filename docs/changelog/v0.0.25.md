# LFAA v0.0.25

## #19.4 Rust 安装诊断优化

### 路径检测

新增 `CARGO_HOME/bin`，支持自定义 Rust/Cargo 安装目录。

### WinGet

`-1978335189 / 0x8A15002B` 现在解释为：

```text
未发现可适用更新
```

WinGet 返回后会重新检测 rustup/Cargo，再决定是否走官方安装器。

### Rust 官方输出

Rust 官方：

```text
info: ...
```

日志继续保留英文原文。

LFAA 在前面明确说明该英文属于官方 rustup 输出。

### 安全

官方 rustup-init 仍然：

```text
static.rust-lang.org
+ 官方 .sha256
+ 本地 SHA-256 校验
```
