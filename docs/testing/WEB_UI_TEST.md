# Web 工作台本地测试

## 前置

```text
Node 24.x
pnpm 11.17.0
```

## 启动

```text
LFAA-Setup.bat
→ 2 启动 Web
```

浏览器：

```text
http://127.0.0.1:5173
```

## 主题测试

1. 默认跟随当前系统偏好初始化；
2. 点击左下角主题按钮，浅色 / 深色切换；
3. 刷新浏览器，确认主题偏好保留；
4. 浅色只使用白 / 浅灰 / 深色文字；
5. 深色只使用黑灰 / 深灰 / 浅色文字；
6. 不应再出现宣纸、山水、水墨、朱砂等元素。

## Layout 测试

1. 左栏从默认宽度向外拖到最大，确认不会无限扩张；
2. 右栏从默认宽度向外拖到最大，确认不会无限扩张；
3. 两侧都展开时，中央区仍保持可操作宽度；
4. 把左栏拖到 96px 左右并松开，确认平滑吸附收起；
5. 把右栏拖到 96px 左右并松开，确认平滑吸附收起；
6. 拖动过程中不得跨阈值突然闪烁 / 跳变；
7. 双击分隔条，确认收起 / 展开；
8. 使用键盘方向键调整宽度；
9. 刷新浏览器，确认宽度和收起状态保留；
10. 缩小窗口，确认右栏 / 左栏按规则切换为浮层；
11. 页面不得产生整页横向滚动。

## 热插拔测试

在以下目录新增或删除一个文件夹：

```text
.lfaa/skills/
.lfaa/plugins/
.lfaa/mcp/
```

右侧资源区应自动刷新，无需手工刷新页面。

## 安全检查

浏览器 Network 中 `/__lfaa/dev/resources` 只允许出现：

- kind
- name
- relativePath
- entryType
- updatedAt

不得出现文件正文、Secret、Token 或绝对路径。
