# Web 工作台本地测试

## 前置

```text
Node 24.x
pnpm 11.17.0
```

## 启动

```text
LFAA-Setup.bat
→ 2 启动 Web
```

浏览器：

```text
http://127.0.0.1:5173
```

## 主题测试

1. 默认跟随当前系统偏好初始化；
2. 点击左下角主题按钮，浅色 / 深色切换；
3. 刷新浏览器，确认主题偏好保留；
4. 浅色只使用白 / 浅灰 / 深色文字；
5. 深色只使用黑灰 / 深灰 / 浅色文字；
6. 不应再出现宣纸、山水、水墨、朱砂等元素。

## Layout 测试

1. 左栏从默认宽度向外拖到最大，确认不会无限扩张；
2. 右栏从默认宽度向外拖到最大，确认不会无限扩张；
3. 两侧都展开时，中央区仍保持可操作宽度；
4. 左栏向内拖，一到 240px，确认无需松手就自动吸附收起；
5. 保持 Pointer 按下并反向拖回，超过约 264px 后重新展开，且 min 附近不反复闪动；
6. 右栏向内拖，一到 300px，确认无需松手就自动吸附收起；
7. 保持 Pointer 按下并反向拖回，超过约 324px 后重新展开；
8. 双击分隔条，确认收起 / 展开；
9. 使用键盘方向键调整宽度；
10. 刷新浏览器，确认宽度和收起状态保留；
11. 缩小窗口，确认右栏 / 左栏按规则切换为浮层；
12. 页面不得产生整页横向滚动。

## 热插拔测试

在以下目录新增或删除一个文件夹：

```text
.lfaa/skills/
.lfaa/plugins/
.lfaa/mcp/
```

右侧资源区应自动刷新，无需手工刷新页面。

## 安全检查

浏览器 Network 中 `/__lfaa/dev/resources` 只允许出现：

- kind
- name
- relativePath
- entryType
- updatedAt

不得出现文件正文、Secret、Token 或绝对路径。


## 端口复用测试

1. 首次 `LFAA-Setup.bat → 2`，默认应使用 `5173`；
2. 保持 Vite 运行，再次执行菜单 2，应识别已有 LFAA Web 并复用，不报端口冲突；
3. 若 5173 被其他程序占用，应自动切到 5174-5199 的首个空闲端口；
4. Setup 不允许自动结束未知占用进程。


## Setup 启动与返回菜单

### Web 快速启动

1. 确认 5173 空闲；
2. `LFAA-Setup.bat → 2`；
3. 菜单选择后应立即出现 Web 端口检测/启动提示；
4. 不应出现十几秒空白等待；
5. 不应自动执行依赖安装。

### 已运行复用

1. 保持 LFAA Vite 运行；
2. 再次运行菜单 2；
3. 应快速识别并复用现有地址。

### 端口冲突

1. 使用其他程序占用 5173；
2. 运行菜单 2；
3. 应快速选择 5174 或下一空闲端口；
4. 不结束未知程序。

### 返回主菜单

- Web 按 `Ctrl+C` 停止后，应返回 Setup 主菜单；
- 环境检查、构建、治理检查等完成后，应返回主菜单；
- 普通错误后，应返回主菜单；
- 只有选择 `0` 才退出终端。


## 三栏交互与终端停靠

### 分隔条行为

- 左右分隔条只能拖拽调宽；
- 分隔条中间不再出现点击按钮；
- 拖拽到最小宽度时立即吸附；
- 反向拖回超过迟滞阈值时重新展开。

### 顶部控制

- 鼠标移入顶部区域，左上 / 右上控制按钮淡入显示；
- 鼠标移出后按钮淡出隐藏；
- 左上可收起 / 展开左栏；
- 右上可收起 / 展开右栏；
- 右上可收起 / 展开终端。

### 终端停靠

- 中间底部默认可见终端停靠区；
- 点击右上终端按钮可开合；
- 点击右栏“终端”按钮也可开合；
- 终端停靠区不会挤坏顶部对话区。


## 真实终端测试

首次同步 v0.0.32 后先执行：

```text
LFAA-Setup.bat → 1
```

以安装 `@xterm/xterm`、`@xterm/addon-fit`、`node-pty` 并同步 lockfile。

然后：

```text
LFAA-Setup.bat → 2
```

验收：

1. 底部真正出现终端 Dock；
2. 能看到真实 PowerShell Prompt；
3. 输入 `pwd` 或 PowerShell 等价的目录命令后得到真实输出；
4. 输入普通项目命令能真实执行；
5. 调整底部高度时 xterm 自动 fit；
6. 关闭 / 展开终端布局平滑；
7. 左栏保持全高；
8. 右栏位于终端上方；
9. 左 / 右侧栏 Hover 时自身控制淡入；
10. 中间顶部不再出现错误的侧栏 Hover 控件。

注意：

- 这是本地开发 PTY；
- 不要用它验证 Agent 权限链；
- Agent 自动执行 Shell 仍属于未来 Rust PTY Broker 范围。
