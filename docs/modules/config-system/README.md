# config-system

## 作用

LFAA 第一个正式业务模块。

负责：

- 通用 Settings；
- 模型管理；
- Provider Account 管理；
- Permission 默认设置；
- 配置持久化；
- 配置 UI；
- 配置 Schema / Migration；
- Secret reference，不保存 Secret 明文。

## 不负责

- Agent Loop；
- Tool 执行；
- Knowledge；
- MCP；
- Plugin Marketplace；
- Coding Agent。
