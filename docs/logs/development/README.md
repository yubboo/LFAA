# 开发日志

这里保存 LFAA 的**开发决策、需求变化、方案修正和当前结论**。

## 先看哪里

任何开发前先看：

```text
INDEX.md
```

再根据关键词打开：

```text
active/
```

只有需要追溯历史时才进入：

```text
archive/
```

## 目录职责

```text
active/
→ 当前仍然有效的记录

archive/
→ 已被后续变更替代的历史记录
```

开发日志不是机器运行日志。

机器运行日志仍然分别放在：

```text
docs/logs/workspace-sync/
docs/logs/github-push/
docs/logs/source-update/
```

完整规则：

```text
docs/standards/DEV_LOGS.md
```
