# 开发日志

这里保存 LFAA 的**需求变化、设计决策、架构调整和规则修正**。

## 阅读顺序

```text
INDEX.md
→ active/
→ 需要对比时再看 archive/
```

## 当前日志命名

```text
NNNN-中文短名.md
```

例如：

```text
0002-配置系统.md
0020-开发日志与文档规范.md
```

## 历史变更命名

```text
NNNN-NN-中文短名.md
```

例如：

```text
0020-00-开发日志初始分层.md
0020-01-历史编号迁移.md
```

显示编号仍写：

```text
#20.0
#20.1
```

## 注意

运行脚本产生的 `.log` 不放这里，统一放：

```text
docs/logs/runtime/
```
