## 当前结论

`LFAA-Setup.bat` 是 Windows 本地开发的统一入口。

根目录不再单独保留：

```text
LFAA-Web.bat
```

统一菜单：

```text
1  一键依赖
2  启动 Web
3  启动桌面
4  构建 Web
5  构建桌面
6  构建发布
7  环境检查
8  项目资源
9  治理检查
10 完整检查
```

Web / Desktop 是否可执行必须检查真实 workspace script；未实现时明确失败，不得假成功。

## 最新变更

- 删除 `scripts/windows/lfaa-web.ps1`；
