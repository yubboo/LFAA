## 当前结论

LFAA 文档和源码必须同时做到**可追溯**和**人类可读**。

当前规则分成两层：

```text
文档层
→ 稳定 docs 目录
→ 中文可读编号文件
→ Active / Archive 分离
→ INDEX 可追溯

源码层
→ 关键实现文件结构化中文文件头
→ CSS 盒子 / 区域分区注释
→ 一级目录 README
→ 项目结构与代码地图
→ comment-check 自动门禁
```

第一次打开项目时的人类导航入口：

```text
docs/项目结构与代码地图.md
```

详细规范：

```text
docs/standards/COMMENTS.md
docs/standards/DEV_LOGS.md
docs/standards/NAMING.md
```
