## 当前结论

Web 工作台仍通过 Vite 做本地热插拔验证，但启动入口统一为：

```text
LFAA-Setup.bat
→ 2 启动 Web
```

不再维护独立 `LFAA-Web.bat`。

UI 继续保持：

```text
左侧菜单 | 中间工作区 | 右侧资源舱
```

左右栏支持自由拉伸、吸附收起和本地宽度记忆。
