## 当前结论

LFAA 文档采用“**稳定目录 + 中文可读文件名 + 明确索引**”的规则。

### 开发日志

当前日志：

```text
NNNN-中文短名.md
```

历史变更：

```text
NNNN-NN-中文短名.md
```

示例：

```text
0020-开发日志与文档规范.md
0020-00-开发日志初始分层.md
0020-01-历史编号迁移.md
```

显示编号仍使用：

```text
#20
#20.1
#20.2
```

文件名不再使用 `0020.1-dev-logs.md` 这种不直观形式。

### docs 目录

`docs/` 顶层目录保留短英文名称，作为稳定工具路径；文档内容与人类可读文件名中文优先。

开发者进入 `docs/` 后先读：

```text
docs/README.md
```
