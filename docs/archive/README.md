# Archives

[简体中文](README.zh.md) · [Documentation](../README.md)

Archives preserve original evidence. They do not establish current capabilities, active contracts or operational authorization. See [architecture](../系统总体架构.md), [active contracts](../PROMPTS.md) and the [current plan](../开发计划.md).

- `audits/`: migration, cleanup, delivery, P0, Minecraft and previous Settings snapshots. Historical physical paths in JSON inventories remain evidence.
- `contracts/01.md` through `09.md`: 171 earlier contracts, retaining IDs and explicit anchors, linked from the main contract index.
- `plans/`: the complete development plan before this reorganization, retaining business acceptance records and unfinished requirements.

Original verification results and languages are preserved. Existing unfinished desktop-update contracts remain on the active contract page to protect ongoing work.
