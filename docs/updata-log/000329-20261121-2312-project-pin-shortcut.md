# 000329｜「置顶」改成快捷入口：项目不再从「项目」列表里消失

- 时间：2026-11-21 23:12 +0800。负责人反馈右键「···」→「置顶」后，项目从「项目」分组被搬走，「项目」里只剩一句「所有项目均已置顶」，以为项目没了；希望置顶是「常用的放到最上面方便找」，项目本身仍然存在。
- 现在：置顶只是顶部「置顶」区的**快捷入口**。同一个项目会同时出现在「置顶」和原来的「项目」列表（若它属于某个自定义分区，也继续留在那个分区），两处点开的是同一个项目，不会复制数据。
- 图钉标记：留在「项目」/自定义分区里的置顶行，名称右侧带一个小图钉，提示它也在顶部置顶区，避免看起来像重复项。
- 取消置顶：仍通过项目行「···」菜单的「取消置顶」或悬停信息卡上的图钉；把项目拖回「项目」分组不再顺带取消置顶（此前会造成「拖一下项目就掉出置顶」的误解）。
- 空态文案：「所有项目均已置顶。」改为「项目都归入自定义分区了。」，只在「项目」分组确实没有可显示项目时出现。
- 验证：真实 5173 宿主 + 无头 Edge，深色与浅色各一轮，走「悬停 → ··· → 置顶」真实交互：置顶后 `置顶` 与 `项目` 两个分组同时存在该项目行，只有「项目」侧带图钉，页面无新增控制台错误；测试用临时项目已在同一轮删除。
- 页面刷新（Ctrl+F5）后生效；本轮只改前端分组与样式，宿主无需重启。
