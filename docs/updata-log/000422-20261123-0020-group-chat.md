# 000422｜新增群聊入口：多个 agent 在同一个会话里依次发言

- 时间：2026-11-23 00:00–00:20（Asia/Shanghai）。
- 新功能：左一图标栏现在有 **首页（单聊）→ 群聊 → Agents** 三个入口。
- 群聊页：左侧是群列表（可新建群，选两位以上 agent 与一个代理人），右侧是群聊窗口——每条回复都带**说话人名字与所用模型**，流式生成时显示小圆点；发送后自动刷新到本轮结束。
- 怎么指定谁说话：点成员 chip 就是 @（顺序即发言顺序）。**不 @ 时由代理人回答**（默认小鱼）。@ 了不在群里的人会被忽略。
- 一回合内最多 3 位成员发言（可在会话配置里调整），每位成员步数上限 12，避免一个群聊回合烧光额度。
- 共享上下文：所有成员看到同一份会话历史，能看到彼此说过的话；用户消息只落一次，不会每人重复一遍。
- 当前限制（下一步）：还没有「代理人先出计划再派人」的智能调度——不 @ 就是代理人自己答；回合折叠、按 agent 分账、群内禁用子任务也在后续阶段。
- 验证：真实本机 Edge 自动验收 **13/13**（新增群聊页空态与新建入口），控制台 0 错误；全量 682 项测试、类型检查、Lint、构建全部通过。
