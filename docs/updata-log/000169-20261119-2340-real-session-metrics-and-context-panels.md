# 000169｜会话统计浮层：上下文、Token、模型与工具耗时

2026-11-19 23:40 +08:00

- 输入框下方状态栏现在可以点开三个浮层：
  - **上下文**：已用百分比与进度条，并拆分系统提示词、工具定义、对话消息的估算 token。
  - **Token**：总计、缓存命中率、未缓存输入、缓存读取、输出。
  - **会话统计**：轮次与工具步数、模型用时、工具调用用时、平均首 token 延迟（TTFT）、输出速度（TPS）。
- 这些数字来自真实运行过程：模型轮次与工具执行的耗时、首 token 时间、输出 token、缓存 token 与上下文构成都会随消息保存，不是前端写死的。
- 模型配置新增「上下文窗口（tokens，可选）」：填写后显示上下文占比；留空则只显示估算用量，不伪造比例。
- 旧消息没有采集指标时不会显示对应项；上下文 token 为 4 字符/token 的估算值。
