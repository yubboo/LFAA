# 000332｜引用图片贴右对齐：不再跑到左侧，竖图也没有左右留白

- 时间：2026-11-22 00:34 +0800。负责人反馈引用图那条用户消息里图片跑到左边、右侧空了一大截，要求右侧对齐。
- 原因：带图消息的宽度由下方长描述胶囊撑开，图片本身是块级元素默认左对齐；竖图又用 `width:100% + max-height + object-fit:contain`，在元素框里留出左右空边。
- 修复：媒体气泡改成右对齐的纵向布局（图片与胶囊都贴右）；竖图改为按高度定尺（20rem 高、宽度自适应），不再出现左右留白。
- 实测：图片右边缘 = 胶囊右边缘 = 气泡右边缘（同一 x=1125），图片 180×320 且宽高比与原图 1152×2048 完全一致（0.563），控制台无新增错误。
- 需要刷新页面（Ctrl+F5）；只改样式，无需重启宿主。
