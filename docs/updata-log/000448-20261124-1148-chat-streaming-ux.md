## 用户能看到的变化
- **欢迎页与起步建议统一收轻**：项目内与项目外的空会话起步建议、消息底部追问建议统一采用无边框轻量图标行，统一中心区宽度轴，去掉厚重卡片边框、粉色圆圈编号、「推荐」强标签与右箭头；左二栏选中态改为干净克制的中性浅底高亮。
- **AI 回复正文 Markdown 排版净化**：取消将普通章节标题与列表劫持为粉色卡片选项的逻辑，正文标题、有序/无序列表、表格、引用块与代码块全面回归清晰优雅的文档阅读排版。
- **思维链与工具链全程可视化**：
  - 按真实执行顺序交错呈现「思维链块（脑形图标 + 思考中… / 已思考 · 耗时 + 左侧柔和竖线引导与微斜体思考正文）→ 过程说明 → 工具链列表（动态适配各类内置/自定义工具的图标、动作/工具名、目标参数、耗时与完成确认动效）→ 最终答复」。
  - 思维链与工具链默认全程展开；点击某轮「已思考」标题可一次性同步收起/展开该轮的思考正文、过程说明与全部关联工具行（收起后标题行提示 `· N 步工具`）；展开工具结果支持最多 8,000 字符的独立滚动代码框（超长明确提示截断与总字数）。
  - 系统提示新增语言一致性约束：中文提问时思考过程与过程说明全程保持中文。
- **会话进行中去噪与任务自动结算**：
  - 会话已有消息后，底部输入框不再重复显示当前项目胶囊。
  - 一轮回复正常交付后自动结算残留的 `in_progress` 任务条目，不再出现「已完成但任务卡永久转圈进行中」的问题。
- **流式流畅度与全项目性能显著提升**：
  - 消除流式输出期间触发四栏工作台全树重渲染、右栏高频同步读盘（`localStorage`）、历史消息与顶栏陪跑重绘、滚动锚点同步回流抖动以及后端每 180ms 全量写盘阻塞；流式增量改用约 32ms 帧合并节流，Markdown 正文采用块级缓存，自动滚底单帧合并更顺滑。
