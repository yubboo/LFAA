# UPDATE-000343｜输入框上方新增任务清单卡片，活动行显示真实进度

- 时间（含时区）：2026-11-22 00:56 +0800
- 类型：新增 / 优化
- 关联开发日志：`../dev-log/000201-000400.md`（DEV-000343）

## 用户能看到的变化

- 输入框上方新增「任务清单」卡片：标题 + `已完成 / 进行中 / 待处理` 计数 + 每条任务一个状态点（完成=绿点、进行中=强调色、待处理=灰点），可点击折叠；清单为空时不占位。
- 任务清单来自会话步骤，刷新页面或重新打开历史会话都能还原，不依赖浏览器内存。
- 活动行里的任务清单不再只写「已完成：更新任务清单」，而是「已更新任务清单（完成 2 / 共 5）」；进行中显示「正在更新任务清单」。
- 超过 12 条时只显示前 12 条并提示「还有 N 条」，长任务不会把输入区顶出屏幕。

## 影响范围与使用提示

- 影响 `@lfaa/chat`（客户端展示）与 `@lfaa/agent`（步骤里带上清单快照）、`@lfaa/session`（`AgentStepTrace.todos`）。旧会话步骤没有该字段，按「没有清单」处理，不需要迁移。
- 该卡片只出现在「对话」视图的输入框上方；「轨迹」视图与右侧面板没有同步展示，按本轮约定后续再议。

## 已知限制

- 极简模式不装配任务清单工具，因此不会出现卡片。
- 卡片只在有清单时出现；全部完成后仍保留，直到下一次运行写入新清单。
- 同一轮里被折叠的长任务只显示前 12 条，暂时没有「展开全部」入口。
