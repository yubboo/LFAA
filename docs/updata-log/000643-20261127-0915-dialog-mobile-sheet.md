# UPDATE-000643｜手机端弹窗改成贴底弹层

- 时间：2026-11-27 09:15（Asia/Shanghai）
- 类型：优化（窄屏交互）+ 规范（新增弹窗规范）
- 关联开发日志：`../dev-log/000601-000800.md`（DEV-000643）

## 变化

- 手机/窄屏（≤767px）下，弹窗不再浮在屏幕中间：改成从底部滑出的整宽弹层，顶部圆角、贴住屏幕底部，底部按机型安全区留白。
- 覆盖两类弹窗：删除 / 移出 / 卸载这类确认弹窗，以及重命名、设置表单这类普通弹窗。
- 确认弹窗在窄屏下「取消 / 确认」变成等宽大按钮，方便拇指点按；桌面布局完全不变。
- 弹出弹层时背后的页面不再跟着滚动。
- 弹窗规则写进开发规范：[弹窗规范](../standards/dialogs.md)（桌面居中几何、手机贴底规则、确认弹窗只能按钮关闭、交付自检）。

## 怎么验证

手机尺寸打开任一会话 → `⋮` → 永久删除：弹层从底部出现、整宽、上圆角；桌面上同一弹窗仍在屏幕中央。

## 已知限制

- 暂不支持下滑手势关闭，也没有拖拽把柄。
- 少数操作用的还是浏览器原生 confirm，不受这次样式影响。
