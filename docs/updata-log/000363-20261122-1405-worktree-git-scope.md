# UPDATE-000363｜工作树会话里的「变更」现在看的是工作树目录

- 时间：2026-11-22 14:05 +0800（Asia/Shanghai）
- 类型：Bug 修复 / 体验一致性

## 你会看到什么

- 在绑定了工作树的聊天里打开右栏「变更」或顶栏 Git 摘要，状态、差异、暂存、提交、分支切换都以该会话的工作树目录为准。
- 主项目目录的 Git 状态不再被工作树改动污染；在普通聊天里仍然看项目主目录。
- 未跟踪文件点开也能直接看到新增内容，不再显示空白差异。

## 兼容性

- 未绑定工作树的聊天行为不变。
- 工作树目录失效时仍沿用现有提示，不会回退到项目主目录。

## 说明

- 右栏文件树、文件预览、媒体输出目录和完整代码审查页仍在下一阶段切换到工作树，本轮只覆盖 Git 审查与工作树文件读取接口。
