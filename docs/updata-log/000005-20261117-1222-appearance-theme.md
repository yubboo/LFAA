# UPDATE-000005｜工作区外观设置

- 时间（含时区）：2026-11-17 12:22:53 +08:00
- 类型：新增与界面调整
- 关联开发日志：`../dev-log/000005-20261117-1222-appearance-theme.md`

## 用户能看到的变化

- 工作区采用截图中的三栏结构：左侧图标入口、二级菜单、中央主工作区。
- 从左侧设置入口打开“外观”，可选择浅色、深色或跟随系统。
- 选择会即时生效，并保存在当前浏览器中；再次打开页面时会恢复上次选择。
- 当前“跟随系统”按设备的浅色/深色设置自动呈现。

## 影响范围与使用提示

- Windows 可运行 `lfaa.bat` 选择 `2`，或运行 `pnpm lfaa web` 打开工作区。
- 本地预览地址：`http://127.0.0.1:5173/`。

## 已知限制

- 当前没有聊天、Agent、会话、文件等业务能力；该轮只交付工作区骨架和外观设置。
- 主题选择按浏览器配置保存，不在浏览器配置间同步。
- 当前项目首版三栏决策已记录于 `docs/architecture/overview.md`；通用规范 §3.3 的四栏方案暂不应用于此首版。
