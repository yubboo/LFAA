# UPDATE-000571｜点文件后右栏不再多出一个「新标签页」

- 日期：2026-11-26（Asia/Shanghai）
- 之前右栏展开着空态时会在最右侧自动补一个「新标签页」；用户从左二文件树点开文件后，这个占位标签仍留在文件标签旁边，看起来像自己没点「+」却凭空多了一个标签。
- 现在只要切到文件、变更审查、终端/侧边提问、子智能体等真实内容标签，空态占位就会自动收起，右栏只剩用户真正打开的那个标签。
- 「新标签页」仍只在右栏空着时出现：不点任何文件、只展开右栏时照旧有一个空白标签；刷新后也不会把上次的空白标签恢复出来。
- 自己按「+」新建的空白标签不受影响，不会被自动关掉。
