# UPDATE-000577｜多 Agent 任务流水线：研究 → 撰写 → 核对，按依赖接力干活

- 日期：2026-11-26（Asia/Shanghai）
- 之前多智能体只能由父 Agent 并行派发，各自回报；没法声明"A 的结论必须交给 B 继续做"，中间也没有验收。
- 新增 `run_crew` 工具：给一个目标和最多 6 个任务，每个任务写清「怎么做」和「交付什么」，支持声明依赖，按顺序接力执行。
- 上游任务的交付先过结构验收（最小长度、JSON 可解析、必须包含的字段），通过后才作为下游任务的输入；不通过会带原因重试一次，仍失败则该任务失败、依赖它的任务跳过，不会假装成功。
- 每个任务在右侧工作台有独立标签，标签名就是任务名，可以看到各自在做什么。
- 执行结束后，整条流水线的结论会汇总成一条团队记忆，运行过程的临时记忆会被清理，不污染长期记忆库。
- 任务目前是只读的：调研、撰写、核对这类工作直接可用；要改文件的产物仍由主 Agent 或你自己落盘。
- 标准模式下开箱可用；插件中心可看到「任务流水线」这一项。
