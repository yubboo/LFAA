# UPDATE-000634｜图片预览默认约占屏幕七成，四周留白

- 时间：2026-11-26 21:46（Asia/Shanghai）
- 类型：fix（图片预览默认尺寸）

## 变化

- 预览不再铺满整屏：图片默认约占屏幕七成，左右与上下都留出明显边距，工具条独立在图片上方。
- 大图按七成缩小、小图按七成放大；仍可点「适应」回到七成、点「1:1」看原始像素，或用「− / +」继续缩放。
- 窄屏（≤768px）没有七成宽的余量，改为占满宽度、高度留出工具条位置。
- 放大清晰度沿用上一版：显示比例超过原图 1.5 倍时像素化渲染，轻微放大保持平滑。

## 怎么验证

点开输入区图片：应只占屏幕约七成、四周留白；点「1:1」回到原始像素，点「适应」或比例数字回到七成；窄屏下图片占满宽度但不贴边。
