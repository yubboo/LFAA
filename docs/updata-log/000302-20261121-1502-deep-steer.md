# 立即插话不再打断生成：新问题会并入当前这轮

- 日期：2026-11-21 15:02 +08:00。
- 设置「后续消息处理方式」选「引导（Steer）」时，运行中发送的新消息现在会**追加到当前这轮对话**，在下一轮模型调用前生效，当前生成不会被打断；排队模式仍然是等这轮结束后依次发送。
- `Ctrl/Cmd+Enter` 在有排队消息时依然表示「把全部排队消息作为插话发出」，现在同样不打断当前运行。
- 实测：长任务运行中发送补充要求 → 接口返回成功、运行继续、回复包含补充要求的总结；控制台无错误。
- 限制：会话历史里这条补充消息暂时显示在助手回复之后（生成上下文是正确的），后续会优化展示顺序。
