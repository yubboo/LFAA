# UPDATE-000357｜项目范围锚定：项目简介与项目内会话防跑偏

- 时间：2026-11-22 10:35 +0800（Asia/Shanghai）
- 类型：新功能 / 体验优化

## 你会看到什么

- 创建或编辑项目时新增「项目简介」：选好文件夹后自动读取 README、package.json 与顶层结构生成初稿，可修改；创建时留空也会自动补一份。
- 项目详情页与右栏项目详情显示项目简介；未填写时给出明确提示。
- 在项目里新开会话，空态出现「本项目专注」卡片，列出项目名与简介，并说明本会话只处理本项目相关任务。
- 绑定项目的会话运行时，AI 会拿到项目名与简介。遇到明显跑偏的请求，会先说明「这看起来不属于本项目范围」，再询问是继续还是改用项目外聊天或新建项目；确认前不会先做无关的文件修改或生成。

## 兼容性

- 旧项目没有简介时按「未填写」处理，不迁移、不报错；新会话里 AI 会先与你确认项目目标。
- 简介保存在本机 `~/.lfaa/projects.json` 的项目记录中，不写入项目文件夹。

## 验收

- 新建项目自动生成简介；编辑后项目内新会话的范围卡片与系统提示同步更新。
- 深色/浅色主题下卡片、输入区与右栏文字对比度正常，浏览器控制台无新增报错。
