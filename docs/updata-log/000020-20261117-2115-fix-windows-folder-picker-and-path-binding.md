# UPDATE-000020｜修复“添加”选文件夹失效问题并支持直接输入路径绑定（如 `G:\app`）

- 时间（含时区）：2026-11-17 21:15:30 +08:00
- 类型：修复与优化
- 关联开发日志：`../dev-log/000020-20261117-2115-fix-windows-folder-picker-and-path-binding.md`

## 用户能看到的变化

- **升级 Windows 原生文件夹选择器**：将“本机 → 添加”的底层实现从兼容异常的旧式树形框升级为现代 Windows 10/11 资源管理器弹窗（`IFileOpenDialog` 选目录模式，屏幕居中置顶显示），修复了之前位置偏移屏幕外及属性报错的问题。
- **支持直接在弹窗输入路径绑定（如 `G:\app`）**：在“在此电脑上添加文件夹 → 添加”下方新增紧凑路径输入框，可直接粘贴或输入本地目录路径（例如 `G:\app`）点击 **“绑定”**（或直接点“创建项目”），系统会实时校验磁盘目录并自动回填项目名，再经 **“信任此文件夹吗？”** 确认后打开该目录工作区。
- **隔离桌面清晰提示不卡死**：当本地开发服务运行在受限/沙箱隔离桌面（例如由后台代理工具拉起的预览进程）时，点击“添加”会立即提示原因并引导在下方直接输入路径，或在自己打开的本地终端执行 `pnpm lfaa web` 启用完整原生弹窗，不再静默无响应。

## 影响范围与使用提示

- 影响 `packages/workspace/workspace` 与 `apps/web`；已在 `http://127.0.0.1:5173/` 使用真实目录 `G:\app` 完成桌面端（`1440×900`）与移动端（`390×844`）全链路验收。

## 已知限制

- 后台代理沙箱拉起的服务处于隔离 Windows 桌面环境，若要直接测试点击 **“添加”** 在当前屏幕弹出系统资源管理器，请在自己电脑的常规终端窗口运行 `pnpm lfaa web`；直接在右侧内置预览页中使用下方路径框输入 `G:\app` 可立即完成绑定和工作区打开。
