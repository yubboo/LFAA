# UPDATE-000347｜任务清单支持「展开全部」，轨迹视图也能看到当前清单

- 时间（含时区）：2026-11-22 03:00 +0800
- 类型：优化
- 关联开发日志：`../dev-log/000201-000400.md`（DEV-000347）

## 用户能看到的变化

- 任务清单超过 12 条时，底部从「还有 N 条」提示改为可点的「展开全部 N 条」；点开后显示全部条目，按钮变成「收起多余条目」。
- 「轨迹」视图顶部也会显示同一张任务卡（默认收起，只留状态摘要），切到轨迹时仍能看到整体进度；「对话」视图保持展开状态，且两者不会同时出现两张卡片。

## 影响范围与使用提示

- 影响 `@lfaa/chat` 客户端：`TodoDock` 新增 `defaultCollapsed` 与展开全部逻辑，`ConversationTrace` 复用同一组件与 `latestSessionTodos` 数据源。
- 展开/收起是当前会话内的临时交互状态，刷新后回到默认（对话展开、轨迹收起）。

## 已知限制

- 「展开全部」只展开条目列表，不会自动滚动到卡片位置。
- 轨迹视图的搜索只匹配轨迹行，不搜索任务清单内容。
