# UPDATE-000625｜新会话出现和退出加了平滑过渡

- 时间：2026-11-26 20:29（Asia/Shanghai）
- 类型：fix（交互过渡）

## 变化

- 点「新聊天」后，新会话行不再瞬间出现：它会从 0 高度展开、淡入，并轻微上移到位。
- 切到历史会话时，新会话行不再瞬间消失：它先在原位收起高度、淡出，再从列表移除，后面的会话行跟着平滑上移。
- 退场中的行不可点击、不进入读屏焦点；系统开启「减少动态效果」时直接到最终状态，不做动画。

## 怎么验证

点项目里的「在新项目里开新聊天」：新会话行应展开出现；点任意历史会话：新会话行应在原位收窄、淡出后再消失。前后切换时后面的会话行应跟着移动，而不是整块跳一下。
