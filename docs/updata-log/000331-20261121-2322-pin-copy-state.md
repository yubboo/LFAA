# 000331｜修复「点一个，两处一起亮」：置顶副本只跟随你实际点的那一行

- 时间：2026-11-21 23:22 +0800。负责人反馈：在「项目」里点一条聊天，「置顶」里同一个聊天也跟着高亮；悬停项目行时两边的 `···` / `✎` 也会一起冒出来，问是不是应该「点哪个就变哪个」。
- 现在：置顶只是同一批项目的快捷入口，两处是同一个项目/会话的副本；选中高亮**只落在你实际点击的那一行**，另一处的副本保持普通样式。
- 悬停同理：`···` 与 `✎` 只在鼠标所在的那一行显示，不会两边同时亮；打开「···」菜单时也只让被点的那一行保持动作可见。
- 刷新页面后仍只高亮一处（默认落在顶部「置顶」的副本），不会出现两处同时选中。
- 页面刷新（Ctrl+F5）后生效；本轮只改前端交互状态，宿主无需重启。
