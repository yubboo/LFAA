# UPDATE-000648｜插件中心只装扩展插件，内置插件的运行状态改由设置中心呈现

- 时间：2026-11-27 09:55（Asia/Shanghai）
- 类型：优化（界面分工）+ 架构（装配方式）
- 关联开发日志：`../dev-log/000601-000800.md`（DEV-000648）

## 变化

- 侧栏「插件中心」只剩「已安装的插件」和「添加插件」：内置插件那 31 张卡、预设切换都移走了，这里专门用来安装 npm 包、Git 仓库或本地目录里的扩展插件。
- 设置中心「内置插件」里的 38 个插件，有 37 个改成了 Cordis Loader 条目：卡片展开后看到的「运行状态」现在是真实 Fiber 状态（运行中 / 等待依赖 / 启动失败），不再是一律的「已装配」。
- 其余 1 个（沙箱）仍随应用静态装配，卡片照常显示「已装配」。

## 怎么验证

打开侧栏「插件」：只有已安装列表与「添加插件」。打开设置 → 集成 → 内置插件：38 个插件都在，点开任意一张能看完整包名、来源、配置状态与运行状态。

## 已知限制

- 沙箱策略仍随应用静态装配、不能停用：它的包默认导出会在根沙箱之外再挂一个本地沙箱，需要拆成两个入口。
- 插件中心目前没有内容时是空态，属预期。
