# Updata Log 000040 — 左右菜单栏支持拖拽调宽与半阈值吸附收起

- **时间**：2026-11-18 00:34:24 +08:00
- **版本号/编号**：000040

## 本次新增与优化

1. **左右侧边栏左键拖拽拉伸调宽**：
   - 在桌面端左二菜单栏右边缘与右侧上下文面板左边缘新增隐形拖拽分割条（悬停与拖拽时亮起柔和强调色指示线）。
   - 支持自由拉伸宽度（`220px` ~ `440px`），自动为中央工作区保留至少 `360px` 可用宽度，自定义宽度会持久化保存并在刷新后恢复。
2. **低于最小宽度一半（`< 110px`）自动吸附收起，且支持未松手拉回重开**：
   - 当按住鼠标左键向内拖拽超过“最小宽度一半（110px）”时，侧边栏即时吸附收起为 `0px`，把空间让给中央工作区。
   - **未松开左键前**反向向外拉回阈值以上，面板会顺滑地原地重新拉开；**一旦在吸附状态松开左键**，侧边栏即确认收起并移除拖拽边界手柄，此时无法再通过拖拽边框展开，只能点击顶部对应的「展开左二菜单栏」或「展开右侧菜单栏」按钮重新打开。
3. **键盘无障碍调宽支持**：
   - 聚焦分割条后可使用方向键微调左右面板宽度。
