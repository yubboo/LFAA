# UPDATE-000521｜关闭最后一个标签收起右栏，启动页居中自适应

- 日期：2026-11-25（Asia/Shanghai）
- 关闭右栏的最后一个标签（浏览器、文件或审查）时，右栏不再停在空启动页或「工作台」，而是直接收起整个右侧菜单栏；如果同时还有其它标签，则保持右栏打开。
- 右栏「快速打开」启动页按 ChatGPT 空态重排：内容整体居中，搜索框改为白色胶囊（极淡描边 + 轻微投影），聚焦时不再出现粉色描边或外发光。
- 搜索框占位文案改为「搜索文件或输入 URL」。
- 四个快捷入口改成图标在上、文字在下的灰色卡片：窄栏两列、宽栏一行四个，块之间留出明显间距；悬停只做轻微底色变化和 1px 上浮，不加边框。
- 目录行与文件行现在共用同一个路径气泡组件：同样的磨砂胶囊、文件/文件夹图标、浮起动效，不再各写一套。
