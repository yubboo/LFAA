# UPDATE-000025｜移入整个项目行即显示悬浮信息卡片

- 时间（含时区）：2026-11-17 21:59:00 +08:00
- 类型：交互优化
- 关联开发日志：`../dev-log/000025-20261117-2158-hover-card-on-entire-project-row.md`

## 用户能看到的变化

- **整行悬停即触发悬浮卡片**：鼠标只要移入左二菜单栏某项目的整个圆角底色行（包括项目图标和项目名称，不再局限于右侧 `···` 按钮），右侧就会平滑弹出该项目的信息悬浮卡片。
- **保持点击抑制不打扰**：点击 `···` 打开或收起操作菜单后，只要鼠标仍在当前项目整行内部移动就不会重新弹出信息卡片；当鼠标移出该项目行后再重新移入，即可再次触发悬浮卡片。

## 影响范围与使用提示

- 影响 `packages/ui/layout` 与 `apps/web`；已在 `1440×900` 下完成整行移入、点击抑制及移出重入全链路实测。
