## 更新与修复

1. **自动识别项目位置与系统用户目录（无硬编码路径）**
   - 项目推荐目录会根据当前项目实际存放的根目录（或工作区当前绑定的项目目录）动态解析 `<项目根目录>\data`；默认用户位置会实时检测当前操作系统登录用户目录 `<用户目录>\.lfaa\data`。
   - 同时将项目根 `/data/` 加入 `.gitignore`，避免个人记忆与资产文件在代码推送时误提交。

2. **修复迁移操作状态回弹与断连提示**
   - 修复设置页输入自定义路径时单选状态可能被异步刷新重设回默认项的问题。
   - 若因后台 `pnpm lfaa web` 服务关闭导致请求失败，页面不再显示生硬英文 `Failed to fetch`，而是明确提示先确认终端服务已启动后再重试。
