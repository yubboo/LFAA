# UPDATA-000353｜会话全文搜索：标题 + 消息正文，命中片段高亮并定位消息

- 时间：2026-11-22 04:37 +0800。负责人选择「会话全文搜索」方向：侧栏搜索从只搜功能与项目扩展为可搜会话标题与消息正文，并支持跳转到命中消息。
- Host：新增纯函数 `searchSessionRecords`（标题/正文、大小写不敏感、片段带省略号、总 20 条/每会话 3 条并标记截断）与 `ChatService.searchSessions`；新增 `GET /api/chat/search?q=...`，含归档会话并返回 `{ results, truncated }`。
- 客户端：`WorkbenchChatProvider` 新增 `searchChat` 与 `openSessionMessage`；搜索弹层合并「会话与消息」「功能与项目」两组，支持方向键/Enter、命中词 `<mark>` 高亮、归档标记、200ms 防抖与搜索中/空结果状态。
- 定位消息：新增 `pendingMessageJump` 状态；聊天视图在会话加载后暂停触底跟随，滚动到 `chat-message-<id>` 并短暂描边高亮（3.2s），再消费请求；用户消息与助手消息都带稳定的消息锚点。
- 实测（独立 5174 宿主 + 无头 Edge）：搜索「海洋」返回 3 条（标题、消息、归档消息）；点击消息结果打开「帮我生成一张海洋图片」并把命中用户消息滚动到视口内（rect.top≈175），显示强调色描边；控制台无报错。截图：`%TEMP%\lfaa-pw\search\01-search-results.png`、`03-jump-visible.png`。
