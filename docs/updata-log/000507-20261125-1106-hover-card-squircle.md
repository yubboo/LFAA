# UPDATE-000507｜项目悬浮卡改用连续曲率圆角，入场更柔和

- 日期：2026-11-25（Asia/Shanghai）
- 项目行的悬浮详情卡不再“啪”地出现：出现时有 180ms 的轻微下移 + 缩放淡入，收尾使用缓出曲线，看起来更顺。
- 会话行的悬浮卡（标题/所属项目/更新时间）也同步使用相同动画与连续曲率圆角。

- 圆角改成连续曲率（squircle，方与圆的过渡），不再是普通圆弧；Chrome/Edge 139+ 生效，其他浏览器自动退回普通圆角；系统开启「减少动态效果」时自动关闭动画。
