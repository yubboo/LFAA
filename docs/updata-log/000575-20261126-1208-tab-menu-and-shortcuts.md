# UPDATE-000575｜右栏标签右键菜单 + 可自定义键盘快捷键

- 日期：2026-11-26（Asia/Shanghai）
- 右栏标签右键出现菜单：关闭 / 关闭其他标签页 / 关闭右侧标签页 / 关闭所有标签页；文件标签可复制路径，浏览器标签可复制网址，也能新建标签页。
- 关闭所有标签页后回到空态「新标签页」；关闭右侧按标签栏当前顺序计算。
- 设置中心新增「键盘快捷键」页（个人 → 键盘快捷键）：列出 18 个真实动作的当前键位，可搜索、点键位录制、Backspace 清除、恢复默认、全部恢复默认。
- 键位按本机保存：重复组合会被拦下并提示与哪个动作冲突；刷新后自定义键位仍在。
- 只登记真实功能：没接入的动作不会出现在列表里；右侧工作台收起时，标签类快捷键随标签栏一起暂不可用（页面底部有说明）。
- 默认键位示例：搜索 `Ctrl+K`、右栏开关 `Ctrl+Shift+B`、新聊天 `Ctrl+Alt+N`、打开终端 `Ctrl+Alt+T`、新建标签页 `Ctrl+Alt+B`、关闭当前标签 `Ctrl+Alt+W`。
## 补充（同日 12:30）

- 新增：`Ctrl+Shift+S` 显示/隐藏左二侧边栏、`Ctrl+/` 直达「键盘快捷键」页、`Ctrl+Shift+D` 语音听写、`Ctrl+Shift+R` 打开模型/推理强度浮窗。
- 「中止回复」默认键位改为 `Ctrl+D`（保留原来输入栏里的 `Ctrl+D` 习惯，同时改为可改键）；输入栏不再硬编码 `Ctrl+M` / `Ctrl+D`，提示键位从注册表读取。
- 「选择推理强度」没有沿用参考产品的 `Ctrl+Shift+M`：该组合已是右栏最大化的既定键位，两者不能同默；可在设置页自行改成 `Ctrl+Shift+M`，冲突会被拦下。
- 参考清单里的「显示智能伙伴（Alt+Win+P）」在本产品没有对应功能，未做占位快捷键。
- 补齐悬停气泡：左二收起/展开、右侧菜单栏开关与最大化、新建标签页、语音听写、模型/推理强度、用户菜单「设置」都带胶囊提示与快捷键徽章；气泡改为 portal 渲染并在顶栏自动落到下方，不再被窗口上沿裁掉。键位提示统一读注册表，改键后同步。
