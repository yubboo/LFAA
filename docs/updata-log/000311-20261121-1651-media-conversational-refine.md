# 生图模型下可以连续对话改图了（不再卡住）

- 日期：2026-11-21 16:51 +08:00。
- 选中生图模型后，不需要切回对话模型也能继续「聊」：每条消息都会作为生图/改图指令执行。生成完一张后，直接说「再亮一点」「改成水彩」「背景换成夜晚」会**基于上一张生成图继续修改**，不会重新随机生成。
- 图片附件也能作为参考图：把图片拖进输入框（或粘贴图片）后发「参考这张改风格」，会按附件图片做图生图。

- 实测：选中 wan2.7-image 发送「把上一张图改成水彩画风格，保留构图」→ 生成成功并在聊天内显示，控制台无错误。
- 说明：生图模式每条消息都会触发一次生成（按张计费）；想纯聊天/做规划时切回对话模型即可。
