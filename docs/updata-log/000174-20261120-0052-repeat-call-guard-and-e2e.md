# 000174｜重复工具调用提醒与真实运行验收

2026-11-20 00:52 +08:00

- Agent 现在会识别**连续相同工具调用**：同一工具、完全相同的参数连续出现第 3、5、8 次时，会插入一条建议性提醒（步骤里显示「检测到重复工具调用」），要求模型检查结果、换方法或结束任务。
  - 提醒只做建议，不阻断执行；
  - 参数会做键排序后比较，`{"a":1,"b":2}` 与 `{"b":2,"a":1}` 视为同一次调用；
  - 不同工具或不同参数会重置计数。
- 用本地 mock OpenAI 流式服务跑了一次真实 Agent 全链路（工具调用 → 结果 → 慢速流式回复），确认统计栏在运行结束前就会变化：
  - 运行中：`1.0k tok`（无轮次）；
  - 完成后：`2.9k tok · 1 轮 · 1 步`。
- 深色/浅色主题均验收通过。
