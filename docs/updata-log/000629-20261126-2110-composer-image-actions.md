# UPDATE-000629｜输入区图片可以撤销、放大，也能复制与另存为

- 时间：2026-11-26 21:10（Asia/Shanghai）
- 类型：fix（输入区图片交互补齐）

## 变化

- 粘贴或选择图片后，按 Ctrl+Z（macOS 为 ⌘Z）撤回刚插入的图片；如果之后改过草稿文字，Ctrl+Z 仍是原来的文字撤销。
- 点击图片缩略图放大查看，Esc、点击空白或关闭按钮退出；放大层工具条里可直接复制图片或另存为。
- 在缩略图上右键：查看大图、复制图片、另存为…、移除；浏览器自带的右键菜单不再盖住图片。
- 复制采用系统剪贴板，成功提示「图片已复制」；浏览器不支持时提示改用另存为。
- 另存为按附件原名保存，缺扩展名时按图片类型补全。

## 怎么验证

在输入框粘贴一张图片：缩略图出现 → 按 Ctrl+Z 应消失。再粘一张：点击缩略图应放大，工具条可复制/另存为；右键缩略图应出现「查看大图 / 复制图片 / 另存为… / 移除」。
