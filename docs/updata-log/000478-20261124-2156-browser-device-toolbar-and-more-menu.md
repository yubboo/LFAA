# UPDATE-000478｜内置浏览器工具栏重构：Codex 风格三点菜单、自由响应式设备工具栏与零黑边铺满

- 时间（含时区）：2026-11-24T21:56:00+08:00
- 类型：功能新增
- 关联开发日志：`../dev-log/000401-000600.md`（DEV-000478）

## 用户能看到的变化

- **工具栏大幅精简**：顶部地址栏右侧只保留「接管」与「`...` 更多菜单」，把设备工具栏开关、电脑铺满显示、控制台与网络、附带页面到对话、新窗口打开全部整齐收纳进 `...` 浮层菜单。
- **Codex 风格响应式设备工具栏**：从 `...` 菜单打开「设备工具栏（响应式）」后，在地址栏下方展开完整设备调试栏：
  - 支持 13 种常见设备下拉预设（`响应式`、`4K`、`Laptop L`、`笔记本电脑`、`Surface Pro 7`、`iPad Air`、`iPad Mini`、`Surface Duo`、`iPhone 15 Pro Max`、`Pixel 8`、`iPhone 15 Pro`、`Samsung Galaxy S24 Ultra`、`iPhone SE`）。
  - 支持自由输入任意像素宽高（`320–2560 × 240–2400`）、一键旋转横竖屏、实时显示缩放百分比（如 `89%`），点右侧 `×` 立即关闭回到铺满显示。
- **默认铺满右侧浏览器视口（零上下黑边）**：关闭设备工具栏时，内置浏览器严格铺满整个右侧视口，绝不出现上下黑边留空。
- **Agent 可自主切换响应式设备**：新增 `browser_set_viewport` 内置浏览器工具，小鱼 Agent 与浏览器子智能体在响应式开发/验收任务中可自主切换不同设备预设或自定义像素尺寸。
