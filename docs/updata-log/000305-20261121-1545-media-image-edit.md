# 生图支持「参考图」：按你给的图片改风格、改内容

- 日期：2026-11-21 15:45 +08:00。
- 现在可以让 Agent 用一张参考图做图生图：`generate_image` 新增 `referenceImages`，传本地图片路径或公网 URL（最多 3 张），例如「把这张图改成水彩画风格」「把参考图换成夜景」。
- 本地图片会自动转成 base64 传给百炼编辑接口，不需要你手动上传；生成结果同样保存到 `.lfaa-media/images` 并在聊天内预览。
- 实测：用项目里的海边日落图 + 水彩风格 → `wan2.7-image` 约 9 秒生成 2048×2048 水彩版并在聊天内显示。
