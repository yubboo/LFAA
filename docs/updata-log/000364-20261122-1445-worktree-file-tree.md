# UPDATE-000364｜工作树会话的文件树、预览与媒体目录

- 时间：2026-11-22 14:45 +0800（Asia/Shanghai）
- 类型：新功能 / 体验一致性

## 你会看到什么

- 在绑定了工作树的聊天里打开右栏「文件」：文件树显示工作树目录，主目录独有的文件不会混进来；工作树独有的文件可以直接打开预览。
- 文件预览、面包屑同级文件、右栏输入路径打开文件，都按工作树目录解析。
- 该聊天里生成图片/视频时，产物写入工作树目录；资料库读取也覆盖工作树里的素材。
- 文件树不再显示工作树的 `.git` 条目。

## 兼容性

- 不绑定工作树的聊天仍按项目主目录显示文件。
- 工作树失效时沿用既有提示，不回退项目主目录。
