# UPDATE-000570｜设置中心可以管理长期记忆了：筛选、编辑、统计与单独删除

- 日期：2026-11-26（Asia/Shanghai）
- 之前「模型与规则 → 长期记忆库」只有新增输入框和一整片删除按钮，记忆一多就找不到，也没法改错。
- 现在记忆按行列出，显示类型、作用域、命中次数、来源与更新时间；顶部有生效 / 已替代 / 已归档统计。
- 支持按类型筛选、按关键词搜索（内容与标签都匹配）；点「编辑」可改正文和类型，保存后列表即时更新。
- 新增记忆时可选择类型（偏好 / 事实 / 决策 / 踩坑 / 约定），不再只能存成事实。
- 删除移到页面最末的「删除记忆」危险分组：先选一条、再点删除，不再和正常操作混在一起。
- 说明：列表一次最多显示 50 条，更多时请用搜索或类型筛选；来源目前只显示会话 ID 前 8 位，还不能点击跳回会话。
