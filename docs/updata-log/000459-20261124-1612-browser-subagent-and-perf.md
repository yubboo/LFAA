# UPDATA-000459｜专属浏览器子智能体、思维链实时浏览器状态卡片与底层性能根治

- 时间：2026-11-24 16:12 +08:00
- 关联开发日志：`docs/dev-log/000401-000600.md`（`DEV-000459`）

## 本次变更

1. **专属「浏览器子智能体」强制分流与视觉自检修复**
   - 新增 `mode: "browser"` 专属浏览器子智能体；当会话启用子智能体（标准模式默认启用）时，主 Agent 自动隐藏原始 `browser_*` 工具并统一通过 `invoke_subagent(mode="browser")` 召唤独立浏览器验收子智能体操作右侧浏览器，确保每次浏览与验收都隔离上下文并在思维链呈现「正在使用内置浏览器 · 思考中 / 步骤列表」卡片。
   - 彻底修复 `browser_visual_check` 在推理型多模态模型（如 `deepseek-v4.1-flash`）下因 `maxTokens: 900` 被思考过程耗尽而返回空描述、导致小鱼“看不见页面 Bug 也不会自己修复”的根因（透传 `profileId`、提升至 `maxTokens: 4096` + `reasoningEffort: "low"` + 兼容 `reasoningContent`，并强化 `VERDICT: PASS / NEEDS_FIX` 缺陷排查闭环）。
2. **彻底根治内置浏览器剩余 2 项底层性能瓶颈**
   - **原生直连空闲自动防空跑**：前端原生 `<iframe>` 吃 GPU 加速渲染时，后台无头浏览器若超过 2.5 秒无 Agent 工具调用且无推流订阅，自动暂停重复动画渲染并降低 CPU 占用，下次 Agent 调用工具前瞬间恢复，杜绝前后端双开 60fps 动画吃资源。
   - **兜底画布零主线程循环解码**：移除被 `X-Frame-Options` 拦截站点走画布兜底时的前端主线程同步 `for` 循环逐字节 Base64 解码，改用原生异步图像解码，显著降低主线程卡顿。
