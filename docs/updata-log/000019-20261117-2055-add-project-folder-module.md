# UPDATE-000019｜新增“添加项目与本地目录工作区”功能

- 时间（含时区）：2026-11-17 20:56:00 +08:00
- 类型：新增功能
- 关联开发日志：`../dev-log/000019-20261117-2055-add-project-folder-module.md`

## 用户能看到的变化

- **无项目空状态快速入口**：左二导航栏“项目”分组现在默认展开；当还没有任何项目时，列表下直接显示可点击的 **`+ 创建新项目`** 按钮，已有项目时仍可通过标题栏 `+` 新建。
- **创建项目与源文件夹选择**：点击新建后打开 **“创建项目”** 弹窗，可输入项目名称并在 **“本机 / 远程”** 之间切换；在“本机”页签点击 **“添加”** 可呼出 Windows 原生资源管理器选择本机已有项目文件夹，并自动回填项目名称（“远程”页签当前如实提示尚未接入）。
- **未选文件夹时的默认生成规则**：如果只输入项目名称（例如 `app1`）而未选本地/远程文件夹，系统会自动读取当前用户的真实 Windows“文档”目录（包括自定义迁移后的路径，如 `D:\系统\文档`），解析生成 `<文档>\lfaa\app1`，遇到同名目录自动顺延为 `app1 2`、`app1 3`。
- **目录信任确认与真实工作区视图**：提交创建前会弹出 **“信任此文件夹吗？”** 确认框展示即将使用的完整路径；点击 **“信任文件夹”** 后会在左二保存项目，主工作区直接展示该项目的真实目录路径与实时文件/文件夹列表（支持手动刷新），右侧上下文面板可随时查看路径详情或将其“从项目列表移除”（仅从列表移除，不会删除磁盘里的文件夹）。

## 影响范围与使用提示

- 影响 `packages/ui/layout`、`packages/workspace/workspace` 与 `apps/web`；项目索引保存在本机 `~/.lfaa/projects.json`，已通过桌面端（`1440×900`）与移动端（`390×844`）内置浏览器实测验收。

## 已知限制

- “远程”源文件夹接入能力尚未实现，目前仅支持本机目录；另注意使用本地服务需要通过 `pnpm lfaa web`（包含 Node Workspaces Host 中间件）运行开发服务器。
