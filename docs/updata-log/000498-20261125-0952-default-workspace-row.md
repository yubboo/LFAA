# UPDATE-000498｜左二栏显示「默认工作区」

- 日期：2026-11-25（Asia/Shanghai）
- 左二栏「项目」分组最前面固定显示「默认工作区」：即使一个文件夹项目都没有，它也会和「+ 创建新项目」一起出现，不再只有空态提示。
- 点击它直接进入未绑定项目的新聊天；当前没有选中项目时，该行保持高亮。
- 悬停用它显示完整目录（例如 `D:\Documents\lfaa\default-workspace`），浮层不会被左栏裁切，靠近窗口边缘会自动收拢，超长路径换行显示。
- 目录仍取自系统「文档」下的 `lfaa/default-workspace`，可在「设置 → 常规 → 默认工作区」里改。
