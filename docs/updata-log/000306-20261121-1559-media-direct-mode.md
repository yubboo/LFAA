# 修复：切到生图/生视频模型后可以直接提要求生成

- 日期：2026-11-21 15:59 +08:00。
- 之前的严重体验问题：切到生图或生视频模型后输入描述，会提示「当前是生图模型，不能直接对话」并拒绝发送，必须先切回对话模型。
- 现在选中生图/生视频模型后，直接输入描述发送即可生成：使用你**当前选中的模型**（如 wan2.7-image / wan3.0-video），显示「正在生成…」，完成后图片/视频直接出现在聊天里，并保留在会话历史中。
- 实测：选中 wan2.7-image 生成图标、选中 wan3.0-video 生成 2 秒视频均成功，聊天内正常预览，控制台无错误。
- 注意：媒体模式下每条消息都会触发一次生成（按张/秒计费）；回到普通对话请切回对话模型（已帮你切回 deepseek-v4.1-flash-1017）。
