# 000426｜Agents 页可以限制某个 agent 能用的工具

- 时间：2026-11-23 01:20–01:40（Asia/Shanghai）。
- 新功能：Agents 页编辑卡多了「禁用工具」一栏。填进去的工具名（逗号或空格分隔）对**这个 agent** 彻底不可用——模型看不到它，代码里查不到它，执行前也会被拒绝。
- 典型用法：
  - 只读审查员：填 `run_command, write_file, edit_file`，它就真的只能看不能改。
  - 群聊里的旁听角色：同样填上写类工具，避免它在你没盯着的轮次里动文件。
- 留空表示不限制，和改造前完全一致；已有 agent 不需要做任何迁移。
- 验证：全量 695 项测试（新增 1 项策略持久化用例）、类型检查、Lint、构建、Web 自动验收（14/14）全部通过；深色截图确认新字段可读。
- 还没做：只能配「禁用」，不能配「只允许」；群聊默认只读还没开——那需要先定一份「写/执行类工具」名单。
