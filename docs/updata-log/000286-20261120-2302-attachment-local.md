# 聊天附加的文件会保存到本机附件库

- 日期：2026-11-20 23:02 +08:00。
- 用户可见变化：在输入栏用「+ → 文件和文件夹」附加文件后，文件会存入本机会话附件库（`~/.lfaa/attachments/<会话>/`），附件 chip 显示「已存入附件库」；刷新页面或重新打开会话后文件仍在，Agent 可调用 `read_attachment` 读取原文（文本直接返回正文，二进制返回类型与大小）。
- 新增全局插件「会话附件」，插件中心可见；提供 `list_attachments` / `read_attachment` 两个只读工具与 `/api/attachments` 上传/列出/读取/删除接口。
- 限制：草稿态（还没创建会话）选择文件只做预览、不上传；单文件上限 10 MiB；二进制附件不会内联给模型。
- 验证。`check`／`lint`／`typecheck`／`build`／`test`（310 项全过）／`probe:loader` 全绿；真实浏览器完成上传、chip、接口回读与插件中心可见四步验收，控制台无错误。
