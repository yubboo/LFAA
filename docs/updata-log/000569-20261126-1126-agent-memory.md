# UPDATE-000569｜Agent 记忆系统升级：会主动记、查得到、多 Agent 共享

- 日期：2026-11-26（Asia/Shanghai）
- 之前 Agent 只在你把「记住 / 以后统一 / 不要再 / 偏好」说出口时才会写长期记忆，召回靠关键词子串匹配，多个子智能体之间也看不到彼此查到的结论。
- 现在每轮结束会用当前模型自动提炼最多 3 条结构化记忆（偏好 / 事实 / 决策 / 踩坑 / 约定），按相似度去重；新结论含「改用 / 不再 / 换成」等修正词时会替代旧条目，不再新旧并存。
- 召回改为「BM25 + 中文 bigram + 项目/团队作用域 + 30 天时间衰减 + 命中次数」，默认每轮注入 8 条 / 1200 字；同一会话里子智能体查到的结论与踩到的坑，会写成团队记忆，父级与兄弟子智能体下一轮就能直接召回。
- 同时修掉一个会丢记忆的老问题：主 Agent 与并行子智能体同时写长期记忆时，之前的实现会互相覆盖，现在写入串行落盘。
- 记忆超过 800 条会自动归档到 `long-term-memory.archive.json`（只归档不删除）；记忆行为开关在 `~/.lfaa/memory-settings.json`，其中 `autoExtract` 控制每轮提炼。
- Agent 新增两个工具：`recall_memory` 按关键词主动查记忆，`forget_memory` 删除已失效条目（需审批）。
- 说明：本轮只做底层与提炼/共享，设置中心里的记忆管理界面（分类筛选、来源跳转、编辑统计）与向量语义召回还没做，后续单独排期。
