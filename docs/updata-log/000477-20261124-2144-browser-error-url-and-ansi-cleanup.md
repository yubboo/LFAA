# UPDATE-000477｜内置浏览器错误态净化：地址栏不再显示 chrome-error 且错误横幅转为清晰中文

- 时间（含时区）：2026-11-24T21:44:00+08:00
- 类型：修复
- 关联开发日志：`../dev-log/000401-000600.md`（DEV-000477）

## 用户能看到的变化

- 当本地预览服务尚未启动或连接被拒绝时：
  - 内置浏览器地址栏**不再被篡改为 `chrome-error://chromewebdata/`**，保留你原本访问的真实网址，方便直接点刷新或修改端口。
  - 顶部红色报错横幅**不再吐出 Playwright 原始终端转义码（`^[[2m` / `Call log:`）**，改为清晰可读的中文提示（如「无法连接到 http://127.0.0.1:4173/（连接被拒绝，请确认对应本地服务是否仍在运行）」）。
