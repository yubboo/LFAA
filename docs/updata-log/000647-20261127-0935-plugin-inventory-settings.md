# UPDATE-000647｜设置中心新增「内置插件」只读清单

- 类型：新功能
- 关联开发日志：`../dev-log/000601-000800.md`（DEV-000647）

## 变化

- 设置中心 →「内置插件」：按「会话插件 / 全局插件」两段列出当前装配的 38 个插件，与 DSH 的内置插件页同一结构。
- 每张卡片显示插件自己的标题与功能描述（描述来自各包 `locale/zh.json`、`locale/en.json`，不再是一句重复提示），折叠时最多两行。
- 点开卡片看 `完整名称 / 来自 / 配置状态 / 运行状态`；会话插件显示所属预设，启动失败会显示失败原因。
- 会话插件段右上角可切换预设查看；全局插件段默认折叠，搜索时两段一起展开。
- 插件中心里每张卡重复的「该能力已由当前应用装配，无需也无法单独安装。」已删除。

## 怎么验证

打开设置中心 →「内置插件」：会话插件 15 个、全局插件 23 个，共 38 个；点任意卡片能看到完整包名与「运行中」；输入「浏览器」搜索能命中。

## 已知限制

- 这页只读：启停与安装仍在侧栏「插件中心」。
