# 000327｜修复引用图缩略图误报「暂不可用」：Windows 路径大小写导致 403

- 时间：2026-11-21 22:23 +0800。负责人反馈引用上一张图后改色成功，但用户消息里出现「附带图片暂不可用 重试」。排查确认生成与引用都正常，是缩略图读取被拒绝。
- 根因：项目登记路径是 `D:\系统\文档\lfaa\app1`，而磁盘真实目录名是 `D:\系统\文档\LFAA\app1`。引用图路径来自真实路径（大写 `LFAA`），`/api/media/file` 用大小写敏感的字符串前缀校验允许根 → **403**，前端进入失败态（同一条路径改成小写即 200）。Windows 文件系统本身大小写不敏感。
- 修复：媒体文件接口的允许根校验在 Windows 上按小写归一化后比较（其他平台保持精确比较）；新增 Windows 回归用例。刷新后该引用图正常显示，无需重新生成。
- 文案：失败占位按来源区分——附件失败显示「附件图片暂不可用」，引用图失败显示「引用图片暂不可用」，不再让引用图顶着「附件」字样。
- 历史消息：过渡版本里的「已保存：xxx.png（8.1 MB）」独立段落也在渲染时收掉，避免同一会话中新旧排版混用。
- 验证：真实 5173 宿主 + 无头 Edge，深/浅主题各一轮：大写路径返回 200、引用图 2048×2048 正常显示、无「暂不可用」、全文无「已保存：」与绝对路径、控制台 0 错误。
- 需要刷新页面（Ctrl+F5）查看（本轮已重启宿主）。
