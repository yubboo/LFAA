# UPDATE-000349｜任务清单可以直接勾选，运行中实时刷新

- 时间（含时区）：2026-11-22 04:00 +0800
- 类型：新增 / 优化
- 关联开发日志：`../dev-log/000201-000400.md`（DEV-000349）

## 用户能看到的变化

- 对话视图里的任务清单，每条都可以点：已完成的点回「待处理」，未完成的点成「已完成」，顶部计数立刻变化，并写入会话记录——刷新页面、重开历史会话都保持。
- 运行中的任务卡会随 Agent 的 `todo_write` 实时刷新（「进行中 1 · 待处理 2」→「已完成 3」），不需要刷新页面。
- 保存失败时会回滚界面并给出错误提示，不会出现「界面勾掉了、磁盘没变」的假状态。

## 影响范围与使用提示

- 影响 `@lfaa/chat`（客户端任务卡、会话 Store、SSE 事件接线）与 `@lfaa/chat` Host 的会话 PATCH 接口（新增 `todos` 字段，按既有规则校验后整表写入）。
- 任务清单的数据源改为「会话记录优先」：会话有 `todos` 时以它为准；旧会话没有该字段时回落到步骤里的最近一次清单，不需要迁移。
- 「轨迹」视图仍是只读展示，不提供勾选。

## 已知限制

- 手动勾选后如果 Agent 再次调用 `todo_write`，会以模型给的整表覆盖，人工改动会被替换。
- 勾选只切换「已完成 / 待处理」，「进行中」仍由 Agent 维护。
- 极简模式没有任务清单，因此没有勾选入口。
