## 用户能看到的变化

- **设置中心无缝切换为三栏**：进入设置中心后，直接复用同一个工作台的左一图标栏、左二菜单栏和中间工作区，并自动隐藏右侧上下文栏与右上角右侧切换按钮，把完整空间让给设置内容；左一与左二宽度、样式、响应式抽屉行为与工作区保持完全一致，返回或点击左一入口即可切回四栏工作区。
- **左一用户入口高亮反馈**：处于设置中心时，左下角用户头像保持激活高亮提示。
- **统一可复用侧栏组件**：工作区与设置中心共用同一套左二菜单组件与样式，减少重复代码与后续扩展成本。

## 影响范围与使用提示

- 影响 `packages/ui/layout` 与 `apps/web`；已在桌面端（`1440×900`）与手机端（`390×844`）通过内置浏览器实测验收。
