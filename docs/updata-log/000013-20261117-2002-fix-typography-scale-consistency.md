# UPDATE-000013｜修复不同设备下字体偏大与字号比例不一致问题

- 时间（含时区）：2026-11-17 20:02:30 +08:00
- 类型：修复
- 关联开发日志：`../dev-log/000013-20261117-2002-fix-typography-scale-consistency.md`

## 用户能看到的变化

- **“界面字号 14px”精准对应真实文字大小**：解耦 `html`（固定 `16px` 用于布局几何尺寸）与 `body`（`--ui-font-size`，默认 `14px`），调整字号不再连带缩放顶栏高度与侧栏宽度。
- **消除侧栏偏大与跨设备波动**：将侧边栏“新聊天”（原 `1.15rem`）、分组标题“置顶/项目/最近”（原 `1.1rem`）统一收敛为 `1em`（`14px`）与 `0.93em`（`~13px`），主标题改用固定 `em` 阶梯（去除 `3vw` 视口波动），并启用 `text-size-adjust: 100%` 防止移动端自动放大字体。

## 影响范围与使用提示

- 影响 `apps/web` 与 `packages/ui/layout`、`packages/workspace/workspace` 全局排版；已在桌面端（`1440×900`）与手机端（`390×844`）复验完全一致。若浏览器旧标签页仍显示早期缓存的“本地模式”双绿点，刷新一次即可。

## 已知限制

- 无。
