# UPDATE-000578｜预览区在左：关掉最后一个标签就收起预览列，点展开恢复分屏

- 日期：2026-11-26（Asia/Shanghai）
- 之前关闭预览列最后一个标签页时，被收起的是最右侧的 AI 会话列：预览区留在原地、会话没了，预览区再也关不掉。
- 现在关闭最后一个标签页只会收起预览列，AI 会话列直接吃满整片宽度。
- 此时顶栏那枚开关显示「展开」：点一下就重新开一个空白「新标签页」，恢复左右分屏。
- 点左二文件树里的任何文件同样回到分屏，并打开该文件。
- 分屏状态下的收起 / 展开保持原样：收最右侧的 AI 会话列、预览列铺满，再点就回来。
- 顶栏只保留一枚侧面板开关（展开 / 收起），不再并排出现两个。
- 两列不会同时收起，所以不会出现「整片空白」的中间态。
- 「聊天区在左」的默认排版行为不变。
