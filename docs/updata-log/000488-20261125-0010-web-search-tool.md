# UPDATE-000488｜新增轻量全网搜索工具 `web_search`，查文档资料快 10 倍

- 编号：UPDATE-000488
- 日期：2026-11-25 00:10（Asia/Shanghai）
- 类型：新功能

## 本次变更

- 为小鱼新增免密钥全网搜索工具 **`web_search`**（支持关键词、条数上限与 `site` 域名过滤，内置 Bing + DuckDuckGo 双源回退）。
- 配合既有的 **`fetch_url`** 网页正文读取工具，小鱼现在查最新技术文档、报错方案和公开资料时可直接「搜索 → 精读正文」，无需启动笨重的完整浏览器，速度更快、Token 消耗大幅降低。
- 同步产出了 [原生 MCP 客户端接入方案](file:///e:/lfaa/docs/plans/mcp-client-support.md)（待评审）。
