# 000425｜Agents 页支持导出 / 导入

- 时间：2026-11-23 00:50–01:00（Asia/Shanghai）。
- 新功能：Agents 页右上角多了「导出」和「导入」。
  - **导出**：把当前所有 agent 与模型绑定存成一个 JSON 文件，用于备份或换机器。
  - **导入**：选一个之前导出的 JSON，同名（同 id）的会被覆盖，新的一律追加；导入完会在顶部告诉你新增和覆盖了多少个。
- 安全细节：导入文件里就算写着「这是内置 agent」，也不会把你自己建的 agent 变成内置；内置的「默认模型」绑定不会被导入内容改掉。
- 验证：全量 693 项测试（新增 3 项导入导出用例）、类型检查、Lint、构建、Web 自动验收（14/14）全部通过；深色截图确认按钮排版正常。
- 还没做：agent 的技能与工具权限虽然能存、能随导入导出走，但还没有真正作用到运行时的工具集。
