# UPDATE-000594｜左下角账号卡片不再压到中间会话区

- 日期：2026-11-26（Asia/Shanghai）
- 之前点左下角头像展开账号卡片时，卡片固定 344px 宽，比左二会话栏还宽，右边直接压到中间的对话区，看着又大又肥。
- 现在卡片跟着左二栏走：左右各贴 2px 内边线，宽度取会话栏本身（最宽仍封顶 344px，栏很宽时不会越拉越大），整块始终落在会话栏里，不再越过栏边。
- 卡片窄下来后头部自动重排：动作名保持单行、过长用省略号；极窄时「暂未接入」「Ctrl+Alt+,」这类辅助标记会先让位，账号头部放不下的外观控件会落到第二行。
- 左二栏收起时没有栏可对齐，仍是原来的独立浮层宽度。
- 其中的外观切换随后按参考图换成了三档发光开关，见 000597。
