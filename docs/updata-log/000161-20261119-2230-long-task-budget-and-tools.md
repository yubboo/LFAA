# 000161｜长任务不再被步数与超时掐断

2026-11-19 22:30 +08:00

- 单个任务默认可用 100 步工具调用；预算用尽但仍在推进时会自动延长，不再停在阶段性总结上。
- 终端命令默认 10 分钟超时，可用 timeoutMs 延长到 30 分钟；超过时限的命令自动转入后台任务继续执行，并给出任务 ID。
- 长时间思考不再被 55 秒掐断：普通模型保留 3 分钟连续推理，思考型模型 10 分钟。
- 新增 glob 与 grep 工具；局部编辑在多处命中时会拒绝执行并提示行号，可显式全部替换。
- 长会话会记住已改文件与已跑命令，减少重复读取；会话列表摘要展示保持不变。
