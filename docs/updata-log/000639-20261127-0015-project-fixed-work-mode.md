# UPDATE-000639｜项目内会话不再显示聊天 / 工作切换

- 时间：2026-11-27 00:15（Asia/Shanghai）
- 类型：fix（项目内模式入口）

## 变化

- 已经进入项目的新会话不再显示「聊天 / 工作」切换：项目内固定为工作形态。
- 项目内即使全局模式还停在聊天，标题与输入栏也按工作形态渲染（标题显示「你想让我们在 … 中构建什么？」、输入栏显示项目头行），不会出现「在项目里还能切回聊天」。
- 未绑定项目的中心引导区仍保留「聊天 / 工作」切换。

## 怎么验证

工作模式选中「默认工作区」：中心区不应有聊天 / 工作分段，标题与输入栏为工作形态。解绑项目或从「最近」新建会话：分段恢复。
