# UPDATE-000485｜新增「樱花粉（Sakura）」主题风格预设（浅色 / 深色双套）

- 编号：UPDATE-000485
- 日期：2026-11-24 23:30（Asia/Shanghai）
- 类型：新功能

## 本次变更

1. **设置中心「外观 → 主题风格」新增第 5 套配色预设「樱花粉 / Sakura」**：
   - 浅色：晨雾樱花白底（`#FFF6F8`）+ 深褐正文（`#3B2A33`）；深色：夜色梅红酒底（`#1D1418`）+ 浅粉正文（`#F4E6ED`），两套正文对比度分别为 12.65:1 与 14.92:1，文字清晰不糊。
   - 两套共用一枚樱花粉强调色（`#C9558A`），选中后的勾选角标、滚动条滑块与用户气泡都跟着换调。
2. **主题真正「换调」而不只是换底色**：图标栏、会话栏、浮层、控件底与卡片底色改为从一组色调令牌派生，樱花粉只替换这组值，因此浅色下三栏保留可分辨的「栏 → 面板 → 背景」层次，深色下整屏呈梅红粉调而非纯黑。
3. **配色卡网格按预设总数自适应列数**：5 套预设时宽屏排满一行，中窄屏退 3 列、手机端 2 列，不再出现最后一张单独掉到下一行。
4. **首屏刷新不再闪回旧主题**：页面首屏绘制前的主题恢复脚本已登记樱花粉，刷新瞬间不会先闪成旧的粉色或丢失玻璃质感。

## 使用方式

打开「设置中心 → 外观」，在「主题风格」分组里点击「樱花粉」卡片即可应用（悬停可先在上方实时预览）；已应用主题会记忆，刷新后保持不变。
