# UPDATE-000366｜工作树：合并命令、领先/落后与失效记录清理

- 时间：2026-11-22 15:40 +0800（Asia/Shanghai）
- 类型：体验优化

## 你会看到什么

- 项目详情的工作树列表显示「领先 X / 落后 Y」，相对创建时的起点分支统计，方便判断是否需要先拉取/合并主线。
- 每个工作树提供「复制合并命令」：复制 `git switch <起点分支>` + `git merge --no-ff <工作树分支>`，由你在主工作区自己执行；不会自动切分支或自动合并。
- 目录被外部删除后，列表会出现「清理失效记录」，一键移除失效登记并让 Git 丢弃对应工作树信息。

## 兼容性

- 旧工作树记录没有起点分支时，合并命令回退到 `main`，领先/落后显示 0。
- 不会自动合并、不会自动删分支、不会携带主工作区的未提交改动。
