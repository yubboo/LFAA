# UPDATE-000631｜图片预览改为铺满整个屏幕，放大不发虚

- 时间：2026-11-26 21:24（Asia/Shanghai）
- 类型：fix（图片预览尺寸与清晰度）

## 变化

- 点开图片预览后，图片默认铺满整个可用区域，不再按原始像素缩在屏幕中间；小图也能看清。
- 工具条新增缩放：缩小、比例（点一下回到「适应」）、放大、1:1（实际大小）；点图片本身也能在「适应 / 1:1」之间切换。
- 放大后保持清晰：显示比例超过原图 1.5 倍时改用像素化渲染（边缘锐利、不发虚）；比例较小时仍用平滑缩放；看原始像素按 1:1。
- 放大到超出屏幕后可在预览区内滚动查看。

## 怎么验证

在输入框粘贴一张图片并点开：图片应铺满屏幕；点「1:1」应回到原始像素大小，点「适应」或比例数字应重新铺满；按「+」放大后边缘仍清晰。
