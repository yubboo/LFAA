# 000333｜置顶行单独展开/收起，图钉可点取消置顶，强调色只代表置顶

- 时间：2026-11-21 23:44 +0800。负责人反馈：在「置顶」里展开 app1，「项目」里的 app1 也跟着展开/收起；行内小图钉点不了；强调色用法不统一，希望「置顶的用强调色、没置顶的不带强调色」。
- 展开/收起按行独立：同一项目在「置顶」和「项目」各占一行，点哪一行就只展开/收起那一行，另一行保持原样；项目下的聊天列表也跟着各自显示。
- 图钉可点：已置顶项目行右侧的图钉现在是按钮，点击即取消置顶（项目从「置顶」区移除，「项目」里仍然保留）；鼠标悬停有「取消置顶」提示。
- 颜色规则：强调色只代表「已置顶」——已置顶行的图钉在「置顶」和「项目」两处副本上都用强调色，未置顶的行不出现任何强调色标记；悬停卡右上角的图钉在已置顶时保持强调色，不再因为悬停变灰。
- 页面刷新（Ctrl+F5）后生效；本轮为前端交互与样式改动，宿主无需重启。
