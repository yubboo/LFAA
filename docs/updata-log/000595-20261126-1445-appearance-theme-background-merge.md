# UPDATE-000595｜外观页：主题就是背景，只剩一面主题卡墙

- 时间：2026-11-26 15:20（Asia/Shanghai）
- 类型：style（设置中心外观页信息架构）

## 变化

- 「外观 → 预设」以前是两面卡片墙：上面 5 张主题风格卡，下面 18 张背景图墙，两处各选一次、各有一个勾。现在合成**一面主题卡墙**：一张卡就是一套完整外观（配色 + 底图或纯色），点一次同时换配色和背景。
- 卡墙顺序：5 套纯色主题 → 16 张内置背景主题 → 我的图片；每个背景主题固定一套配套配色，不再需要先去选配色再选背景。
- 不再有独立的「背景」分组、作用位置分段或第二条背景轴；「上传」也收进主题标题行。
- 悬停任意卡只在顶部实时预览，点击才应用；工作区与设置中心同步成同一套外观。
- 个人图上传后直接成为一张主题卡，删除需要点两次；删掉正在用的图会回到 LFAA 纯色主题。

## 怎么用

设置中心 → 外观 →（预设）→ 主题：直接点一张卡，配色与背景一起换。想用自己的图，点右上角「上传」；不想要了就点卡片右上角的删除。

## 注意

- 配色与背景不再支持自由混搭（例如「樱花粉 + 服务机房」）；每个背景主题自带一套配色，这是「一个功能」的直接结果。
- 需要单独微调强调色、底色或字体，仍可在「高级设置」里改。
