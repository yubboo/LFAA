# 000145｜流式尾部持续执行状态、工程步数优化与 Minecraft 插件开发技能

2026-11-19 15:24 +08:00

- 流式输出期间，当上一轮工具完成后进入下一轮思考、正文输出中或用户收起顶部过程时，回复末尾持续显示当前轮次的实时执行状态行（脉冲圆点、动态高光、阶段名称与当轮用时），避免轮次切换出现“看似已完成”的空窗；活跃工具分组同步增加脉冲指示点，完成后自动收起。
- Agent 默认工具步数上限从 `10` 提升至 `28`，引导同轮并行批量读写独立文件并匹配当前 Shell 原生命令语法，减少多文件插件/工程任务中途截断。
- 前台终端命令超时从 `15s` 放宽至 `90s`，适配 Maven / Gradle / TypeScript 编译构建。
- 新增内置技能 `minecraft-plugin-dev`（我的世界 Paper / Spigot / Folia 1.20.x–1.21.x 插件开发规范与工具调用避坑指南），可在「技能中心」查看/二创并在聊天中通过 `$minecraft-plugin-dev` 选用。
