# UPDATE-000632｜标题里的项目名可以点击切换项目

- 时间：2026-11-26 21:33（Asia/Shanghai）
- 类型：feat（引导区项目入口）

## 变化

- 新会话标题里的项目名现在是可点击的变量：点一下就在标题下方展开项目选择器。
- 选择器复用输入栏的项目菜单：搜索项目、切换项目、新建项目、选择「不在项目中工作」都在同一处。
- 切换后标题立即更新，例如从「你想在 app1 中聊些什么？」变为「你想在 默认工作区 中聊些什么？」。
- 浮动层字号重置为正常菜单字号，不会跟着大标题一起变大；点空白或按 Esc 关闭。

## 怎么验证

在项目内新建会话，点击标题里高亮的项目名：标题下方应出现项目搜索与列表；选择一个项目后标题里的项目名立即变化且浮层关闭。按 Esc 或点空白也应关闭浮层。
