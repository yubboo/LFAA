# UPDATE-000583｜长会话滚动与输入更顺：离屏消息不再参与布局绘制

- 任务编号：UPDATE-000583（对应 DEV-000583）
- 时间：2026-11-26 14:20（Asia/Shanghai，UTC+08:00）
- 类型：perf（体验优化）
- 关联：DEV-000583

## 用户能看到什么

- **长会话打字更跟手**：同一个大会话里，打字帧 p95 从 35ms 降到 14ms，最大 49ms 降到 21ms，超过 33ms 的卡顿帧归零。
- **往上翻历史更顺**：向上滚动帧 p95 从 62ms 降到 35ms，卡顿帧从 45/123 降到 16/160；滚轮每格位移稳定，停止滚动后没有位置回弹（实测位移 0px）。
- **点刻度跳转、回到底部照常**：锚点跳转仍能定位并高亮对应轮次，回到底部仍精确贴底。
- **右栏不再跟着正文刷新**：右栏工作台只订阅自己用到的状态，AI 流式输出时右栏不再陪着重画。

## 已知未解决

- 离屏消息不再参与布局：滚动条比例按「已渲染实测 + 未渲染估算」计算，屏幕阅读器要读到很久以前的消息需要先滚过去。若不接受这种取舍，删掉那条 CSS 规则即可回滚。
- 切换会话仍需 250–370ms，瓶颈是 React 一次性创建上万元素，只有消息列表窗口化（虚拟列表）能真正解决，属于下一阶段方案。
