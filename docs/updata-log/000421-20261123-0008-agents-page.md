# 000421｜新增 Agents 页：给每个 agent 绑定任意模型

- 时间：2026-11-22 23:44–2026-11-23 00:08（Asia/Shanghai）。
- 新功能：左一图标栏新增 **Agents** 入口（首页下方）。页面左侧是 agent 列表，右侧是编辑卡：名称、用途（个人助手 / 干活）、人设指令、模型绑定，以及新建绑定。
- 解决的问题：以前整个应用只有一个隐含的「小鱼」和一个全局模型，换模型全局串台。现在每个 agent 可以各自绑定**任意供应商的任意模型**，同一份绑定也能被多个 agent 复用。
- 行为细节：
  - 内置「小鱼」始终存在，可以改名或停用，不能删除；列表里带「内置」徽标。
  - 绑定下拉里「默认模型（跟随全局配置）」表示沿用原来的全局设置，老用户不改任何东西也一切照旧。
  - 「新建绑定」直接列出所有已配置供应商的模型（`供应商 / 模型`），选中即建。
  - 保存失败会把服务端原因原样显示，不静默。
- 附带修复：Web 自动验收脚本的「浅色主题」步骤此前只改了一个不会被读取的键，断言恒真；现在同时改两个键，深色主题检查才真正生效。
- 验证：真实本机 Edge 自动验收 **12/12**（含新增的 Agents 列表、窄屏 Agents、深色 Agents 编辑态），控制台 0 错误；深色与浅色、390px 窄屏均目视确认；全量 673 项测试、类型检查、Lint、构建全部通过。
- 已知限制：模型绑定目前只支持单目标；路由组（多目标按序/轮流/用量最少）与导入导出留到后续阶段。
