# UPDATE-000619｜图片主题下输入区不再是“一大块白”

- 时间：2026-11-26 17:44（Asia/Shanghai）
- 类型：fix（观感）

## 变化

- 用背景图时，输入框脚下那块「从透明渐变到白色」的遮挡不再叠上去。原因是四栏底色本身已经是同一档薄纱（约 62%），再叠一层不透明白就变成约 86% 的白，横跨整栏、一百多像素高，看起来像一条白色底板。
- 现在输入卡片直接浮在壁纸上，卡片自身仍是磨砂玻璃，正文照常淡出；纯色主题（不选背景图）完全不变。

## 怎么验证

设置中心 → 外观 → 工作区背景图选任意一张 → 回到会话：滑到最底部，输入框周围应能看到壁纸，不再有齐整的白块；切回「纯色」应恢复原来的淡出遮挡。
