# UPDATE-000590｜右栏「+」和新建标签快捷键可以连续新建标签页

- 日期：2026-11-26（Asia/Shanghai）
- 之前当前标签正好是「新标签页」（空白占位）时，点「+」没有反应，Ctrl+Alt+B 也一样：只能先切到文件或终端，再点一次才能多开一个。
- 现在每次点「+」或按 Ctrl+Alt+B 都会新建一个标签页，空白标签在场也照加；浏览器首次打开时仍先露出空态占位，不会白开一个宿主标签。
- 快捷键就是悬停「+」时显示的 Ctrl+Alt+B（Ctrl+T 被浏览器自己占用，网页抢不到，所以没改用它）。
- 另外修好了「设了快捷键却没反应」：工作台收起（或预览区在左时预览列收起）后按 Ctrl+Alt+B，现在会先把工作台展开、再新建标签页；预览区在左时直接恢复分屏。
- 顺手确认：切换布局、关掉最后一个标签、再点展开这些流程不受影响。
