# UPDATE-000496｜「文档\lfaa」里的项目文件夹会自动纳入，删掉就自动移出

- 日期：2026-11-25（Asia/Shanghai）
- 现在只要在 `<系统文档>\lfaa` 里放一个文件夹，它就会被自动当成项目：既包括应用里「新建项目」生成的文件夹，也包括你自己在资源管理器里手动创建的文件夹。切回应用即刷新（窗口重新获得焦点时会静默拉取），不用手动刷新页面。
- 反过来也成立：在资源管理器里把某个项目文件夹删掉后，左二栏对应的项目会自动移出，不会再留一个点进去是空目录的项目。
- 项目外聊天目录（`<系统文档>\lfaa\default-workspace`）、Git 工作树目录（`<项目名>-worktrees`）、隐藏目录与普通文件不会被误当成项目。
- 只处理 `<系统文档>\lfaa` 这一层：绑定在 `G:\...` 等其他位置的项目保持原样，仍由你自己选择/绑定，磁盘删除也不会自动移出。
- 应用里的「移除项目」和你先在资源管理器删文件夹是两件事：**「移除项目」只把项目从列表里移出，硬盘上的文件夹不会被删除**（聊天也保留）；只有你在资源管理器里真的删掉文件夹，lfaa 才会跟着不显示。
- 移除过的项目不会被自动加回来（避免刚移出又自己冒出来）；之后想重新加入，用「新建项目」再次绑定这个文件夹即可。
- 被自动移出的项目只是从列表里消失，聊天记录仍留在「最近」分组里可以继续打开。
- 顺手修掉项目悬停信息卡的 1.6px 错位：「编辑项目」行的图标与文字现在和其它行严格同列，文件夹路径行也和名称行同字号同列（只靠颜色区分层级）。
