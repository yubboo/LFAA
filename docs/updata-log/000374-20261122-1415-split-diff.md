# 000374｜变更查看改为左右分屏 Diff：左修改前、右修改后

- 时间：2026-11-22 13:50–14:15 +0800。负责人要求「有变更时用分屏对比：左边没改之前，右边改之后」，并给出带 hunk 头与行号的分屏参考图。
- 用户可见变化：文件预览切到「差异」后，不再上下堆叠「修改前/修改后」片段，而是左右两栏逐行对照：左栏修改前（红色删除行）、右栏修改后（绿色新增行），中间一条分隔线；顶部显示 `@@ -a,b +c,d @@` hunk 头，两侧各自显示原始行号，未对齐的一侧用浅色空行占位。
- 覆盖两条数据来源：
  - 已保存文件的 Git 统一 diff（`/api/git/diff` 返回的 `diff` 文本）→ 解析 hunk 后分栏；
  - Agent 步骤里的 `fileChange.before/after` 片段 → 行级 LCS 对照后分栏（行号从 `firstLine` 起算）。
- 实现：新增纯函数 [diff-view.ts](packages/core/chat/client/components/diff-view.ts)（`splitFromUnifiedDiff` / `splitFromFragments` / `countDiffLines`，含超大片段退化与 4000 行上限）；`FileChangePreview` 内新增 `SplitDiff` / `SplitSideCell` 渲染；`FileChangePreview.diff.module.css` 重写为分栏布局（hunk 头横跨两栏、红绿底色、行号与 +/- 标记、单元格内折行不出现横向滚动条）。
- 回归测试：新增 `packages/core/chat/tests/diff-view.test.ts` 4 项（统一 diff 解析与行号、片段 LCS 配对、新增文件全为右侧新增、空 diff）。
