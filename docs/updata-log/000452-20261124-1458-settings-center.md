# 000452｜设置中心重排 + 记住你停在哪一页：一项设置一行、去掉分组外框、刷新不再把你踢回工作区

- 时间：2026-11-24 14:26–15:10（Asia/Shanghai）。
- 变化：
  - **刷新不再丢位置**。以前在设置中心按 F5 或强制刷新，会被踢回工作区、要重新点一遍；现在刷新后仍停在原来那一页（比如「通知」），关掉设置再刷新才回到工作区。设置中心内部换页也各自记住，关掉设置会回到你打开它之前看的那个页面与项目。
  - **一项设置一行**。名称与说明在左，控件在右并右对齐；布尔是开关、短选项是分段按钮、长选项是可搜索下拉。以前有的页面用复选框、有的整块单选卡片、有的自制按钮，现在全站一套。
  - **去掉分组外面那层框**。设置页不再套一层带边框和底色的卡片，分组只用标题和留白区分；组与组之间留白明显更大，组内行贴紧。
  - **多分组、加标题**。「常规」页原来 16 项挤在一个标题下，现在拆成「权限 / 位置 / 运行环境 / 界面 / 历史与性能 / 启动与扩展」。
  - **删除类操作单独放**。自定义提示音的删除、长期记忆的删除，移到页面最末的独立危险分组，不再混在普通设置行里。
  - **表单不再照搬行式布局**。存储位置与迁移、浏览器配置、规则与记忆、提交/PR 指令这些需要顺序填写的表单，改成标签在上、控件在下、按钮在表单底部。
  - **目录只留能用的 8 项**。以前目录里 23 项有 15 项点进去只是「功能不可用」；未接入的条目已从目录移除，只保留常规、外观、通知、存储、模型与规则、代码审查、Git、浏览器。
  - **「设置」入口修正**。用户菜单里的「设置」以前跳到外观页，现在进设置中心「常规」；「个性化」仍旧直接打开外观。
  - 设置窗口本身改为不透明底色：去掉页面卡片后，浅色主题下正文会透出背后工作区的文字，现在不会再串色。
- 两种主题都验过：深色、浅色下正文、说明、分隔线、下拉与弹层对比正常；390px 窄屏下目录变为顶部横滑胶囊、控件落到说明下方且无横向溢出。
- 验证：`pnpm check`、`pnpm lint`（578 文件 0 问题）、`pnpm typecheck`、`pnpm test`（746/746）、`pnpm build`、`pnpm probe:boot`（3/3）、`pnpm probe:loader`（13/13）、`pnpm verify:web`（16/16，含新增的「刷新后仍停在设置子页」一步）、`pnpm ui:shot --only=settings`（11/11）全部通过；无头浏览器控制台 0 报错。
