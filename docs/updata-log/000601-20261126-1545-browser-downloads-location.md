# UPDATE-000601｜浏览器下载位置：默认跟着你电脑的「下载」走

- 时间：2026-11-26 15:45（Asia/Shanghai）
- 类型：fix（默认值写死）+ feat（跟随系统 / 恢复默认）

## 变化

- 默认下载位置不再写死 `C:\Users\<用户名>\Downloads`：自动读取本机系统「下载」目录，Windows 上把「下载」移到 D 盘等其它位置也能识别，Linux 读 XDG 配置。
- 设置中心 → 集成 → 浏览器 → 下载：这一行显示当前真实路径，并标出「系统默认」，不再出现别的电脑或别的用户的目录。
- 选过自定义目录后，右侧会多出「恢复默认」，一键回到系统「下载」目录；「更改…」仍可随时选别的文件夹。
- 本机默认路径不再写进设置文件：以后换电脑或换用户名，默认下载位置会自动对上新机器。

## 怎么用

设置中心 → 集成 → 浏览器 → 下载 → 下载位置：直接看当前路径；要改就点「更改…」选文件夹，想回到系统默认就点「恢复默认」。
