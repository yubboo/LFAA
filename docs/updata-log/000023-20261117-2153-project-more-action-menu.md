# UPDATE-000023｜新增项目 `···` 点击操作菜单，并优化悬停与点击交互互斥

- 时间（含时区）：2026-11-17 21:54:00 +08:00
- 类型：新增功能与交互优化
- 关联开发日志：`../dev-log/000023-20261117-2153-project-more-action-menu.md`

## 用户能看到的变化

- **Hover 与 Click 互斥交互**：鼠标移入项目行右侧 **`···`** 时会在左侧栏外侧显示项目信息卡片；点击 **`···`** 后信息卡片立即隐藏并在下方弹出操作菜单。点击后即使关闭菜单、指针仍停留在 `···` 上也不会反复弹出信息卡片，只有将鼠标移开再重新移入 `···` 时才会再次显示信息卡片。
- **`···` 下拉操作菜单项**：
  - **置顶 / 取消置顶**：一键切换项目置顶状态。
  - **编辑**：直接打开“编辑项目”整页居中弹窗。
  - **分区 >**：展开子菜单快速切换至 **置顶分组 / 项目分组**（未接入的“自定义分区”如实置灰不可用）。
  - **在资源管理器中打开**：在本地终端运行 `pnpm lfaa web` 时，点击可直接在 Windows 资源管理器中打开该项目对应文件夹（沙箱预览桌面下会清晰提示原因）。
  - **归档聊天**：当前无会话时保持置灰禁用状态。
  - **移除项目**：一键将项目从 LFAA 列表中移除（不删除磁盘文件）。

## 影响范围与使用提示

- 影响 `packages/ui/layout`、`packages/workspace/workspace` 与 `apps/web`；已完成桌面端（`1440×900`）与移动端（`390×844`）交互与布局验收。
