# UPDATE-000579｜流水线验收更准了：清单类短交付不再被误判，重试不再多出标签

- 日期：2026-11-26（Asia/Shanghai）
- 在默认工作区实跑 `run_crew` 时发现两个问题，已修。
- 问题一：交付验收原来要求至少 40 字，列个文件清单只有十几个字就被判失败，任务白重试一次。现在默认只挡「好」「完成」这类空交付；确实需要更长时，在交付要求里写「不少于 N 字」即可。
- 问题二：交付要求里写「必须包含：类型名称」这种元描述时，模型列出了内容却没原样出现这几个字，被误判失败。工具说明已明确：这里要写期望文字里真实出现的词。
- 副作用修复：归档写入改为等待完成，并发写记忆时归档文件不会再出现「已归档但文件还没写完」的时序问题。
- 实测：修完后同样的两步流水线首次通过，18 秒、2 个任务标签，控制台无报错。
