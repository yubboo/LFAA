# UPDATE-000606｜会话区滚动不再被「自动贴底」抢走

- 时间：2026-11-26 16:40（Asia/Shanghai）
- 类型：fix（滚动体验）

## 变化

- 流式输出时向上滚动会话，视口会真的停在你滚到的位置，不再被自动贴底反复拽回底部，也不会再出现「上下上下来回跳、滚不动」。
- 内容继续增长时，正在读的历史保持不动；滚回底部后自动恢复跟随。
- 回合结束后迟到出现的追问建议、已编辑文件卡片仍会平滑让位，不甩动正文。
- 在内嵌的思考正文 / 工具输出块里往上滚，仍属于块内滚动，不会误停整个会话的跟随。

## 怎么用

在会话里直接向上滚动即可停在当前位置；想继续跟随最新输出，点右下角「回到底部」或自己滚回底部。
