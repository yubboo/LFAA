## 新增功能与体验优化

1. **全新共享交互组件库 `@lfaa/ui-primitives`**
   - 统一封装居中弹窗（`ModalDialog`，支持多种尺寸与统一可改弹窗动效）、浮层卡片（`PopoverCard`）和离散滑块弹窗（`StepSliderPopover`），供全站所有交互页面复用与集中调优。
2. **输入栏「选择模型」与「推理强度」滑块浮窗**
   - 替换原底部原生下拉框为胶囊选择器：点击模型名称打开「选择模型」卡片列表，点击推理强度档位或按快捷键 `Ctrl+Shift+M` 打开渐变圆点滑块（支持 `最低 / 低 / 中 / 高 / 极高` 调节与一键重设）。
3. **「模型管理」多提供商卡片网格 + 点击居中弹窗配置**
   - 模型设置页改为 OpenAI、DeepSeek、MiniMax、通义千问、火山方舟、智谱、硅基流动、OpenRouter、Gemini兼容、Claude、xAI Grok、本地部署、自定义 共 13 张提供商卡片，清晰标示当前启用（✓）与已配置状态；点击任意卡片即弹出居中配置窗口，完成模型参数修改、测试连通、启用或删除。
