# 000147｜新增右侧控制台、内置 Playwright 浏览器、后台任务与子智能体协作

2026-11-19 15:59 +08:00

- **后台任务服务（`@lfaa/jobs`）**：支持小鱼 Agent 启动长时后台命令、查看增量输出日志、按会话隔离任务状态及停止进程树。
- **内置浏览器（`@lfaa/browser`）**：基于 `playwright-core` 独占驱动本机 Edge/Chrome，提供导航/点击/输入/滚动/按键/截图/控制台日志 8 项 Agent 工具，并在右栏支持实时画面交互、人工接管暂停/恢复与「设置 → 浏览器」独立配置；对话输入框 `+` 菜单新增「浏览器」快速入口。
- **多 Agent 协作（`@lfaa/subagent`）**：支持进程内异步派发只读调研或读写执行子智能体、并发等待与续接对话，阻断递归嵌套派发并控制并发上限。
- **右侧栏控制台初版重构**：右侧栏新增快速搜索/URL 跳转、终端与后台任务 / 浏览器 / 侧边提问 / 子智能体 / 代码审查 / 扩展 6 项入口及会话子智能体、后台任务运行列表；Web 常驻服务 `http://127.0.0.1:5173` 已同步更新。
