# 000424｜群聊能看到这一轮花了多少钱

- 时间：2026-11-23 00:35–00:45（Asia/Shanghai）。
- 新功能：群聊窗口右上角显示本轮**总成本**（鼠标悬停可看每位成员各自花了多少），每条回复旁边也标出这条自己的成本。
- 说明：成本按模型配置里填写的单价换算；没填单价的模型不显示金额，不会出现假数字。
- 为什么做这个：群聊一轮可能叫 3 个 agent，每个都跑十几步——不看成本很容易一晚上烧掉一天的额度。
- 验证：真实本机 Edge 自动验收 **14/14**（新增 390px 窄屏群聊页），控制台 0 错误；构建、类型检查、Lint、全量测试全部通过。
