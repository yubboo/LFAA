# UPDATE-000617｜连接器连上后，agent 一定看得见、用得上

- 时间：2026-11-26 17:06（Asia/Shanghai）
- 类型：fix（连接器可用性）

## 修复了什么

- 之前在**旧会话**里，设置里连好的连接器不会出现在 agent 的工具列表里（模型会说「没有这个工具」）。原因是会话保存的是连接器上线之前的模块清单，读取时没有补齐。
- 现在：只要会话使用标准 / 创造模式的默认模块组合，打开会话时会自动补上连接器与 MCP 能力；你自己去掉过的其它能力（例如技能、浏览器、群聊）不会被加回来。
- CLI 工具在模型眼里也更好认了：描述里带上「连接器名 · 动作 · 本机命令」，模型更容易判断该不该调用。

## 怎么验证

设置中心连一个连接器（例如 Git）→ 回到任意旧会话，让它「用 cli__git__status 看下工作区状态」，它会直接调用并返回命令输出。
