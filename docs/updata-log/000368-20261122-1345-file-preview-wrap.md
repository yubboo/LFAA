# 000368｜文件预览长行自动折行，不再出现横向滚动条

- 时间：2026-11-22 13:30–13:45 +0800。负责人截图反馈：右栏打开 `build5.log` 后长日志行把预览撑出横向滚动条，要求去掉。
- 用户可见变化：文件预览（只读代码查看器）中的长行——日志、URL、压缩后的 JSON 等——在代码区内自动折行，底部不再出现横向滚动条；行号仍只标在逻辑行首行，折行内容缩进对齐，选中/搜索高亮/行内批注不受影响。
- 根因：`FileChangePreview.module.css` 的 `.source` 用 `overflow: auto` 同时承担横纵滚动，`.codeContent` 又固定 `white-space: pre`，长 URL 必然把内容撑宽。
- 修复：`.source` 改为 `overflow-y: auto; overflow-x: hidden`；`.codeContent` 改为 `white-space: pre-wrap; overflow-wrap: anywhere`，并保留 `min-width: 0`，让网格列可以收窄。行号列与内容列沿用 `grid` + `align-items: start`，折行后行号仍对齐首行。
- 实测（无头 Chrome，5173 现有 dev 服务，绑定 app1 打开 `build5.log`）：检测页面内所有 `overflow-x: auto/scroll` 且 `scrollWidth > clientWidth` 的容器为 0；长 URL 行 `code` 高度 93px（自动折到 5 行）、`scrollWidth === clientWidth`；浅色与深色均无横向滚动条，控制台 0 错误。截图：`%TEMP%\lfaa-icons\log-final.png`、`one-line.png`、`log-dark.png`。
- 门禁：`tsc -b tsconfig.host.json` 0；`pnpm check` 0 错误 / 4 条既有警告（55 包 469 源文件）；`pnpm lint` 458 文件 0 问题；完整测试套件通过。
- 范围：只改文件预览的换行与滚动策略；Diff 视图保持原有横向滚动（对照差异更清楚），文件树/标签/面包屑未动。
