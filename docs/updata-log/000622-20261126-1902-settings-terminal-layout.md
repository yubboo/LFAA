# UPDATE-000622｜设置中心「终端」页与其它设置页同一套版式

- 时间：2026-11-26 19:02（Asia/Shanghai）
- 类型：fix（界面一致性 + 文案）

## 变化

- 「终端」页现在有和其它设置页一致的页标题与 56rem 内容列：标题下是「布局」分组，一行「展示位置」，右侧是「右侧面板 / 底部面板」分段选择，控件与页面右缘对齐。
- 说明文案改为实际行为：「在右侧工作台以标签页打开，或停在工作台底部。」底部面板只在右侧工作台列内，不再写成「铺在中间与右侧下方」。
- 切换位置仍然即时生效，刷新后保留；选中态由位置偏好本身驱动，不再依赖工作台内部的重渲染。

## 怎么验证

打开设置中心 → 终端：应看到大标题「终端」、分组「布局」与一行「展示位置」。点「底部面板」，右侧工作台列底部应出现终端；点「右侧面板」回到右侧标签。
