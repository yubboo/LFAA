# UPDATE-000472｜活动行：动词与目标文件名落在同一条基线上

- 时间（含时区）：2026-11-24T20:52:00+08:00
- 类型：修复
- 关联开发日志：`../dev-log/000401-000600.md`（DEV-000472）

## 用户能看到的变化

- 工具活动行里「正在读取中 / 已读取 / 已分析 …」这类动词，与后面的目标文件（如 `docs/index.html`）现在压在同一条基线上；此前目标文本被抬高约 4.5px，看上去像浮在上面一行。
- 只在带文件彩标（橙色/彩色文件图标 + 路径）的行上有可见变化；纯文字目标的行本来就对齐，不受影响。

## 影响范围与使用提示

- 只影响活动行标题内部的基线对齐方式；行高、图标槽、耗时、状态图标、展开箭头与右侧对齐均未改动。
- 深浅主题一致，无颜色变化。

## 已知限制

- 中文动词的字形底边会比拉丁路径低约 1 个物理像素（汉字字形自带的下沉），属字体度量差异，不是错位。
