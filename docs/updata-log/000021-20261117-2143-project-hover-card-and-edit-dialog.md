## 用户能看到的变化

- **左二项目行悬停双操作**：鼠标移入左二菜单栏任意项目行时，右侧会平滑露出两个操作图标：
  - **`···`（查看项目信息）**：鼠标悬停或点击即可在左侧栏外侧弹出悬浮项目信息卡。
  - **`✎`（在该项目里开新聊天）**：点击可定位到对应项目并展示项目内新聊天准备提示（待后续聊天服务接入后直接发起对话）。
- **悬浮项目信息卡**：展示当前 **项目名**、右上角 **图钉置顶开关**（点击可一键将项目置顶至左二 **`置顶`** 分组或取消置顶）、真实 **聊天次数**（当前为 `0 次聊天`）、绑定的 **源文件夹列表与路径**，以及底部的 **⚙ 编辑项目** 入口。
- **“编辑项目”整页居中弹窗**：点击“编辑项目”可修改项目名称、自由增删多个本机源文件夹（继续保留资源管理器选择及路径输入绑定两种方式）、点击左下角 **“移除本地项目”** 安全移除索引，或点击 **“保存”** 实时持久化并同步多目录工作区页签视图。

## 影响范围与使用提示

- 影响 `packages/ui/layout`、`packages/workspace/workspace` 与 `apps/web`；已完成桌面端（`1440×900`）与移动端（`390×844`）全流程及视觉对齐实测，本地开发服务运行于 `http://127.0.0.1:5173/`。

## 已知限制

- 因聊天与 Agent 运行时服务尚未接入，悬浮卡展示真实计数 `0 次聊天`，点击行尾 `✎` 仅切换到对应项目并给出诚实的未接入状态提示，不会伪造对话记录。
