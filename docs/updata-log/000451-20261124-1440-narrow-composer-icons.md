# 000451｜中间栏变窄时输入框不再被挤坏：模式/模型只留图标，位置与项目并进输入卡片顶部

- 时间：2026-11-24 14:08–14:40（Asia/Shanghai）。
- 变化：把右栏拉宽、中间对话区变窄之后，输入框不再出现这些问题：
  - 「标准模式（默认）」以前会被挤成一个「标」字，现在窄栏里直接收成一枚图标（悬停或点开仍能看到完整模式名与说明）；模型和权限胶囊也按同一规则在窄栏收成图标，工具栏放不下时整组换行，发送按钮不会再被顶到卡片外面。
  - 输入框上方那张「此计算机 / 项目名」的小卡以前会压在输入框圆角上，形成两道边、占位文字像贴在边框上；现在它并进输入框卡片顶部，用一条分隔线隔开，宽窄屏都是同一张卡片。
  - 「本项目专注 …」的提示条仍在输入框正上方，行为不变。
- 两种主题都验过：深色、浅色下分隔线、占位文字和图标对比正常；窄栏下项目选择、模式菜单、加号菜单的弹出位置都正常。
