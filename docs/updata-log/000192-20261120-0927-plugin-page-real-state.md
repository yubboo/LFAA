# 插件中心改为展示真实装载状态

- 2026-11-20 09:27 +08:00

## 变化

- 插件中心不再显示旧的硬编码内容，改为展示 Cordis Loader 的真实状态：运行中 / 已停用 / 加载失败。
- 每张卡片显示插件包名（如 `@lfaa/tools`），失败时显示具体错误原因。
- 已被当前应用装配的能力标记为「已装配」，并说明无需也无法单独安装，安装按钮置灰。
- 当前没有安装任何插件时，给出「先安装、再点启用」的引导文案。
- 「二创副本」按钮暂时置灰，并提示该功能尚未实现。

## 验收

- 浅色与深色主题下均已实测：标题、卡片、徽章、空状态显示正常，控制台无 JS 报错。
- 可安装目录 14 项全部为「已装配」，因此安装按钮当前不可用；这是当前装配方式的结果，不是故障。
