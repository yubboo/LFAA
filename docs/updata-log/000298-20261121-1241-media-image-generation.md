# 生图现在真的能用了：调用套餐生图模型并保存到工作区

- 日期：2026-11-21 12:41 +08:00。
- 现在可以对 Agent 说「帮我生成一张海边日落的图片」：它会调用套餐里的生图模型（如 `qwen-image-3.0-pro`），把图片保存到当前项目的 `.lfaa-media/images/` 目录，并在回复里给出完整路径。支持尺寸、张数、seed、水印、负向提示词、指定模型等参数，可配合普通提示词、skill 与其它工具使用。
- 兼容三类接口：阿里云百炼/Token Plan 原生同步接口、火山方舟 `/api/v3/images/generations`、其他 OpenAI 兼容端点；百炼返回的临时图片链接会自动下载落盘（24 小时内有效，避免过期）。
- 实测：真实生成 1024×1024 海边日落 PNG（约 1.3 MB）成功；此前「套餐有生图模型却报 400 / url error」的根因是调错旧接口，已改用原生多模态接口。
- 限制：回复里暂以文件路径呈现（聊天内图片预览、生成画廊、视频与语音生成在后续阶段）。
- 验证。`check`／`lint`／`typecheck`／`build`／`test`（351 项全过）／`probe:loader` 全绿；真实 Agent 工具调用一次成功出图。
