# UPDATE-000638｜刷新页面不再出现「框」

- 时间：2026-11-26 23:56（Asia/Shanghai）
- 类型：fix（刷新后的悬停/焦点残留）

## 变化

- 刷新页面后，如果鼠标指针还停在分组标题上，或浏览器把焦点还给了上次点的按钮，页面不再一打开就出现一个像被选中的框。
- 指针真正移动（或按下键盘）后，悬停底色与键盘焦点框立刻恢复正常，不影响原有交互。
- 聊天模式与工作模式的分组标题一致生效。

## 怎么验证

把鼠标停在「今天」标题上，按 Ctrl+R 刷新：标题不应出现悬停底；移动一下鼠标再悬停，底色恢复。用 Tab 键进入侧栏，焦点框仍按原样显示。
