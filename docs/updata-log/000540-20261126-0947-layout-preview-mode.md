# UPDATE-000540｜设置中心新增「页面排版」：预览区在左 / 聊天区在左

- 日期：2026-11-26（Asia/Shanghai）
- 设置中心 → 常规 → 页面排版，新增一个两选一：**预览区在左** / **聊天区在左**。
- 选「预览区在左」：中间变成代码与文件预览，AI 会话挪到右侧（类似 VS Code / Cursor）；左一图标栏和左二文件树/会话列表不动。
- 选「聊天区在左」：就是现在默认的样子，中间 AI 会话、右侧预览。
- 选择会记住，刷新后保持；窄屏和平板抽屉自动回退「聊天区在左」。
- 本轮是第一步与第二步：切换与列位已经生效；**会话列的拖拽调宽、两侧折叠按钮在该模式下的语义、工作台图标轨的位置**还没调整，下一轮补。
