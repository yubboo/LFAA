# 000337｜会话置顶真正出现在「置顶」区，项目图钉常显可点击切换

- 时间：2026-11-22 00:10 +0800。负责人反馈：点会话的快捷图钉后图标变成强调色，但「置顶」区仍显示「暂无置顶项目或对话」，置顶没生效；另外 app1 行上没有图钉，只有通过 `···` 菜单点「置顶」后才出现图钉。
- 置顶会话现在会出现：在「最近」或项目下点会话的快捷图钉，会话会进入顶部「置顶」区（未归档；若它所属项目已在置顶区带出会话，则不重复列一行）；点顶部这条置顶会话可正常打开，并且只高亮它自己。
- 项目图钉常显：每个项目行右侧都有图钉，未置顶是灰色、点一下即置顶；已置顶变成强调色、点一下取消置顶。不再需要绕到 `···` 菜单里操作。
- 强调色规则不变：强调色只代表「已置顶」，未置顶的行不出现强调色。
- 页面刷新（Ctrl+F5）后生效；本轮只改前端导航数据组装与样式，宿主无需重启。
