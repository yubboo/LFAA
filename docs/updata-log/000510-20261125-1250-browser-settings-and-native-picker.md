## 用户可见变化

1. **Windows 选择文件夹（资源管理器）秒开且清晰原生**
   - Electron 桌面端直接调用系统原生 `dialog.showOpenDialog`，毫秒级弹出并跟随 Windows 深浅主题与中文界面；
   - Web 端预编译缓存原生 `IFileOpenDialog` 组件 DLL，彻底消除每次点击反复编译导致的卡顿，并开启高分屏 DPI 清晰度与中文「选择文件夹」按钮。
2. **设置中心「浏览器」页全面升级（含 6 个管理子页）**
   - **内置浏览器常规**：智能体控制总开关、网页 URL / 本地开发 URL 默认打开位置、地址栏显示完整网址、批注截图策略、一键清除浏览数据。
   - **浏览历史 & 下载历史记录子页**：按日期分组、搜索过滤、「智能体」访问标签、在资源管理器中定位已下载文件、单条删除与一键清空。
   - **自动填充与本地加密密码管理器**：支持添加/查看/搜索/删除凭据、密码与通行密钥开关、CSV 导入导出、联系信息自动填充（本地 AES-256-GCM 加密存储）。
   - **下载设置**：支持直接调用原生资源管理器更改下载位置，以及「下载前询问保存位置」开关。
   - **浏览器权限与安全控制**：网站访问/下载规则表（默认「需要批准 / 始终允许 / 屏蔽」+ 添加域名/通配符例外，直接对智能体导航生效）、历史访问策略、网站设置（位置/摄像头/麦克风/通知/嵌入式内容/第三方 Cookie/JS/图片/弹窗/自动撤销）、开发者模式「启用完整 CDP 访问权限」高风险开关与本地扩展程序管理器。
