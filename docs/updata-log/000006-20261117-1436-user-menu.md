# UPDATE-000006｜左下角用户菜单

- 时间（含时区）：2026-11-17 14:36 +08:00
- 类型：新增
- 关联开发日志：`../dev-log/000006-20261117-1436-user-menu.md`

## 用户能看到的变化

- 左下角新增圆形用户头像入口。点击可展开个人菜单，包含智能伙伴、邀请好友、个性化、个人资料、设置、帮助和退出登录。
- “个性化”和“设置”进入已有外观页；头像菜单样式随浅色、深色或系统主题变化。
- 点击菜单外部或按 Escape 可关闭菜单；Escape 关闭后焦点回到头像入口。
- 账户资料、邀请、智能伙伴及登录能力尚未接入，菜单会显示本地模式或不可用说明，不会假装操作成功。

## 使用与验证

- Web 预览：`http://127.0.0.1:5173/`。
- 已在运行页面检查浅色、深色呈现、菜单打开/关闭、外观页跳转和未接入能力提示；类型检查与生产构建通过。

## 已知限制

- 当前菜单显示本地用户状态，不代表已有真实账户、会员或认证会话。
- 帮助与退出登录仅提供本地模式提示；没有远程服务调用。
