# 000463｜桌面端固定使用 5173：占用时先结束旧进程再重启

- 时间：2026-11-24 18:49–18:58（Asia/Shanghai）。
- 变化：
  - **桌面端固定监听 `127.0.0.1:5173`**：Electron 窗口地址固定为 `http://127.0.0.1:5173/`，不再每次随机换端口；Web 端与桌面端共用 5173，同一时间只跑一个入口。
  - **菜单 3 启动桌面端**：先结束已在运行的 LFAA 桌面端（含宿主子进程，释放单实例锁），再结束占用 5173 的进程并等端口真正释放，然后重启桌面端；如果端口被系统进程占用导致释放失败，会明确提示而不是留下空白窗口。
  - **菜单 2 启动 Web**：同样先结束桌面端，再从干净的 5173 启动 Web，避免桌面宿主被单独杀掉后弹出「LFAA 已停止」错误框。
  - 桌面宿主发现 5173 被占用时会给出可读提示：关闭占用程序后重试，或用仓库菜单 3 自动释放。
- 验证：`pnpm typecheck` 0 错误、`pnpm build:desktop:app` 通过、`pnpm lint` 587 文件 0 问题；5173 被占用时直接启动宿主会输出固定端口占用提示并以退出码 1 结束；`lfaa.bat 3` 实测输出「端口 5173 被占用：node.exe（PID 32500），正在结束占用进程…」「端口 5173 已释放。」后进入桌面端启动流程。本 Agent 会话内 Electron 受沙箱限制会以 `0x80000003` 退出，窗口与单实例重启需在普通终端双击 `lfaa.bat` 选择 3 实测。
