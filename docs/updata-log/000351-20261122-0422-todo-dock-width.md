# UPDATE-000351｜任务清单卡片与输入框同宽对齐

- 时间（含时区）：2026-11-22 04:22 +0800
- 类型：修复
- 关联开发日志：`../dev-log/000201-000400.md`（DEV-000351）

## 用户能看到的变化

- 输入框上方的任务清单卡片，现在和输入框**完全同宽、同左边缘**（此前比输入框宽，左右各多出一截）。桌面、深色、390px 窄屏三种情况下实测偏差均为 `0px`。

## 影响范围与使用提示

- 仅影响 `@lfaa/chat` 客户端中任务卡的外层容器：复用输入栏原有的 `composerStack` 列宽（`--chat-column-width` + 居中），没有改动卡片内部布局与交互。
- 轨迹视图里的任务卡不受影响（它本来就在轨迹面板的整列宽度内）。

## 已知限制

- 任务卡宽度跟随输入栏列宽，因此窗口极窄时卡片也会同步收窄（与输入框一致）。
