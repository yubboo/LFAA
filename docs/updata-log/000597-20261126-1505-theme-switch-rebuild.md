# UPDATE-000597｜账号菜单里的外观切换换成参考图那枚发光拨动开关

- 日期：2026-11-26（Asia/Shanghai）
- 之前账号卡片右上角是一枚「跟随系统 ▾」胶囊，点开再选三项，字多、在窄卡片里还占一行。
- 现在换成参考图里的拨动开关：玻璃轨道 + 带光晕的方块滑块，滑块里是像素月亮/太阳。深色档冷紫辉光，浅色档暖琥珀辉光。
- 三档：左＝深色、中＝跟随系统、右＝浅色，点轨道哪一段就切到哪一档；键盘方向键 / Home / End 也能移动，Esc 仍只关菜单。
- 「跟随系统」档显示哪个图标，取决于系统实际解析出的明暗，不是固定月亮。
- 卡片太窄（左二栏 <约 225px）时，开关落到账号名下方一行；再窄（卡片约 130px）才整体收起。外观设置页里仍保留完整的三选一。
