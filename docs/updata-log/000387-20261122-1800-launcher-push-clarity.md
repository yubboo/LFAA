# UPDATE-000387｜推送菜单说清楚「推了什么」，不再显示过期的提交信息

- 时间：2026-11-22 17:50–18:05 +0800（Asia/Shanghai）
- 类型：体验优化

## 你会看到什么

- 推送菜单不再显示「上次提交的信息是 …」——那行读的是菜单自己记的旧值，直接 `git commit` 之后就是过期信息。现在显示「当前 HEAD：…」，永远等于 `git log -1`。
- 工作区没有新改动、但本地已有提交时，会先列出「将推送 N 个提交」和每个提交的摘要，而不是只报一句「直接推送当前提交」。
- 本地已经和 `origin/main` 同步时，直接提示「没有需要推送的提交」，不再执行一次空推送。
- 仓库地址改为小写 `lfaa`：GitHub 已把仓库改名，旧地址每次推送都会回「repository moved」。下次运行菜单会按脚本既有逻辑把 `origin` 改写成新地址。

## 兼容性

- 只改推送菜单的提示文案与「无待推送时短路」两处；提交、安全检查与强制推送（选项 5）行为不变。
- 提交仍走 pre-commit 的空白检查、`check`、`lint` 与日志编号检查。
