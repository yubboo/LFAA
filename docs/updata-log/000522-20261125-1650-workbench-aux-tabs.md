# UPDATE-000522｜终端/文件/侧边提问改为独立标签页

- 日期：2026-11-25（Asia/Shanghai）
- 右侧工作台的终端、工作区文件树、侧边提问等不再是「一次只能开一个、切换就消失」的面板，而是和浏览器、文件、变更一样各自独立成标签。
- 可以同时打开「终端」「工作区文件」两个标签并来回切换；再新建浏览器标签也不会把它们顶掉。
- 每个辅助标签都带关闭按钮；关闭最后一个内容标签且没有其它标签时，右栏仍会整体收起。
- 新开的标签追加在所有标签之后、「+」的左侧，不再按类型插到中间；「+」紧跟最后一个标签，不额外拉开距离。
- 标签栏不再显示固定的「工作台」占位标签；启动页仍会在需要时显示。
- 关闭右栏最后一个标签（终端、文件、浏览器或审查）时，右栏都会整体收起。
- 展开右侧菜单栏会自动出现一个「新标签页」；此时点「变更」「终端」「文件」「侧边提问」，会把当前空白标签直接变成对应标签，不会再冒出第二个标签，也不会只剩一个孤零零的「+」。
