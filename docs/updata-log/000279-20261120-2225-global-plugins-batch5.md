# 任务 000279｜全局插件第五批：定时任务

- 插件中心「全局插件」再增 1 项（26 → 27）：**定时任务**。
- Agent 现在可以登记「30 分钟后提醒我看日志」这类任务，支持一次性或重复（每 N 分钟 / 每天固定时刻）；任务存在 `~/.lfaa/schedules.json`，跨会话保留。
- 到期由 `schedule_due` 工具领取：重复任务自动推进到下一次，一次性任务取走即移除；另有 `schedule_list`、`schedule_cancel` 管理。
- 说明：这一版**没有后台定时器**，不会在你没操作时偷偷起一次 Agent 运行；到期项需要 Agent 在对话里领取（后续可以加界面轮询/通知）。
- P0 只剩 3 条：向用户提问（与已有澄清工具重复，待你定夺）、压缩命令、系统提示装配。
