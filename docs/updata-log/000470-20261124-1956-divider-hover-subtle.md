# UPDATE-000470｜分隔条：悬停不再是一条粉色粗线，且顶部一段也能拖、也有提示

- 时间（含时区）：2026-11-24T19:56:00+08:00
- 类型：修复
- 关联开发日志：`../dev-log/000401-000600.md`（DEV-000470）

## 用户能看到的变化

- 鼠标移到左二栏与中间区之间、或中间区与右侧栏之间的分隔条上时，提示线从**2px 粉线**改成**1px 中性细线**：不再抢眼，也不会因为半透明粉叠在两种底色上而一边深一边浅。
- 强调色只在**真正按住拖动**（2.5px）和**吸附到位**（3px + 光晕）时出现。
- 分隔条的顶部一段（顶栏那条的高度）现在也计入悬停与拖拽：以前鼠标移到最上面那截没有反应、提示线也断在那里，现在整条从窗口顶到底都能拖、提示线也是连贯的。

## 影响范围与使用提示

- 只影响分隔条的悬停/拖动视觉与顶部命中范围；左右栏宽度、吸附档位、折叠逻辑不变。
- 鼠标靠近顶栏左缘 5px 内会优先命中分隔条（顶栏自身控件有 1.25rem 内边距，不会被误触）。

## 已知限制

- 非整数缩放（如 125%）下 1px 线仍会落在半个像素上，边缘会有极轻的抗锯齿；这是缩放导致的，无法只靠 CSS 消除。
