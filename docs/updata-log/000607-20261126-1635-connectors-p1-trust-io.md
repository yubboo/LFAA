# UPDATE-000607｜连接器：动作单独授权 + 配置可导入导出

- 时间：2026-11-26 16:35（Asia/Shanghai）
- 类型：feat（连接器增强）

## 变化

- **动作级审批**：每个动作可以单独设置「继承连接器 / 每次确认 / 始终允许」。例如让只读查询免确认、写操作仍然逐次确认；默认继承连接器设置。
- **导出连接器**：命令行工具每行新增「导出」，弹窗里可以直接复制或下载 JSON。导出内容包含环境变量的字面值，界面已标注请勿分享到不可信位置。
- **导入连接器**：命令行工具分区右上角新增「导入」，粘贴之前导出的 JSON（单个对象、数组或 `{ "connectors": [...] }`）即可；导入后默认停用，确认无误再打开开关，重名会被拒绝。

## 怎么用

设置中心 → 集成 → 连接器 → 命令行工具：

1. 点某个工具「编辑」→ 在动作卡片的「审批」里单独选择授权方式；
2. 点「导出」复制/下载配置；
3. 点右上「导入」粘贴 JSON，导入后打开该行的开关启用。
