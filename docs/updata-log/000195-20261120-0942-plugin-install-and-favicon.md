# 插件可安装、二创有反馈、图标不再 404

- 2026-11-20 09:42 +08:00

## 变化

- 插件中心「可安装」区现在真的有可装的包：浏览器、后台任务、子智能体默认不再随应用启动，可由你自行安装并启用。
- 安装后点「启用」会真正装载；对应接口随之可用。
- 「二创副本」不再是一个无声失败的按钮：会先复制插件包，再检查依赖能否解析；不能解析时立即删除副本并说明原因，不会留下装不上的残留。
- 浏览器标签页不再显示 404 图标错误，应用有了自己的图标。

## 验收

- `catalog=14 / provided=11 / installable=3`；安装并启用浏览器插件后状态为运行中，`/api/browser` 返回 200。
- `/favicon.ico` 返回 200。
- 二创在当前 Windows 环境会明确提示需要 profile 级依赖安装，且不产生残留记录。
