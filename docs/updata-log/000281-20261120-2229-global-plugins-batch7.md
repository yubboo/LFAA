# 任务 000281｜全局插件第七批：压缩命令（P0 收官）

- 插件中心「全局插件」再增 1 项（28 → 29）：**压缩命令**。给 Agent 一个 `compact_context` 工具，对话太长时可以主动请求压缩，下一次模型调用前按更小预算强制压一轮（只留系统提示、最近两轮和最后一条需求）。
- 为什么做成工具而不是按钮：压缩发生在运行内部，工具调用正好落在下一轮模型调用之前；做服务端接口 + 前端斜杠命令改动面更大、收益相同。要按钮的话后续加 `/compact` 即可。
- 压缩请求是一次性的，登记后由压缩服务消费一次即清除；说明文字会告诉模型"下一轮才生效"，避免它误以为上下文已清空。
