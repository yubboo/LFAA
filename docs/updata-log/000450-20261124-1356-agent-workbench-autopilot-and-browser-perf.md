## 本次变更

1. **所有 Agent 接入右侧工作台自测验收闭环**
   - 统一为单聊小鱼、自定义 Agent、子智能体及群聊成员注入右侧工作台与内置浏览器闭环验收准则：凡涉及网页、前端 UI 或动画任务，自动在右侧内置浏览器打开实测、检查控制台与网络、对照用户需求进行视觉或 DOM 自检，发现不符或异常会自主循环修复后再交付。

   - 右上角操作栏新增「跟随 Agent」开关（默认开启并持久化）；运行中手动折叠右栏后本轮不再抢焦点，下一轮自动恢复。
