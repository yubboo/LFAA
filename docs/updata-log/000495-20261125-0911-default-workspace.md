# UPDATE-000495｜默认工作区放到「文档\lfaa\default-workspace」

- 日期：2026-11-25（Asia/Shanghai）
- 项目外「新聊天」的默认工作区从 `~/.lfaa/workspace` 改为 `<系统文档>\lfaa\default-workspace`：路径跟随系统的「文档」位置，不写死盘符或用户名（文档被重定向到 D 盘时会自动落在 `D:\Documents\lfaa\default-workspace`）。
- 首次启动自动创建这个目录；设置 → 常规 的「项目外聊天文件夹」会显示实际路径与新的说明。
- 老配置自动升级：如果之前一直是默认值，会平滑迁移到新目录；手动改过的目录保持不动。对话历史仍然固定存在 `~/.lfaa/sessions`。
- 桌面端同样使用系统「文档」下的默认工作区。
