# UPDATA-000449｜内置浏览器全面重构：原生直连 + 高清低延迟协同双引擎、防滚动穿透与去白雾

- 时间：2026-11-24 12:48 +08:00
- 关联开发日志：`docs/dev-log/000401-000600.md`（`DEV-000449`）

## 本次变更

1. **双引擎自动切换（原生直连 + 高清协同）**
   - 本地开发预览（如 `localhost` / `127.0.0.1`）以及未限制嵌入的网页默认使用**原生 `<iframe>` 直连**，具备 60/120fps 原生清晰度、丝滑滚动、完整选字/悬停/右键与动画体验。
   - 遇到设置 `X-Frame-Options` 或 `CSP frame-ancestors` 禁止嵌入的公网站点、与工作区同源地址，或小鱼 Agent 主动操控浏览器时，自动切入重构后的**高清低延迟 CDP 协同视图**；工具栏新增「原生 / 协同」一键切换按钮。
2. **彻底修复滚动越界乱跑与穿透**
   - 视口挂载原生非被动滚轮监听并启用 `overflow: hidden` + `overscroll-behavior: none`，受控页面同步注入根滚动防越界规则，到达顶部或底部时立即刹停、绝不穿透拖动外层工作区。
   - 远端滚轮附带真实鼠标指针坐标 `(x, y)`，采用单帧合并与单在途背压机制，避免请求堆积导致停手后画面继续乱滚。
3. **大幅提升流畅度、清晰度并去除白雾遮罩感**
   - 新增超轻量 `POST /api/browser/input` 通道（直接复用常驻 CDP 派发键鼠并返回 `204`），前端协同视图改用 `<canvas>` + `createImageBitmap` 双缓冲绘制，绕过每帧 React 重渲染，并修复 `ResizeObserver`/`MutationObserver` 每帧重建及聚焦地址栏断流问题。
   - 补齐鼠标悬停、按住拖拽选字与常用编辑快捷键（`Ctrl+A/C/V/X/Z`）。
   - 修复高分屏 DPR 重置、1× 有损 JPEG 放大发糊及同源嵌套递归互抢视口引起的左右留白与闪抖问题：后端锁定 `--force-device-scale-factor=2` 直接输出恒定 2× Retina 无损 PNG，并阻断内嵌页递归打开第二套右栏与隐藏标签抢占视口；同时去除右工作台壳层的白色高光渐变与玻璃滤镜，画面纯净通透。
4. **严格控制权隔离与 Agent 接管知情**
   - 默认由 Agent 控制时，视口盖全透明防误触护盾（零白雾）并锁定地址栏、前进/后退/刷新与远端输入，点击视口弹出「立即接管」提示；
   - 用户点击「接管」后立刻解锁全部操作，并通过每轮动态系统提示与工具守卫实时通知 Agent「用户已接管浏览器并暂停自动化」，点击「交还 Agent」后无缝归还控制权。
