# 任务 000255｜主题色全面变量化

- 界面里的状态色、链接色、增删色、差异高亮、遮罩与开关控件不再写死颜色，全部改为语义变量并在浅色/深色下成对定义。最直接的体感：浅色主题下状态提示、正文链接、危险操作文字的可读性明显变好（此前部分状态色在白底上对比度只有 1.6–2.8:1）。
- 新增状态/语义色一律按浅色深色成对提供，正文对比度保证 ≥ 4.5:1；组件里不再需要为浅色单独写颜色覆盖。
- 开发规则新增硬性条款：项目代码严禁写死颜色，只允许消费语义变量；由 `pnpm check` 自动拦截，写死色值只允许出现在变量定义层、代码高亮调色板与主题预览样张（5 个文件登记在豁免清单，只减不增）。
