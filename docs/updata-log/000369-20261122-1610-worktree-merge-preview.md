# UPDATE-000368｜工作树合并预演：先看能不能干净合，再决定要不要合

- 时间：2026-11-22 16:10 +0800（Asia/Shanghai）
- 类型：新功能

## 你会看到什么

- 项目详情每个工作树多了一个「合并预演」按钮。
- 点击后只读检查并显示：
  - 「可干净合并」；
  - 或「有冲突：文件列表」；
  - 「已包含全部提交」；
  - 主工作区有未提交改动、主工作区不在起点分支时会额外提示。
- 预演不会切分支、不会改文件、不会写 Git 索引；真正合并仍需你复制命令或自行操作。

## 兼容性

- 旧工作树没有起点分支时，预演用提交短哈希作为基准，仍可提示是否已包含全部提交。
- 不会自动合并、不会自动删分支。

## 说明

「复制合并命令」仍然保留：预演通过后，你可以在主工作区自行执行 `git merge --no-ff <工作树分支>`。
