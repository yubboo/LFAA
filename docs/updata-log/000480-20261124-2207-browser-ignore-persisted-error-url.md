# UPDATE-000480｜内置浏览器：恢复历史会话时自动忽略 chrome-error:// 脏地址

- 时间（含时区）：2026-11-24T22:07:00+08:00
- 类型：修复
- 关联开发日志：`../dev-log/000401-000600.md`（DEV-000480）

## 用户能看到的变化

- 修复了刷新或重进旧会话时，因本地缓存残留 `chrome-error://chromewebdata/` 导致内置浏览器自动跳转并弹出「出于安全边界，内置浏览器仅支持 http/https 协议，已拦截：chrome-error:」报错横幅的问题。
- 内置浏览器现在只在 URL 为合法 `http://` / `https://` 时写入本地缓存，恢复历史会话时自动过滤非 `http(s)` 脏地址。
