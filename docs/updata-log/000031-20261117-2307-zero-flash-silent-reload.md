# UPDATE-000031｜实现页面刷新零闪烁秒开与后台静默同步

- 时间（含时区）：2026-11-17 23:07:10 +08:00
- 类型：体验优化
- 关联开发日志：`../dev-log/000031-20261117-2307-zero-flash-silent-reload.md`

## 用户能看到的变化

- **刷新零闪白 / 零色偏**：按 `F5` 或重开工作区页面时，首帧绘制前即直接恢复你的明暗主题、液态玻璃背景色与强调色，不再闪现一瞬白色或默认主题。
- **项目、分区与目录树秒开直出**：刷新页面时侧栏不会先闪回“还没有项目”再跳出列表，也不会闪现“正在读取项目目录...”或“暂未接入”中间画面；页面会以本地快照零延迟渲染，同时在后台静默向本地服务核对最新变化（数据未变时完全无感，不触发多余重绘）。

## 影响范围与使用提示

- 影响网页入口、工作台初始化以及项目/分区客户端缓存；已在桌面端 `1440×900` 完成停留在自定义分区与项目详情页下的真实 `domcontentloaded` 秒开与后台校对实测。

## 已知限制

- 若切换全新浏览器或无痕模式，首次访问无本地缓存时仍会请求后端拉取一次初始列表，随后即启用秒开缓存。
