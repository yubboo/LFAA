# 000162｜长任务上下文有预算，关应用不再卡住

2026-11-19 22:47 +08:00

- 一次任务内的对话有预算（默认 16 万字符）。信息过多时会自动压缩早期工具结果；模型报上下文超限时会压缩后重试，不再整轮失败。
- 单次读取/检索/命令输出有上限，截断处会提示如何续读；模型输出被长度截断时会提示拆成多次写入。

- 终端命令超时会连同子进程一起结束；命令不能读取应用的模型配置、凭据和会话文件；子进程不再继承模型 API Key；每条命令记入本地审计日志 `~/.lfaa/logs/commands.jsonl`。
- 命令仍以当前用户权限运行，尚未提供操作系统级隔离。
