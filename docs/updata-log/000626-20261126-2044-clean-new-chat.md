# UPDATE-000626｜新会话页面更简洁：去掉对话/轨迹与项目范围提示

- 时间：2026-11-26 20:44（Asia/Shanghai）
- 类型：fix（新会话界面收敛）

## 变化

- 新会话（还没有消息）不再显示「对话 / 轨迹」切换条，中心只保留标题、聊天/工作分段、输入栏与起步建议。
- 输入框上方不再常驻「本项目专注…」的项目范围提示条；正常新会话更干净。
- 真正的异常提示仍由既有错误横幅展示，只在出错时出现。
- 打开有消息的历史会话后，「对话 / 轨迹」切换条恢复；从轨迹切回新会话会自动回到对话空态。

## 怎么验证

新建聊天：顶部不应有「对话 / 轨迹」，输入框上方不应有「本项目专注…」。打开一条历史会话：切换条应恢复；在历史会话点「轨迹」后再新聊天，应直接回到干净的对话空态。
