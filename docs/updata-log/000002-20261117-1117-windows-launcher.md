## 用户能看到的变化

- 双击根目录 `lfaa.bat` 可打开 Windows 菜单并安装当前工作区依赖。
- Web 启动项会先检查应用入口配置；骨架阶段会说明入口尚未就绪，不会运行不存在的应用。

- 配置 CLI 入口 `apps/cli/src/bin.ts` 和根 `package.json` 的 `lfaa` 命令后，Web 启动项才可用。
