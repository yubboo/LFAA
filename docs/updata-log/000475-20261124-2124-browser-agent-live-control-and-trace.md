# UPDATE-000475｜浏览器子智能体操控体验升级：意图硬分流、15 步定向验收、真人光标轨迹与自动展开

- 时间（含时区）：2026-11-24T21:24:00+08:00
- 类型：优化
- 关联开发日志：`../dev-log/000401-000600.md`（DEV-000475）

## 用户能看到的变化

- **「帮我打开浏览器看效果」不再重跑验收**：主 Agent 明确区分「纯预览」与「定向验收」，说查看/预览时仅调用一次 `browser_present` 展开右侧浏览器并立即结束（实测 4 秒、1 步完成）。
- **浏览器子智能体告别无头苍蝇盲扫**：默认步数上限由 40 步收紧为 15 步，禁止用 `browser_evaluate` 改 `scrollTop` 逐屏盲扫与双重截图，改为真实点击/输入/平滑滚动 + 1–3 次视觉抽检；实测单页网站验收从原先 4 分 25 秒 / 43 步降至 **46 秒 / 12 步**（复验 9 步），并精准抓出 `/favicon.ico` 404 后自动修复复验通过。
- **像真人一样的页面操控可视化**：Agent 点击、悬停、输入、滚动页面时，内置浏览器画面内实时展示平滑移动的虚拟光标、目标元素高亮框、点击波纹与动作标签（如「点击 · 预约吧台座位」「向下滚动」），视觉截图验收前自动隐藏不遮挡画面。
- **右侧浏览器自动展开 & 卡片实时可见截图缩略图**：浏览器子智能体启动时自动展开右侧工作台并切到浏览器舞台；思维链卡片实时转发阶段思考摘要，并直接在卡片内展示「实时验收截图」缩略图条（点击可展开大图）。

## 影响范围与使用提示

- 浏览器子智能体首次启动时自动展开右侧栏；若你在同一次运行中手动收起右侧栏，后续步骤会尊重你的收起选择不再反复弹回。
- 深色/浅色双主题下卡片与缩略图条均消费 `@lfaa/ui-theme` 语义变量。
