# UPDATE-000630｜新会话标题显示当前项目，并拉开间距

- 时间：2026-11-26 21:16（Asia/Shanghai）
- 类型：feat（引导区标题）

## 变化

- 在项目里新建会话时，中心标题会显示真实项目名，例如「你想让我们在 **app1** 中构建什么？」；项目名带浅底与点状下划线，像标题里的变量。
- 未绑定项目时使用「你想聊些什么？ / 你想让我们构建什么？」的通用标题。
- 标题字距、行高与图标/标题/模式分段/输入区的间距都拉开了一些，整体居中，不再显得拥挤。
- 项目名较长时会自然换行，高亮背景在每一行保持完整。

## 怎么验证

在任意项目里新建会话：标题应出现该项目名并单独高亮；切到「聊天」应显示「你想在项目名中聊些什么？」；没有项目的会话只显示通用标题。
