# UPDATE-000372｜工作树「移除并删分支」：只删已合并的分支

- 时间：2026-11-22 17:35 +0800（Asia/Shanghai）
- 类型：新功能 / 安全边界

## 你会看到什么

- 项目详情的工作树行，在「没有聊天绑定、没有领先提交、目录存在」时会出现「移除并删分支」按钮。
- 点击后二次确认：移除工作树，并用 `git branch -d` 删除已合并的分支。
- 分支还没合并时不会强删：工作树会被移除，分支保留，并提示“分支未合并，已保留”。
- 有未提交改动时仍会拒绝删除，避免丢改动。

## 兼容性

- 普通「删除工作树」按钮行为不变，仍然只移除目录、保留分支。
- 未绑定工作树的聊天不受影响。
