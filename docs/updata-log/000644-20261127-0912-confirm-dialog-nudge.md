# UPDATE-000644｜确认弹窗点外面或按 Esc 会轻轻抖一下

- 时间：2026-11-27 09:12（Asia/Shanghai）
- 类型：优化（反馈）
- 关联开发日志：`../dev-log/000601-000800.md`（DEV-000644）

## 变化

- 在删除等确认弹窗里，点弹窗外的空白处或按 Esc：弹窗会横向轻轻抖一下，提示「这里点不掉，得选一个」。
- 只抖，不加边框、不弹提示文字；系统开了「减少动效」时完全不抖。
- 上一版那圈包住按钮的描边框已经去掉。

## 怎么验证

打开「永久删除」确认框 → 点空白处或按 Esc：弹窗抖一下但仍留在原地；点「取消」才会关。

## 已知限制

- 手机上不会震动（iOS 不支持网页震动），只有动效。
- 「减少动效」系统设置下没有任何视觉反馈。
