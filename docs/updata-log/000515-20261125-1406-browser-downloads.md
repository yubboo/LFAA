# 内置浏览器下载接入权限与历史

- 更新编号：`000515`
- 日期：2026-11-25（Asia/Shanghai）
- 开发记录：[DEV-000515](../dev-log/000401-000600.md)
- 设计方案：[内置浏览器下载闭环](../plans/browser-downloads.md)

Playwright 和桌面原生浏览器会按站点规则和默认策略处理下载。需要确认时，可以在右侧浏览器或「设置 → 浏览器 → 下载历史记录」选择保存或取消。开启保存位置询问后，可以为单次下载更改目录。

文件成功保存后自动出现在下载历史。同名文件自动编号，删除历史记录会保留本地文件。Web 原生预览可通过「接管后下载」进入受管视口。
