# UPDATE-000642｜删除等二次确认弹窗只能点按钮关闭

- 时间：2026-11-27 09:00（Asia/Shanghai）
- 类型：修复（破坏性确认弹窗可被误关）
- 关联开发日志：`../dev-log/000601-000800.md`（DEV-000642）

## 变化

- 「永久删除会话」「移出项目」「删除 MCP 服务」「删除命令行工具」「卸载插件」这类确认弹窗，现在必须点「取消」或确认按钮（或右上角关闭）才会关闭。
- 点弹窗外的区域不再关闭它；按 Esc 也不再关闭，且不会连带把背后的菜单一起关掉。

## 怎么验证

会话列表悬停某条会话 → `⋮` → 永久删除：弹窗出现后点空白处、按 Esc，弹窗都还在；点「取消」才退出。

## 已知限制

- 弹窗里仍保留右上角关闭按钮（等于取消）。
- 少数操作（工作树移除 / 合并、清空浏览历史、删除全部密码、撤销本轮修改、Git 丢弃改动）用的还是浏览器原生 confirm，不受本次改动影响。
