# 000447｜项目范围提示改成输入框上方的一条：只在「工作」里出现，聊天不打扰

- 时间：2026-11-24 10:19–10:40（Asia/Shanghai）。
- 变化：在项目里新开聊天时，原来输入框下面压着一张三行卡片（「本项目专注 · 项目名」+ 简介 + 规则说明），占地方也抢视线。现在换成输入框正上方的一条细边框提示：
  - 一行文字，形如 `本项目专注「app1」 · 做一个插件市场`；简介太长就省略号收尾，鼠标悬停能看到完整的范围规则。
  - 项目还没填简介时，提示改成「项目简介尚未填写，AI 会先与你确认项目目标再开工」。
  - **只在「工作」模式出现**：聊天模式不显示这条提示；没绑定项目的会话也不显示。切回聊天，提示立刻消失。
- 没变的：系统提示里的项目范围与「跑偏先提醒再询问」规则原样保留，聊天模式只是不再用界面提示强调它。
