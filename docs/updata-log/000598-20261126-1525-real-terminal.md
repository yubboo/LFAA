# UPDATE-000598｜右栏有了真正的终端（PTY），旧任务面板改名「后台任务」

- 日期：2026-11-26（Asia/Shanghai）
- 右侧工作台新增 **终端** 标签：真 PowerShell（Windows 用 ConPTY），支持 `cd`、交互命令、颜色、Ctrl+C、拖大面板自动重排行列。
- 原来的「终端与后台任务」其实只是「跑一条命令看输出」，现在改名为 **后台任务**，两个入口并排，互不冒充。
- `Ctrl+↓` 现在打开真实终端（原来打开的是任务面板）；后台任务仍可从右侧图标轨进入。
- 断线/刷新不会杀终端：页面刷新后回到同一个终端，输出会补回来；关标签或切会话时才回收进程。
- 底部面板与「右侧 / 底部」位置切换还没做，下一轮补。
