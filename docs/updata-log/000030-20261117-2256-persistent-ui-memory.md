# UPDATE-000030｜新增工作台持久化记忆，刷新页面不再重置收起状态与当前页面

## 用户能看到的变化

- **侧栏分组收起/展开永久记住**：无论是左二栏的 **「项目」**、**「置顶」**、**「最近」**，还是你自己新建的任意 **自定义分区**，收起或展开后刷新页面都会保持你的选择（不再刷新后自动重新展开）。
- **页面、项目与左右栏状态完整续接**：刷新浏览器后会直接回到你刚才正在查看的页面或项目详情，同时记住 **左侧栏 / 右侧上下文栏收起状态**、**项目排序方式**（按创建时间 / 按名称）、**工作模式**（ChatGPT / Codex）、**外观高级选项展开状态** 以及多源文件夹项目的 **当前选中目录页签**。
- **失效状态安全回退**：如果正在查看的本地项目已被外部移除，刷新加载后会平滑退回工作区首页，不会停留在报错页面。

## 影响范围与使用提示

- 持久化记忆自动保存在当前浏览器本地存储（与外观点数设置一致），桌面端与窄屏移动端抽屉自动收起互不覆盖。
- 已完成 12 项单元自动化测试及两次真实浏览器全量刷新实测。

## 已知限制

- 当前记忆保存在本机浏览器本地存储中，使用无痕模式或更换浏览器会以默认初始状态启动。
