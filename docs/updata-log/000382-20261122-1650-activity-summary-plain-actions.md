# UPDATE-000382｜活动行不再说「N 项操作」，改成看得懂的「已运行命令、已读取 2 个文件」

- 时间：2026-11-22 16:39–16:52 +0800（Asia/Shanghai）
- 类型：体验优化

## 你会看到什么

- 一轮里有多步操作时，折叠的活动行会直接说明做了什么，并按真实先后并列：
  「已运行命令 · mvn -B -o clean test、已更新任务清单（完成 3 / 共 4）」「已读取 4 个文件」「已查找文件、已读取 pom.xml」。
  不再出现「2 项操作 · 已完成：文件匹配」这类看不出内容的数量前缀。
- 单步动作仍然点名对象：例如「已读取 README.md」「已编辑 README.md」「已运行命令 · npm test」。
- 同类动作不超过三个时直接列出对象，超过三个才报数量（「已读取 4 个文件」），避免摘要被文件名撑长。
- 运行中的动作只说进行态（「正在读取中」），不会提前写成完成；失败的动作退回中性主体名（「网页抓取」）并保留右侧失败徽标，不再出现「已完成：… 2 项执行失败」这种自相矛盾的组合。
- `glob` / `grep` 不再显示「已完成：文件匹配」这类内部工具名，改为「已查找文件」「已检索内容」，图标也按只读检索处理。

## 兼容性

- 只改活动行摘要文案与其聚合逻辑，不改运行流程、步骤数据与展开区内容。
- 中英文同步；英文为「Ran command · …」「Read 4 files」「Preparing to call …」等对应表述。
