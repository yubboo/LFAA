# 000348｜资料库缩略图落到本机：换浏览器/清缓存也只读小图，右栏预览改 960px

- 时间：2026-11-22 03:58 +0800。
- 之前：缩略图只缓存在浏览器里，换浏览器、清缓存或换桌面端后会重新读取原图（31 张约 180MB）；右栏点开图片还要再取一次完整原图。
- 现在：
  - 浏览器生成一次 480px WebP 后回传给宿主，存到本机 `~/.lfaa/media/thumbs/`（每张约 30–60KB，实测 20 张约 1MB）；之后任何浏览器/客户端都只读这张小图，不再碰原图。
  - 右栏图片预览改成 960px 缩略图（第一次点开生成并缓存，之后 0 请求），不再每次取完整原图；视频/音频仍按需加载播放文件。
  - 宿主未生成缩略图时接口返回 204（不刷错误），客户端生成后自动回传；原图变化时缓存名自动失效。
- 实测（隔离宿主）：第一次进入图像分类 20 张原图 / 127MB（一次性，每张以后不再重复）；换一个全新浏览器配置再进入：0 次原图请求、20 次缩略图命中、首屏约 1.1s；点开图片 62–79ms、960×960、不取原图；同一张第二次点开 0 请求。
- 修复：右栏偶发坏图（旧版本把「宿主未生成」和 SPA 回退页当缩略图缓存）。缓存已升级并自动清理旧条目，读到非 WebP 会删除重生成；坏图会从 960 回退到 480，再失败显示占位文案。
- 需要**重启一次 LFAA** 才会启用新接口；缓存目录可随时删除，会自动重建。
- 首次打开新素材仍会读一次原图来生成缩略图（本机没有服务端缩图能力），之后所有客户端复用。
