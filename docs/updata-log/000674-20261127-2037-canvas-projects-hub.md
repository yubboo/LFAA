# UPDATE-000674｜无限画布新增「我的项目」入口大厅并与左二项目自动绑定

- 日期：2026-11-27
- 关联：DEV-000674

## 用户可见变化

- 打开右侧工作台的「无限画布」后，默认先进入**「我的项目」**大厅页，仅展示已有画布的项目（不混入普通纯代码项目）。
- 支持两种创建方式，创建后均会自动收录至左二会话项目菜单栏并直接进入该项目的画布：
  - 点击网格首卡「**+ 新建项目**」：一键快速创建「未命名项目」并直达画布；
  - 点击右上角「**+ 新建**」：打开创建项目弹窗，自定义项目名称与目录后直达画布。
- 大厅页提供卡片缩放滑块、关键字搜索、排序切换（最近编辑 / 名称）与网格/列表视图切换，完整适配深浅双主题。
- 画布编辑器左上角新增「**< 我的项目**」返回按钮，可随时回到大厅切换或新建项目。
