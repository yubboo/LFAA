# 任务 000274｜全局插件第一批：网页抓取 seam 与目标工具

- 插件中心「全局插件」新增 4 个真实可用的内置插件：**网页能力 seam**、**HTTP 抓取**、**目标服务**、**目标工具**（全局清单从 16 项增至 20 项）。
- 网页能力：抓取实现可替换、按优先级回退；默认 HTTP 实现只允许 http/https（不能拿 `file://` 读本机文件），有超时，单页超过 2MB 会截断并标注，不会把整页大文件灌进上下文。
- 目标能力：Agent 现在能登记长期目标、记录进度、标记完成或受阻（例如「卡在等某个依赖」），目标与进展存在 `~/.lfaa/goals.json`，跨会话还能查回来；回给模型的是摘要，不会刷屏。
- 插件页里这两组都能看到名称与包名，标记「内置 / 已装配」，与既有的会话插件分区不重叠。
- 后续批次继续按 P0 → P1 → P2 清单补齐剩余全局插件（计划模式、定时任务、上下文压缩、长结果落盘、超时策略、权限审批等）。
