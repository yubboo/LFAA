# UPDATE-000531｜外观页改成「预设 / 高级设置」两个 tab

- 日期：2026-11-25（Asia/Shanghai）
- 设置中心「外观」页顶部新增「预设 / 高级设置」选项卡，左对齐内容列，点一下就能切换，不再需要找折叠入口。
- 「预设」页：明暗模式与主题风格两组主题卡，负责挑外观。
- 「高级设置」页：主题细项（主题预设与导入/复制、强调色、背景、前景、界面字体），以及字号、字体、主题与显示、动效与光标。
- 顶部实时预览在两个页都保留，调色时能直接看到效果；「悬停预览 · 点击应用」提示只在「预设」页显示。
- 上次选的页会记住，默认停在「预设」；深色、浅色与窄屏下排版一致。
