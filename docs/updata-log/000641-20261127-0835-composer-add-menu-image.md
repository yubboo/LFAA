# UPDATE-000641｜「生成素材库」入口并入 + 号「添加上下文」菜单

- 时间：2026-11-27 08:35（Asia/Shanghai）
- 类型：feat（新增菜单项）+ 优化（工具行收敛）
- 关联开发日志：`../dev-log/000601-000800.md`（DEV-000641）

## 变化

- 工作模式底部工具行的 `+` 菜单里新增「图片」项，位置在「文件夹」之后、「提及」之前，图标与原按钮一致的图片图标。
- 点「图片」打开的就是原来那枚独立按钮的「生成素材库」弹窗；「复用提示词」仍会回填到输入框。
- 工具行不再单独放这枚图片按钮，`+` 右侧直接是权限（完全访问）胶囊，按钮间距由布局自动补位。

## 怎么验证

新建聊天 → 切到「工作」→ 点左下角 `+`：菜单依次是 文件 / 文件夹 / 图片 / 提及 / 操作 / 浏览器 / 云端硬盘；点「图片」弹出「生成素材库」，Esc 可关闭；工具行只剩 `+` 与权限入口。

## 已知限制

- 素材库入口现在只在菜单里，工具行没有快捷按钮。
- 聊天模式本来就没有素材库，因此聊天模式的菜单里不出现「图片」项。
