# Updata Log 000052 — 聊天输入栏新增工作位置与项目选择挂载条

- **时间**：2026-11-18 08:43:41 +08:00
- **版本号/编号**：000052

## 本次新增功能

1. **输入栏上方工作位置与项目挂载条**：
   - 未绑定项目时显示 `此计算机` 与胶囊按钮 `选择项目`；已绑定项目时显示 `此计算机` 与对应项目名称（如 `lfaa`），替换原底部原生下拉框。
2. **工作位置与项目搜索浮层**：
   - 点击 `此计算机` 可查看工作位置菜单（`此计算机` 已选中；`云端 默认环境` 明确提示暂未接入）。
   - 点击项目入口弹出带 `搜索项目` 输入框的列表菜单，支持实时过滤、当前项目勾选高亮、直接点击 `+ 新建项目` 创建并自动绑定，以及点击 `不在项目中工作` 快速解除绑定。
