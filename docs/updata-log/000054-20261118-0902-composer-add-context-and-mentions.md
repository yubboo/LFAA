# Updata Log 000054 — 输入栏新增 + 添加上下文菜单与 @ 提及浮层

- **时间**：2026-11-18 09:02:51 +08:00
- **版本号/编号**：000054

## 本次新增功能

1. **左下角 `+` 添加上下文菜单**：
   - 悬停 `+` 显示「添加文件等内容 `@`」提示；点击弹出「添加上下文」菜单，支持直接选取本地多个文件或整个文件夹附加到对话，也可一键进入 `@` 提及或查看未接入服务状态（`浏览器` / `云端硬盘 Set up`）。
2. **`@` 提及与模式快捷浮层**：
   - 输入 `@` 或从菜单进入时实时弹出分组列表，支持关键字过滤与方向键/回车选择：
     - **添加**：文件和文件夹、快速唤起项目选择器、激活 `目标` 或 `计划模式` 标签芯片。
     - **LFAA 对话**：快速引用历史会话作为本轮上下文。
     - **插件**：展示可用扩展入口及真实接入状态。
