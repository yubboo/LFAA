# UPDATE-000028｜新增自定义分区（新建/重命名/删除/项目归类）并修正「最近」仅用于聊天会话

- 时间（含时区）：2026-11-17 22:28:00 +08:00
- 类型：新功能与问题修复
- 关联开发日志：`../dev-log/000028-20261117-2228-package-split-sections-and-recent-chats.md`

## 用户能看到的变化

1. **新增自定义分区（新建分区...）**：
   - 打开任意项目的 **`···`** 菜单 → **`分区 >`**，现在不仅可以看到已创建的自定义分区列表（当前所属分区会显示勾选标记），底部还提供了 **`新建分区...`** 入口。
   - 创建分区后，该分区会出现在左二栏「置顶」与「项目」之间；空分区会显示「将聊天、页面或项目拖放到这里」引导提示，悬停分区标题行右侧同样支持 **`···`**（重命名 / 删除分区）与 **`✎`**（在分区内开始新聊天）操作。
   - 支持通过菜单或拖拽方式将项目归类到对应分区，也支持从分区移回默认「项目」列表；删除分区时，原分区内的项目会自动回到「项目」列表，不会丢失。
2. **修正「最近」栏语义**：
   - 「最近」分组现专门用于存放聊天会话；点击打开或切换本地项目、设置页面等不再错误出现在「最近」列表中。在聊天服务尚未接入前，展开「最近」会明确显示「暂无聊天会话（聊天服务尚未接入）。」。
3. **模块化结构升级（无功能回退）**：
   - 主题外观、自定义分区、本地项目管理与四栏 Shell 已拆分为独立插件包协同运行，外观切换、项目悬浮卡与悬停行操作体验保持一致。

## 影响范围与使用提示

- 影响范围：左二栏导航分组、项目 `···` 分区子菜单、分区本地存储（`~/.lfaa/sections.json`）及外观设置；已有本地项目 `app1`、`app` 保持完整不变。
- 已在桌面端（`1440×900`）与移动端（`390×844`）浏览器完成创建分区、重命名、项目归属、删除分区自动回退及「最近」空聊天态验收。

## 已知限制

- 拖拽项目进分区的 HTML5 交互已内置，但本轮自动化验收仅实测了菜单指派路径；聊天会话创建与展示将在后续接入聊天插件时补全。
