# UPDATE-000446｜滚动条统一成强调色胶囊滑块，并抽成可复用滚动容器

- 时间（含时区）：2026-11-24 10:35 +08:00
- 类型：优化
- 关联开发日志：`../dev-log/000401-000600.md`（DEV-000446）

## 用户能看到的变化

- 全站滚动条统一换成 4px 内嵌圆角胶囊：轨道透明，滑块只留一条淡淡的强调色，不再出现浏览器原生灰条或上下三角按钮。
- 颜色继续归设置中心的「强调色」管：切到蓝、绿、粉、紫等任意强调色，所有滚动条立刻跟着变；深色与浅色主题各自都看得清。
- 增加交互反馈：指针压到滑块上或正在滚动时，滑块会加深到更接近强调色，状态一目了然。
- 设置中心左栏目录与右侧正文的滚动条不再贴着卡片圆角边缘，而是作为悬浮胶囊停在内容内侧；正文区常驻预留滚动条槽位，切换设置页时内容不会左右抖动。

## 影响范围与使用提示

- 影响所有使用浏览器滚动条的容器：四栏工作区、聊天与会话列表、设置中心、弹窗与下拉列表等，均无需逐个改动。
- 需要自定义滚动区域的后续开发，统一使用 `@lfaa/ui-primitives` 的 `ScrollArea`（支持纵向/横向/双向、常驻槽位与滚动视口 ref）；只写样式的旧容器也能自动获得新外观。
- 代码预览区（文件源码视图）保留自己的中性细滚动条，未纳入强调色，属于有意区分。

## 已知限制

- Firefox 只支持标准滚动条属性，显示为细条 + 强调色，没有 4px 胶囊的精确宽度与悬停动画。
- 内容刚好溢出很少时，滑块长度会接近整条轨道，这是浏览器按溢出比例计算的结果。
