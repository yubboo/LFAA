# UPDATA-000135｜LFAA 扩展中心（技能中心与插件中心）

- **技能中心（`@lfaa/skills`）**：支持个人（`~/.lfaa/skills/`）、项目（`.agent/skills/`）与插件提供的 `SKILL.md` 统一查看，支持新建、导入、编辑（含版本冲突保护）、二创复制（「复制为我的版本」）、启停与删除。
- **插件中心（`@lfaa/plugins`）**：移除侧栏写死的虚假已安装插件，接入真实安装记录与 Cordis 隔离启停；内置首个可安装本地插件「文本计数」，启用后实时注册 `count_text_stats` 工具、`text-counter-guide` 技能与扩展详情页，停用或卸载即时清理。
- **聊天 `$` 技能选用**：输入栏支持输入 `$` 检索并选用已启用的技能，仅注入本轮 Agent 上下文；发送前若技能已停用将明确提示原因并保留输入草稿。
