# 桌面端：安装包瘦身 90%（2 万文件 → 276，安装 155 秒 → 13 秒）与稳定性补强

- 日期：2026-11-22 00:31 +0800
- 类型：性能优化 / 可用性改进

## 改动

- 安装包负载裁剪：`react`、`react-dom`、`scheduler`、`@tabler/*` 只在渲染进程使用（宿主 lib 已核对不 import），不再打进桌面宿主依赖；`@lfaa/*` 只保留运行期需要的 `lib/*.js + package.json`，第三方包去掉类型声明、sourcemap、文档、测试与 TS 源码。
- 安装体积与速度：安装包 129.6MB → **118.9MB**；staging 文件数 20,619 → **276**；安装实测 155 秒 → **12.8 秒**（安装后约 338 个文件）；免安装 zip 165.5MB → **149.8MB**。
- 版本号不再写死：安装包/zip 版本以 `apps/desktop/package.json` 为唯一来源。
- 新增启动与崩溃日志：`~/.lfaa/logs/desktop.log`，启动失败、宿主异常、未捕获错误都会落盘。
- 记住窗口尺寸与位置（`~/.lfaa/desktop-window.json`），显示器变化导致越界时回退默认尺寸。
- 新增 `LFAA.exe --new-instance`：上次异常退出导致「双击没反应」时强制再开一个窗口排查。

## 说明

- 安装器「目标目录不是空目录就拦下」的预检**没有实现**：electron-builder 的 `customInit` 在目录选择页之前执行（`$INSTDIR` 还是默认值），`customInstall` 又在文件复制之后，没有干净时机拦截用户选的目录。没有加假检查，改为文档强提示 + 免安装 zip 兜底。
- 仍未签名，部分机器可能提示 SmartScreen。

## 验收

- `pnpm build:desktop` 产出新安装包与 zip；静默安装到全新目录耗时 12.8 秒，`Uninstall LFAA.exe` 与 `LFAA.exe` 均生成。
- 安装后的程序启动：窗口「LFAA 工作区」，宿主子进程独占端口，`/api/workspace/sections` 返回 200。
- `pnpm typecheck` 通过；测试目录、临时用户数据与测试进程已清理。
