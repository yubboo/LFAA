# 000153｜修复内置浏览器新建空白标签页无响应及切回标签地址栏同步

2026-11-19 17:24 +08:00

- **新建空白标签页可用（[RightWorkbenchPane.tsx](file:///e:/lfaa/packages/core/chat/client/components/RightWorkbenchPane.tsx)）**：修复已打开默认「内置浏览器」空白页时点击顶部 `+` 因 `browserTabs.length === 0` 提前返回导致的无响应问题，现在无论已有 0 个、1 个还是多个真实浏览器页签，点击 `+` 均立即新建空白标签页（统一显示「新标签页」，不暴露 `about:blank`）。
