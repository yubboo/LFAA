# 任务 000287｜会话模式从输入栏移到顶栏标题右侧

- 「会话模式」徽标不再挤在输入框工具栏里：现在跟在顶栏标题右侧（`个我的世界签到插件，1.21.1` → `🔒 标准模式（默认）` → `本地模式`），与 DSH 的位置一致；新建会话可下拉切换模式，已有消息时显示锁定图标与提示。
- 徽标显示的是真实会话模式，不再落到「旧会话」：早期会话没有记录 `sessionPreset`（实测该会话接口返回 `null`），旧逻辑对锁定会话直接回退成「旧会话」；现在按 `selected → 当前默认预设` 解析，未记录预设的会话显示它实际运行的默认模式名；预设被删除等未知情况同样回退到默认预设名，只有目录读取失败才显示「模式不可用」。
- 输入栏工具栏随之让出位置，`+ / 请求批准 / 删除` 恢复到更松的一行，窄栏不再被模式下拉挤占。
- 顶栏新增通用能力：`workbench.registerTitleAction({ id, order, render })`，任何插件都能向标题右侧贡献状态控件，与右侧工作台动作分开排序、各自独立注销。
- 实测（真浏览器，1280×700）：顶栏文本为「个我的世界签到插件，1.21.1标准模式（默认）本地模式」，徽标位于标题右侧 `x=472.7`、宽 72.8、`aria-label="标准模式（默认）. 会话模式已锁定。新建会话可切换。"`；新会话下拉 `value=standard`、610 窄栏无溢出；输入卡片内已不再包含模式控件；控制台 0 报错。
- 影响范围：只有顶栏标题区与输入栏工具条，无数据与协议变化。
