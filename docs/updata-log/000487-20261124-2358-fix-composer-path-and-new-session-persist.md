# UPDATE-000487｜修复输入框误识别包名为本地路径，以及新会话刷新后跳回「新聊天」

- 编号：UPDATE-000487
- 日期：2026-11-24 23:58（Asia/Shanghai）
- 类型：修复

## 本次变更

1. **修复 `@lfaa/ui-theme` 等包名被误识别为本地路径**：输入框提取绝对路径现要求前导边界（空白/标点/行首），且 POSIX 路径需包含至少两级目录段，不再把 `@scope/pkg`、相对路径、URL 或 `/plan` 误标成 `[本地文件路径：...]`。
2. **修复新会话首次发消息后刷新被踢回「新聊天」**：新聊天草稿首次创建会话后立即写入 `localStorage` 活动会话记忆，无论按 F5 还是触发 Vite 热重载，刷新后都会留在原会话并自动续接实时流。
