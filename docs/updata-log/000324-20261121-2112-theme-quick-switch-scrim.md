# 修复：账号菜单里的主题切换点不动

- 日期：2026-11-21 21:12 +0800
- 类型：Bug 修复

## 问题

左下角账号菜单里的「跟随系统 / 浅色模式 / 深色模式」点选项没反应：菜单能打开、选项也看得见，但点下去主题不变，反而整个账号菜单一起关掉。

## 原因

上一次修「账号菜单穿模 / 被压住」时给菜单加了全屏透明遮罩（`z-index: 239`）和不透明面板（`z-index: 240`），两者都挂到了 `body`。主题快捷菜单仍挂在内层容器 `[data-device]` 上、`z-index` 只有 108，于是被透明遮罩盖住——看着在，点不到，点击被遮罩吃掉并触发关闭。

## 修复

- 主题快捷菜单改为挂到 `document.body`，和账号面板同一层叠上下文。
- `.menu` 的 `z-index` 从 108 提到 245，高于面板（240）与遮罩（239）。
- 定位仍按触发按钮的 viewport 坐标计算，改动不影响弹出位置。

## 验收

- 无头 Edge 实测：`浅色模式` → 主题变 `light`、`深色模式` → 主题变 `dark`；选项中心点击命中的是菜单自身而不是遮罩。
- 切换后主题菜单关闭、账号面板保持打开；控制台 0 错误。
- `check` / `lint` / `typecheck` / `test`（391 项）/ `build` 全部通过。
