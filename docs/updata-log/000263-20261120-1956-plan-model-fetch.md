# 任务 000263｜套餐也能拉取全部模型

- 模型配置弹窗里，套餐（千问 Token Plan、方舟 Agent Plan 等）和普通 API 一样有「获取官方模型」按钮，点一下就会把该套餐名下的模型全部列出来，点哪个就用哪个，不再只能手填一个模型 ID。
- 千问 Token Plan 现在能看到 `qwen4-max`、`qwen4-max-preview`、`qwen3.8-max`、`qwen3.8-flash`、`qwen3.7-max/plus`、`deepseek-v4.1-flash`、`glm-5.3`、`auto` 等 23 个模型，可随时切换。
- 拉取到的模型清单会存进档案，聊天页的模型选择器里也能直接看到并切换；保存和「测试连接」都会带上这份清单。
- 打开已配置的套餐弹窗时会自动同步一次，所以千问档案一打开就是完整列表，不用手动点。方舟套餐的模型接口官方未开放（404），仍展示官方公开目录。
