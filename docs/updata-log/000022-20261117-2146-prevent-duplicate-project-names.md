## 用户能看到的变化

- **禁止重复项目名称**：新建项目或使用“编辑项目”改名时，不再允许创建或保存与已有项目同名的名称（自动忽略首尾空格与大小写差异，如 `app` 与 `APP` 视为重名），并会在表单上直接提示“项目名称已存在，请更换其他名称。”。
- **保留磁盘目录冲突顺延逻辑**：如果某个旧项目已经从 LFAA 列表移除、但磁盘“文档\lfaa”下仍残留同名目录，此时再次用该名字新建项目仍可正常创建并将磁盘子目录顺延为 `app1 2`。

## 影响范围与使用提示

- 影响 `packages/workspace/workspace`（前后端双端校验）与 `apps/web`；已通过单元测试、HTTP 接口校验与内置浏览器实测验收。
