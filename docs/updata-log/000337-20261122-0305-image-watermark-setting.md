# 000337｜生图默认不再带「AI 生成」水印；设置中心新增「生图水印」开关

- 时间：2026-11-22 03:05 +0800。负责人反馈生成的图片右下角有「AI 生成」水印，要求去掉；若一定要水印也应该是「小鱼 agent 生成」，并在设置中心提供「生图无水印」设置。
- 提供方水印：方舟（Seedream）生图接口默认带水印，我们之前没传 `watermark` 参数。现在方舟生图请求默认发送 `watermark: false`，实测用 `doubao-seedream-5.0-flash` 生成的 2048×2048 图片右下角已没有「AI 生成」角标。
- 新设置：设置中心 → 常规 → 趣味实验 → 「生图水印」（默认关闭）。开启后仅在聊天里给生成图叠加一枚「小鱼 agent 生成」小标签（渲染层叠加，不写进图片文件）；关闭则完全无水印。
- 需要刷新页面（Ctrl+F5）；宿主已重启。
