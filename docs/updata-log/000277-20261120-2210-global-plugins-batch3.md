# 任务 000277｜全局插件第三批：计划模式与写前必读

- 插件中心「全局插件」再增 2 项（22 → 24）：**计划模式**、**写前必读**。
- 计划模式：Agent 可以先进入「计划模式」，此时写文件和执行命令都会被拦住，只能查代码、读文档；等它把计划说清楚、调用退出，才允许真正动手。适合你想先看方案再让它改代码的场景。
- 写前必读：改一个已存在的文件前必须先读过它，避免模型凭猜测盲改；新建文件不受影响，写完之后继续编辑也不会被反复拦。
- 两条策略都基于上一轮上线的工具中间件 seam，按会话隔离，不影响其他会话。
- 剩下 6 个 P0 插件（向用户提问、定时任务、上下文压缩、压缩命令、工具结果精简、系统提示装配）需要先各自的接入点设计，会在后续轮次继续。
