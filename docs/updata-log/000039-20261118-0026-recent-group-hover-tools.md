# UPDATE-000039｜「最近」分组新增聊天排序与快捷新聊天入口

- 时间（含时区）：2026-11-18 00:26:00 +08:00
- 类型：功能补充
- 关联开发日志：`../dev-log/000039-20261118-0026-recent-group-hover-tools.md`

## 用户能看到的变化

- **「最近」分组补齐快捷按钮**：将鼠标移入左二菜单栏 **「最近」** 分组标题行时，右侧现会平滑显现两个快捷图标（默认隐藏，离开即隐）：
  1. **聊天排序**：点击可切换「按创建时间排序 / 按名称排序」，选择结果刷新后永久记住；
  2. **新聊天**：点击直接聚焦新聊天入口。

## 影响范围与使用提示

- 影响 `@lfaa/ui-layout` 左二栏「最近」分组标题行；已在 `1440×900` 完成未悬停隐藏、悬停显现、排序刷新保留及快捷新聊天验收。

## 已知限制

- 真实聊天会话数据与项目内会话计数待接入 `@lfaa/chat` 包后联动展示。
