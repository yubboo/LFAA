# UPDATE-000599｜终端可以放到下方了，右侧 / 底部一键切换

- 日期：2026-11-26（Asia/Shanghai）
- 终端标题栏多了「移到下方 / 移到右栏」按钮：放到底部时占中间+右侧两列，关掉右栏也不影响它；放回右侧就是原来的标签页。
- 位置会记住：刷新后还在你上次放的地方；默认仍是右侧。
- `Ctrl+↓` 会跟着走：在底部模式展开底部面板，否则打开右栏「终端」标签。
- 两处位置共用同一个终端进程，切换不会丢历史、不会重开。
- 底部面板高度暂固定 260px（拖高、标签切换在下一轮）。
- 右栏起始页的「终端」卡片现在打开真终端；设置中心新增「终端 → 展示位置」，可选右侧面板 / 底部面板。
- 修好了切到底部时左下角露出背景图的问题：图标轨通高、面板铺满其右侧整条。
