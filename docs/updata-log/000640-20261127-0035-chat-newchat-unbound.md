# UPDATE-000640｜聊天模式点「新聊天」不再绑定项目

- 时间：2026-11-27 00:35（Asia/Shanghai）
- 类型：fix（聊天模式的会话归属）

## 变化

- 聊天模式下点「新聊天」：永远是全新的未绑定会话，不再带上之前选中的项目；标题回到「我们要聊些什么？」。
- 从聊天模式切回工作模式：如果草稿还没开始，会恢复最近一次选中的项目，工作模式的项目上下文不会因为切过聊天而丢失。
- 已经在项目里的会话不受影响：项目内固定工作形态，新会话仍绑定该项目。

## 怎么验证

工作模式选中「默认工作区」→ 切聊天：标题变「我们要聊些什么？」、无项目胶囊；点「新聊天」仍是未绑定；再切回工作：项目上下文恢复。
