# 000339｜资料库改成「全宽画廊 + 右栏详情」：分类只留左二，右栏不再显示聊天工作台

- 时间：2026-11-22 00:23 +0800。
- 布局：资料库去掉中心那排分类标签，分类只由左二切换；中央标题显示当前分类与数量（如「图像 31」），画廊恢复全宽（1500px 窗口 5 列，之前被页内预览压到 2 列）。
