# 000458｜思维链思考区限高滚动条与流式智能贴底

- 时间：2026-11-24 15:44–15:59（Asia/Shanghai）。
- 变化：
  - **长思考不再把整页聊天无限拉长**：思维链正文区域（`ThinkingBlock`）现在复用全站统一的 `ScrollArea` 细滚动条，设置最大高度（桌面 `15rem` / 约 8–10 行，窄屏 `12rem`）。短思考时自然贴合高度、不留白也不出现滚动条；超过阈值后在左侧引导竖线内原地启用滚动条，下方的工具行与正式答复保持在视口内可见。
  - **流式思考智能贴底**：模型实时流式输出推理时，思考框内部自动同步滚到最新几行；一旦向上滚轮翻看前面的思考内容，立即暂停跟随不与用户抢滚动条，滚回底部后自动恢复跟随。
  - **思考结束后保持平稳**：思考完成后维持同样限高与滚动条，不会突然展开撑跳页面；可滚方向边缘带有柔和渐隐提示，浅色与深色主题下都清晰自然，点击标题仍可一键收起或展开。
- 验证：新增 3 条思维链滚动单元测试（`thinking-block-scroll.test.tsx`），`pnpm test:pkg ui-chat`（171/171）、`pnpm check`、`pnpm lint`、`pnpm typecheck`、`pnpm build`、`pnpm probe:boot`（3/3）、`pnpm probe:loader`（13/13）、`pnpm verify:web`（16/16）、`pnpm ui:shot`（3/3）及内置浏览器深色/浅色/390×844 窄屏实测全部通过，控制台 0 报错。
