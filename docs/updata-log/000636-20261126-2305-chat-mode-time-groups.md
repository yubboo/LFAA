# UPDATE-000636｜聊天模式左二栏改成按时间分组的纯会话列表

- 时间：2026-11-26 23:05（Asia/Shanghai）
- 类型：feat（两种模式联动）

## 变化

- 切到「聊天」模式后，左二栏不再是置顶 / 项目 / 最近，而是：
  - 新聊天
  - 今天
  - 昨天
  - 最近（7 天内）
- 三种分组之外，超过 7 天的会话不在列表里出现（不删除，搜索仍能找到并打开）。
- 收起过的分组会记住：刷新、切走再回来都保持收起状态。
- 聊天模式下隐藏「项目工作区」入口；聊天模式也列出属于项目的会话，点击直接打开。
- 工作模式保持原结构（新聊天 / 置顶 / 项目 / 最近）；「最近」只收聊天会话，平铺显示，同样只列 7 天内的。
- 空态标题改成「我们要聊些什么？」。

## 怎么验证

切到「聊天」：左二应只有今天 / 昨天 / 最近（7 天内），没有置顶和项目，也没有「项目工作区」按钮。切回「工作」：置顶 / 项目 / 最近原样，最近里是平铺的聊天会话。
