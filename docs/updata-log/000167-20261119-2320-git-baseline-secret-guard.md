# 000167｜首次运行不会再把密钥提交进项目

2026-11-19 23:20 +08:00

- 首次在项目里运行任务时，如果目录里存在未被 `.gitignore` 忽略的 `.env`、证书私钥、`credentials/`、`secrets/`、`id_rsa`、`.npmrc` 等疑似密钥文件，会跳过自动 Git 基线，并在运行轨迹里说明原因。
- `.env.example`、`.env.sample` 等模板文件不受影响；已被 `.gitignore` 忽略的密钥文件本来就不会被提交。
- 跳过基线不会中断任务，只是该次运行暂时没有可对比的 Git 基线。
