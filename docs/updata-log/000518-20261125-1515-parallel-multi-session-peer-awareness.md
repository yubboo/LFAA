# UPDATA-000518｜支持同工作区多会话并行与并发感知协作

- 日期：2026-11-25 15:15 +08:00
- 对应开发日志：`DEV-000518`

## 更新内容

1. **同一项目/工作区支持多会话并行运行**
   - 解除此前「同一工作区仅允许单条会话运行」的互斥锁限制：当某个会话正在执行任务时，可直接点击「新聊天」在同一项目或默认工作区下并行发起新会话，不再弹出工作区占用（HTTP 409）阻塞提示。
2. **同工作区会话间实时并发感知**
   - 当同一工作区存在多个并发运行的会话时，每个会话会自动感知其他活跃会话的标题与当前正在执行的工具/文件操作，并遵循协作原则：只读分析放心并行，避免改写其他并发会话正在处理的文件或干扰其运行中的构建、测试与本地服务。
