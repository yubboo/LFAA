# 用户消息不再丢图：引用图与聊天附图都会显示

- 日期：2026-11-21 20:05 +0800
- 类型：Bug 修复

## 问题

直连生图上传的附件在 000318 已能保留，但还有两条路会让「我说的那张图」在聊天气泡里消失：

1. 点生成结果上的「引用」，再发一句「按这张改」：图只作为参考图发给模型，用户消息里没有任何记录。
2. 切回对话模型后附图发送：`/api/agent/runs` 不带附件 id，气泡里只有一段 `[附加文件: …]` 文字。

## 修复

- 用户消息新增 `references`（来源消息 id + 宿主校验后的路径）与已有 `attachments` 并列保存，聊天气泡在同一组缩略图里先显示附件、再显示引用图。
- 媒体直连：引用图经宿主确认归属与真实路径后写回用户消息；上传附件仍写附件引用。
- 聊天运行：`/api/agent/runs` 接受 `attachmentIds`，宿主校验「属于本会话且是图片」后写入用户消息；引用图数量与解析结果不一致时直接不写，避免记录不可信的路径。
- 用户消息里的图片改为显示在文字**上方**（与对话内的生成结果一致），先看图再读需求；只有图片时不留多余空白。
- 观感收敛：用户气泡不再画 accent 描边、也不再用粉色底，改为中性底色（浅色下实测 `rgb(241,241,242)`）；缩略图不画描边、铺满气泡宽度、按原比例不裁剪；1 张占满一行，2 张并排两列，3 张以上三列。
- 运行中发送带图消息会提示「请等待当前任务结束」，不再静默丢图（排队/插话链路暂不携带图片）。
- 旧的错误数据不会自动改写；缺少附件或文件时气泡显示「附带图片暂不可用」并可重试。

## 验收

- 新增运行落盘、HTTP 桥接、引用图写回与渲染断言，`pnpm test` 391 项全通过；`check` / `lint` / `readme:pair` / `typecheck` / `build` / `probe:loader` 均通过。
- 隔离宿主 + 无头 Edge（CDP）实测：用户气泡同时显示附件与引用图两张缩略图，深色与浅色主题正常，控制台错误 0。
- 接口实测未调用真实套餐：两条链路都确认用户消息写入对应字段，`/api/attachments/:id` 返回 `image/png`。
