# 000080 更新日志 — 聊天会话悬停信息卡、快捷操作与「⋮」完整菜单

- **时间**：2026-11-18 13:37:51 +08:00
- **任务编号**：000080

## 1. 用户可见新功能

1. **聊天行悬停快捷操作与右侧悬浮信息卡**
   - 左侧「最近」列表日常展示会话相对更新时间（如 `刚刚`、`1h`、`2d`）；
   - 鼠标悬停到任一聊天行时，右侧自动切换为 **归档对话**、**置顶**、**⋮ 更多操作** 三个快捷按钮，并在侧栏右侧弹出悬浮详情卡片，展示 **会话标题**、**所属项目（或 Outside of 项目）**、**更新时间** 与 **未读蓝点状态**。
2. **「⋮」完整会话菜单与快捷键**
   - 支持 **重命名**（`Alt+Ctrl+R`）、**置顶**（`Alt+Ctrl+P`）、**标记为未读**（`Ctrl+Shift+U`）、**项目**（切换所属项目或移出项目）、**分区**（归入或移出自定义分区）、**分叉**（复制完整消息生成分支会话）、**分享**（复制 Markdown 对话内容）、**复制**（复制标题 / 对话内容 / 会话 ID）、**在新窗口中打开**、**归档**（`Ctrl+Shift+A`）与 **永久删除**（含二次确认弹窗）。
