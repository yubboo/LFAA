# UPDATE-000032｜左一菜单栏底部新增外观模式快捷切换（跟随系统 / 浅色模式 / 深色模式）

- 时间（含时区）：2026-11-17 23:22:15 +08:00
- 类型：新功能
- 关联开发日志：`../dev-log/000032-20261117-2322-rail-theme-quick-switch.md`

## 用户能看到的变化

- **左一底部快捷切换胶囊**：在最左侧菜单栏底部（本地工作区状态与头像按钮正上方）新增外观模式快捷胶囊，实时显示当前模式图标与名称（**跟随系统** / **浅色模式** / **深色模式**）。
- **点击弹出三选一浮层**：无需层层进入设置页面，直接点开即可在 **跟随系统**、**浅色模式**、**深色模式** 间一键切换并永久记住；在窄屏移动端自动切换为底栏紧凑图标与上浮菜单，不拥挤、不裁切。

## 影响范围与使用提示

- 由 `@lfaa/ui-theme` 插件通过左一栏底部插槽向 Shell 贡献；已在 `1440×900` 桌面端与 `390×844` 移动端完成切换、刷新持久化与无溢出验收。

## 已知限制

- 无。
