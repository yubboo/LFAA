# UPDATE-000652｜新增内置技能「ui-measure」：能量位置、判对齐

- 时间：2026-11-27 10:12（Asia/Shanghai）
- 类型：新功能
- 关联开发日志：`../dev-log/000601-000800.md`（DEV-000652）

## 变化

- 技能中心新增内置技能 `ui-measure`（内置，不可删，可停用）。
- 提示词的「内置专业技能」名单固定把 `ui-measure` 排在最前，其余内置技能仍只报数量——既让它能被看见，又不增加每轮上下文。
- Agent 遇到「对不齐 / 差几像素 / 左二栏缩进 / 圆点没居中 / 四栏宽度不对」时，会先 `list_skills` 检索、再 `load_skill` 读正文，然后用 `getBoundingClientRect` 给数值，而不是截图下结论。
- 技能内置判定口径：相邻栏 ≤1px、图标与文字 ≤1px、子行缩进不许倒挂、浮层左缘 +2 / 右缘 −12、resize handle 压边 2px 属设计。
- 附带六个可直接复用的测量片段（四栏、活动行、会话列表、浮层、主题变量、多视口）。

## 怎么验证

打开设置中心 →「技能」能看到「ui-measure · 内置」；在对话里问「这个页面的四栏是不是差 2px」，看 Agent 是否加载该技能并回一张「元素 / 期望 / 实际 / 差」的表格。

## 已知限制

- 内置技能不进每轮提示词正文，只在被检索到时加载。
- 技能里的选择器片段基于当前 CSS Modules 命名，改哈希规则要同步。
