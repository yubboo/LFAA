# 媒体预览失败可一键重试；用生图模型发对话会得到明确提示

- 日期：2026-11-21 17:18 +08:00。
- 「媒体加载失败」实为页面在服务重启前加载、请求失败态未刷新：文件与接口都正常（实测 200 image/png、7.8MB）。现在失败处新增**「重试」按钮**，点击即可重新加载，无需整页刷新；硬刷新（Ctrl+F5）同样有效。
- 16:57 的 `400 input.messages…` 是重启前旧宿主的历史错误（把生图模型当聊天模型）。重启后的服务已拦截：用生图/生视频模型发起对话会直接提示「当前选中的是生图模型，不能用于对话，请直接在输入框发送生成描述，或切换回对话模型」，不会再报厂商 400。
- 生图模式下继续发描述/「再亮一点」仍会正常生成或改图。
