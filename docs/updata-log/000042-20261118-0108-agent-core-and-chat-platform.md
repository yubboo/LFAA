## 本次新增核心功能

1. **Agent 四大核心基础能力**：
   - **LLM 大脑（`@lfaa/llm`）**：接入 OpenAI-Compatible 标准接口（支持 DeepSeek、OpenAI 及本地 Ollama），支持流式推理与工具调用；API Key 仅保存在本机 Host 配置文件中并向前端脱敏展示。
   - **工具手脚（`@lfaa/tools`）**：内置工作区文件列表、读取、搜索、写入、局部编辑及终端命令工具；严格限定于已绑定项目目录沙箱内运行，写文件与命令执行默认需您点击批准后再执行。
   - **记忆能力（`@lfaa/memory`）**：支持短期会话持久化与超长上下文摘要裁剪，并提供全局/项目维度的长期事实记忆存储与按需自动召回。
   - **分层规则（`@lfaa/rules`）**：内置不可覆盖的系统安全底线，自动发现绑定项目根目录 `AGENTS.md` / `.lfaa/rules.md`，并支持配置用户全局规则。
2. **Agent「思考 → 行动 → 检查」任务工作循环（`@lfaa/agent`）**：
   - 每轮任务执行自动按 **思考规划 → 工具行动（带高风险授权确认）→ 结果检查** 闭环推进，并在消息上方提供可展开的步骤轨迹与高风险操作审批卡片。
3. **核心聊天工作台与全局联动（`@lfaa/chat`）**：
   - 中央工作区上线完整聊天对话流、模型/项目绑定栏及流式停止按钮；左二「最近」列表与项目悬停卡「`N 次聊天`」改为真实会话实时驱动（不含已归档会话）。
   - 右侧上下文栏新增「Agent 核心能力」状态卡；设置中心开放「模型与规则配置」页面，支持一键维护模型接口、用户规则与长期记忆。
