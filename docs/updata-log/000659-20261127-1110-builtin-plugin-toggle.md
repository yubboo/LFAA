# UPDATE-000659｜内置插件可以停用和重新启用了

- 时间：2026-11-27 11:10（Asia/Shanghai）
- 类型：新功能
- 关联开发日志：`../dev-log/000601-000800.md`（DEV-000659）

## 变化

- 设置 → 集成 → 内置插件：展开任意一张卡，右下角多了一个「停用 / 启用」按钮。
- 停用立即生效：该插件注册的工具、服务与界面贡献马上卸载，卡片上的运行状态变成「未运行」。
- 重新启用同样立即生效，不需要重启。
- 选择会记住：重启应用后，停用的插件仍然停用。
- 沙箱也纳入了这套清单——它的默认入口现在只挂安全策略，本地沙箱仍由应用根层提供，所以停用策略不会连带关掉执行环境。

## 怎么验证

打开设置 → 内置插件，展开「内置浏览器」→ 点「停用」：卡片状态变为未运行，工具列表里浏览器工具消失；再点「启用」恢复。重启应用后再看，停用状态保持。

## 已知限制

- 启停是应用级设置，对所有会话生效，不是单个会话的开关。
- 停用核心插件（如工具注册表、聊天工作台）会让对应能力整体不可用，属预期。
- 侧栏插件中心仍然只负责安装扩展插件，内置插件的启停只在设置页。
