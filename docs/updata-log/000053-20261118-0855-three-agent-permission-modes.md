# Updata Log 000053 — 新增三种 Agent 权限模式（请求批准 / 帮我审批 / 完全访问权限）

- **时间**：2026-11-18 08:55:57 +08:00
- **版本号/编号**：000053

## 本次新增功能

1. **三种严格分级的 Agent 权限模式**：
   - **请求批准**：保持项目目录沙箱保护，每次修改文件或执行终端命令均弹出 `批准 (Yes)` / `拒绝 (No)` 确认。
   - **帮我审批**：保持项目目录沙箱保护；系统记住你的授权选择，同类常规操作累计批准 **3 次** 后自动放行（若拒绝则重置计数），高危破坏性命令及敏感密钥文件仍强制询问。
   - **完全访问权限**（橙色高亮警示）：解除目录沙箱限制并全自动执行所有工具操作，不再弹出确认框。
2. **输入栏切换浮层与上下文同步**：
   - 在聊天输入栏左下角新增权限模式切换胶囊与「应如何批准 LFAA 操作？」浮层（附带 `了解更多` 说明），选择结果自动记忆并在右侧 `Agent 核心能力` 面板实时显示与重置自动放行记录。
