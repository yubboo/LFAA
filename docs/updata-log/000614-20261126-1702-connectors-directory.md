# UPDATE-000614｜连接器改成目录卡片，点一下就能装好并连上

- 时间：2026-11-26 17:02（Asia/Shanghai）
- 类型：feat（连接器体验改版）

## 变化

- 设置中心「集成 → 连接器」默认是**目录**：27 个内置连接器以卡片墙呈现，支持搜索、按类型（全部 / MCP / CLI）与分类（热门 / 开发 / 办公 / 数据 / 系统）筛选。
- 点卡片右下角「+」即可连接：MCP 连接器会自动下载并启动对应服务器（首次由 npx 拉包）；CLI 连接器本机没装时会静默安装（winget / choco / scoop / npm 任一可用），装好自动连上。过程中顶部显示「正在下载 / 安装…」，完成后提示「连接器 X 已连接」。
- 已连接的卡片带状态点，点开详情可以看到「试试这样用」的示例（点击复制）、使用的命令/服务器、类别、开发者、版本与网站；卸载在详情底部，用危险色。
- 「自定义连接器」菜单保留：想手动建 MCP 服务器或命令行工具，会跳到对应页签并直接打开新建弹窗。
- 原来的行式管理（编辑、测试、导出、导入、启用开关、动作级审批、删除组）保留在「MCP 服务器」「命令行工具」两个页签里。

## 怎么用

设置中心 → 集成 → 连接器 → 在目录里找到要用的连接器（比如「记忆图谱」「文件系统」「Git」）→ 点「+」。需要令牌或目录的会在弹窗里先填（例如文件系统会让你选一个允许访问的目录）→ 完成后卡片变成已连接，工具立即可在会话里调用。
