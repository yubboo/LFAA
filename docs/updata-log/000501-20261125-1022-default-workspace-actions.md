# UPDATE-000501｜默认工作区恢复完整操作，可改位置、可删除

- 日期：2026-11-25（Asia/Shanghai）
- 左二栏「默认工作区」现在和普通项目一样，行内提供···（置顶/编辑/打开/移除等）、✎（在默认工作区里开新聊天）和置顶按钮，不再只有一行不可操作的文字。
- 「编辑」可以修改默认工作区的项目名和文件夹位置；「移除项目」可以删除它，删除后不会被自动加回来。
- 默认工作区在首次启动时自动创建并登记，目录仍取系统「文档」下的 `lfaa/default-workspace`，可在「设置 → 常规 → 默认工作区」或项目「编辑」里改。
- 创建命名项目后仍会自动打开绑定该项目的新聊天。
