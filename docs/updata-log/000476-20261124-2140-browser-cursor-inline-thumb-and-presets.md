## 用户能看到的变化

- **Antigravity 风格虚拟光标与四点「深度思考…」指示器**：
  - 受控页内光标改为白底黑边尖头指针 + 轻柔圆形点击光环 + 干净白底圆角动作胶囊，点击/输入/滚动响应速度提速约一倍。
  - 右侧浏览器视口底部在 Agent 思考与执行期间实时显示 2×2 四点脉动指示器 + 圆角胶囊（思考态显示「深度思考…」，动作态显示当前操控目标）。

  - 切换 `响应式 / 电脑显示 / 手机端显示` 或右侧栏展开时，服务端立即采集新尺寸画面并推流重绘，且前端用请求序号屏蔽来回快速切换时的乱序覆盖。

  - **电脑显示**：保持在右侧栏内（绝不遮挡中间会话），以 ≥1280px 桌面宽度按右侧容器宽高比换算高度渲染，既触发桌面端布局又彻底消除上下黑边。
  - **手机端显示**：390×844 手机端居中展示，同步开启移动端视口模拟（`mobile: true`）。
