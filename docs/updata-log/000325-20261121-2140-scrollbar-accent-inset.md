# 滚动条贴近栏边界，颜色跟随强调色

- 日期：2026-11-21 21:40 +0800
- 类型：优化 / Bug 修复

## 问题

左二栏的滚动条离栏边界空出一截，看着像被孤零零地摆在中间；颜色也一直是浏览器原生灰色，和设置中心选的强调色无关。

## 原因

- `--pane-scroll-inset: 8px` 是为了避开分隔手柄向内的 5px 拖拽热区，结果滚动条与栏边界隔了约 9px。
- 左二栏和聊天区都写了 `scrollbar-width: thin`，Chromium 遇到标准滚动条属性时不再应用 `::-webkit-scrollbar` 伪元素样式，所以原来的灰色样式既没生效、也没法用伪元素改色。

## 修复

- 滚动条留白 8px → 4px（刚好贴住拖拽热区内边界），内边距同步补偿，正文位置不变。
- 全局滚动条改用标准属性 `scrollbar-color`，颜色取 `var(--color-accent)`；旧内核的 webkit 伪元素同样改为强调色作为兜底。

## 验收

- 滚动条右缘到栏边界：9px → 5px。
- 计算样式 `scrollbar-color` = 强调色 `#E66AA8` 的 62% 透明版本；浅色、深色主题一致。
- 展开「最近」、滚动会话列表实测，控制台错误 0；`check` / `lint` / `typecheck` / `test`（391 项）/ `build` 全部通过。
