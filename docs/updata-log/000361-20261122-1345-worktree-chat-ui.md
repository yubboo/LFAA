# UPDATE-000361｜工作树会话：从项目里新建一个隔离的聊天

- 时间：2026-11-22 13:45 +0800（Asia/Shanghai）
- 类型：新功能

## 你会看到什么

- 项目行「···」菜单新增「新建工作树会话」：填一个分支名（默认 `lfaa/<日期>-<随机>`），可选起点，创建后直接打开绑定该工作树的新聊天。
- 输入框上方显示分支 chip，悬停可看完整目录；点 × 解除绑定，聊天回到项目主目录。
- 项目详情新增「工作树」区块，列出分支、目录、绑定聊天数和未提交改动；有聊天绑定时不能删除，目录缺失会提示。
- 工作树创建在项目仓库同级的 `<仓库名>-worktrees` 目录，不写进项目目录；主项目目录的编译/扫描不会把它算进去。

## 需要注意

- 工作树是干净检出：`node_modules`、`.env`、本地数据库和未跟踪文件不会带过去，需要在新目录单独准备。
- 有绑定聊天的工树默认不能删；解绑后可在项目详情里删除，未提交改动会被强制丢弃（有确认）。

## 兼容性

- 不创建工作树时行为与之前完全一致；旧聊天没有工作树字段，不受影响。
- 删除聊天只解除绑定，不删除工作树目录。
