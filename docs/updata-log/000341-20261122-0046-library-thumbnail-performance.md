# 000341｜资料库图像不再卡：缩略图按需加载、缩到 480px 并缓存，二次进入不再下载原图

- 时间：2026-11-22 00:46 +0800。
- 问题：整理资料库后打开「图像」明显变卡。实测 31 张卡片共请求 **178.6MB** 原图（单张最大 8.5MB），32 张 2048×2048 同时解码并常驻内存；每次切进图像分类或刷新都重新下载，点开详情还要再下一次原图。
- 现在：
  - 只加载视口附近的卡片（预取 240px），首屏约 20 张，其余滚动时再加载；
  - 卡片用 480px WebP 缩略图，原图解码后立即释放，不再常驻大图；
  - 缩略图写入本地缓存，第二次进入图像分类 **0 请求、0MB**；
  - 点开素材时先用缓存小图垫底，完整原图到达后替换，不会先空一秒；
  - 选中卡片只重绘受影响的两张，不再整页重渲染；
  - 本地媒体接口支持 ETag/304（重启宿主后生效），重复取同一张图不再整份重读。
- 实测：冷启动 20 请求 / 128.9MB / 首屏约 1.7s；同一浏览器刷新 0 请求 / 0MB / 首屏约 1.1s；滚动流畅（p95 帧间隔 4.7ms）；滚动后补加载剩余 11 张，素材库弹窗复用缓存无额外请求。
- 首次打开仍会读取原图一次（本机没有服务端缩图能力），之后都走缓存；若要把首次 128MB 也降下来，需要引入服务端缩图能力，另行确认。
- 刷新页面即可（Ctrl+F5）；如果界面仍是旧行为，重开一次 LFAA 让宿主加载新的媒体接口。
