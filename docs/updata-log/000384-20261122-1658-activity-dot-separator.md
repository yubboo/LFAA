# UPDATE-000384｜活动行用小圆点把动作和对象隔开

- 时间：2026-11-22 16:52–17:02 +0800（Asia/Shanghai）
- 类型：体验优化

## 你会看到什么

- 活动行在动作和对象之间多了一个小圆点：`已读取 · pom.xml`、`已编辑 · README.md`。
- 同一动作有多个对象时，对象之间仍是顿号：`已读取 · a.ts、b.ts`；同类动作超过三个改为数量：`已读取 4 个文件`。
- 一轮里有多种动作时用小圆点并列，只保留动词和数量，避免摘要在成串圆点里失去重点：`已运行命令 · 已读取 2 个文件`、`已运行命令 · 已更新任务清单（完成 3 / 共 4）`。
- 未登记工具在并列摘要里用正式动作名（`已编辑 · 网页抓取`），不再出现「已完成：网页抓取」这种带冒号的说法。
- 运行中的动作仍只报进行态（`正在读取中`），失败项仍用中性动作名并保留失败徽标。

## 兼容性

- 只改活动行的文案与分隔符，不改运行流程、步骤数据和展开区内容；中英文同步（英文同样使用 ` · ` 并列）。
