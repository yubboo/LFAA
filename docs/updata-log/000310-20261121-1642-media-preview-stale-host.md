# 破图问题已定位：需要重启本地服务；已加兜底提示

- 日期：2026-11-21 16:42 +08:00。
- 聊天里「生成图片/视频」显示破图，原因不是文件丢失，而是本地服务（5173）还是在旧版本上运行：新增的 `/api/media/file` 宿主接口没生效，被开发服务器回落成 HTML，浏览器于是把 HTML 当图片显示。

- 同时已加兜底：以后遇到返回内容不是图片/视频，会显示「媒体加载失败（可尝试刷新页面或重启本地服务）」，不再出现破图图标。
