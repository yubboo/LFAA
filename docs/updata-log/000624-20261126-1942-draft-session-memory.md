# UPDATE-000624｜新会话即时出现在项目下，未发送文字与图片会记住

- 时间：2026-11-26 19:42（Asia/Shanghai）
- 类型：feat（会话入口 + 草稿记忆）

## 变化

- 在项目里点「新聊天」或顶部的「新聊天」后，**对应的项目下会立即出现一行「新聊天」**并处于选中态；如果还没发消息就切到历史会话，这一行会撤下。从「最近」新开时，同样的草稿行会出现在最近分组。
- 切走时不会丢输入：输入框里的**文字和已附加的图片**会按项目/会话记住。下次再点该项目的新聊天，文字与图片一起恢复。
- 刷新页面也不会丢：只要还停在新会话草稿，项目下的「新聊天」行、文字与图片都会恢复。
- 草稿不会串到别的会话：切到历史会话时输入框是空的；回到原来的会话或草稿才恢复属于它的未发送内容。

## 怎么验证

点项目行的「在该项目里开新聊天」→ 项目下出现选中的「新聊天」→ 输入文字、贴一张图 → 点一条历史会话（「新聊天」行消失、输入框为空）→ 再点该项目的新聊天（文字与图片回来）→ F5 刷新（行、文字、图片仍在）。
