# 000435｜设置中心变成弹窗：点开就在工作区上弹一层，关掉回到原页面

- 时间：2026-11-23 21:45–22:15（Asia/Shanghai）。
- 变化：设置中心不再把整个工作区换成设置页。现在点「设置」会在当前页面之上弹出一张居中卡片：左边是设置目录（个人 / 集成 / 编码），右边是当前设置页，右上角一个关闭按钮；背后的工作区保留原样并压暗。外观与参考截图一致。
- 关掉的方式有三种：右上角 ×、按 Esc、点卡片外面的灰色遮罩，之后回到你打开设置前的那一页（如果当时在看某个项目，会回到同一个项目，而不是首页）。
- 窄屏（手机/窄窗口）下弹窗铺满屏幕，设置目录变成顶部一排可横向滑动的胶囊按钮。
- 一个小变化：设置不再被记住为「上次打开的页面」。以前刷新会直接落到设置页，现在刷新回到工作区——弹窗不该在启动时自己弹出来挡住你。
