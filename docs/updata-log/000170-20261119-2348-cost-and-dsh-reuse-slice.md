# 000170｜按人民币单价看成本，上下文估算与 DSH 对齐

2026-11-19 23:48 +08:00

- 模型配置新增「成本单价（元 / 百万 tokens）」：输入、输出、缓存读取三个可选字段。填写后：
  - 输入框下方状态栏显示 `≈ ¥金额`；
  - Token 浮层新增输入成本、缓存成本、输出成本与合计成本。
- 金额按真实 token 用量在本地估算，不参与计费；缓存读取单价留空时按输入单价计算；三项都未填写时不显示成本。
- 上下文 token 估算改为与 DSH token-meter 相同的口径（4 字符/token + 块/角色开销），数字更接近真实请求。
