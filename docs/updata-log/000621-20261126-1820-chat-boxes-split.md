# UPDATE-000621｜中间区拆成四个盒子，正文区不再被输入框压住

- 时间：2026-11-26 18:20（Asia/Shanghai）
- 类型：refactor（结构）+ fix（观感）

## 变化

- 中间区现在是四块各占一行的盒子：**顶部切换条 · 对话会话区 · 刻度胶囊（窄栏时） · 输入框**。会话区自己带一层 1.2rem 的底部渐隐，正文滚出视口时柔和淡出，不会再被输入卡片压住、也不会再出现「一整块白」。
- 输入框单独成行，滚动条只到会话区底缘；滚到最底部时最后一行是完整可见的，不会被糊掉。
- 中间区独占整屏时，正文列与输入卡片一起放宽（最宽约 64rem，约三成更宽），不再两侧空一大片。
- 输入框里的**任务盒子**（会话任务清单）与**目标盒子**（进行中的目标）保持原样，仍然贴在输入卡片上方。

## 怎么验证

打开任一有历史的会话，滑到最底部：最后一句话应完整可读，输入卡片紧贴会话区、中间没有空白带；把右栏收起让会话区独占整屏，正文与输入卡片会一起变宽但仍居中；缩到 900px 左右，刻度条会变成输入框上方的胶囊。
