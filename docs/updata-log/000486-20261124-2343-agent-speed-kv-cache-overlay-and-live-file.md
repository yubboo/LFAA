2. **浏览器 Agent 点击指示层去边框重做**：去掉丑陋的目标元素方框边框，改为极简指针 + 柔光涟漪 + 无重边框毛玻璃小标签，不遮挡按钮文字。
3. **保住 KV 缓存并大幅提速省 Token**：
   - 冻结运行期首条 System Prompt 前缀（动态步数/接管状态改由尾部按需注入），避免每轮打穿 KV Prompt Cache。
   - 引导 Agent 并行批量读文件、合并验证命令、克制单轮视觉验收。
   - 修复 `grep` 传入单个文件路径时的报错，减少无意义重试轮次。
