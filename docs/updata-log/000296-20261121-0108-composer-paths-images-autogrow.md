# 输入框升级：支持绝对路径、粘贴图片、拖拽文件与自动增高

- 日期：2026-11-21 01:08 +08:00。
- 新增能力：
  - 粘贴或输入本机绝对路径（如 `E:\lfaa\AGENTS.md`）会生成「绝对路径」芯片，发送时作为本地文件上下文交给 Agent 读取；
  - 直接粘贴图片、或把文件/图片拖进输入卡片，会自动存入会话附件库并显示在附件芯片里；
  - Shift+Enter 换行后输入框会自动长高（超过上限才内部滚动），不再写死高度；
  - 附件芯片标签/详情单行省略，悬停可看完整路径，删除按钮保留。
- 验证。`check`／`lint`／`typecheck`／`build`／`test`（340 项全过）／`probe:loader` 全绿；真实浏览器完成 Shift+Enter 三行增高、粘贴路径、粘贴图片、拖拽文件四项验收，控制台无错误。
