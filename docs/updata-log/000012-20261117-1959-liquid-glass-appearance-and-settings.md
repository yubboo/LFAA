# UPDATE-000012｜全新设置中心外观能力与苹果液态玻璃视觉风格

- 时间（含时区）：2026-11-17 19:59:15 +08:00
- 类型：新增 / 优化
- 关联开发日志：`../dev-log/000012-20261117-1959-liquid-glass-appearance-and-settings.md`

## 用户能看到的变化

- **苹果液态玻璃视觉体系**：新增柔和双色低眩光氛围背景（默认 `LFAA 液态玻璃`），侧边栏、设置卡片与弹出菜单具备毛玻璃模糊、增色、轻柔叠白、顶边亮边与内描边折射质感，同时压低文字区域底亮度以保障清晰可读。
- **升级外观设置页面**：
  - **视觉风格**：新增模式缩略预览胶囊（跟随系统 / 浅色 / 深色）、多套主题预设（`LFAA 液态玻璃`、`经典极简`、`柔雾青灰`、`静谧夜蓝`）及主题 JSON 导入/复制按钮。
  - **色彩与字体**：新增强调色下拉菜单（默认/蓝/绿/黄/粉/橙/紫/白/自定义取色）、背景与前景 HEX/取色器、界面字体选择。
  - **高级面板**：支持调节界面字号（px）、代码字号（px）、减少动态效果、分别设置浅色与深色模式、界面字重、内容字体、代码字体、半透明侧边栏开关、对比度滑块、差异标记及指针光标开关，全部即时生效并保存在本地浏览器。
- **升级设置中心左二菜单栏**：新增顶部设置项搜索过滤框，并将设置项整理为“个人 / 集成 / 编码”三组；未接入条目清晰标注“暂未接入”。

## 影响范围与使用提示

- 影响 `packages/ui/layout` 与 `apps/web`，已在桌面端（`1440×900`）与手机端（`390×844`）通过内置浏览器实测验收；个人设置保存于当前浏览器 `localStorage`。
