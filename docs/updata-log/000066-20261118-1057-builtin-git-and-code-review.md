## 新增功能

1. **设置中心 → 编码新增「Git」配置页**
   - 支持配置新建分支前缀（默认 `lfaa/`）、Pull Request 合并方法（`合并` / `压缩合并`）、`始终强制推送`（`--force-with-lease`）、`创建草稿 Pull Request`、`/review` 审查结果呈现方式（`内联` / `单独`），以及自定义「提交指令」与「Pull Request 指令」。
2. **设置中心 → 编码新增「代码审查」配置页**
   - 自动探测本地与绑定项目中的 Git 代码仓库，支持按仓库单独切换自动审查策略（遵循个人偏好 / 强制启用 / 关闭），并支持配置全局「自动代码审查」「审核触发条件」「全面代码审查」「将额度用于审查」以及「审查智能体」侧重方向与自定义指引。
3. **内置 Git 与代码审查工作台 + `/review` 命令**
   - 点击左二或设置快捷入口即可进入「内置 Git 与代码审查」工作台：查看当前分支与变更文件、逐文件查看着色 Unified Diff、暂存/取消暂存、新建前缀分支、按指引生成提交草案与 PR 草案、浏览 Git 提交历史，并一键运行本地代码审查（或在聊天输入框直接输入 `/review` 启动审查）。
