# UPDATE-000618｜连接器不再“假连接”：真跑一次、显示真实工具数、详情可测试

- 时间：2026-11-26 17:12（Asia/Shanghai）
- 类型：fix（可信度）

## 变化

- **连接前真跑一次**：CLI 连接器会先真正执行一次命令（Git/pnpm 等跑 `--version`，Docker 跑 `info` 验证守护进程，kubectl 跑 `version --client`）。执行失败就不写入配置，直接把原因告诉你，不会留下“看起来连上了、其实跑不动”的连接器。
- **卡片显示真实工具数**：已连接的卡片会显示「N 个工具」；MCP 的数字来自服务器进程实际声明的工具（例如「记忆图谱」是 9 个），不是写死的。
- **详情可以当场测试**：CLI 连接器详情里新增「测试」，点击后真实执行并回显路径与版本，例如 `D:\AI\Git\cmd\git.EXE · git version 2.53.0.windows.1`。
- 连接成功的提示也带上了证据：`连接器 Git 已连接，命令探测成功：git version 2.53.0.windows.1。`、`连接器 记忆图谱 已连接，服务器返回 9 个工具。`

## 怎么验证

设置中心 → 连接器 → 点「+」连 Git 或记忆图谱 → 卡片上出现「3 个工具 / 9 个工具」；点开详情 →「测试」看真实版本输出；再让会话里的 agent 调用一次（例如 `cli__git__status`），返回的就是真实命令结果。
