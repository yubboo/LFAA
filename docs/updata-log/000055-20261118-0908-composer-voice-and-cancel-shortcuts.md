# Updata Log 000055 — 输入栏新增语音输入（Ctrl+M）与运行取消（Ctrl+D）交互

- **时间**：2026-11-18 09:08:19 +08:00
- **版本号/编号**：000055

## 本次新增功能

1. **语音输入按钮与 `Ctrl+M` 快捷键**：
   - 在发送按钮左侧新增麦克风按钮，悬停显示 `语音输入 Ctrl+M`（英文 `Record Audio Ctrl+M`）；点击或按下 `Ctrl+M` 开启语音识别时变为红色三竖条动画波形并提示 `停止录音 Ctrl+M`（若浏览器不支持或网络受限会明确提示错误原因）。
2. **运行中取消按钮与 `Ctrl+D` 快捷键**：
   - Agent 任务执行期间发送按钮切换为红色方块停止按钮，悬停提示 `取消 (Ctrl+D)`，支持点击或直接按 `Ctrl+D` 中止当前任务。
