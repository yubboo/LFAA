# 输入框斜杠命令支持 Host 注册

- 日期：2026-11-20 23:27 +08:00。
- 用户可见变化：在输入框输入 `/` 时，除内置命令外会出现 Host 注册的命令（当前内置示例：`/summarize` 总结会话、`/explain` 解释上一条）。选中后提示词会展开到输入框，确认后发送；插件中心新增「斜杠命令」插件。
- 接口：`GET /api/commands` 列出命令、`POST /api/commands/run` 执行（未知命令 404、缺参 400）。
- 限制：暂不支持在命令后直接带参数（`/explain 缓存`），选命令只展开提示词；命令列表在页面加载时获取一次。
- 验证。`check`／`lint`／`typecheck`／`build`／`test`（318 项全过）／`probe:loader` 全绿；真实浏览器验证接口、弹层、提示词展开与插件中心可见，控制台无异常。
