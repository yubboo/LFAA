# 000366｜文件树换 VS Code 风格彩色图标：新增 @lfaa/ui-icons 包

- 时间：2026-11-22 11:30–11:55 +0800。负责人先问「有没有字体图标库、阿里 iconfont、能不能做个 fonts 包」，随后选择「彩色 SVG 图标包」并把本轮范围限定为文件树。
- 结论：项目此前没有字体图标库，只有 `@tabler/icons-react`（线性单色）。字体方案（Material Symbols / Font Awesome / Remix）单色、整套 13–25 MB 且需子集化，做不出多色文件图标；阿里 iconfont 没有官方 npm 包、需要账号导出、逐图标授权不透明，故不引入。改为新增彩色 SVG 图标包。
- 用户可见变化：右栏文件树、文件标签栏、路径面包屑、Git 审查与回合变更列表改用 VS Code Seti 风格彩色图标；根目录、`src`、`docs`、`tests`、`assets`、`scripts`、`config`、`packages`/`node_modules` 等文件夹各有不同图标，常用文件夹还区分展开态。
- 新包 `packages/ui/icons`（`@lfaa/ui-icons`，归 `ui/` 组）：
  - `contract/file-glyphs.ts`：扩展名、特殊文件名、目录职责 → 图标 key 的纯映射，无 DOM/React，Host 与 Client 共用。
  - `client/glyphs.ts`：从 `@iconify-json/vscode-icons@1.2.30`（MIT）提取 80 个字形（53 个文件类型 + 27 个文件夹，含常用 `-opened`），约 160 KB 源码。
  - `client/index.tsx`：`FileTypeIcon`（内联 SVG，`size` 默认 16，支持 `root`/`expanded`）。
  - `client/FileTypeIcon.module.css`：极淡暗色 `drop-shadow` 描边，避免浅色底上的白色文档图标看不清。
  - `LICENSES/vscode-icons-LICENSE.txt` 保留 MIT 原文；README 三件套与 `README.i18n.yaml` 已生成。
- 接入：`@lfaa/chat` 增加 `@lfaa/ui-icons` 依赖；5 处 `FileTypeIcon` 导入改到 `@lfaa/ui-icons/client`；删除旧 `client/components/file-icons.tsx` 与其聊天测试；文件树根节点传 `root`；`RightFileTreePane.module.css` 移除旧的 9 色调与色块规则。
- 注册与文档：`tsconfig.base.json` paths（含 `/contract`、`/client`）、`tsconfig.host.json` 引用、chat `tsconfig.json` 引用、`pnpm-lock.yaml`；`docs/architecture/overview.md` 与 chat README 依赖列表同步。
- 实测（无头 Chrome + 本机 Chrome，5173 现有 dev 服务，绑定 app1）：浅色/深色下彩色图标与展开态正确，根目录、`README.md` 的标签页与面包屑一致，控制台 0 错误。截图：`%TEMP%\lfaa-icons\panel-light.png`、`panel-dark.png`、`panel-light-expanded.png`、`open-file.png`。
- 体积：Web 产物 JS 1,038.60 KB → 1,183.62 KB（gzip 303.98 → 351.98 KB），CSS 基本不变；取舍是把 80 个字形内联进包，换取零额外请求、离线与 Electron 稳定可用。
