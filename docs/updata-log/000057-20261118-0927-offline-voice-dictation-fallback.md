## Bug 修复与体验优化

1. **修复点击语音输入报错「`语音输入不可用: network`」**
   - 当浏览器自带在线语音识别在受限网络或离线环境下触发 `network` 错误时，LFAA 现在会自动无感切换至 **本机浏览器 16kHz WAV 录音 + Windows 离线 SAPI 语音识别**，全程无需连接外网即可完成中文/英文听写并填入输入框。
   - 若本机无可用麦克风或未授权麦克风，也会显示清晰可读的中文指引，不再输出原始英文错误码。

2. **输入区提示条可关闭优化**
   - 优化输入区状态/错误提示条的卡片对比度与排版，并新增右侧 `×` 关闭按钮，随时一键收起提示。
