# UPDATE-000593｜长会话只渲染屏幕附近的消息，翻历史与切会话更轻

- 任务编号：UPDATE-000593（对应 DEV-000593）
- 时间：2026-11-26 14:50（Asia/Shanghai，UTC+08:00）
- 类型：perf（体验优化）
- 关联：DEV-000593

## 用户能看到什么

- **长对话不再把整段历史都挂在页面上**：消息超过 60 条的会话，只保留可视区上下各 4 条，其余用占位高度代替。同一个 80 条消息的会话，页面常驻节点从 4,736 降到 1,237（少 74%），一次渲染最长任务从 298ms 降到 123ms。
- **翻历史更稳**：连续上滚 25 次没有回跳，停止滚动后位置不漂移；「回到底部」仍然精确贴底。
- **从顶部看起也正常**：滚到最顶时日期分隔条与第一条消息不重叠。
- **点刻度跳转更准**：点「第 6 轮」，窗口化下落在第 6 轮的第一条消息（偏差 0px）；原来的全量渲染路径约有 400px 偏差。
- **短会话完全不变**：60 条以内的会话仍是一次性渲染，观感与之前一致。

## 已知未解决

- 屏幕外的历史消息不在 DOM 里，屏幕阅读器与「全选复制」拿不到完整历史（导出对话不受影响）。
- 滚动条比例按「已测量 + 估算」计算，和真实高度有偏差，滚动过程中会逐步校准。
- 需要临时回到旧渲染时：控制台执行 `localStorage.setItem("lfaa:thread-virtualization","off")` 后刷新；恢复默认删除该键即可。
