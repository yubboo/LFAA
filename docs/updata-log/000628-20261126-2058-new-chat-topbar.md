# UPDATE-000628｜新会话顶栏更干净：不再显示「新聊天」和「本地模式」

- 时间：2026-11-26 20:58（Asia/Shanghai）
- 类型：fix（顶栏收敛）

## 变化

- 新会话（还没有消息）的中央顶栏不再显示「新聊天」标题，只保留左右侧栏控制。
- 顶部右侧的绿色圆点 + 「本地模式」提示已完全移除，不再出现在任何会话里。
- 打开已有消息的历史会话后，顶栏恢复显示该会话标题（例如「你好」）；项目视图仍显示项目名。

## 怎么验证

新建聊天：中央顶栏不应出现「新聊天」或「本地模式」。打开一条历史会话：标题应恢复为该会话名，右侧仍不应出现「本地模式」。
