# 000445｜中间区域换成「聊天 / 工作」两种形态：分段切换、输入框并入中心区、标准模式挪到输入框旁

- 时间：2026-11-24 09:05–09:45（Asia/Shanghai）。
- 变化：新建会话的中间区域不再是「标题 + 三枚胶囊 + 底部远处的输入框」，改成和参考图一致的一块：
  - 顶上是一条小鱼线稿图标，下面是标题——**聊天**模式是「我们从哪里开始？」，**工作**模式是「我们要做什么？」。
  - 标题下面是一枚两段胶囊「聊天 / 工作」，点一下整块中心区跟着变，刷新后还记得上次选的模式。
  - 输入框直接搬进这块中心区（不再贴在工作区最底部），下面接三条带小图标的起步建议和一行提示（提示会说明当前模式能做什么）。
  - 发出第一条消息后，输入框自动回到底部原来的位置。
- 两种形态的差别（**工作模式一个入口都没少**）：
  - 聊天：输入栏压成一行——会话模式、加号、输入框、模型、语音、发送；项目挂载、媒体库、权限这些「干活」的入口收起来，界面干净。
  - 工作：项目/工作位置挂载条、媒体库、加号、权限、模型、语音、发送、统计全部照旧；只把「标准模式」胶囊从顶栏挪到了输入栏里，和项目选择在同一行附近，一眼能看到当前会话模式。
- 小变化：左上角的栏头文字改回品牌「小鱼」（原来显示的是模式名），点开仍然是模式菜单。
- 不想要动效/窄屏也没问题：窄窗口输入栏自动回落到两行，窗口再小就按原来的手机布局走。
