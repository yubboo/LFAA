# 生图续改遵循原图与修改要求（DEV-000316）

**时间：** 2026-11-21 18:31 +0800

用户反馈生图模型收到「太丑了，苗条一些」等续改后像重新抽图，提示词没落实，人物被替换。

排查发现，连续改图的自然语言识别规则没有覆盖这些口语表达，导致直连生图请求没有附上上一张图片。旧结果 sidecar 也印证了两条续改记录都没有参考图。Wan 2.7 请求体还包含该模型不支持的 `prompt_extend` 参数。

本轮补齐相对修改词识别；用户没有明确引用图片时，续改自动参考当前聊天最近一张生成图。编辑提示词现在先写用户的修改要求，并要求修改结果清晰可见，再要求保持同一主体和未点名的画面内容。Wan 2.7 生图请求省略 `prompt_extend`。新增回归覆盖精确反馈、参考图传递、编辑指令优先级和 Wan 2.7 请求参数。

**真实模型验收：** 在 5173 的原聊天中只发起一次 `wan2.7-image` 编辑，点击引用第一张「美少女」图片并发送原句「太丑了，苗条一些，要模特身材」。模型约 15 秒返回 2048×2048 PNG；sidecar 的 `referenceImages` 为 1，参考路径与第一张图完全一致。结果保留了同一个人的脸、发型、表情、姿势、服装和樱花背景，但整体没有明显变苗条，身材指令本次没有充分落实。随后改进编辑提示模板并通过自动化测试；为避免继续消耗套餐额度，没有再做真实生成，因此新提示模板的实际修改效果还需后续生成确认。

重启后在内置浏览器刷新原聊天，历史图片都能解码，控制台无新增错误。`pnpm test` 376 项、`pnpm check`、`pnpm lint`、README 配对、`pnpm typecheck`、`pnpm build`、`pnpm probe:loader` 均通过；构建保留现有 Web 大分块提示。未提交或推送。
