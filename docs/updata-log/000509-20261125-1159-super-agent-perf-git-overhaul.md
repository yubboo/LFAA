# UPDATA-000509｜性能全面提速、多角色子智能体右栏流式工作台、改动安全气囊与内置 Git 收口

- 编号：`000509`
- 日期：`2026-11-25 11:59:00 +08:00`
- 关联开发日志：`docs/dev-log/000401-000600.md`（`DEV-000509`）

## 用户可见变化

1. **F5 刷新与日常交互明显提速**
   - 开发服务非 API 模块请求不再经过鉴权与 30 条路由网关；服务端会话列表按文件 `mtime + size` 缓存；首屏移除多余请求与空闲轮询，刷新更快、更轻。
2. **小鱼智能体更快、更稳，且改代码自带「安全气囊」**
   - 补齐 DeepSeek / 火山方舟多轮思考协议与 `deepseek-v3/v4` 能力识别，默认推理深度调整为更均衡的 `medium`，冻结首条系统提示以提升 KV Cache 命中率。
   - `edit_file` 自动兼容 Windows CRLF / LF 换行差异，减少编辑失败重试。
   - **每轮改动一键撤销**：小鱼在每轮首次修改/新建文件前自动保存改前快照，可在「本轮变更」中一键「撤销本轮改动」无损恢复；修改核心配置文件采用独立高敏审批桶。
3. **多角色子智能体协作 + 右侧多标签流式舞台**
   - 支持按需派发 `research`（只读调研）、`coder`（定向实现）、`reviewer`（只读代码审查）、`browser`（浏览器操控验收）专职子智能体。
   - 主聊天区以紧凑派发行展示子智能体动态与汇报回执；右侧工作台自动为每个非浏览器子智能体打开独立标签页，**复用主聊天流式思考与工具链**实时输出，完成后自动折叠总耗时并展示「任务已完成，结果已回传给主智能体。」提示，支持在标签底部直接追问。
4. **内置 Git 与工作树（Worktree）体验收口**
   - 智能体新增免审批只读 `git_status` / `git_diff` 工具，直接感知仓库状态与差异。
   - 右侧 Git 变更面板新增单文件「放弃更改」按钮并正确联动会话绑定工作树；工作树列表新增安全「合并回主分支」入口及脏目录删除保护。
   - 清理设置中心「Git」与「代码审查」中的重复项与未接线占位开关，所有保留设置均真实生效。
