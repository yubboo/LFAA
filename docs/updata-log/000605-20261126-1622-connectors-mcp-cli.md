# UPDATE-000605｜连接器：把 MCP 服务器和本机命令行工具接进会话

- 时间：2026-11-26 16:22（Asia/Shanghai）
- 类型：feat（设置中心 · 新能力）

## 变化

- 设置中心「集成」里的「MCP」升级为「连接器」：一页分两个分段——**MCP 服务器**（原有连接、项目范围、工具审批、导入 JSON 全部保留）和**命令行工具**（新增）。
- 命令行工具把本机 CLI 接成智能体可调用的动作：每个动作有 id、标题、参数（字符串 / 数字 / 布尔、可选值、必填）和 argv 模板；工具名为 `cli__<连接器>__<动作>`。
- 添加时有三个模板可直接用：**GitHub CLI**（PR / Issue / 仓库查询）、**Docker**（容器、镜像、日志、compose 启动）、**pnpm**（依赖列表、过期检查、运行脚本）；也可以从空白自建。
- 可执行文件支持「探测」：显示解析到的完整路径与版本；找不到时连接器标红「未找到 xxx」，不会假装可用。
- 审批按连接器设置：默认每次确认，信任后免确认；标记为「只读」的动作不会被当成写操作。
- 安全边界：命令按 argv 直接启动、不经过 shell；参数强类型校验；默认 60 秒超时并结束整棵进程树；超长输出截断；环境变量可写 `${env:NAME}` 引用系统变量，配置本身加密保存。

## 怎么用

设置中心 → 集成 → 连接器 → 命令行工具 → 添加工具 → 选 Docker（或 GitHub CLI / pnpm）→ 探测 → 保存。之后在会话里就能让智能体调用这些动作；不需要时在同一页关闭开关或删除。
