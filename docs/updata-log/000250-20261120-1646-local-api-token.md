# 任务 000250｜本机接口鉴权与安装安全加固

- 本机 Web 接口现在需要一次性令牌：页面由 Host 自动注入，正常使用无感知；任意网页、其他标签页或扩展发起的跨站请求会被 401/403 拒绝。点开恶意网页不再能悄悄触发插件安装或改写模型配置。
- 插件安装来源不再拼进 `cmd /c` 命令行：Windows 下每个参数单独加引号，含 `&`、`|`、`%` 等元字符的来源直接给出明确错误；能拿到 pnpm 入口时改用 `node` 直接执行，完全绕开 shell。
- 已打开的旧页面需要刷新一次（开发服务器重启后令牌会变化）。同机同权限进程不在防护范围内，本机"沙箱"仍是工具层策略，详见 `docs/architecture/local-api-auth.md`。
