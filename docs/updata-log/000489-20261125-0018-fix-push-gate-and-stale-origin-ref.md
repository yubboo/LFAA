# UPDATE-000489｜一键推送不再被内置技能文档拦下，「领先 N 个提交」也不再误报

- 编号：UPDATE-000489
- 日期：2026-11-25 00:18（Asia/Shanghai）
- 类型：修复

## 本次变更

- **提交不再被内置技能文档卡住**：`lfaa.bat` 菜单 4 之前会因上游收录的技能文档（行尾空格、文件尾空行）被空白检查拦下，现在该目录与其它检查一样被跳过，改完代码一次就能提交。
- **推送前先对齐远端记录**：本地保留的 `origin/main` 可能只是旧记录，控制台会显示并不存在的「领先 N 个提交」；现在推送前先刷新远端引用，待推送提交与实际一致，状态行也跟着显示正确。
- **「未提交 N 项」不再跳动**：同一批改动不会因为暂存前后从 224 项突然变成 861 项。
