# UPDATE-000371｜工作树清理更稳：有聊天绑定的失效记录不会被悄悄删掉

- 时间：2026-11-22 17:05 +0800（Asia/Shanghai）
- 类型：体验优化 / 安全边界

## 你会看到什么

- 目录被外部删掉、但仍被聊天绑定的工作树记录不会被「清理失效记录」删除；它会保留并显示失效警告，提醒你先解绑。
- 只有没有聊天绑定的失效记录才会被清掉。
- 工作树区块的提示更具体：读取失败、合并预演失败、复制合并命令失败分别提示。

## 兼容性

- 不改变正常删除工作树的规则：有绑定会话或未提交改动时仍默认拒绝。
- 不影响已绑定工作树的聊天运行与文件读取。
