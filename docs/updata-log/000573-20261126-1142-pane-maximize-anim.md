# UPDATE-000573｜最大化/还原不再瞬切：两块面板互补变形

- 日期：2026-11-26（Asia/Shanghai）
- 之前点「最大化工作台」或按 Ctrl+Shift+M 是瞬间换排版；现在是 260ms 连续动画：会话列淡出、工作台从自己那侧铺满。
- 两种排版都生效：聊天区在左时工作台从右往左铺开；预览区在左时工作台从左往右铺开。
- 任意一帧中间区域都被两块面板之一覆盖，实测两种排版、两个方向都是 0 空白帧；动画结束后不残留 transform、不残留覆盖层，滚动位置不变。
- 变形期间工作台只显示底色，收尾时按新宽度显示内容——这是为了避免 `scaleX` 把文字与图标拉扁。
- 系统开了「减少动态效果」时仍然瞬时切换；面板收着的时候点最大化也走瞬时切换。
- 请在真实聊天里试一次最大化再还原，看淡出与铺开的节奏是否合适。
