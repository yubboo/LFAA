# UPDATE-000660｜右侧工作台加入无限画布

- 时间：2026-11-27 10:55（Asia/Shanghai）
- 类型：新功能
- 关联开发日志：[DEV-000660](../dev-log/000601-000800.md#dev-000660无限画布与白模预演)

## 变化

- 在项目里点击右侧「＋」→「无限画布」，新建或打开已保存的画布。提示词、素材、白模、生图、生视频各自可拖动和连线。
- 双击白模节点可摆人物、道具和相机，记录走位及相机关键帧。静帧可作为分镜构图参考，短片可以作为支持该用途的视频模型的运动参考。
- 生图和生视频保留各次结果，选中的产物版本可以继续连到下游。修改节点后可单独运行，原有连线继续引用原版本。关掉标签、刷新或重启后，可从同一项目重新打开画布。
- 视频模式由所选模型决定。支持首尾帧或参考素材的模型会显示相应端口。运动参考需要 MP4。

## 实测

在隔离项目使用万相模型，完成分镜图、图片首帧生视频，以及白模 MP4 作为运动参考生视频。图像和两段视频均已下载到测试画布。
