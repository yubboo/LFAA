# UPDATE-000483｜基础 UI 组件库接入 Base UI 无头原语，提升浮层菜单与控件交互手感

- 编号：UPDATE-000483
- 日期：2026-11-24 22:44（Asia/Shanghai）
- 类型：优化 / 新能力

## 本次变更

- 在 `@lfaa/ui-primitives` 中正式引入无头组件底座 `@base-ui/react`（与 LFAA 现有 CSS Modules 和深浅双主题变量无缝融合，不引入 Tailwind），首批封装并导出 5 个高频通用组件：
  - `DropdownMenu`（下拉菜单，自动防溢出定位、键盘上下选择与 Esc 恢复焦点）
  - `UiSwitch`（触感开关）
  - `UiSelect`（键盘可选下拉选择器）
  - `UiTabs`（平滑分段标签）
  - `UiTooltip`（悬停防抖与自动避障提示）
- 内置浏览器工具栏的「更多选项（`...`）」菜单已率先升级为 `DropdownMenu`，深色与浅色主题下均自动避开视口边缘且支持键盘操作。
