# UPDATE-000592｜默认快捷键全面重排：统一 Ctrl+Alt 命名空间，避开浏览器/系统冲突

- 日期：2026-11-26（Asia/Shanghai）
- 之前 `Ctrl+Shift+S`（左二栏）、`Ctrl+Shift+B`（右栏）、`Ctrl+Shift+M`（最大化）、`Ctrl+K`（搜索）、`Ctrl+D`（中止）这些默认键位被浏览器/系统截走（另存为、书签栏、强制刷新、地址栏搜索、加书签…），设了也没反应。
- 现在所有默认键位统一成 `Ctrl+Alt`（少数再叠 `Shift`），一组表在 `packages/ui/layout/client/shortcut-defaults.ts` 里，注册表、悬停提示、右键菜单提示都读它：
  - 搜索 `Ctrl+Alt+K`、活动 `Ctrl+Alt+U`、左二栏 `Ctrl+Alt+1`、右栏 `Ctrl+Alt+2`、最大化右栏 `Ctrl+Alt+M`
  - 键盘快捷键页 `Ctrl+Alt+/`、设置中心 `Ctrl+Alt+,`、资料库 `Ctrl+Alt+L`
  - 新聊天 `Ctrl+Alt+N`、归档 `Ctrl+Alt+Shift+A`、置顶 `Ctrl+Alt+Shift+P`、标记未读 `Ctrl+Alt+Shift+U`、中止 `Ctrl+Alt+X`
  - 听写 `Ctrl+Alt+V`、推理强度 `Ctrl+Alt+R`
  - 新建标签页 `Ctrl+Alt+B`、关闭标签 `Ctrl+Alt+W`、下一个/上一个标签 `Ctrl+Alt+PageDown` / `Ctrl+Alt+PageUp`
  - 终端 `Ctrl+Alt+T`、变更审查 `Ctrl+Alt+G`、侧边提问 `Ctrl+Alt+S`
- 输入框里也放行 `Ctrl+Alt` 组合（打不出字符），所以听写 / 推理强度 / 中止在输入栏里同样生效；单键与纯 `Ctrl` 组合仍交给输入框。
- 旧键位不再绑定；你之前在设置里手动改过的动作保持你的绑定不变（只换默认值）。
- 悬停气泡、右键菜单、设置页里的键位徽章全部跟着新默认走，不会再出现「提示写的是旧键位」。
- 追加：三栏开合改成方向直觉键位——Ctrl+← 左二栏、Ctrl+→ 右栏、Ctrl+↓ 终端（当前是右侧工作台里的终端标签页，不是底部独立面板）；输入框里 Ctrl+←/→ 仍是按词移动光标，不会被抢。
