# UPDATE-000388｜推送菜单里的中文提交信息不再乱码

- 时间：2026-11-22 18:05–18:20 +0800（Asia/Shanghai）
- 类型：Bug 修复

## 你会看到什么

- 菜单里「当前 HEAD：…」和「将推送 N 个提交」的列表，中文提交信息显示正常，不再出现 `鎺ㄩ€佽彍鍗?` 这类乱码。
- 仓库地址恢复为 GitHub 的规范名 `https://github.com/yubboo/LFAA.git`（大写）；此前误改成小写，推送时服务器会回 `repository moved`。

## 原因

- 菜单由 Windows PowerShell 5.1 执行，它默认按本地 OEM 代码页解码原生命令输出；`git log` 输出的是 UTF-8，于是中文被拆错。
- 修复方式：脚本启动时把 `[Console]::OutputEncoding` 设为 UTF-8；PowerShell 自身输出走 `WriteConsoleW`，不受影响。

## 兼容性

- 只影响原生命令输出的解码与远程地址常量；提交、安全检查、推送与强制推送逻辑不变。
