# UPDATE-000613｜中间工作区顶栏与左二栏统一成同一种胶囊

- 时间：2026-11-26 17:10（Asia/Shanghai）
- 类型：feat（界面统一）

## 变化

- 中间工作区的顶栏从「一整条带分割线的平栏」改成悬浮胶囊：和左二会话栏头部同一形状、同一描边与底色，圆角、留白两端一致。
- 胶囊里保留原来的全部内容：左栏展开/收起、会话标题、会话模式（如「标准模式（默认）」）；右侧仍是本地模式状态、更多操作与右栏展开/收起。
- 深色、浅色、图片主题与 1024 窄窗、390 手机下形态一致；胶囊内部的按钮、标题省略与悬停反馈都没变。

## 怎么用

无需操作；这只是外观统一。鼠标移到胶囊里的按钮上，提示与点击行为与之前相同。
