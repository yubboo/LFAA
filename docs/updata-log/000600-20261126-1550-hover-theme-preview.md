# UPDATE-000600｜外观页：鼠标一移，预览跟着走

- 时间：2026-11-26 15:55（Asia/Shanghai）
- 类型：feat（设置中心外观页交互）

## 变化

- 顶部常驻预览取消：不用再滚回页首看效果。
- 鼠标移入任意主题卡或明暗卡，光标旁会浮出一块实时预览（迷你工作台 + 主题名 + 「点击应用」），松手点击卡片才应用。
- 悬停时系统箭头换成显示「预览」两字的自定义光标；移开卡片即恢复。
- 浮层靠近屏幕右/下边缘会自动翻到另一侧；滚动、滚轮或按下鼠标立即收起，不挡操作。
- 预览跟随只写位移，不触发整页重渲染；卡片之间移动时延迟 70ms 收起，避免闪烁。
- 浮层有平滑过渡：淡入 + 轻微上浮，收起时淡出，换图时照片淡入，不再硬切。
- 移除了卡片上的系统原生名字提示（悬停约半秒会弹出来挡住预览的那块），名字只在浮层底部显示。

## 怎么用

设置中心 → 外观 →（预设）：把鼠标放到任意主题卡上，预览就在光标旁出现；点一下应用整套外观。
