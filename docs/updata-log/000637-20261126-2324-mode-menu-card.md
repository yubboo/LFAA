- 模式卡片不再越出左二栏：1440 窗口下从 360px 收到 194.5px（栏宽 208.5px − 左右内缩 14px），1920 下最宽 266.5px，卡面上限仍是 21.5rem。

## 怎么验证

点左上角模式按钮：卡片应只在左二栏内展开、右缘留出滚动条位，深色/浅色都是实底；切到 1024 窗口时卡片只显示「聊天 / 工作」两行。切到「工作」再打开，勾应落在「工作」；按 Esc 卡片关闭且焦点回到按钮。
