# UPDATE-000466｜活动行左侧图标与动词起点对齐

- 时间（含时区）：2026-11-24T19:00:00+08:00
- 类型：修复
- 关联开发日志：`../dev-log/000401-000600.md`（DEV-000466）

## 用户能看到的变化

- 聊天里的工具活动行（如「已检索内容 …」「已读取 …」）与文件活动行（如「已分析 README.md」）现在共用同一条左侧图标槽：类型图标中心、动词起点逐像素对齐，不再出现上下两行「已分析」比「已检索内容」往右错 4px 的情况。
- 命令行、技能行、任务清单行与文件行的图标列一并对齐，整段活动链左侧成一条直线。

## 影响范围与使用提示

- 只影响聊天活动链的左侧图标列，行高、文案、右侧耗时/状态/箭头、点击展开与右栏预览逻辑均未改变。
- 深浅主题下都按同一套语义色令牌呈现，图标颜色不变（创建绿、编辑强调色、删除红、分析青玉色）。

## 已知限制

- 目标参数（路径/文件名）仍跟随动词长度自然排布：文件行带彩色文件图标与胶囊背景，工具行是等宽路径文本，因此两者不追求同一列。
