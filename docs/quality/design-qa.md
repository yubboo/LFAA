## 已实现

- 常规页新增权限、任务目录、默认打开方式、智能体环境、Shell、语言、视图、底部面板、终端位置、速度、提示建议、插件、编辑器、发送方式、弹窗、通知、实验功能与工作台偏好。
- 设置侧栏补齐参考图中的个人、集成、编码和归档入口，同时保留 LFAA 专属配置入口。
- 左右分隔器缩为单像素可见边线，透明拖动热区向两侧扩展；设置侧栏不再额外绘制重复边框。
- 设置中心和应用工作区共享左栏宽度，并迁移旧页面分别存储的宽度。
- 设置页保存进入前的工作区路由；返回时恢复该路由。
- Pointer 取消/失焦/丢失捕获/页面隐藏/卸载会回滚尺寸、取消动画帧并清理全局拖动状态。
- 前端、后端 TypeScript 构建已通过。

## 验收环境

- 目标视口：参考截图约 2048 × 1114 CSS 像素；当前未能启动浏览器进行页面截图。
- 浏览器能力：本任务环境没有可用浏览器；Cua 浏览器状态初始化返回 `nodeRepl.fetch request failed`。
- 禁止的替代验证：未使用 Playwright 或其他直接浏览器自动化，因为用户没有授权该验证方式。
- 检查范围：编译构建；未核对浏览器控制台、实际滚动、交互状态或最终像素差异。

## 尚未确认

- 统一栏宽在浏览器中的跨页面保存、刷新恢复和窄屏约束。
- 分隔器热区与单像素边界的实际命中范围，以及多种指针取消情形下的运行时恢复。
