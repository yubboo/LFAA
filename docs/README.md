## Sources of truth

- Rules: repository [AGENTS.md](../AGENTS.md) and [development rules](../开发规范.md).
- Current implementation: source code, package READMEs, and [system architecture](系统总体架构.md).
- Outstanding goals: [development plan](开发计划.md).
- Evidence for one task: its contract linked from [PROMPTS](PROMPTS.md).
- Archive: [historical index](archive/README.md). Historical files describe the implementation and validation at that time; they do not override current source or rules.

English pages provide navigation to available English guides. The Chinese architecture, plans, and historical contracts remain authoritative when a full English version is unavailable.
