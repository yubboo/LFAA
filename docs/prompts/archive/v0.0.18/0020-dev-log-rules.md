# #20 开发日志分层规范

## 主模块

`project-foundation`

## 目标

建立“当前日志 / 历史日志”分层，并把开发日志读取顺序、编号、命名和中文文档要求写成硬规则。

## 关键要求

- 开发前先读 DEVELOPMENT；
- 再读 Development Log INDEX；
- 只从 active 获取当前结论；
- archive 只用于回溯；
- 同一问题使用 #NN.x；
- 旧记录不删除；
- 旧记录必须指向新记录；
- 文档中文为主；
- 标题清晰、内容逐项列出；
- 文件名短、准、规范。

## 状态

`delivered in v0.0.18`
