# #21.2 黑白工作台重构

## 主任务

`#21 Web 工作台 UI`

## 用户要求

- UI 改为 Codex / ChatGPT 类风格；
- 不再使用水墨风格；
- 使用黑 / 白 / 灰主题；
- 左右栏允许更大范围拉伸，但必须有最大宽度；
- 吸附收起必须更丝滑。

## 实现约束

- 不复制 Codex / ChatGPT 品牌标识；
- 保留 LFAA 自有信息架构；
- 复用同一套 Web / Desktop App Shell；
- 侧栏拖动使用 rAF + CSS 变量预览；
- collapsed 状态只在拖动结束时提交；
- 动态最大宽度保护中央工作区；
- 不改 `.lfaa` 热插拔协议。
