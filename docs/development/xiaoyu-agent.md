# Shared Xiaoyu agent workspace

The product uses one shared work entry and one existing Agent Loop for every App. Apps retain their regular interfaces; optional App and capability references guide discovery without loading instructions or restricting the model's tools. Existing sessions and project data remain owned by their original account and services.

See the [Chinese development prompt and acceptance contract](xiaoyu-agent.zh.md). Runtime, browser, Provider and real game-server verification must be reported separately.
