# AI Work 回复排版修正合同

## 目标与 Owner

入口：AI Work `/tasks` 中央聊天。

Owner：`packages/client/ui-chat/src/AiWorkChat.tsx` 负责消息顺序、交互展开状态和当前动作行；`activity-duration.ts` 负责整轮时长文案；`ai-work-chat.css` 负责下方分隔线、当前动作与轨迹样式。活动来源继续使用 Session 已持久化的真实 `AiActivityItem`。

## 目标排版

1. 助手回复顶部展示整轮处理时间。运行中显示“已处理 xx 分钟 xx 秒”，时间随真实 Run 持续更新；完成后显示“用时 xx 分钟 xx 秒”。
2. 时长行下方放置细横线，正文紧接横线之后，保持普通聊天回复，不折叠最终答复。
3. 助手正文之后显示一行紧凑的当前动作摘要。Run 刚开始、尚无活动记录时仍显示“正在思考”；随后只按真实活动切换为思考、运行命令、调用工具、编辑文件、等待审批或等待补充信息。存在活动记录时，该行可展开完整活动轨迹。
4. 完整活动轨迹位于正文之后，运行中和完成后的默认状态均为收起。展开后每条活动都显示独立的可展开/收起摘要；详情、文件变更审阅入口及写作审阅入口仅在对应活动展开时显示。Run 结束时自动收起总轨迹；用户之后可以手动展开总轨迹并逐条查看。

## 边界与设置

- 只修复 Client 聊天呈现和直接相关回归；不改 Agent 决策/循环、Session 数据、SSE、权限、工具执行位置、滚动、Provider 或文件/Git Owner。
- 保持流式文本节点稳定且无光标，不展示隐藏推理、Shell 输出或原始工具结果。
- 沿用 Appearance 已有主题、字体/字号、强调色、壁纸遮罩/模糊和减少动态效果映射；不新增、重置或覆盖设置。
- 保留现有澄清记录、文件差异入口和回答正文。
- 保留工作树已有并行修改，仅触及本合同允许的片段。

## 验收与验证

- 回归确认运行中时长前缀为“已处理”，完成时为“用时”。
- 呈现回归确认时长行在正文前、分隔线在时长行下方、当前动作与完整轨迹在正文之后。
- 尚无持久化活动的 streaming Run 仍显示“正在思考”；收到真实活动后当前动作随其状态更新。
- 完整轨迹默认收起，用户可展开；轨迹内每条活动详情默认收起并可独立展开/收起；结束回调强制收起总轨迹。
- 运行活动耗时和 Client 聊天呈现定向回归、聊天包构建、适用类型/入口检查、`pnpm run check:workspace` 与 `git diff --check`。
- 真实浏览器交互/帧时间、Provider 与运行中服务加载须按实际执行情况单独报告；不得将静态/构建通过表述成这些已验证。

## 实施记录

回复布局现为“时长行 + 下方细分隔线 + 普通助手正文 + 当前活动摘要 + 可展开的完整活动记录”。运行中时间显示“已处理”，完成/失败/停止后显示“用时”；当前动作取自最新真实活动，尚无活动记录时仍显示“正在思考”。总轨迹默认收起；轨迹内每条活动独立展开，详情仅在对应行展开时显示。结束 Run 和切换会话时关闭展开状态。没有改动模型选择、权限/执行链、Session 活动格式、滚动或流式文本节点。

定向活动耗时与 Client 呈现回归 36/36 通过；`lfaa-client-ui-chat` 构建通过；根 `pnpm run typecheck`、`pnpm run build:web`、`pnpm run check:workspace`（178 个包）和 `git diff --check` 通过。构建产物写入根目录 `dist/`。未运行真实浏览器交互/帧时间、Provider 对话或重启/核实运行中服务加载。

本轮按用户最新截图继续补齐：无首个可见 token 时正文下方保留文本“正在思考”状态；模型开始流式输出后继续显示稳定纯文本正文，不展示隐藏推理。展开工作轨迹后，单条活动行可独立开合，详情、文件差异入口和写作审阅入口只在对应行展开时出现。AI Work 本机应用提示现在要求先发送简短、真实的用户可见进度说明，再观察当前屏幕；若目标已打开则结束，未打开才使用一次 `computer_use_launch_local_app.query`，随后观察并停止重复搜索/启动。提示修改遵从现有模型决策与统一权限，不做关键词路由。
