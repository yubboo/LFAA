## 设置中心接入与消费

没有新增设置或重置账户偏好。使用 `aiRuntime.commandTimeoutSeconds` 和现有请求/工具预算；Minecraft Runtime 的核心、执行方式、内存/端口及下载、安装、就绪、停服时限继续由领域 Owner 读取。`permissions.mode`、`general.integratedShell/agentEnvironment/taskFolder`、Provider/MCP App 作用域保持原授权。

共享类型、默认值与写入校验覆盖 `general`、`appearance`、`shortcuts`、`ai-runtime`、`minecraft-runtime`、`git`、`permissions`、`plugins`、`personalization`、`computer-control` 十个现有分类。Git、插件、个性化与电脑操控的执行入口/授权默认值保持现有 Owner；它们参与设置合同收敛，不因此新增产品能力。

客户端共享 `general`、`appearance`、`shortcuts` 默认值，继续使用主题、强调色、字体/字号、对比度、背景、遮罩/模糊、减少动态效果和 `updateSurfaceOpacity`；共享背景清单不改默认图片。快捷键在提交后更新配置引用，设置对象变化不会重新挂载键盘监听。严格写入校验覆盖十个分类；旧记录读归一化不等于允许非法新写入。

### MCP 出站与分页阻塞修复（2026-10-08）

- 远程生产控制端会校验 MCP 主机的全部 DNS 结果；任一私网、环回、链路本地、共享地址、文档/协议保留段或其他非公网单播地址都会拒绝。连接使用本次校验并固定的 IP，避免校验后 DNS 重绑定；不跟随重定向。本机桌面、本机 CLI 回环和开发/测试回环仍可访问本机 MCP。

- 本轮实际回归：MCP 地址/协议测试 2/2、Session 多页/反馈/隔离/冷缓存回归 1/1、完整 Web Profile API 回归 1/1、Host 类型检查通过。完整装配测试新增认证分页断言；将异步记忆回读改为有上限等待，并把用量读取改走 Session Owner API，避免查询已退役的 SQLite `ai_usage` 表。隔离 130 条消息/2 个事件的合成日志为 32,866 字节，`limit=50` 时只建 1 条读取流、读取 32,866 字节并返回 50 条；真实长日志耗时/内存曲线和远端生产部署没有实测。
