# 小鱼智能体共享工作入口开发提示词

## 目标与产品流程

你维护的是 LFAA 自有 Harness。将 AI Work 正式命名为“小鱼智能体”，简称“小鱼”。所有 App 共用同一工作界面、会话目录、项目目录和主 Agent Runtime；按用户配置的模型理解、规划、选择能力及委派，不为各 App 建独立智能体系统。

全局入口是“应用 / 工作”。应用进入应用中心，用户选 App 后进入该 App 原常规功能；工作直接进入 `/work`，无需先选 App。原 `/tasks`、`/apps/<app>/ai-work` 是兼容入口，归一到共享工作界面；原 App 常规路由保留。设置、文件、通知、快捷键、浏览器历史/刷新、App 的“交给 AI”操作都复用此规则。模式存储 normal/ai-work 的协议值可为已有偏好兼容保留，不能继续呈现 App 专属工作模式。

## 现状与唯一 Owner

当前只有一个执行 Agent Loop；重复来自 Workbench 的逐 App 草稿/活动会话状态、应用卡的两模式入口、ApplicationWorkspace 的逐 App 会话/项目查询。保留原 Session JSONL、账户认证、Provider/模型配置、Tools/Skill/Prompt/Expert 注册表、子 Agent 委派、权限及领域服务，不建立并列实现。

新会话由 workspace 来源创建，旧 App 会话不改写、不合并、不删除，统一目录可继续查看和对话，后端仍验证原会话来源与账户。项目是账户下真实节点目录登记，App 标签仅保留历史来源；共享工作可选择现有 workspace/Minecraft 项目，目录/Git/文件任务仍由已登记 Daemon 验证，不能借共享 UI 跨账户、猜测节点路径或绕过能力检查。

## 可选关联与按需加载

共享聊天提供可选 App 和 Skill/Prompt/Expert 参考关联。默认留空，用户可以撤销；仅持久化有界 ID 引用，不复制正文、不自动启用插件、不隐式加载全部领域工具。模型收到关联参考及当前项目元数据后，按目标使用原发现/加载工具；关联不是工具白名单或业务路由。失效/卸载能力不得伪装可用，执行前仍重新核验配置和权限。用户材料与能力正文是不可信参考，不构成操作授权。

关联保存于原 Session 日志，空闲时可改，运行中不换上下文。分支继承准确的关联快照，侧聊保留既有空工具限制；取消、暂停、重连与未知副作用继续遵守原合同。目录刷新只由配置/选择变化触发，避免输入 token 触发能力枚举、重复订阅或无界缓存。

## 设置中心

盘点并使用 general.defaultMode/defaultStandaloneChat、taskFolder/integratedShell、导航/终端设置、Provider 账户与主/子 Agent 模型、reasoning_mode、aiRuntime 输出/上下文/请求/工具/子 Agent 预算、promptSuggestions、plugins.enabled/skillDirectories/Prompt/专家/MCP 配置、computerControl.enabled、三种 permissions.mode、通知与全部适用 Appearance。把旧模式名称改为“应用 / 工作”，说明工作统一由小鱼处理；不重置已有偏好，不硬编码模型或权限，不另建 App 级模型控制层。

## Minecraft 能力验收

核查原工具的真实准备/部署、内核版本、Java 环境、EULA、节点目录、进程、端口、日志、任务结果和状态回报。分别说明原版、插件服、模组服的真实支持范围；不能把列表存在、合成 Provider、下载或 launch_requested 说成已开服。

验证共享工作模型先发现能力元数据，按需读取 Minecraft Skill/提示词、加载领域工具并按真实结果继续；没有选择时不注入全文。领域部署参数校验和固定节点执行步骤可以存在，但选择内核/工具/专家与下一步判断必须由用户设置的模型负责，禁止关键词路由或静默降级。用户此次要求核实能力，不构成对既有实例停服、删除或改配置的授权；如需实际开服，优先隔离且用户目标明确的验收实例，不操作既有实例。

## 边界、交付与验证

允许：共享导航/聊天/项目关联、原会话合同与 API、Agent 上下文、设置映射、真实能力检查、相关长期测试、包 README/依赖、当前架构/计划/合同。禁止：第二套 Agent/Session/身份/权限、重置偏好、修改外部 checkout、删除真实历史、无关重构、发布/提交、未经授权重启既有服务。

按设置控制主题/字体/字号/壁纸/颜色/遮罩/模糊/对比度/减少动态效果，复用 ResizableWorkbench 的容器响应式与 Dock/Overlay。运行直接会话/项目/按需能力/权限回归，Client/Host 类型、相关包与正式 Web/Control Plane 构建、check:workspace、差异和指纹对账。内置浏览器实测应用/工作入口、旧会话、项目选择、关联及撤销、设置生效、刷新/返回、代表性窄/短容器和错误状态。真实 Provider、节点开服、桌面/设备和帧时间分别记录；每个变更文件绝对路径与职责写入交付记录。
