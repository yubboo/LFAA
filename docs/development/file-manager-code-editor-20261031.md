# 文件管理代码预览与编辑器（2026-10-31）

<a id="lfaa-file-manager-code-editor-20261031"></a>

## 用户目标与可见结果

用户希望文件管理中的预览与编辑像电脑上的代码编辑器：不同文件类型有清楚的语法颜色，编辑时能看行号、定位与查找，并获得真实语法问题提示；当前截图中的 JSON 预览只有纯白文本，编辑框是普通文本框。

## 入口、Owner、设置与安全边界

- 入口：统一文件工作台 `/files`；预览和编辑弹窗由 `packages/client/ui-sidebar-files` 提供。
- 唯一 UI Owner：`packages/client/ui-sidebar-files/src/FileManagerPage.tsx` 与同包样式；文件内容仍由现有 Connection、`workspace-files`/Daemon 文件 Owner 读取和写回，不在 Client 解析远端绝对路径。
- 设置：复用账户 `appearance.advanced.fonts.code`、`appearance.advanced.codeFontSize`（默认 system/12 px）及当前 Appearance 主题、强调色、对比度和表面令牌；`Workbench.tsx` 已映射为共享 CSS 令牌。本任务不增设或持久化编辑器偏好，不改变用户设置。
- 数据与权限：保留现有只读预览与读/写操作分离、编辑最大 2 MiB、超级管理员/Permission Owner 授权、写入携带 `expectedSha256` 的并发冲突保护及真实服务端结果。验收只打开真实文件做只读预览或未保存草稿，不保存文件。
- 性能与生命周期：代码编辑器仅在打开预览/编辑后按需加载；复用单个 CodeMirror 实例处理当前文件，切换/关闭弹窗时销毁实例和其诊断计时；保留现有文件大小上限，不增加轮询、请求、观察器或文件快照。

## 分批实施与验收

1. **只读预览**：普通文本预览使用按扩展名识别语言的编辑器视图，提供行号、语法着色与内部滚动；Markdown 继续走现有渲染预览，图片/PDF 不变。先构建并在内置浏览器 `/files` 验收桌面及窄/短视口。
2. **文件编辑**：以同一编辑器替换普通文本框，保留 Markdown 并排实时预览、未保存关闭提醒与 SHA-256 保存合同；提供编辑器基本查找、行/列位置和括号匹配。JSON 使用实际 JSON 解析器给出错误标记与问题面板；其他文件只展示有实际语言支持的语法颜色，不虚构编译器或语言服务器诊断。完成后再次运行直接回归/类型/构建并实页验收编辑交互。

## 允许与禁止

- 允许修改文件管理 Client 包、直接相关长期回归、本包 README、此合同及任务索引；新增依赖必须属于该包并按需加载，构建输出只在仓库根 `dist/`。
- 不修改文件服务、Daemon、路径/权限/认证合同、Settings Owner、Markdown 安全渲染、图片/PDF、保存行为或用户文件；不新增编辑器设置、语言服务器、远程执行、自动格式化或虚构诊断。
