## 用户目标与边界

- 用户指出：项目会话同时出现在“项目”和“最近”；在“最近”打开同一会话的三点菜单时，项目分组里的重复行也会一起展开菜单；“展开显示”悬停时另有灰色矩形底。
- 让列表操作只影响用户点击的具体行；“最近”定义为三天窗口内未归档、未置顶且没有项目归属的独立会话。项目会话只从所属项目分组访问；置顶仍由置顶区访问。
- 唯一 UI Owner：`packages/client/ui-workspace/src/ApplicationWorkspace.tsx`，Web/Desktop 共用 `/work` 左侧 `ApplicationSidebar`。项目和会话读取仍来自 Workspace / Session Owner；仅改变 Client 展示过滤，不更改会话归属与持久化。
- Appearance 设置：不新增设置，保留主题、字号、文字颜色共享映射；“展开显示”悬停时保留 Appearance 灰底，并铺满与嵌套会话行相同的宽度。
- 会话重命名、置顶、归档仍调用现有操作与 Owner；浏览器验收只打开/关闭菜单，不执行菜单动作，不改变用户数据或偏好。
- 相关历史合同 `LFAA-AI-WORK-DEFAULT-PROJECT-NEW-SESSION-20261027` 曾规定项目会话作为跨项目入口重复出现在“最近”。本合同按用户本轮反馈修订当前展示语义，历史实施记录保留为历史。

## 验收条件

1. 三天窗口内的无项目、未置顶会话出现在“最近”；项目会话不进入“最近”，仍由所属项目分组显示；置顶与归档规则不变。
2. 菜单状态以分区/分组中的具体行实例为键；同一会话因列表布局而出现多处时，只展开点击的那一行菜单。弹层停靠在行右侧，不盖住下一行的三个点。
3. “展开显示”悬停灰底的左右边界与同组嵌套会话行一致；文字起点与会话标题列对齐保持不变。
4. 直接回归、ui-workspace 构建、Client 类型检查、正式 Web 构建及源码指纹检查通过；ChatGPT 内置浏览器实测 `/work` 桌面和相关窄视口的列表内容、单行菜单与悬停样式。记录真实视口、交互、截图与未测范围；不声称帧时间已验。

## 设置、数据与权限

- 设置：不涉及新增或修改设置；沿用 Appearance 共享令牌和现有账户/App 隔离的侧栏开合偏好。
- 数据：`updatedAt`、`projectId`、归档状态由 Session Owner 返回；本次筛选只影响近期导航呈现，不删除或迁移会话。
- 权限：不改变菜单动作的现有权限/数据合同；实页验收不执行重命名、置顶或归档。
- 性能：继续复用已有三天时间窗与单个到期 timeout；无新请求、订阅、轮询或无界状态。
