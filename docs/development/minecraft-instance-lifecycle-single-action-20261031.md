# Minecraft 实例概览启停合并为单一状态按钮

<a id="lfaa-minecraft-instance-lifecycle-single-action-20261031"></a>

## 用户目标与可观察结果

- 在实例概览摘要卡中，将并排显示的“启动”和“安全停止”合为同一操作位置的单个状态按钮。
- 实例已停止或异常时按钮显示“启动”；实例启动中或运行中时显示“安全停止”。安装中、停止中和状态未知时只显示禁用的真实状态，不提供误导性生命周期操作。
- 安全停止继续要求原有确认；启动、停止、重启的真实任务回报与现有页面/提示卡反馈保持不变。
- 按钮在桌面、平板、手机、窄分栏和短屏中保持可见、可达、无横向溢出；实例名称、状态与其他管理操作不被遮挡。

## 入口、Owner、数据与权限

- 页面：`/games/minecraft/instance/:instanceId/overview`；运行入口为当前正式 Web/共享 Client。
- UI Owner：`packages/client/ui-minecraft/src/MinecraftWorkspace.tsx`；状态以当前认证账户的 Minecraft 实例快照为准。
- 生命周期动作仍调用 `runMinecraftInstanceAction`，并沿用 Minecraft Service、Daemon、任务记录和真实结果反馈；本轮不改服务端、数据模型、API 或装配。
- 管理员角色、节点在线、实例状态和执行模式/能力条件继续决定按钮是否可用；安全停止沿用原 `Popconfirm`。按钮显示或禁用不替代服务端授权和校验。
- 验收不实际启动、停止、重启、删除实例或写入配置。

## 设置中心配置盘点

- 不新增、重置或修改设置。安全停止仍读取账户级 `minecraftRuntime.minecraftStopTimeoutSeconds`（共享默认 30 秒，Settings Owner 持久化在 `minecraft-runtime` 类别并校验 5–300 秒），确认文案继续提示使用该停服时限。
- 操作结果继续使用 `general.notificationPopupsEnabled`（默认开启）和 `general.notificationToastDurationSeconds`（默认 5 秒）；设置服务按账户持久化并进行现有校验。
- 现有 Minecraft 外观继续消费共享主题、强调色、字号、背景、遮罩/模糊与减少动态效果映射；`appearance.advanced.interfaceFontSize` 默认 14px，`general.cardMotionEffect` 默认 `fluid`。本轮不增加动画或 CSS 变量。

## 允许与禁止范围

- 允许：只改实例概览卡片中的启停入口为单一、按真实状态选择的按钮；更新对应包说明、直接回归和本任务记录。
- 禁止：改 Minecraft Service/Daemon 生命周期规则、权限合同、设置中心、共享组件、其他页面启停入口或本轮无关的已有工作区改动；不得在浏览器验收时触发真实生命周期副作用。
