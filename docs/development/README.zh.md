## 从任务开始

- **了解当前规则：** 根目录 [AGENTS.md](../../AGENTS.md) 与[开发规范](../../开发规范.md)。
- **了解当前实现：** [系统架构](../系统总体架构.md)、[开发计划](../开发计划.md) 和相关包 README。
- **查找某项改动：** 在 [PROMPTS 任务索引](../PROMPTS.md) 搜索功能名、问题或编号，再打开对应合同。
- **定位包 Owner：** 查看[包职责规范](package-responsibilities.zh.md)、[运行入口图](../workspace-entry-map.md) 和[生成包清单](../harness-packages.md)。
