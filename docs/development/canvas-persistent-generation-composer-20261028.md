# 无限画布节点上下文生成面板（2026-10-28）

## 用户问题与目标

用户以即梦画布作参考指出，LFAA 当前固定在画布底部的生成面板位置不对。目标交互是选中图片、视频或生成节点后，在该节点下方显示生成面板；面板跟随节点拖动、画布平移/缩放与工作区尺寸变化。未选中可生成节点时隐藏面板。生成模式下的空画布提供清晰入口，创建生成节点后自动选中并展开面板，避免无节点时无从开始。

面板继续提供图片/视频、比例/时长、设置状态、提示词、当前项目参考素材、运行状态和生成操作；复用当前 Canvas Generation Owner。选中图片/视频素材节点时，它作为面板锚点，生成仍由现有 Owner 创建真实 generation 节点，不把素材节点伪装为生成节点或改变项目数据合同。选中 generation 节点时，回填其已保存的提示词与参数并支持真实重生成。

## Owner、设置与边界

- 运行入口：Web/Desktop 共用 Client 的 `/apps/<appId>/canvas`，实现 Owner 为 `packages/client/ui-workspace` 的 `CanvasWorkspace`。
- 项目/节点/素材：继续由 `packages/canvas/canvas` Canvas Owner 管理；认证、账户/App 隔离、原子保存和并发冲突合同保持不变。
- 生成：继续调用现有 Canvas Generation Owner 和 Client Connection API；不在界面新增 Provider 或权限逻辑。实际图片/视频生成会访问已配置的账户，不属于本轮验收操作。
- 设置：`canvas.defaultMode` 仍只决定初始工作模式；生图读取 `aiRuntime.imageGenerationMode/imageGenerationAccountId/imageGenerationModelId/imageGenerationLocalModelId`，视频读取现有 `aiRuntime.videoGeneration*`；不新增设置、不改默认值、不重置用户偏好。主题、字体、字号、强调色、背景材质与减少动态效果继续沿用 Appearance 共享映射。
- 范围外：聊天/Agent 工具、手动面板、App 工作流、模型与凭据设置、素材存储格式及其他画布节点行为。

## 可观察验收

1. `/apps/aivideo/canvas` 中未选中图片、视频或生成节点时不出现底部常驻生成面板；生成模式空画布仍有可见的“添加生成节点”入口。
2. 选中图片、视频或生成节点后，完整生成面板贴在选中节点下方；清除选择或选中其他节点后面板隐藏。图片/视频节点会设置相应生成类型；生成节点回填真实保存的提示词与参数。
3. 面板在节点拖动、画布平移/缩放、容器缩放及窗口尺寸变化时保持跟随；可用区域不足时在节点上下方择位并保持在画布边界内，窄/短视口操作仍可达。
4. 首次生成继续由现有 Owner 在当前项目建立真实生成节点；图片素材仍写入当前画布项目素材库；错误、任务刷新和取消仍显示 Owner 的真实结果。
5. 不触发真实图片/视频 Provider，不持久化修改真实用户画布；源码、构建、浏览器视口和交互证据分开记录，未测帧时间与设备边界如实标注。

## 实施与验收记录

- 原批次使用固定底栏，和用户补充的即梦参考图不一致；本次将其修正为选中节点上下文面板，并更新此前错误的固定底栏验收目标。
- 空画布显示“添加生成节点”和“创建文本节点”；创建生成节点后自动选中并显示面板。无可生成节点选中时面板隐藏，画布点击会清除选择并显示选择提示。
- 完整面板定位在选中节点下方，水平居中；空间不足时调整选中节点的画布视口位置/缩放，优先保留节点与完整面板的上下关系。节点业务坐标不变，视口调整不触发项目保存。定位刷新通过单帧调度；ResizeObserver、事件与待执行动画帧在锚点变化/卸载时清理。
- 设置中心无新增配置：继续读取 `canvas.defaultMode`、`aiRuntime.imageGeneration*`、`aiRuntime.videoGeneration*`，并使用 Appearance 共享主题/字号/背景材质/减少动态效果映射。未修改任何用户设置。

- 实际路由：`http://127.0.0.1:3000/apps/aivideo/canvas`；服务 `/api/health` 返回 200，画布路由返回 200；正式重启 Web 时本机 Daemon 已按用户授权一并重启。
- 桌面 1280×720：选中临时生成节点后，节点框为 x=284、y=134、340×300；完整面板为 x=114、y=446、680×203，节点和面板中心对齐，间距 12px。
- 窄屏 390×720：窄屏折叠面板为 374×37，位于节点下方。展开后视口自动缩至 98%，节点为 x≈28、y=128、334×295，面板为 x=10、y=435、374×275，间距 12px，底部余量约 10px。
- 短屏 390×560：展开态视口缩至 53%，节点为 x≈105、y=104、180×159，面板为 x=10、y=275、374×275，间距 12px，底部余量约 10px；生成表单仍可见且宽度未溢出。
- 实际点击空白画布取消节点选择后，生成面板隐藏并显示节点选择提示；空白项目页和新构建标签均显示“已保存”。
- 验收节点只在隔离的浏览器标签中临时创建；没有点击保存、没有发起生图/生视频请求。验收标签关闭后，保留的干净画布页仍是已保存空项目，未修改其项目数据或素材。
