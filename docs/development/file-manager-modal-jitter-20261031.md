# 文件管理预览/编辑弹窗抖动（2026-10-31）

<a id="lfaa-file-manager-modal-jitter-20261031"></a>

## 用户观察与目标

用户反馈在 `/files` 点击文件打开预览或编辑时画面会抖动，怀疑提示通知动效。目标是在实际页面重复复现、记录画面，查明抖动来自通知、弹窗进场、编辑器懒加载或状态更新中的哪一段，再按证据做最小修复。

## 入口、Owner、设置与边界

- 运行入口：当前工作副本的正式 Web 与 ChatGPT 内置浏览器 `/files`；Web/Desktop 共用 Client UI。
- UI Owner：`packages/client/ui-sidebar-files/src/FileManagerPage.tsx` 管理预览/编辑状态和 Modal；`FileCodePreview.tsx` 管理编辑器装配；任务状态浮层与文件页布局由同包 `FileManagerPage.css` 拥有。预览/编辑读取链路没有触发 Ant Design `message`；侧边栏通知气泡不属于这条链路。
- 设置：保留 Appearance 主题、强调色、字号/字体、材质与 `appearance.advanced.reducedMotion` / 系统减少动态效果映射；验收不写入设置、不切换用户偏好。
- 数据与权限：沿用当前账户、Permission Owner 与文件服务权限。复现使用真实测试实例 `bukkit.yml` 的预览/打开编辑，不输入、不保存、不改动文件；当前实例显示已停止。
- 可修改范围：只修改直接相关 UI/样式与任务记录；不改文件读取/写入合同、全局通知规则或无关页面动效。

## 批次与验收条件

1. **复现和归因**：先确认 Web 构建指纹与正式服务一致；在实际内置浏览器检查文件读取提示与页面布局，并读取对应状态更新和动效代码。记录通知是否实际触发、抖动出现时序和边界。只读操作，不变更真实文件。
2. **有证据的修复**：将文件操作状态提示放到文件工作区中央的轻量浮层，不参与页面排版；短于延迟阈值的请求不闪现提示，提示使用透明度和位移过渡，遵循外观设置的减少动态效果。保留现有权限/文件行为。完成相关构建与页面检查，并覆盖桌面、窄分栏/短屏。

## 实施与调查结论

正式 Web 已按当前稳定源码重建并启动：构建转换 3948 个模块、Vite 构建 12.36 秒、菜单 Web 构建总用时 26.8 秒，`node scripts/runtime-build-state.mjs web` 返回 `[]`，`/api/health` 返回 200。ChatGPT 内置浏览器 `/files` 打开真实 Minecraft 实例“模组 1.16.5”，实例显示已停止；测试文件为真实 `bukkit.yml`，没有输入或保存。

用户提供的复现截图中，文件页标题下出现“正在处理文件操作…”状态条；该条插入在页面 Header 与工具栏之间。源码确认预览和编辑都通过 `runTask()` 设置 `busy` / `taskMessage`，并在 `busy` 时条件渲染 `.file-manager__task`；它处于普通文档流，新增/移除会推动工具栏和文件表格上下移动。打开链路没有调用 `messageApi`；通知动效只应用于侧边栏通知气泡。故根因是处理状态条的布局重排，常规 Modal 入场动效和消息通知不是这次整页上下移动的原因。

修复已实现：处理状态现在作为 `.file-manager-page` 的绝对定位浮层居中显示，不占文档流，也不拦截输入；延迟 120ms 再显示，快速读取不会闪一下；入场/退场只使用 `opacity` 与 `transform`，不做模糊或整页位移。外观设置的减少动态效果标记与系统减少动态效果偏好都会关闭过渡和旋转。权限、读取与保存逻辑未改。

## 实页验收与性能边界

- ChatGPT 内置浏览器正式路由 `/files`，桌面嵌入视口约 1750×1244：在同一真实实例先后打开 `bukkit.yml` 预览和编辑；分别检查提示过渡与稳定画面。提示出现在文件工作区中央，工具栏和文件列表在提示出现/消失前后保持原位；编辑器只打开，保存按钮保持禁用，关闭时未保存。
- 同一路由窄分栏视口约 889×1244：文件列表转为窄栏布局，无横向溢出；打开预览时中央处理提示覆盖在现有列表上，打开编辑时 Modal 在可用视口内居中且代码区可滚动，底部关闭/保存操作可见；关闭未修改的编辑器后，分栏恢复至原宽度约 1751px。
- 真实页面画面确认整页上下跳动来自插入普通文档流的任务状态条，而不是通知气泡动效。现在浮层出现/离开时，文件页内容没有垂直位移；Modal 自身仍保留局部入场动画。未运行自动化测试，也没有测量帧时间/FPS；本轮没有可用的浏览器 Console 诊断结果，因此只记录实际页面视觉和构建/健康检查证据。
- 设置：未新增或调整设置。保留当前 Appearance 主题和背景映射，并在样式中读取既有减少动态效果状态；验收期间没有更改偏好。未新增订阅、轮询、观察器或持久化数据。
