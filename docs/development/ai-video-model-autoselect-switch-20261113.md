# AI Video 模型自动选择与切换

## 用户问题与目标

设置中心已有远程与本机视频模型配置，但账户、模型或本机模型就绪后可能仍没有默认模型。用户希望仅在没有可用视频模型时保持未选择；远程视频账户/视频能力模型配置完成，或本机视频模型下载校验完成后，自动选中一个可用模型。此后用户能从一个清晰的视频模型选择入口切换远程账户/模型或本机模型，选择结果同步到设置中心持久化字段和 AI Video 实际执行所读取的模式/账户/模型。

聊天模型仍由 AI Work 模型目录选择；选择视频模型不得将视频模型发送到文本对话接口。图片模型配置与偏好不受影响。

## Owner、设置与边界

- 运行入口：设置中心 `/settings?section=ai` 的“AI 漫剧视频生成”区域；AI Video `startShotVideo()` 消费已保存的设置并由 `lfaa-llm` 调用真实远程任务接口或本机适配器。
- 设置 Owner：`packages/settings/settings`；现有 `aiRuntime.videoGenerationMode`、`videoGenerationAccountId`、`videoGenerationModelId`、`videoGenerationLocalModelId` 以及时长、比例、分辨率、音频、水印、本机时限/释放设置继续为权威配置和账户持久化字段。
- 账户/能力数据：远程模型和密钥来自当前账户可见的 Settings Provider 目录；Agent Plan 视频模型能力与档位来自 Settings 的官方目录；本机候选模型须来自 LFAA 本机模型 Runtime，且只有 `ready` 模型可默认选择/执行。不得从模型名称推测能力或把聊天模型作为视频模型。
- AI Video Owner 保持项目、任务、成片保存和 Provider 调用边界；图片生成设置、普通聊天模型和用户已选的有效视频模型均不得被无关自动选择覆盖。
- 权限仍由现有 Permission Owner 执行；不新增审批、凭据传递、Provider URL 或本机模型执行路径。

## 允许范围

- 仅修改与视频模型候选、自动默认选择、视频模型切换同步及其直接回归/文档有关的 Settings Client、Settings Owner 或 AI Video 验证代码。
- 可复用现有设置分类与自动保存；不得新增第二套视频模型持久化来源。
- 保留用户已选且仍有效的账户、模型和引擎模式。首次没有选择或当前选项已经失效时，按确定顺序从真实可用候选选择一个，并将模式、账户、本机/远程模型字段一起保存。
- 本机模型只有下载后经 Runtime 核验 `ready` 才可自动选中；加载状态不是必要条件。
- 当前没有可验证的远程视频模型、没有已就绪本机视频模型时才保留空选择，并在设置中心说明下一步。

## 禁止范围

- 不把视频模型暴露为 Agent Loop 文本主模型，不切换或覆盖 DeepSeek 等聊天模型。
- 不从模型名/ID 猜测任务类型，不静默替换已有效用户偏好，不把“已配置账户”“下载中”或“文件不完整”当作视频能力可用。
- 不触发真实 Provider 计费任务，不下载大模型，不改写用户现有偏好作为验收数据。
- 不清理或覆盖工作区已有改动，不扩展到图片模型的默认/切换行为。

## 验收条件

1. 已有有效远程视频选择保持不变；新可用远程视频目录在当前选择为空/无效时只自动保存一次默认账户和视频模型。
2. 本机视频模型下载和完整性检查通过后，模型进入候选并能被自动默认或手动选中；下载中/不完整模型不可选。
3. 统一视频模型选择入口切换远程账户/模型或本机模型后，设置中心显示已选目标，账户、模型和 `videoGenerationMode` 的持久化值一致；AI Video 读取到同一组字段。
4. 没有任何真实可用视频模型时保持空选择并给出配置/下载指引。
5. Agent Plan 只显示当前套餐档位支持且官方目录标记 `video-generation` 的模型；不影响聊天模型目录、图像模型字段与设置、权限/凭据隔离。
6. 运行直接相关的回归与构建，差异检查通过；从当前源码构建的正式 Web 在 ChatGPT 内置浏览器检查 `/settings?section=ai` 的桌面及窄屏真实视口与切换交互，记录证据和未测范围。真实 Provider 计费生成不作为验收操作。
