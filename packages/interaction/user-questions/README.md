# 用户问题服务

本包以 Cordis 插件形式登记可替换的用户问题回答者，并按回答者优先级尝试处理请求。回答者可返回答案，或返回 `undefined` 明确让给下一通道；异常和取消会直接结束当前请求，不会静默切换通道。

每次请求绑定账户、应用、Run、UUID v4 问题编号和取消信号；一个 Run 同时只能等待一个问题。提问长度、选项数量和回答长度均有上限。回答者可以随插件 Fiber 卸载撤销；撤销或服务关闭会取消该回答者正在处理的等待。

服务只持有短暂的回答者登记和活动等待，不保存问题、答案、身份、设置或审批状态。Agent Run 回答者继续把澄清答案交给 `lfaa-session` 唯一记录 Owner；现有 Session Controller 仍拥有认证后的 HTTP 回答入口。

## 第一方接线

`lfaa-tool-ask-user` 仍是模型可调用的问题工具；`lfaa-agent-loop` 将每个可提问的主 Run 登记为一个有账户/App/Run 范围的回答者，并通过本服务派发。子 Agent 不登记回答者，因此不会把问题错误路由给主会话。当前 Web Profile 仍使用 Agent Run 回答通道，其他插件可独立注册命令行、桌面或应用专用通道。
