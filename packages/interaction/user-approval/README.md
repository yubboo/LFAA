# 一次性审批通知

本包提供通道中立的审批等待通知插件。审批请求、权限策略、用户身份和最终状态仍由 `lfaa-permission-presets` 与现有认证 API 持有；本包只用账户 ID 与审批 ID 唤醒等待中的 Agent，不复制审批记录，也不自行授予权限。

`watch()` 必须在读取审批状态前注册。调用方随后读取权限 Owner 中的最新状态；如状态仍为待处理，再等待本包通知。这样既避免轮询数据库，也不会漏掉“读取和订阅之间已经完成审批”的竞态。`notify()` 只能在权限 Owner 成功写入审批决定后调用。

每个账户和审批 ID 最多一个等待者。请求可由取消信号、最多 5 分钟的时限、插件卸载或状态通知结束；结束时会撤销计时器、事件监听和 Map 登记。通知本身不携带决定内容，调用方必须重新读取权限 Owner 的状态，并继续校验完整工具参数后才可执行。

该服务不新增设置项，不改变当前审批界面、账户/App/Session 隔离、审批持久化或已记忆授权语义。
