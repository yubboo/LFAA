# 账户资料快照与恢复

`lfaa-settings-snapshots` 是设置中心账户资料归档与版本化快照的 Owner。它编排 Settings、Conversation Memory、Session 与 Attachment 四个现有 Owner，并在 SQLite 中保存受限大小的 gzip 快照；不接管各数据域的原始持久化。

新导出的 v2 `.lfaa-snapshot` 包括可移植账户设置、会话记忆、公开用户/助手对话、经路径清理的活动摘要、回复段落、分支记忆检查点以及会话引用附件字节。Attachment Owner 验证字节、媒体类型、名称、摘要和账户配额；导入按内容摘要复用目标账户已有附件，否则创建目标账户附件并重映射会话引用。v1 归档仍可预览和恢复，但不含 Agent 检查点或附件。SQLite 中本机快照继续使用 v1 内容，供本机快速回滚；换电脑请使用设置中心“导入与导出”生成 v2 文件。

权限模式、插件/MCP 连接、计算机和浏览器访问设置、密钥、凭据、模型请求/工具原始日志、用量、本机绝对路径、项目文件与运行中任务不进入迁移包。Mini 的账户偏好随归档迁移，窗口运行状态仍由本机 Electron Host 管理。会话恢复为已归档的独立会话并清除旧项目绑定；同账户同 ID 冲突时跳过，导入不会覆盖已有会话。项目文件需另行迁移并重新关联；新设备继续遵循当地账户的 Provider、权限和插件设置。

v1 使用 gzip JSON、SHA-256 完整性校验，压缩体最大 32 MiB、解压体最大 128 MiB。v2 最大压缩体 256 MiB、解压体 384 MiB，会话正文最大 64 MiB，附件最多 200 个/200 MiB，超限拒绝整包且不静默截断。跨 Owner 恢复先预览，设置、记忆和会话由用户分别选择；附件仅随会话导入。设置与记忆恢复发生后续写入失败时会补偿恢复原值；会话导入若已部分提交会报告失败并保留附件，避免留下失效引用。所有写入入口仍由调用方经过统一 Permission Owner；本包不实现第二套审批策略。

运行于 Control Plane。API Controller 与 Agent Tools 使用同一 Owner；用户账户、设置校验和三种权限模式沿用现有 Settings/Identity/Permission Owner。
