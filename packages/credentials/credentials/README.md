# 凭据引用服务

`lfaa-credentials` 是由 Cordis 插件装配的凭据来源与记录注册表。它把不含秘密值的引用和明确的账户 ID 路由到来源插件；每个来源和记录所有者都声明可读取它的第一方消费者，未列出的消费者会被拒绝。引用读取和状态查询都使用同一条路径。

本包不创建密钥文件、不持久化账户、不缓存解密结果。当前 `lfaa-settings` 来源仅允许 `lfaa-agent-default-model` 插件消费，仍由设置中心从本机密文存储读取；浏览器只获得 `configured` 等不含秘密的状态。通用记录仅接受有界的 `api-key` 与不透明 `grant` JSON，读者须在记录所有者白名单内；持久化适配器只能由活动的 `lfaa-settings` Fiber 注册，记录状态接口不包含载荷。

AI Provider 密钥和插件凭据记录沿用设置中心现有的 AES-256-GCM 密钥文件与原子配置存储；插件记录的认证数据绑定账户、插件所有者和记录 ID，防止密文跨地址调换。没有增加第二个秘密 Owner、浏览器密钥传输或用户设置。记录变更只发出账户、引用和操作类型，不包含秘密值。DeepSeek Platform 登录、远程授权入口和任意环境变量引用尚未接入，不能标记为已支持。
