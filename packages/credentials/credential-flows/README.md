# 通用凭据授权流程

`lfaa-credential-flows` 是第一方 Cordis 插件，为其他插件提供通用登录/授权 Flow 注册、启动、取消、状态查询和卸载清理。它只管理交互协议与运行生命周期，不包含任何具体 Provider 登录实现，也不持有秘密。

每个 Flow 绑定一个插件所有者和一条凭据引用，并声明允许读取其记录的消费者。授权请求显式携带账户 ID、方法、取消信号和本次请求的交互回调；同一账户的同一凭据同时只运行一次。Flow 必须在本次尝试中提交记录后才能以 `authorized` 结束，旧记录不会使新尝试误报成功。

凭据引用、消费者白名单和记录变更事件由 `lfaa-credentials` 提供；记录密文及 AES-256-GCM 密钥由 Settings 唯一持有，按账户、插件所有者和记录 ID 分区，并以关联数据绑定三个地址字段。授权 Flow 插件卸载后会撤销该插件登记的流程和活动尝试，已保存的记录保留为可清理的孤儿记录。

本包不新增设置、HTTP/UI 路由、DeepSeek Platform 登录适配器或用户问题持久化。真实授权入口及具体登录提供方须由其各自的 LFAA Owner 接入。
