# `lfaa-client-ui-workspace`

共享小鱼工作区接收 Workbench 投递的 `AiWorkGoalRequest` 并传给 `AiWorkChat`；聊天仍通过既有 Agent Loop 执行目标，没有 Provider 时保留草稿。

2026-10-16：普通 App 是手动操作与成果管理面板，Agent 对话、能力资源和侧聊只在共享工作区展示。写作侧栏改用 `normal/WritingBookInfo`，保留作品信息与写作方法管理，不再提供 App 专属 AI Work 切换。普通面板不加载 Agent 能力目录；共享工作读取目录可取消，离开或切换账户时撤销请求。两类自定义模板（成果/应用面板）的目标与待实施范围见 [模板目标](../../../docs/development/application-panels-templates.zh.md)，本轮不声明模板运行时已实现。

Web/Desktop 共用的应用工作区 UI。除通用 Workspace 外，`AiVideoCanvasWorkspace` 将单个 AI 漫剧项目呈现为剧本、角色/场景档案和 React Flow 分镜画布，通过 Client Connection 调用认证 API 保存，不把浏览器存储作为项目数据 Owner。

整体布局由 `.module-workbench-stage` 外层盒子包住一个 `ResizableWorkbench` 根节点。图标功能区、二级菜单、中间工作区和右侧菜单作为根节点的四个同级区域直接传入；各区域 class 分别为 `module-workbench-region--leading`、`--secondary-navigation`、`--center-workspace`、`--right-menu`。分隔条与浮层是布局辅助元素，不把四个内容区域互相嵌套。公共几何样式从 `ui-dockkit/src/css/common.css` 复用；图标轨样式由 `ui-sidebar/src/GlobalNavigationRail.css` 负责，左二、中间、右侧内容盒子的样式分别由 `src/css/secondary-navigation.css`、`center-workspace.css`、`right-menu.css` 负责；`src/css/workbench-regions.css` 只保留四个同级区域共用的文字基线与底部面板样式。其他页面仍由各自 UI 包设置布局与外观。图标轨宽度继续使用现有 64px/48px 令牌，并沿用账户外观设置。

应用侧栏与中心区复用 `ResizableWorkbench`。响应式容器足以保留侧栏与中心区最小宽度时，展开的二级导航占用左侧 Dock 并推动中心区；更窄时继续使用 Overlay。公共几何样式由该组件引入 `src/css/common.css`；各区域的局部外观继续由各自 CSS 文件维护。AI Work 中间聊天表面与正文按当前中心列宽度左右内缩 20–32px；消息、锚点、提示和输入框维持在该间隙内，内部不重复增加间距。消息滚动轨道横向延伸到中心列右边缘，纵向止于输入框顶部；输入框与正文内容保持在滚动条左侧的内缩宽度。宽列中输入框与 920px 正文列对齐。间距不按整个浏览器视口计算，300px 中心下限内仍可输入与滚动。

漫剧界面沿用工作台设置的主题、字体、强调色、侧栏对比色和字号；不新增外观设置。减少动态效果偏好由工作台现有样式链继承。剧本、角色/场景文字描述、参考图、镜头文字/连线/引用、视频任务状态、导入媒体、时间线和白模相机状态均由服务端账户项目文件保存。镜头图片用设置中心所选 OpenAI/豆包模型，已关联的本机角色/场景参考图会随请求传入。镜头视频用设置中心所选火山方舟账户/模型与参数；提交后显示真实排队/运行状态，工作区在当前项目打开时串行查询，应用服务也会在运行期继续保存任务结果。媒体工作区支持项目媒体浏览、导入/删除、视频/音频/字幕时间线、剪辑预览和浏览器原生编码导出；成片保存回项目并可下载。3D 导演台使用原生 Canvas 透视投影编辑白模和相机；用户点击后可启动设备取景并保存镜头参考图。上传与导出各有明确容量边界，音轨混合和 MediaRecorder 能力取决于运行浏览器。代码已接入；真实浏览器编解码、相机权限、桌面与运行服务尚未验收。

构建输出位于仓库根 `dist/packages/client/ui-workspace/`。

工作区终端可切换真实交互式会话和 Agent 任务输出；交互页选择已连接的本机/远程 Daemon，使用 xterm 处理输入、ANSI、中文、尺寸变化和 Ctrl+C。沿用 `general.integratedShell/taskFolder/terminalPosition/showBottomPanelControl`、统一权限模式及工作台主题、代码字体/字号、强调色、壁纸/遮罩/模糊和减少动态效果。容器 ResizeObserver 合并一帧内的缩放，输入与缩放分别串行发送；绘制容量 512 Ki 字符、历史 2000 行，超限失败关闭。卸载关闭会话并撤销 SSE、观察器与动画帧；节点状态查询复用可见性控制的串行轮询。

AI Work 的聊天始终留在中心工作区。顶栏 Git 菜单打开项目摘要悬浮卡：当前会话绑定的仓库置于主卡，账户下其他已登记项目文件夹逐行显示各自的真实 Git 状态和增删统计；“变更”入口联动打开对应仓库的右侧 Git 管理面板，不替换聊天或输入区。摘要下方“输出内容”和“来源”只汇总当前会话活动记录里的真实新建/修改与读取文件，超过首屏数量时可展开“查看全部”；通用附件未接入时不伪造来源。Agent Git 管理器管理多个完整本机项目仓库，并随 Agent 会话绑定；不要求用户手工添加仓库，也不依赖 Daemon 节点。默认工作区启用本地 Git 版本管理；用户项目在 Agent 首次获准实际创建或写入文件时自动初始化，Git init 与本次文件操作共用 Permission Owner 授权。状态、变更统计、差异、文本查看/编辑、暂存、提交历史与分支操作都基于真实仓库根。本地执行由 Agent Git Controller、Permission Owner 与 LFAA Host 负责。分支前缀读取账户 `git.branchPrefix`，Appearance 继续使用工作台共享主题。HTTPS remote 支持 fetch、干净工作区快进 pull、当前分支 push 和发布分支；凭据按账户加密保存。SSH 同步与 PR 写入未接入。Agent 的可选 Daemon 项目仍只表示节点任务目标。

主项目和其他项目文件夹各自的“变更”行在悬停、键盘聚焦或触屏环境下提供 Git 操作入口。增删数和展开箭头组合为行尾信息；桌面悬停或键盘聚焦时收起该信息，并由最右侧 Git 操作图标接替。触屏下同时展示操作图标和留出空间的行尾信息。桌面四项 Git 操作菜单竖排；手机卡片内改为四项横排，卡片极窄时切换为两列并自然占位，不覆盖项目内容。项目分支与标题保持同一行并靠右显示。摘要滚动区与外框使用紧凑且左右对称的间隙；不为滚动条预留双侧空槽，只有内容溢出时滚动条才占用空间。项目增删数和分区计数由行与内框的留白和滚动条隔开。“输出内容”和“来源”各自使用完整宽度的内框，标题/文件信息左对齐、项目数右对齐，内框和行内容都限制在卡片宽度内。点击当前图标、点击菜单外部、按 Escape 或选择操作都会关闭；四项操作分别定位到现有管理器的提交信息、远端推送按钮或分支管理弹窗，不复制 Git 执行、远端能力和权限逻辑。Agent 写入活动变化时，已打开的摘要会取消过期读取并重新查询最多 12 个真实仓库的状态；不轮询，卡片关闭后会撤销计时器和请求。

手机布局不再把摘要作为悬浮卡片；从顶栏打开后，摘要在左侧项目/会话栏中作为独立页面显示，沿用同一份项目、Git 状态、输出和来源数据。顶部“项目与会话”返回按钮回到原会话列表，侧栏关闭、Escape 与进入 Git 管理器也会结束摘要页；操作项仍使用同一 Git 管理器。摘要内容在侧栏内独立纵向滚动，不改变会话/项目选择 Owner。

## 小鱼共享工作入口（2026-10-14）

根地址与默认首页进入 `/work` 小鱼智能体对话区。全局导航的“应用”入口打开右侧 Dock 的“应用”视图，保留游戏库及 SteamCMD、Minecraft、LFAA 联机服务、写作空间和 AI 漫剧常规入口。应用切换继续调用 Workbench/Client Renderer 已有打开与路由标记，不在菜单复制业务规则；应用视图选择状态由 Workbench 持有，切换 App 路由后保持可用。

`/work` 和专业应用使用固定四栏组合：全局导航轨、左侧 AI Work 会话/项目栏、中间工作区、右侧工具资源与应用菜单栏。右侧菜单用“工具与资源”和“应用”视图切换；应用条目复用 Workbench 注入的 `applicationNavigationItems`，由 `SecondaryNavigation` 展示，并调用现有路由或 App 打开回调。Minecraft、联机服务子菜单及写作目录 Portal 也归右侧应用视图。左侧 Dock 只管理草稿、置顶、项目、最近会话；最近会话入口仍展开该 Dock。菜单与聊天区之间不再提供位置交换；左二/中间及中间/右菜单的宽度、拖动、收起和响应式行为继续归 `ResizableWorkbench`。

AI Work 的会话与右侧工具页签由 `ApplicationWorkspace` 持有。中心区展开时只在标题栏显示当前会话名；中心列拖动越过完全收起阈值、按住不放时，右侧菜单顶栏立即显示会话、新标签页、已打开的工具页签和加号；反向拖回或取消手势会撤下预览，松手仍停在阈值才提交收起。初始工具页签为“新标签页”，展示真实可用的浏览器、Git 变更、侧边聊天、应用导航和已登记扩展面板入口；点击入口后当前空白页签变为该功能，后续点击加号创建新的“新标签页”，各页签可关闭。Skill/Prompt/Expert/Tool 目录只作为能力资源展示，不伪装为可点击 UI 功能；浏览器、Git、应用和扩展页都复用各自现有 Owner。选择会话页签恢复中心列；拖动收起时暂时填满工作区的浏览器 Dock 不覆盖用户保存的栏宽，聊天恢复后回到收起前的宽度。`ResizableWorkbench` 只在吸附预览状态变化时通知上层，不随每帧尺寸更新触发 React 渲染；页签是组件本地瞬态状态，不创建第二个浏览器或会话。

首次桌面三栏工作区默认展开右侧资源栏以组成四个可见区域；用户已有面板开合状态继续优先。`general.navigationLayout`、Appearance 共享令牌和 `ResizableWorkbench` 左栏宽度偏好保持现有设置 Owner，不新增或重置配置。

AI Work 右侧“新标签页”以工具主页呈现：变更、终端、文件和侧边聊天按右栏实际容器宽度排成紧凑双列或单列；浏览器、应用、扩展面板及已登记能力资源收在原生“更多工具”展开区；推荐区接收当前 Browser Dock 已打开的网页标签，沿用 BrowserPanel / Browser Owner 数据，不另建网站清单或读取历史。空列表时提示打开浏览器；点击网页卡片通过一次性导航请求复用当前 Browser Dock。所有入口继续调用当前 `ApplicationWorkspace` 回调，样式由本包 `src/css/right-menu.css` 单独维护并沿用 Appearance 主题令牌。

推荐区继续显示当前打开的网站标签；“最近”通过 Client Connection 的认证 API 加载 Browser Owner 按账户保存的 LFAA Browser Dock/Agent 最近网站记录，点击记录复用现有浏览器标签导航。记录是否启用由 Settings Owner 的 `browserUse.recordRecentSites` 控制；该区域只保留按需查询的页面状态，不建立本地历史库。新标签页地址栏复用 Browser Address Owner 的 URL/搜索词解析与 Browser Dock 导航；推荐、最近和地址栏进入同一个浏览器标签流程，后退、前进、刷新也由当前 BrowserPanel/NativeBrowserPanel 执行。关闭右侧工作区标签时只移除该页签，最后一个页签以空白“新标签页”替代并收起右侧栏。

AI Work 中心区在桌面、紧凑和移动布局下均可收窄到 300px；聊天输入容器在 380px 及以下将项目、权限、更多和模型操作切换为图标，保留可访问名称及悬浮提示。会话导航刻度单独定位并贴齐中心列左缘，随左二 Dock 宽度变化；会话滚动框在左侧为刻度保留可视区并以等宽内边距补偿，消息舞台、正文、滚动区和输入区保持原有位置与响应式尺寸。右侧分隔条可将剩余宽度分配给右侧菜单。左二栏是次窄区域：启用 `responsiveRightDock` 时其最大宽度按容器宽度的 26% 计算，范围为 320–440px；最小宽度、默认宽度与用户宽度偏好格式不变。上述中心/左右栏规则不改变 Settings/Plugin Manager 的通用范围。

左右分隔线均只通过拖动调整。吸附预览和反向拖回在同一 Pointer 按压期间完成；松手时若仍处于吸附预览则提交收起，收起且已松手的分隔线不再接受新拖动会话。普通点击不会改变栏宽或列顺序。

工作区顶栏状态与左侧导航状态点共同消费设置中心 `general.showServiceStatus`；Appearance 的字体、颜色、壁纸、遮罩、模糊、字号、对比度和减少动态效果继续读取工作台共享令牌。中心列宽不超过 560px 时，语音、状态、Git 和面板操作收为图标，当前对话名仍以可截断文字显示；按钮保留可访问名称和提示。

应用仅组合原常规界面，共享工作组合一个聊天/项目/会话 UI。项目和旧 App 会话按账户统一查询，公共会话列表不随当前 App 分区；列表在账户间隔离、按账户缓存，并在离开工作模式或切换账户时取消过期请求。全局导航“最近会话”在工作区内展开左侧 Dock，在设置、文件、插件等独立页通过 Workbench 的一次性打开请求进入 `/work` 后展开同一 Dock，并复用同一份会话列表、刷新与选择操作；不渲染悬浮卡片或第二份会话列表。请求在工作区确认处理后清除，不持久化、不重放；刷新请求串行复用，过期请求取消且不能覆盖后续会话变更。“工作·小鱼智能体”入口只进入公共工作，不代替最近会话入口。游戏“交给小鱼”进入公共工作；容器布局仍归 ResizableWorkbench。

AI Work 项目清单继续从 Workspace Owner 实时读取；已有同账户快照在后台刷新时保持可见，不把正在校验显示成空项目。默认工作区目录初始化在同一页面会话按账户最多执行一次；页面刷新仍按正式 API 重新校验，不将账户路径或项目快照写入浏览器存储。

独立 `/voice` 页面复用同一个 ApplicationWorkspace 与 AiWorkChat 会话，隐藏工作区导航和 Dock。语音页加载仅读取现有工作区状态，不触发默认目录初始化或 Session Git 仓库 ensure 写入；项目、会话和 AI 请求仍归原 Owner。语音页在 Workspace 通用聊天纵向裁切规则之上保留独立可滚动容器，短屏时可访问页面底部状态和语音设置，不影响普通 AI Work 的消息滚动区。

AI Work 右 Dock 的“浏览器”与当前 AI Session 共享本机隔离浏览器会话：用户可预览截图、切换页面文本/交互元素/JSON 检查视图，并直接点击截图中的页面。页面变化以单一 revision 轮询刷新；导航和操作通过 Browser Owner/认证 API 完成，页面内容不持久化。默认 Edge/Chrome 上下文不继承系统登录态；仅在用户明确选用 Tabbit 后才连接其个人浏览器会话。个人 Chrome/Edge Profile 当前没有 Browser 面板镜像适配器；用户明确要求控制已打开浏览器时，可走现有 Windows CUA，画面不进入右 Dock。

小鱼智能体左侧会话栏按草稿、置顶、项目、最近分区；置顶 ID 使用 Client Store 的账户隔离本机偏好，项目与会话仍由现有 Owner 管理，界面沿用 Appearance 共享令牌。

构建只写仓库根 dist/packages/client/ui-workspace/；当前合同见 [开发提示词](../../../docs/development/xiaoyu-agent.zh.md)。构建、合成模型、浏览器与真实模型/节点验收分别报告。

2026-10-16：置顶、项目与最近会话行统一通过三点菜单调用既有置顶/归档操作；Web 保留浏览器原生右键，桌面宿主可右键打开相同菜单。菜单挂在工作区，自动翻转，短屏可滚动，继承主题；Esc、点击外部与布局模式变化会关闭，临时监听随菜单生命周期撤销。聊天读取通用中心宽度下限；窄容器打开一侧会收起另一侧，桌面缩入紧凑布局且右栏已开时收起左栏。普通 App 仍沿用应用布局指标，不改变 Session/项目数据。

桌面和紧凑布局中的 Git 摘要浮层挂载在当前中心列，宽度受真实列宽约束，右缘贴齐中心列与右侧工作台之间的可拖拽分隔线；它从中心内容区顶部向左展开，按摘要内容自然收高，底部保留空间，超出短屏时内容在卡片内滚动。四项 Git 操作菜单定位在摘要卡范围内，避免被中心列裁切。手机继续在左侧项目/会话栏显示摘要页。展开效果读取 Appearance 的减少动态效果状态，摘要数据与 Git 操作仍由原有 Owner 管理。
