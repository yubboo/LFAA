# LFAA 联机服务工作区

单一跨游戏 Connectivity App 的客户端界面。侧栏分别进入总览、LFAA 房间域名、自备穿透、第三方 Provider 和组网扩展；游戏 App 通过真实目标适配器接入，不在游戏部署页面内复制网络路线逻辑。

现阶段路线/房间 API 和 Minecraft Java 目标适配器已接入。LFAA Relay 与 Daemon 数据面尚未交付；第三方 Provider 仅在其官方 API 合同完成核验后登记；EasyTier 尚未纳入 Daemon 运行包，界面不报告虚拟 IP 或对等连接状态。MCTier 只作为公开功能范围参考，未使用它的代码、UI、文案或资产。

本工作区沿用登录会话、服务端角色与 Appearance 主题映射，不新增设置项。浏览器刷新路由受应用中心入口状态保护。

“组网与扩展”当前可由管理员选择新版在线 Windows x64 Daemon，提交 EasyTier v2.6.4 官方运行包安装，并查看自己创建的最近任务。节点状态以心跳中经核心程序版本核验后上报的能力为准；安装成功不显示成组网已连接。任务状态由用户手动刷新，没有常驻轮询。
