# Minecraft 面板

管理工作区用共享 Snapshot Cache 按当前 `userId` 与角色保存最近一次完整成功的读取结果；同一身份 30 秒内再次进入先呈现快照并跳过整轮首屏请求。冷进入先等概览、节点和实例三项关键状态，Java、任务和部署信息随后补齐；首个 Socket 握手不重复触发快照，Socket 变更仍即时对账，REST 在连接时每 30 秒、断开时每 10 秒兜底。日志由 Socket 推送，在线每 30 秒、断连每 5 秒兜底。缓存只作短期展示，不替代认证 API 的权限、状态与参数校验。普通总览不请求 Mojang 或核心来源目录；打开部署选择流程时先用共享 Snapshot Cache 展示最近成功目录，同时重新读取核心目录，用户也可手动刷新。目录请求失败时丢弃失效目录和选择，不再继续请求其构建。版本目录仍使用真实来源数据，服务器与 Java 文件仅由已授权部署/环境安装任务在目标节点下载。

`MinecraftWorkspace.tsx` 读取真实节点、实例、部署、任务和日志；`MinecraftDeploymentPanel.tsx` 以三步向导完成核心/版本选择、节点/实例参数设置和部署前许可核对。核心目录及版本由真实来源提供，程序包自动匹配，普通向导不要求用户挑选构建编号。最终一步只提交一次正式 provision API，网页关闭后任务继续由节点执行。

首次配置推荐 Paper（一般插件生存服）；模组服按整合包选择 Fabric/Forge，代理和基岩按各自用途显示。版本来自在线目录；每个核心版本自动采用目录首个工件，并由服务端解析可信来源与摘要。切换核心和版本时会丢弃过期响应。唯一可用节点自动选中，多节点由用户选择。控制端 Socket 连接与节点在线状态分别呈现；离线节点不可派发。

默认核心、内存、Java/基岩端口与执行边界读取共享账户设置；保存默认值后只更新仍采用旧默认的输入，保留用户已填写参数。页面沿用主题、强调色、字体/字号、对比度、Minecraft 壁纸、遮罩、模糊和减少动态效果的共享映射；Ant Design 字号使用 interfaceFontSize。CSS 不另建主题或资产来源。

总览中的三个运维状态入口和 Daemon 节点预览行使用 `lfaa-card-motion` 消费 `general.cardMotionEffect`。悬停时使用共享卡片动效；聚焦显示清晰轮廓，按压给即时表面反馈；总览区域不添加入场编排。`appearance.advanced.reducedMotion` 与 `cardMotionEffect=none` 仍由共享 `ui-theme` 样式优先停用变换和过渡。

实例列表提供名称/核心/节点搜索、真实状态筛选和有权限/节点在线/状态前置条件的启动与安全停止入口；宽分栏中实例名称、真实状态、运行事实和操作各自保留可读空间，窄容器中卡片改为单列、操作换行且可滚动到达。空实例状态引导先检查 Daemon 节点或开始首次部署。没有持久化“已看过引导”字段，部署页每次进入都会显示向导，输入只保存在当前页面状态中。

当前 Minecraft 手动开服/运维工作区使用有层次的运维界面：总览提供真实开服入口、Daemon 准备状态及节点到实例关系；节点、实例、任务和工作流按实际信息分组，动作随容器宽度对齐或重排。只显示真实心跳、执行能力、实例和任务，不伪造 CPU/TPS 等未接入采样。颜色、主题、字体、字号、壁纸、遮罩、模糊和卡片动效继续读取 Appearance/常规设置。任务卡片在宽屏将状态与操作并排展示，窄屏纵向重排；查看详情、取消、选择和删除仍执行既有权限与结果合同。实例“控制台”使用系统共享终端管理器接入真实 Minecraft 受管 PTY，显示该进程最近最多 128 KiB 的有界内存回放和实时输出，并将键盘输入送入同一进程；终端不读取或显示日志快照。独立“日志”路由由左二 Minecraft 管理菜单进入，实例选择与日志筛选/自动滚动由 `MinecraftWorkspace.tsx` 呈现；日志通过现有 API、Socket 和轮询读取。旧实例日志路由保留兼容，但页面本身不会显示实例页签。侧栏展示真实节点、核心、端口和内存数据。快捷命令只向当前活动的 Minecraft 服务端 PTY 写入，未连接时禁用。终端继续沿用设置中心代码字体和强调色。详见本轮合同 `docs/development/minecraft-player-launchpad-ui-20261030.md` 与 `DESIGN.md`；早先管理后台参考布局与浏览器记录保留在 `docs/development/minecraft-admin-ui-reference-20261027.md`，仅作历史证据。

参考站可生成独立 Windows `.bat` 与 Linux/macOS `.sh`，并允许复制/下载。LFAA 当前由 Daemon 以结构化参数数组和 `shell:false` 启动实例；实例数据、进程标记、任务和安全停服都由 Daemon 跟踪。本 UI 不生成可绕过这些状态的外部启动脚本，也不展示未接入持久化/执行链路的假启动参数编辑器。要支持可视化修改，需先将参数定义为实例级配置，由 API 校验保存并让 Daemon 的真实启动合同消费；外部可执行脚本与托管生命周期应作为不同能力单独评估。

部署记录显示历史执行结果，当前运行状态以实例为准。未知结果不提供自动重放；强制结束显示橙色“已强制停止”，不声称正常存档退出。PocketMine 不展示 Java 内存配置；代理不提供世界备份或 Java 世界属性编辑。

代码与实机记录见 [开发计划](../../../docs/archive/audits/minecraft-deployment-plan.md)。浏览器可视验收与构建分别记录，不能把产物构建当作主题、字号及操作体验已通过。输出仅进入根 `dist/`。

Minecraft 常规模式的“工作流”页提供无限画布式 Agent DAG：节点可拖动、连线表达前置依赖，位置与定义由账户隔离的 Workflow Owner 保存。每个节点仍运行于 Minecraft App 的现有 Agent Loop、Session 和 Minecraft 工具/权限链；当前运行按拓扑顺序串行执行，不提供循环、计划任务、跨 App 或任意代码节点。界面沿用现有外观设置与主题令牌，不新增设置项。浏览器编辑、拖动、连线、保存/刷新恢复和缩放验收见 `docs/PROMPTS.md` 的 `LFAA-AGENT-WORKFLOW-CANVAS-01`。

Minecraft 工作流画布仍是专用适配器，继续处理 Minecraft 工具选择与 EULA。嵌入系统 Canvas 外壳时用 `visible` 暂停隐藏面板的运行状态刷新，并向当前画布 Agent 报告所选工作流的真实 ID/标题/更新时间；上下文只作定位提示。Client 模块入口同时登记 `MinecraftWorkspace.js` 与 `MinecraftWorkflowCanvas.js`，供 `ApplicationWorkspace` 的动态模块加载器按需装配。

Minecraft 的“联机”菜单跳转到独立的 LFAA 联机服务 App。Minecraft 包只登记当前账户拥有、节点在线且真实运行的 Java TCP 目标与已保存端口；不会在此包复制路由表单、创建公网映射或触碰开服/实例启停。完整游戏目标合同见 `packages/network/game-connectivity`。

## 共享运行环境

部署页按核心真实工件解析 Java 要求，通过 RuntimeManager 选择匹配的设备环境；环境准备跳转到游戏库，当前账户的短期草稿通过 Client Snapshot Cache 保留，退出账户统一释放。返回后重新校验核心、构建、节点与显式 Java，EULA 不保存在草稿中。原生 install/start 任务提供取消请求，只有节点确认才结束，不将停止聊天当成停服成功。

Minecraft 环境菜单直接进入共享运行环境页，部署草稿/实例均可原路返回；旧 Java 管理界面已移除。向导默认端口被同节点实例登记时建议下一个未登记端口，显式修改保留，重名/端口冲突/失效 Java 在提交前提示。成功提交消耗当前草稿，下一次新建不复用已提交的实例名和端口。

实例列表提供“删除实例”：已停止/失败可申请归档，未知状态交由节点核实；运行或活动任务拒绝。节点检查真实路径、元数据归属、进程与安装标记，完整目录移动至节点 `backups/minecraft/deleted-instances` 后才移除登记及关联部署，历史任务保留。失效目录不存在时由节点明确回报，不伪造文件归档；不永久清除备份。

删除仅提交归档任务并留在实例页，页面明确提示可到“任务”菜单查看进度。任务页展示控制端返回的最近 200 项真实任务、各状态计数、运行进度、节点消息和归档结果；Socket 与定期快照继续由工作区统一更新。读取失败与无记录分别给出状态提示，不把空白内容当作成功。

任务菜单可打开单条详情，按需读取原任务参数、提交/开始/结束时间、结构化节点结果及最多 1000 条任务关联日志。失败详情以实际任务回报和关联日志中的异常证据说明问题；缺少更具体日志时明确标示证据边界。管理员可单条或批量删除已完成、失败及结果未确认等异常终态记录；终态卡片主体可点击选择，选中后整卡显示危险色浅底和单一边框；卡片始终不显示选择圆圈或勾选标记，鼠标点击未选卡片不会留下红色焦点外框。批量选择 ID 使用共享浏览器持久化层按用户隔离保存，刷新后恢复；已不存在或不再是终态的任务会自动从选择中剔除。非终态卡片点击主体打开详情但不可选择删除。卡片以左侧任务信息、右侧状态操作组织；窄容器中操作换到内容下方，触控尺寸与分组间距保持可用。独立按钮不触发卡片选择，批量操作全有或全无。清理同时删除所选任务日志，不影响 Minecraft 实例、部署登记、备份或其他任务。详情与日志在小视口内滚动，并沿用共享主题令牌；无新增设置项。

实例“终端”页在实例运行、节点在线且当前用户可管理时自动附着 `lfaa-client-ui-sidebar-terminal` 的共享终端表面和受管服务端 PTY；Daemon 只对真实 PTY stdout 保留最多 128 KiB 的临时内存回放，后续输出/键盘输入都来自同一活动 PTY。终端输入只发送给该 Minecraft 服务端，不是操作系统 Shell，断开连接不会停止实例；实例停止或节点离线时说明无法连接。独立“日志”页从日志 API 展示持久化日志；页面仅清理 ANSI/不可见控制符及明确位于终端边界的替代符，每条显示最多 4096 字符，不修改日志数据。

实例配置页不再用 UI 默认值假装文件配置。无快照时经领域 Owner 提交只读 `properties-read` 任务，通过 Daemon 声明的 `minecraft-server-properties-file-v1` 能力读取真实 `server.properties`。中央编辑器以节点快照中实际存在的每个属性为准：已识别的布尔值和枚举用选择器，已知数字项用数字输入，其余属性可编辑为文本；敏感值默认隐藏，未触碰的空白保持原值，输入后清空可移除该项。保存只提交已变化键并留在当前编辑页，写入任务通过实例互斥、节点校验和敏感值加密后由目标 Daemon 原子更新真实文件、保留注释与其他行并回读完整脱敏快照。未读取前不显示编辑表单；管理员可显式重新读取。

任务、节点和实例列表使用 `lfaa-card-motion` / `lfaa-card-motion-list` 注册共享动效，不在页面复制动画实现。实际效果由设置中心“常规 > 整体卡片动效”的账户设置选择；选中和真实状态保持清晰，桌面动作列与窄屏动作区按容器重排。`appearance.advanced.reducedMotion` 与系统减少动态偏好继续由共享 Theme Owner 控制；不增加 JS 动画循环、CSS 自定义属性或设置项。

服务器总览卡片在右上放置现有启停、终端和实例管理操作；右下展示当前真实实例的核心标识、核心名与 Minecraft 版本。Paper 使用未改色的官方标志（来源：[PaperMC Art Assets](https://docs.papermc.io/misc/assets/)），其他核心显示中性方块图标；核心类型和版本直接取自同一个实例快照。

实例详情概览用横向摘要卡组织插画、实例名称、真实状态、节点/端口/运行配置和生命周期按钮；下方展示 JVM 实例配置，不把任务列表混进实例信息。摘要与 JVM 设置卡注册共享入场/悬停动效，由 `general.cardMotionEffect` 选择，减少动态效果与系统偏好优先。所有实例任务继续只在“任务”菜单中浏览。安全启动/停止/重启统一调用已有 Minecraft action API 和权限合同；安全停止完成后，共享 Terminal Manager 收起该实例已退出的终端视图。

实例概览中的 `MinecraftJvmSettings` 只编辑已安装实例的 JVM 堆与受支持参数，不显示 Java 下载入口；参数保存调用 Connection 暴露的 Minecraft Service API，运行中和节点离线时只读。卡片按路由中的实例 ID 重新挂载，始终消费当前实例自己的核心、Java、堆和参数；API 运行时缺少这些字段时只暂停 JVM 编辑并提示刷新，不崩溃，也不以默认值覆盖实例数据。卡片按中间工作区容器宽度重排，并使用共享色板、外观表面透明度与减少动态偏好。
