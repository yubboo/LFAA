# Minecraft 面板

进入具体实例详情或带实例 ID 的日志页时，MinecraftWorkspace 将当前实例与节点 Java 快照的最小摘要交给共享工作区右栏。只有实例固定的 Java 运行时 ID 与节点实际报告项匹配时，才显示该运行时为已选/当前使用，并展示发行商、版本、发行版、架构、系统及接口允许返回的可执行路径。自动管理列出节点真实上报且主版本相符的环境，并标明只是节点登记项、实例启动时仍由节点解析；未上报、离线及 PocketMine 状态分别说明。安装时间、安装目录、JDK/JRE 类型和环境变量状态没有权威字段，不显示。

具体实例的 `overview` 路由还向共享右栏提供“服务器信息”。实例名称、核心/版本/构建随当前 Minecraft 实例快照变化；游戏模式、服务端口和世界名仅取节点 `server.properties` 文件快照，并标注读取时间。管理员在概览首次无快照时沿用既有只读读取任务，也可手动刷新；核心/节点不支持、离线、权限不足或读取失败时明确展示状态。玩家地址来自当前账户下 `game-connectivity` 登记且精确匹配该实例的 `playerAddress`，按真实路线状态标注；没有路线就提示未登记，不从节点名或端口拼地址。实例目录仅由管理员 API 读取 Minecraft Owner 解析后的当前目录。地址和目录经真实浏览器剪贴板复制，只有写入成功才反馈成功。列表路由与其他实例详情 Tab 不挂载该模块，迟到请求通过 AbortSignal 取消。

实例详情页的标题、单行副标题、状态提示与实例导航由顶部信息容器统一排布，容器内部与窄视口换行行距均为 8px；没有副标题时不预留垂直空行。导航与配置正文之间仍沿用工作区区块间距，避免把整页其他内容一并压紧。

Minecraft 总览页的控制端状态与最近同步时间置于标题区域右侧；新建和刷新等操作独立留在操作行，窄容器下按标题、状态、操作顺序纵向排布。实例概览标题操作提供“返回服务器列表”入口，替代该页重复的控制端连接徽标；其他工作区页面的状态提示保持原样。

实例列表顶部的状态摘要卡片按同一份真实实例快照计数并可直接筛选，与列表状态下拉同步；“需核对”只汇总异常和状态未知实例，搜索条件继续与状态筛选组合。

实例概览中的“打开实例文件”将账户限定的稳定实例 ID 写入共享的一次性文件位置合同，并附上同一 ID 的实例概览路由后进入 `/files`。文件页可据此返回准确实例，原入口支持再次打开文件。`workspace-files` 包按已登记的实例、节点和能力解析真正目录；本包不从 Minecraft 版本、实例名称或本机配置自行拼出物理路径，也不在跳转时发起文件写操作。

实例列表卡片主体与“管理”按钮是两个独立入口，各自点击后直达实例概览；悬停卡片主体不会让“管理”按钮呈现悬停态。启停、重启、控制台和文件操作只在实例内部展示。归档删除在实例概览中使用原确认提示和节点归档任务，提交后回到实例列表。

管理工作区用共享 Snapshot Cache 按当前 `userId` 与角色保存最近一次完整成功的读取结果；同一身份 30 秒内再次进入先呈现快照并跳过整轮首屏请求。冷进入先等概览、节点和实例三项关键状态，Java、任务和部署信息随后补齐；首个 Socket 握手不重复触发快照，Socket 变更仍即时对账，REST 在连接时每 30 秒、断开时每 10 秒兜底。日志由 Socket 推送，在线每 30 秒、断连每 5 秒兜底。缓存只作短期展示，不替代认证 API 的权限、状态与参数校验。普通总览不请求 Mojang 或核心来源目录；打开部署选择流程时先复用当前账户本次系统运行中的最近一次成功核心目录，首次无可用快照才读取完整目录；用户可手动刷新。空失败目录不进入缓存。版本目录仍使用真实来源数据，服务器与 Java 文件仅由已授权部署/环境安装任务在目标节点下载。

`MinecraftWorkspace.tsx` 读取真实节点、实例、部署、任务和日志；`MinecraftDeploymentPanel.tsx` 以三步向导完成核心/版本选择、节点/实例参数设置和部署前许可核对。核心目录及版本由真实来源提供，程序包自动匹配，普通向导不要求用户挑选构建编号。最终一步只提交一次正式 provision API，网页关闭后任务继续由节点执行。

首次配置推荐 Paper（一般插件生存服）；模组服按整合包选择 Fabric/Forge，代理和基岩按各自用途显示。版本来自在线目录；每个核心版本自动采用目录首个工件，并由服务端解析可信来源与摘要。切换核心和版本时会丢弃过期响应。唯一可用节点自动选中，多节点由用户选择。控制端 Socket 连接与节点在线状态分别呈现；离线节点不可派发。

默认核心、内存、Java/基岩端口与执行边界读取共享账户设置；保存默认值后只更新仍采用旧默认的输入，保留用户已填写参数。页面沿用主题、强调色、字体/字号、对比度、Minecraft 壁纸、遮罩、模糊和减少动态效果的共享映射；Ant Design 字号使用 interfaceFontSize。CSS 不另建主题或资产来源。

总览中的三个运维状态入口和 Daemon 节点预览行使用 `lfaa-card-motion` 消费 `general.cardMotionEffect`。悬停时使用共享卡片动效；聚焦显示清晰轮廓，按压给即时表面反馈；总览区域不添加入场编排。`appearance.advanced.reducedMotion` 与 `cardMotionEffect=none` 仍由共享 `ui-theme` 样式优先停用变换和过渡。

实例列表提供名称/核心/节点搜索、真实状态筛选和通往实例内部的管理入口。内部启停按账户权限、节点在线、实例状态和能力限制；宽分栏中实例名称、真实状态与运行事实保留可读空间，窄容器中卡片改为单列且管理入口可达。空实例状态引导先检查 Daemon 节点或开始首次部署。没有持久化“已看过引导”字段，部署页每次进入都会显示向导，输入只保存在当前页面状态中。

当前 Minecraft 手动开服/运维工作区使用有层次的运维界面：总览提供真实开服入口、Daemon 准备状态及节点到实例关系；当前服务器卡片对应节点的整机 CPU、物理内存、全部本地固定卷合计和 IPv4 默认路由网卡收发速率来自 Daemon 实际采样，通过认证接口在总览显示最近 30 条、至多约 5 分钟的有界趋势；旧 Daemon、首次基线、采集失败、过期和离线分别呈现真实状态，不补示例值。节点、实例、任务和工作流按实际信息分组，动作随容器宽度对齐或重排。控制台路由的最外层右侧菜单另提供服务端运行指标卡：在线人数、服务器公布版本和节点到服务端 Ping 使用实际协议查询，运行时间来自受管进程启动记录，Paper TPS 从用户已连接控制台时的低频 `tps` 查询输出读取。Paper 查询会把命令和真实输出留在控制台，其他核心标明不提供 TPS。颜色、主题、字体、字号、壁纸、遮罩、模糊和卡片动效继续读取 Appearance/常规设置。任务卡片在宽屏将状态与操作并排展示，窄屏纵向重排；查看详情、取消、选择和删除仍执行既有权限与结果合同。实例“控制台”使用系统共享终端管理器接入真实 Minecraft 受管 PTY，显示该进程最近最多 128 KiB 的有界内存回放和实时输出，并将键盘输入送入同一进程；终端不读取或显示日志快照。实例运行状态显示在页面“控制台”标题旁，终端标签只显示实例名；Shell 会话存活不冒充服务端运行状态。独立“日志”路由由左二 Minecraft 管理菜单进入，实例选择与日志筛选/自动滚动由 `MinecraftWorkspace.tsx` 呈现；日志通过现有 API、Socket 和轮询读取。旧实例日志路由保留兼容，但页面本身不会显示实例页签。侧栏展示真实节点、核心、端口和内存数据。快捷命令只向当前活动的 Minecraft 服务端 PTY 写入，未连接时禁用。终端继续沿用设置中心代码字体和强调色。详见本轮合同 `docs/development/minecraft-player-launchpad-ui-20261030.md` 与 `DESIGN.md`；早先管理后台参考布局与浏览器记录保留在 `docs/development/minecraft-admin-ui-reference-20261027.md`，仅作历史证据。

参考站可生成独立 Windows `.bat` 与 Linux/macOS `.sh`，并允许复制/下载。LFAA 当前由 Daemon 以结构化参数数组和 `shell:false` 启动实例；实例数据、进程标记、任务和安全停服都由 Daemon 跟踪。本 UI 不生成可绕过这些状态的外部启动脚本，也不展示未接入持久化/执行链路的假启动参数编辑器。要支持可视化修改，需先将参数定义为实例级配置，由 API 校验保存并让 Daemon 的真实启动合同消费；外部可执行脚本与托管生命周期应作为不同能力单独评估。

部署记录显示历史执行结果，当前运行状态以实例为准。未知结果不提供自动重放；强制结束显示橙色“已强制停止”，不声称正常存档退出。PocketMine 不展示 Java 内存配置；代理不提供世界备份或 Java 世界属性编辑。

代码与实机记录见 [开发计划](../../../docs/archive/audits/minecraft-deployment-plan.md)。浏览器可视验收与构建分别记录，不能把产物构建当作主题、字号及操作体验已通过。输出仅进入根 `dist/`。

Minecraft 常规模式的“工作流”页提供无限画布式 Agent DAG：节点可拖动、连线表达前置依赖，位置与定义由账户隔离的 Workflow Owner 保存。每个节点仍运行于 Minecraft App 的现有 Agent Loop、Session 和 Minecraft 工具/权限链；当前运行按拓扑顺序串行执行，不提供循环、计划任务、跨 App 或任意代码节点。界面沿用现有外观设置与主题令牌，不新增设置项。浏览器编辑、拖动、连线、保存/刷新恢复和缩放验收见 `docs/PROMPTS.md` 的 `LFAA-AGENT-WORKFLOW-CANVAS-01`。

Minecraft 工作流画布仍是专用适配器，继续处理 Minecraft 工具选择与 EULA。嵌入系统 Canvas 外壳时用 `visible` 暂停隐藏面板的运行状态刷新，并向当前画布 Agent 报告所选工作流的真实 ID/标题/更新时间；上下文只作定位提示。Client 模块入口同时登记 `MinecraftWorkspace.js` 与 `MinecraftWorkflowCanvas.js`，供 `ApplicationWorkspace` 的动态模块加载器按需装配。

Minecraft 的“联机”菜单跳转到独立的 LFAA 联机服务 App。Minecraft 包只登记当前账户拥有、节点在线且真实运行的 Java TCP 目标与已保存端口；不会在此包复制路由表单、创建公网映射或触碰开服/实例启停。完整游戏目标合同见 `packages/network/game-connectivity`。

## 共享运行环境

部署页按核心真实工件解析 Java 要求，通过 RuntimeManager 选择匹配的设备环境；环境准备跳转到游戏库，当前账户的短期草稿通过 Client Snapshot Cache 保留，退出账户统一释放。返回后重新校验核心、构建、节点与显式 Java，EULA 不保存在草稿中。原生 install/start 任务提供取消请求，只有节点确认才结束，不将停止聊天当成停服成功。

Minecraft 环境菜单直接进入共享运行环境页，部署草稿/实例均可原路返回；旧 Java 管理界面已移除。向导默认端口被同节点实例登记时建议下一个未登记端口，显式修改保留，重名/端口冲突/失效 Java 在提交前提示。成功提交消耗当前草稿，下一次新建不复用已提交的实例名和端口。

实例列表提供“删除实例”：已停止/失败可申请归档，未知状态交由节点核实；运行或活动任务拒绝。节点检查真实路径、元数据归属、进程与安装标记，完整目录移动至节点 `backups/minecraft/deleted-instances` 后才移除登记及关联部署，历史任务保留。失效目录不存在时由节点明确回报，不伪造文件归档；不永久清除备份。

删除仅提交归档任务并留在实例页，页面明确提示可到“任务”菜单查看进度。任务页展示控制端返回的最近 200 项真实任务、各状态计数、运行进度、节点消息和归档结果；Socket 与定期快照继续由工作区统一更新。读取失败与无记录分别给出状态提示，不把空白内容当作成功。

部署、实例生命周期、配置写入和任务取消等异步操作提交成功后留在当前路由；设置中心 `general.notificationPopupsEnabled` 开启时，右下角出现单条可关闭的 5 秒倒计时提示，点击提示才打开任务页。通知总开关关闭时改用页面内状态提示。任务和实例删除仍走现有 API、角色/节点检查与 Permission Owner；任务数据仍由原 Snapshot Cache、Socket 和受限轮询更新。JVM 参数保存、任务记录删除等即时操作只显示完成提示，不伪装成后台任务。浮卡使用 Appearance 主题/字体/字号/强调色/表面透明度/模糊令牌，入场位移遵从 `appearance.advanced.reducedMotion`；计时器在卡片关闭、更换和组件卸载时清理，不新增请求、订阅或偏好。

任务菜单可打开单条详情，按需读取原任务参数、提交/开始/结束时间、结构化节点结果及最多 1000 条任务关联日志。失败详情以实际任务回报和关联日志中的异常证据说明问题；缺少更具体日志时明确标示证据边界。管理员可单条或批量删除已完成、失败及结果未确认等异常终态记录；终态卡片主体可点击选择，选中后整卡显示危险色浅底和单一边框；卡片始终不显示选择圆圈或勾选标记，鼠标点击未选卡片不会留下红色焦点外框。批量选择 ID 使用共享浏览器持久化层按用户隔离保存，刷新后恢复；已不存在或不再是终态的任务会自动从选择中剔除。非终态卡片点击主体打开详情但不可选择删除。卡片以左侧任务信息、右侧状态操作组织；窄容器中操作换到内容下方，触控尺寸与分组间距保持可用。独立按钮不触发卡片选择，批量操作全有或全无。清理同时删除所选任务日志，不影响 Minecraft 实例、部署登记、备份或其他任务。详情与日志在小视口内滚动，并沿用共享主题令牌；无新增设置项。

实例“终端”页在实例运行、节点在线且当前用户可管理时自动附着 `lfaa-client-ui-sidebar-terminal` 的共享终端表面和受管服务端 PTY；Daemon 只对真实 PTY stdout 保留最多 128 KiB 的临时内存回放，后续输出/键盘输入都来自同一活动 PTY。终端输入只发送给该 Minecraft 服务端，不是操作系统 Shell，断开连接不会停止实例；实例停止或节点离线时说明无法连接。独立“日志”页从日志 API 展示持久化日志；页面仅清理 ANSI/不可见控制符及明确位于终端边界的替代符，每条显示最多 4096 字符，不修改日志数据。

实例配置页不再用 UI 默认值假装文件配置。无快照时经领域 Owner 提交只读 `properties-read` 任务，通过 Daemon 声明的 `minecraft-server-properties-file-v1` 能力读取真实 `server.properties`。中央编辑器以节点快照中实际存在的每个属性为准：已识别的布尔值和枚举用选择器，已知数字项用数字输入，其余属性可编辑为文本；敏感值默认隐藏，未触碰的空白保持原值，输入后清空可移除该项。保存只提交已变化键并留在当前编辑页，写入任务通过实例互斥、节点校验和敏感值加密后由目标 Daemon 原子更新真实文件、保留注释与其他行并回读完整脱敏快照。未读取前不显示编辑表单；管理员可显式重新读取。

任务、节点和实例列表使用 `lfaa-card-motion` / `lfaa-card-motion-list` 注册共享动效，不在页面复制动画实现。实际效果由设置中心“常规 > 整体卡片动效”的账户设置选择；选中和真实状态保持清晰，桌面动作列与窄屏动作区按容器重排。`appearance.advanced.reducedMotion` 与系统减少动态偏好继续由共享 Theme Owner 控制；不增加 JS 动画循环、CSS 自定义属性或设置项。

服务器总览卡片仅保留一个“实例概览”入口，使用当前卡片实例 ID 直达对应实例的 overview；启停、终端和文件操作在实例内部页面处理。卡片右下展示当前真实实例的核心标识、核心名与 Minecraft 版本。Paper 使用未改色的官方标志（来源：[PaperMC Art Assets](https://docs.papermc.io/misc/assets/)），其他核心显示中性方块图标；核心类型和版本直接取自同一个实例快照。

实例详情概览用横向摘要卡组织插画、实例名称、真实状态、节点/端口/运行配置和生命周期操作；下方展示 JVM 实例配置，不把任务列表混进实例信息。启停共享一个按钮：停止/异常时显示“启动”，启动中/运行中时显示需确认的“安全停止”，安装中/停止中/未知状态显示禁用状态。摘要与 JVM 设置卡注册共享入场/悬停动效，由 `general.cardMotionEffect` 选择，减少动态效果与系统偏好优先。所有实例任务继续只在“任务”菜单中浏览。安全启动/停止/重启统一调用已有 Minecraft action API 和权限合同；安全停止完成后，共享 Terminal Manager 收起该实例已退出的终端视图。

实例概览中的 `MinecraftJvmSettings` 编辑已安装实例的 JVM 堆与受支持参数，不显示 Java 下载入口。所有 Java 服务端核心共用推荐与高性能 G1 参数；未显式配置的实例显示并在部署/启动时使用推荐默认值，用户显式保存的参数（包括空列表）保持原样。保存调用 Connection 暴露的 Minecraft Service API，运行中和节点离线时只读；目标 Java 在启动前真实验证参数，拒绝时不会启动服务端。PocketMine 使用 PHP，不消费 JVM 参数。卡片按路由中的实例 ID 重新挂载，始终消费当前实例自己的核心、Java、堆和参数；API 运行时缺少这些字段时只暂停 JVM 编辑并提示刷新，不崩溃，也不以默认值覆盖实例数据。卡片按中间工作区容器宽度重排，并使用共享色板、外观表面透明度与减少动态偏好。

部署、生命周期和配置任务成功后留在当前页，由统一通知偏好控制右下提示卡的 1–60 秒停留时间、进场效果和提示音；声音复用 `client-resources` 的既有通知音频实现。提示卡复用 `ui-primitives` 的 `NotificationToast`，任务入口、倒计时、声音与动作结果仍由 Minecraft Owner 管理。通知总开关关闭时不播放提示音并使用页内状态；减少动态效果仍覆盖所有进场动效。

实例详情页头由一个共享盒子容纳左侧标题/说明与右侧状态/操作；所有实例 tab 保留同一行说明高度，避免配置说明出现后把操作与 tab 挤下移。内容容器宽于 420px 时左右并排，420px 及以下上下排列。相关回归运行 `pnpm --filter lfaa-client-ui-minecraft test`；包构建运行 `pnpm --filter lfaa-client-ui-minecraft run build`。

任务卡片的状态徽标与已有操作按钮在右侧同组显示；卡片内容区不超过 460px 时整组移到任务信息下方，状态位于操作按钮上方。窄卡片显示“完成 / 失败 / 异常”等短状态，无障碍名称保留完整状态文案，宽卡片继续显示完整文案。Minecraft 总览“最近任务”面板横跨仪表盘两栏，使用单列卡片列表，复用同一状态来源和布局。

总览“最近任务”卡片主体可进入任务列表；任务详情关闭后，隐藏弹层不会拦截工作区点击，尚未完成的详情读取会被取消。
