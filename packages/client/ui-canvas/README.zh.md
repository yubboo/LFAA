# @lfaa/client-ui-canvas

[English](README.md) | 中文

## 摘要

浏览器插件在右侧工作台的新建标签页添加「无限画布」，承载项目画布编辑器和 3D 白模预演。

双击画布空白处新建节点或导入素材。右键画布空白处可添加节点、适应画布、粘贴或上传。新节点和导入素材会落在点击位置。

从资料库拖入图片或视频，可在松手位置创建参考素材节点。点击素材也能插入。移动单个或多个已选节点后，可撤销或重做这次移动。

画布左侧可打开节点列表、创作广场、应用资料库、添加节点面板、可搜索的全部功能和剪辑器。图片工具支持裁剪、旋转、缩放、标注、宫格切分和九宫格排版。视频工具支持截帧、拉片取帧、裁切画面、缩放、片段截取及音视频分离。图片和视频结果作为新素材加入画布，音轨单独下载。视频导出需要浏览器支持录制。

## 导出

- `./client` 提供浏览器 Cordis 插件。
- `.` 为包的构建入口，内容为空。

## 开发说明

React Flow 提供画布编辑和连线。Three.js 在打开白模节点时按需加载。画布文档与导出素材均通过带鉴权的项目画布接口保存。
