# client/ui-settings-account

本包持有账户设置界面与登录/账户安全提示。账户身份、凭据状态、通行密钥可用性与写入仍由 Account Owner 提供；Client 只展示状态并调用其已认证 API。

`PasskeySetupPrompt` 的自动弹出受账户 `general.notificationPopupsEnabled` 控制；关闭总开关只隐藏提示，不读取或改写通行密钥状态。用户主动进入安全设置后，通行密钥注册、密码验证和凭据操作继续按 Account Owner 与 Permission Owner 的既有合同执行。

通行密钥提示在检查和显示期间向 Workbench 报告弹窗占用状态，使版本公告等待它结束后再展示；不改变原检查、会话内跳过或账户数据行为。

视觉消费 Appearance 共享令牌及减少动态效果偏好。构建只写仓库根 `dist/packages/client/ui-settings-account/`；认证、真实账户与浏览器验收分别记录。

未认证登录页从 `ui-theme/login-appearance.ts` 读取按用户名隔离的、最近一次服务端确认的安全外观快照，消费主题、强调色、界面字体/字号、遮罩与对比度；账号不匹配时回到产品默认外观。登录背景继续作为当前设备的内置图片选择。缓存不含凭据、账户私有图片或插件配置；登录后认证转场仍直接使用服务端 Appearance 设置。

登录表单底部使用共享 `ServiceStatus` 的真实检查/在线/离线状态；状态圆点和状态说明始终在同一行显示，左侧状态、右侧密码恢复入口。支持行容器不超过 280px 时，恢复入口由“忘记密码？使用恢复密钥找回”交叉淡变为“忘记密码？”，完整动作仍作为无障碍名称；切换遵循 Appearance 减少动态效果设置，不额外增加偏好项。

登录成功后固定反馈位先显示紧凑的黑洞环形等待动画；工作台预热后，内置转场以 CSS 绘制静态暗角、黑洞核心和倾斜吸积环，并让登录布局通过透视旋转与深度缩放汇入中心。转场约 420ms，只动画合成层的 `transform` 与 `opacity`，不启动全屏 WebGL 帧循环，也不创建碎片/粒子群；覆盖层再用 160ms 淡出，动画结束后才解除工作台交互门控并显示提醒。此路径沿用 `appearance.advanced.reducedMotion` 和系统减少动态效果偏好；自定义转场槽保持原行为，错误与其他成功反馈仍使用原有 Alert。
