## React Bits LightRays

Source: `@react-bits/LightRays-JS-CSS`, adapted from the JavaScript + CSS variant supplied by the user on 2026-10-26. Upstream: https://www.reactbits.dev/backgrounds/light-rays and https://github.com/DavidHDev/react-bits/blob/main/LICENSE.md.

The LightRays renderer is modified for TypeScript, LFAA theme and reduced-motion settings, a bounded WebGL pixel budget, lifecycle cleanup, and a CSS fallback. It is consumed inside the LFAA application and is not exposed or distributed as a standalone component package.
