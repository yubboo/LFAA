# LFAA AI Work 聊天

其他 Client 管理页可通过 `aiWorkGoalRequestEventName` 将用户明确点击的目标交给共享 Workbench；本聊天只消费该目标并调用既有 `/ai/chat/stream`。权限审批、工具选择、插件执行和状态回读仍由服务端 Agent Loop、Capability Owner 与 Permission Owner 持有。无活动 Provider 时保留目标在输入框，不伪造执行结果；设置读取完成后若没有可用账户，提示仅显示“尚未配置大模型”，并由“去配置模型”直接打开“AI 与模型”设置区。

`lfaa-client-ui-chat` 展示同一 Agent Run 的公开正文、真实工具活动、用户问题和权限审批，执行与持久化仍归原 Agent Loop、Session 与 Permission Owner。

全局 `/work` 使用 `workspace` 兼容作用域，用户无需先选业务 App 就能讨论、写代码和处理项目；项目目录关联是可选的工作上下文，与业务 App 关联分开。项目文件修改继续按默认工作目录/Agent Git 绑定规则和统一 Permission Owner 执行。全局聊天的可选 App 关联只提供模型参考，不扩张当轮工具范围。输入区按 `APPLICATION_LABELS` 显示真实 App 或“通用工作区”，不把 Agent 本身标成一个业务 App。

普通 AI Work 的唯一聊天根接收 `ui-workspace` 传入的标题栏 slot，随后按顺序呈现会话消息流、输入区与 `AiUsageFooter`；标题、对话流、输入区和用量盒子分别使用同一套响应式左右间距。输入区把计划提示、待处理澄清/审批卡和 composer 包在同一个父盒子中。消息舞台内部由左锚点导航轨、中间消息流轨和右侧滚动条轨组成；消息列表持有主对话区滚动，正文代码围栏、活动输出、操作详情等有界内容保留自身滚动条，滚动到边界后滚轮继续传递给消息列表。内部轨道延展进入两侧间距，使锚点及滚动条分别贴近中间列两侧，正文和输入内容共用宽度基准。工作区只限定轨道位置和强调色滚动条。缓存/上下文仍由真实用量与 `aiRuntime.showContextUsage` 设置控制，不新增数据或偏好。

回复运行和完成后都固定显示“小鱼助手 · 已处理/用时”标题与分隔线。思考状态按真实事件落点显示为不可点击状态；公开回复开始后跟随最新可见正文显示“正在回复”，已派发工具则显示对应可展开操作摘要。重复模型请求、推理、接收和准备阶段不进入展示；隐藏推理不展示。处理中状态以回复 ID 稳定派生七色流光相位，不随 token 更新闪色，并采用读取 `appearance.overlay` 与 `appearance.blur` 共享令牌的液态玻璃胶囊；`appearance.advanced.reducedMotion` 生效时保留静态磨砂表面并停止彩色扫光，不增加运行状态订阅或请求。

仅当活动记录标明内置 Browser Tool 与已校验 Provider 且状态为成功时，聊天通知工作区切换到同一 Browser Owner 的 Dock；失败、审批未完成和个人 Tabbit 活动不触发切换。

回复摘要统一以主题强调色绘制“小鱼助手”鱼形 SVG 标识。只有真实处理中状态轻微游动，完成、等待、失败和停止时保持静止；设置中心 `appearance.advanced.reducedMotion` 或系统减少动态偏好生效时停用动效。耗时文本继续使用共享秒表，但不放入 live status 区域，避免屏幕阅读器每秒重复播报时长。

对话消息列表始终从上向下排列。短对话的剩余空间留在正文之后；回复内容和真实活动一直按同一 DOM 顺序显示，只有各工具/操作详情单独折叠。正文增量仍只在用户跟随最新消息时同步滚动，不会在消息之间插入补偿空白或改变助手标题位置。展开完成态“小鱼助手 · 用时”过程区时暂停自动贴底，并在绘制前校正浏览器原生折叠造成的视口偏移，让被点击的标题留在原处；展开和校正产生的程序滚动不会单独显示“回到底部”。全部收起后恢复原跟随状态，期间用户主动滚动时以用户的新位置为准。会话切换按账户、App 和会话分别恢复滚动位置与“跟随最新消息”状态；原本贴底的会话按当前内容高度重新贴底，不沿用过期像素位置。

“回到底部”只在消息区存在实际滚动距离、且离最新回复超过跟随阈值时显示。滚轮在内容无溢出或已到滚动边界时不会凭滚轮幅度虚构离底距离。

全屏 `/voice` 模式仍由 `AiWorkChat` 持有并复用当前会话；语音输入、播报和语言沿用 `aiRuntime.voiceInputEnabled`、`aiRuntime.readResponsesAloud` 与 `general.language`。真实识别文本逐轮自动发送，播报结束或关闭播报时恢复聆听；语音识别与播放由浏览器宿主提供，不创建语音会话或录音存储。独立全屏视觉只展示当前状态、输入控件和当前会话信息，粒子球图片存于 `src/assets/voice-particle-core.png`；会话记录仍由 AI Work 唯一 Owner 管理。

语音主脑的粒子球由 `VoiceOrb3D` 负责：宿主可用 WebGL 时以固定数量点云绘制带透视的 3D 球，状态控制旋转与呼吸；WebGL 不可用时保留图片并使用 CSS 3D 倾转和双轨道动画。语音模式的 SpeechRecognition 临时结果只发送短暂活动强度给动画，不向输入区展示、提交或持久化临时转写。动效继续读取 Appearance 的强调色、标题色与 `appearance.advanced.reducedMotion`；不新增偏好。WebGL 路径在页面隐藏、离开视口或减少动态效果时停止/冻结逐帧绘制，减少动态效果设置在 CSS 后备中也会关闭动画；卸载时撤销帧循环、观察器、监听器与 GPU 资源。

语音主脑保持透明以透出当前 Appearance 工作区背景或 Wallpaper Engine 画布，并以 `src/assets/voice-starry-background.webp` 叠加无网格的青金星空与边缘星云；桌面高度充足时铺满视口，窄屏/短屏内容通过语音容器纵向滚动，账户背景、遮罩与模糊仍沿用 Workbench 共享令牌。背景静态绘制，不覆盖用户壁纸选择或减少动态效果偏好。

主聊天输入栏在模型按钮左侧消费 DSH `conversation.input.right` Slot，并把当前主会话 `sessionId` 作为 Slot owner 属性传给扩展；没有启用扩展时该位置为空，不保留占位。Slot 只提供 LFAA 已装配 Client 扩展的显示入口，不创建会话、授权或模型路由能力。

消息历史按单条消息行记忆；流式增量只更新内容或交互状态实际变化的行，历史正文不会跟着每个文本批次重新渲染。用量栏也按真实用量、上下文或显示状态变化更新，不随消息文本增量重复渲染。

`AiWorkChat` 可把当前已加载会话消息中的真实 `activity.fileChanges` 通知共享工作区；切换会话时先隔离旧消息，输出与来源摘要由工作区按新建/修改和读取分别归类。此活动记录不代表通用附件已接入。

活动中的项目相对文件路径在带有效 `projectId` 时作为按钮呈现，并把项目、路径和可选来源节点交给 `ApplicationWorkspace` 打开右侧文件标签；本包不读取本机文件或推断 Git 状态。

自动完成、问题、审批与错误提醒只有 `general.notificationPopupsEnabled` 开启时才发送到工作台通知、Toast、浏览器系统通知或提示音；类别开关和完成策略继续独立过滤提醒。总开关关闭不删除、不隐藏当前会话里的审批与澄清卡，也不改变消息/任务状态。

`response-timeline.ts` 按正文范围与活动落点形成同一条时间线；`AiWorkResponse.tsx` 在运行与完成状态下都显示固定“小鱼助手 · 已处理/用时”标题和分隔线。流式运行期间，公开助手文字、真实工具/命令活动与交互仍按原顺序即时呈现；回复完成且存在过程记录时，标题成为默认收起的过程折叠入口，展开后按原顺序查看过程，最终答复始终留在折叠区外并保持可见。没有过程记录时标题不显示空折叠入口。思考时只显示不可点击的单一状态；有真实工具派发时，在其正文落点显示可展开的执行摘要。重复的准备、模型请求、推理和流式接收阶段在运行与完成状态下都隐藏；真实上下文整理、错误和不可用状态保留为简洁记录，不显示隐藏推理。流式片段忽略开头空行以避免预格式空白撑高回复，正文内部空行仍保留。工具组、单步操作与合同详情仍各自可展开，默认不展开。失败原因只显示真实错误/回复内容，不合成诊断。没有过程数据的旧消息明确显示“此回复没有保存可展示的过程更新或工具操作”，不推测历史。真实文件变更以摘要卡放在答案下方，标题显示变更文件数与新建/修改/删除文件数，默认列出前三条路径，较长清单可展开/收起。卡片动作和路径行沿用现有项目 Git 差异入口；数据合同不含逐文件增删行数或单条回复撤销能力，因此不显示这两类统计/动作。历史正文缺少可靠分段时保留原文，不推测活动位置。页面只呈现本轮公开执行活动，不包含能力登记元数据、隐藏推理或原始工具结果；复制按钮仍只复制最终答案。

成功的 `browser-use.navigate` 与 `browser-use.open-workspace-file` 活动会从工具入参生成已校验、去凭据/查询串的网页目标摘要；只有记录了成功结果和内置 Browser Provider 的回复才显示“网页预览 / 打开方式”卡，并复用原 Browser Owner Dock。个人 Tabbit 页面、失败导航、网页正文和无导航的普通回答不生成预览卡。该动作只在用户点击后打开，不改写 `browserUse.webUrlOpenLocation`、`browserUse.localUrlOpenLocation` 或其他设置。

正在等待的审批与澄清共用输入框上方的交互卡，同一 Run 只展示当前一项；批准/拒绝或回答/跳过后，安全记录再按原活动落点显示在对应回复中。审批继续调用现有 Permission API，澄清回答继续绑定原 Run/questionId。后台提醒设置不隐藏当前会话必需的交互卡。

回复过程按正文落点把连续操作收成紧凑组，标题提供命令/文件数量和运行状态；运行中组摘要随真实回复过程即时显示，完成后整个公开过程收在小鱼助手时长折叠区内，默认收起，展开后用轻量动作行查看真实活动与文件变更，单步详情按需打开。Shell 展示 Owner 已脱敏/限长的命令预览和执行摘要；网页工具展示已有安全查询/地址预览。活动投影没有 Shell 原始输出，Client 不补造 stdout、Git 增删行数或成功结果。组内列表和展开详情均有高度上限与内部滚动；到达内层滚动边界后，滚轮可继续移动主消息列表；最终答复始终在过程折叠区外显示。

工具活动摘要优先显示人类可读的动作标题、步骤数量与执行状态；展开后先用简洁行列出真实阶段，完整函数名、Owner 用法、参数字段和操作约定放在二级详情中。参数值、凭据、原始工具返回正文、网页/截图正文和隐藏推理不渲染；工具描述以普通文本展示，不作为新的对话指令。已回答的问题与审批记录沿时间线简洁呈现，待处理交互仍使用输入区现有操作卡。流式消息提交后在绘制前同步到底部，仅在用户仍跟随最新回复时生效；用户上翻后保留其阅读位置。当前合同与定向回归见 `LFAA-AGENT-TOOL-CONTRACT-STREAM-20261027`。

文件变更继续使用真实活动提供的路径和工作台 Git 差异入口。隐藏推理、凭据及原始工具结果不属于公开过程。

普通回答分支从空白新聊天开始；Agent Loop 先让当前 Provider 把所选完整回答之前的有效上下文压缩为记忆，子会话仅持久化版本化记忆与来源关系，不显示或复制父会话问答/工具事件。摘要失败时留在原聊天并显示错误。分支会话在消息首屏展示 JSONL 持久化的“接续自”来源，位于聊天历史末尾和输入框之间；父会话仍可用时点击返回，并同步切回其项目。归档来源保留标题但不可导航。来源与消息分页共享一次受账户/App 校验的完整日志扫描，不新增设置、请求或运行状态订阅；视觉使用现有主题令牌。

历史首屏按账户/App/会话标识去重已完成读取；切换会话或卸载时取消旧首屏请求，`busy` 状态变化不重发已加载会话的相同请求。更早消息继续使用现有游标分页。

正文只保存一份，范围不复制文本；当前流式片段固定显示在最终回复所在区域，Provider 确认的阶段说明才进入过程时间线，避免最终正文在区域间移动而像重复输出。Connection 按空格或中英文标点优先合并真实增量，在下一帧交付；没有边界时最多等待 72ms，待处理文本最多 2048 个 UTF-16 字符。流式正文与完成态共用 Markdown 解析和主题样式：标题、段落、列表、引用、表格和围栏代码随真实正文逐步显示；已闭合块进入固定大小分块缓存，仅当前增长块重新解析。长围栏代码按视口高度限制块高，保留横向与纵向滚动，内层边界继续向消息列表传递滚轮。时间线按消息数据变化计算；秒级耗时使用共享外部时钟，仅通知活动耗时文本，不更新聊天根状态或重渲染历史消息。时钟只在工作运行期间启动，最后一个活动工作区卸载/停止后清理。继续复用分页与订阅撤销。样式读取设置中心已有主题、颜色、字体、字号、对比度、壁纸、透明度、模糊和减少动态效果令牌，不新增偏好或依赖。

提问输入框由自身 Grid 列约束，内部文本框宽度跟随聊天容器；三栏同时展开导致中心列收窄时，不得用隐式 Grid 最小宽度撑入侧栏。底部只常驻附件、权限、更多、模型、语音和发送操作；关联应用与 Skill/提示词/专家选择放入“更多”的纵向菜单，点选后在菜单内打开对应选择器，避免窄栏中长选择器挤压常用操作。菜单最大宽高受可用视口约束，长目录在选择器内滚动。

消息正文在窄聊天列中保留随容器宽度伸缩的两侧留白；嵌入 `/work` 时消息舞台延伸到中心列左缘承载提问锚点，锚点不跟随内缩后的正文偏移。权限操作常驻输入框底部；应用关联与 Skill/提示词/专家选择通过“更多”菜单访问，关联仍只是模型参考，不代表自动加载或授予权限。

提问框的插入光标跟随输入文字颜色，并仅在此控件覆盖 Wallpaper Engine 注入的白色全局 `!important` 光标规则，避免浅色主题/表面上消失。页面打开时不抢占键盘焦点，用户点击输入框后显示光标。

`/work` 中心列为 380px 及以下时，聊天输入容器把项目选择、当前应用、权限、更多和模型操作压缩成已有图标；可见宽度恢复后文字标签会自动返回。模型按钮把目录版本号保留为独立可见标签，窄屏图标模式仍通过原有 `aria-label` 与 `title` 提供完整目录名称和调用 ID；交互和设置 Owner 不变。断点按 `.ai-work-chat` 容器宽度判断，适用于窄 Dock 与嵌入式视口。

模型切换器按当前认证账户的全部 AI 账户模型目录汇总选项，账户名、Provider、模型原始名称、独立版本标签和调用 ID分别展示；任务类型、套餐档位、输入模态、上下文、输出限制与可信思考参数只呈现 Settings Owner 保存的目录字段。缺失的目录能力明确标注为未提供，不按模型名补全；非文本模型和当前套餐不支持的模型不会进入 Agent 文本选择。长目录最多先渲染 60 项，可继续分批加载或按账户/Provider/模型名搜索。选择账户与模型通过认证 Settings API 原子完成，并沿用账户 scope、系统账户管理员写权限及已保存思考偏好。

输入卡在鼠标悬停时保持静止，聚焦时只平滑过渡主题边框；底部操作按钮平滑过渡颜色，不改变输入卡或操作区的布局尺寸，也不投外沿阴影。空闲虚化只作用于 AI 回复区域，输入上下文和操作按钮始终清晰；设置中心的减少动态效果和系统减少动态偏好会关闭过渡。

活动 DSH Wallpaper Engine 画布时，聊天输入卡、用户消息气泡、审批/交互卡和聊天浮层读取插件生成的 `--we-chat-glass-fill`、浮层逐面令牌及对应的模糊/饱和度/亮度/对比度；视觉按 `data-we-glass-chat` 与 `data-we-glass-floaters` 门控。插件停用或画布不活动后只消费 LFAA 共享令牌，不保留旧玻璃值，也不新增设置或运行状态请求。

输入框支持 `/` 命令菜单和 `@` 关联菜单。命令目录只登记已有入口：`/plan`、`/plan off`、`/side` 复用当前消息解析，`/model` 打开当前模型选择器；`@` 从工作区传入的应用与 Skill/提示词/专家目录筛选，选择后通过现有 Session 关联合同保存，并把名称插入草稿供用户确认。关联能力只是模型参考，不代表自动加载或权限授予。菜单通过方向键、Enter、Tab、Escape 与鼠标操作，外观读取现有共享主题令牌；没有新增设置、目录请求、持久化或执行器。任务合同见 [LFAA-AI-WORK-COMPOSER-SLASH-MENTION-20261015](../../../docs/PROMPTS.md#lfaa-ai-work-composer-slash-mention-20261015)。

定向验证位于 `apps/cli/tests/ai-work-response-timeline.test.mjs`、`client-performance.test.mjs`、`ai-work-activity-duration.test.mjs` 和 `client-ai-work-composer-responsive.test.mjs`。合成事件/SSR 验证与实际 Provider、浏览器、桌面及帧时间验收分别记录。

## 小鱼共享工作入口（2026-10-14）

可选能力引用按服务端真实目录选择，内置 bundled Skill 不受外部插件总开关误禁；引用不授予执行权限。AI Work 项目管理器支持将项目关联到多个已登记业务 App；关联以 ID 保存并作为项目领域背景传给 Agent，不扩大工具范围或权限，也不关联 Daemon/节点。新建项目选择本机工作区父目录，LFAA 本机 Host 在其下创建同名项目文件夹；编辑时可管理附加本机源目录。

小鱼只有一个聊天界面；旧会话按原来源继续调用，公共列表不按 App 切分。App/Skill/Prompt/Expert 可选引用，空闲时保存到 Session；正文和工具由模型按需加载。项目选择统一消费账户目录；新建会话默认归入 Workspace Owner 返回的默认工作区，具体项目入口和用户在当前草稿中的主动选择优先。

AI Work 首次使用沿用默认项目语义；可用默认项目成为新会话的初始项目，既有会话不重绑。Electron/Tauri 桌面可用原生文件夹选择器；Web 使用 LFAA 本机 Host 目录浏览器选择父目录和附加源目录。项目有固定主目录及可选附加目录；目录核验不依赖 Daemon，项目和存储设置及 `LFAA_DATA_DIR` 不参与这条路径。

构建只写仓库根 dist/packages/client/ui-chat/；当前合同见 [开发提示词](../../../docs/development/xiaoyu-agent.zh.md)。构建、合成模型、浏览器与真实模型/节点验收分别报告。

主聊天和侧边聊天的输入框下方均显示当前会话累计的 Provider 用量。支持缓存的 Provider 按自身能力自动处理前缀缓存，不需要用户为每个会话开启缓存；LFAA 不伪造本地命中或节省量。点击缓存统计可查看输入、未缓存输入、缓存读取、输出和 Provider 统计覆盖请求数；命中率只在同一 Provider/模型分组且真实字段完整时计算，多模型会话分别展示，不跨模型混算。缺失字段显示未知，显式零保留为零，部分请求未返回缓存读数时显示覆盖率并将命中率标为不完整。

刷新或切换会话时，底栏区分读取中的会话用量、读取失败和 Provider 未返回用量，并预留按钮行高；不能在会话读取完成前把空摘要误报为 Provider 缺项。模型账户以本次 Settings/Connection 返回值为准，收起的模型按钮显示目录名称及 `versionTag`，版本标签不改写 Provider 调用 ID。

`aiRuntime.showContextUsage` 开启时，两个输入框下方也显示最近一次实际模型请求的上下文占用环。上下文容量取请求使用的模型目录；目录缺失时使用 `aiRuntime.contextWindowTokens`，明细明确标记容量来自模型目录或设置中心兜底。请求发出前按真实系统提示、工具 Schema 和消息估算分项，Provider 返回后总量更新为实际 prompt tokens。分项明确标为估算，图片 token 成本只纳入 Provider 实际总量。主聊与侧聊均从 Session 页面投影恢复累计用量和最近上下文快照，SSE 逐请求更新当前状态；不根据界面常数生成数据。

当 `aiRuntime.showContextUsage` 关闭时，输入框下方保留“上下文已关闭”提示；点击后可直接跳转到设置中心“AI 与模型”的对应开关并定位到该行，不自动开启或修改账户设置。关闭只隐藏上下文占用详情，不影响 Provider Token 与缓存统计。

输入操作栏的项目、当前应用、附件、权限、更多、模型、语音、发送和运行控制提供悬停提示；可操作控件同时支持键盘聚焦，禁用的项目按钮继续保留原生提示。会话用量与上下文指标的悬停说明来自当前 Provider 用量/上下文投影，点击仍打开原有详情 Popover；上下文关闭提示继续由 `aiRuntime.showContextUsage` 控制。

历史会话绑定的项目目录只有经 Session/Agent Loop Owner 与 Project Files Host 确认为不存在或非目录时才进入只读提示态；仍可查看消息记录，但禁用该会话的新提交和项目切换。加载失败、离线节点和权限错误均不按目录丢失处理。切换到其他会话时只中止原 Client SSE 订阅并隔离旧事件，不取消服务端 Run；重新打开时续接同一 Run。读取会话若发现 streaming/queued 消息会自动恢复跟随，断线后也可以从当前活动消息显式恢复跟随。续接允许空正文，但不会提交新用户消息；终态仍以服务端事件/Session 消息为准。

AI Work 新 Run 可选携带 Client 当前 `workspaceView`；续接中的 Run 不重复提交该字段。该 JSON 仅描述选择的工作台面板，不进入消息历史或 Session 持久化。
