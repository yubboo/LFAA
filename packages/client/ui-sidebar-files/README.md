# 文件管理共享界面

本包提供 Web/Desktop 共用的 `/files` 资源工作台，资源导航独立于真实目录与惰性目录树；游戏实例和节点真实游戏目录优先于普通资源。保留面包屑、列调整、预览/摘要编辑、拖放、批量操作、回收站、审计、上传下载和有界快照。

Connection 读取资源合同，Settings/领域/节点决定实际位置、状态、权限与可执行操作。左侧分类使用稳定资源 ID 显示中英名称及真实路径/Owner 说明；这些分类是快捷入口，不代表伪造目录。UI 不解析或重写远端绝对路径，不修改数据库/插件安装清单，不将上传当扩展插件安装。安装、更新、启停与卸载进入现有设置中心/Plugin Manager。目录不存在报错且不创建；SteamCMD 工具根缺失时提示实际路径并引导从运行环境页修复，内部挂载 ID 不显示为目录名，旧节点不兼容明确提示。

读取切换取消旧请求，账户/权限限定快照，流/观察器/URL 随卸载撤销。分类不新增后台轮询；目录大小只按需计算。外观复用主题、强调/文字色、字号/字体、代码令牌、表面透明度、壁纸、模糊和减少动态效果；页头在宽容器横向显示标题与存储位置/操作，实际容器窄于 680px 时纵向堆叠且路径截断，目录分类放到列表上方，目录树与表格独立滚动。

构建仅写根 dist/packages/client/ui-sidebar-files。[设计与开发提示词](../../../docs/development/file-resources.zh.md)。源码/类型/构建不能代替登录态浏览器、手机/短屏和帧时间验收。

## 小鱼共享工作入口（2026-10-14）

文件页全局导航的“应用”入口直接导航到 `/work`，由 Workbench 展示唯一应用清单和四栏布局，不打开紧凑应用弹层；房子仍返回来源工作区，文件与单根存储合同保持。

全局“最近会话”入口独立调用 Workbench 的跨页打开请求，进入 `/work` 后由 `ApplicationWorkspace` 展开并刷新同一会话 Dock；文件页不持有会话列表或展开状态。

设置页可向全局导航传入由 Workbench Settings 快照派生的可见应用项；应用显示/隐藏来自 `general.hiddenApplicationNavigationIds`，本包不另存清单或开关。

上传直接提交 File 原始字节，不再生成 Base64 字符串；远程下载和图片/PDF 预览从 Connection 取得短期 Blob。单文件沿用 3 MiB 上限和现有 20 MiB 批量上限，账户/权限切换后不再展示迟到的预览结果。

构建只写仓库根 dist/packages/client/ui-sidebar-files/；当前合同见 [开发提示词](../../../docs/development/xiaoyu-agent.zh.md)。构建、合成模型、浏览器与真实模型/节点验收分别报告。
