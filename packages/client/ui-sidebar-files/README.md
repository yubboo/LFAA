# 文件管理共享界面

本包提供 Web/Desktop 共用的 `/files` 资源工作台，资源导航独立于真实目录与惰性目录树；游戏实例和节点真实游戏目录优先于普通资源。保留面包屑、列调整、预览/摘要编辑、拖放、批量操作、回收站、审计、上传下载和有界快照。

Connection 读取资源合同，Settings/领域/节点决定实际位置、状态、权限与可执行操作。UI 不解析远端绝对路径，不修改数据库/插件安装清单，不将上传当扩展插件安装。安装、更新、启停与卸载进入现有设置中心/Plugin Manager。目录不存在报错且不创建，旧节点不兼容明确提示。

读取切换取消旧请求，账户/权限限定快照，流/观察器/URL 随卸载撤销。分类不新增后台轮询；目录大小只按需计算。外观复用主题、强调/文字色、字号/字体、代码令牌、表面透明度、壁纸、模糊和减少动态效果；窄容器把分类放到列表上方，目录树与表格独立滚动。

构建仅写根 dist/packages/client/ui-sidebar-files。[设计与开发提示词](../../../docs/development/file-resources.zh.md)。源码/类型/构建不能代替登录态浏览器、手机/短屏和帧时间验收。
