# 文件管理共享界面

本包提供 Web/Desktop 共用的 `/files` 资源工作台。页面复用 DockKit 的四个同级区域：全局图标轨、资源分类、文件操作区和真实目录树；中心区标题栏复用 `ui-primitives/WorkbenchHeader` 的四槽结构，资源与目录按钮分别控制左右 Dock，服务状态和外观令牌继续读取现有设置。资源分类独立于物理目录，游戏实例和节点真实游戏目录优先于普通资源。文本预览与编辑按文件扩展名按需加载 CodeMirror 语言支持，提供彩色语法、行号、查找、括号匹配及行列位置；JSON 编辑显示真实语法解析结果。Markdown 保留并排实时预览、未保存提醒和原有 SHA-256 写入保护。其余文件操作继续提供面包屑、列调整、拖放、批量操作、回收站、审计、上传下载和有界快照。

Connection 读取资源合同，Settings/领域/节点决定实际位置、状态、权限与可执行操作。左侧分类只展示稳定资源 ID 对应的中英名称；完整说明保留在悬浮提示，活动目录的真实路径显示在中心区。分类是快捷入口，不代表伪造目录。UI 不解析或重写远端绝对路径，不修改数据库/插件安装清单，不将上传当扩展插件安装。安装、更新、启停与卸载进入现有设置中心/Plugin Manager。普通资源目录缺失时返回真实错误；Minecraft/Steam 游戏根由 Daemon 按 Owner 保存的目录设置安全补建，之后列表和 CRUD 仍操作真实文件。SteamCMD 工具根缺失时提示实际路径并引导从运行环境页修复，不自动创建；内部挂载 ID 不显示为目录名，旧节点不兼容明确提示。

Minecraft 实例页可把稳定实例 ID 作为一次性资源位置传给 `/files`，并附加该实例的概览路由。文件页只在存在当前账户的真实实例来源时提供“返回实例”，浏览文件子目录后入口仍可用；返回后可再从实例打开文件。Minecraft 和 Steam 左二菜单也可传递领域存储根与来源 App；文件页显示“返回 Minecraft”或“返回 Steam”，沿来源路由返回后可再次从该 App 打开相同领域根。真实目录仍由 `workspace-files` 按领域记录和节点存储设置解析；Client 不从发行版本号拼目录。内部 UUID 只用于请求和面包屑按钮路由，面包屑显示实例真实目录末级名称，悬停标题显示节点物理路径；节点资源根仅显示在线节点，不把离线历史身份伪装成可浏览文件夹。

从 Minecraft、Steam 或 Minecraft 实例文件入口进入时，资源分类只保留 LFAA 数据、游戏实例、游戏存储、备份、运行环境、工具目录和日志。AI 漫剧项目、资料库、节点资源、项目缓存、临时文件及本机磁盘只从左一全局文件管理总入口展示；在游戏文件页点击左一“文件管理”会切回 LFAA 数据总览和完整分类。此筛选只控制快捷入口可见性，不替代 Files Owner 的路径或权限校验。

AI 漫剧项目媒体在“应用资源/AI 漫剧项目”中按当前账户只读浏览；从漫剧媒体库进入时定位当前项目。预览遵守通用 3 MiB 图片上限；大媒体由领域 Owner 提供认证流下载，导入、删除和素材引用仍回原 App 处理。

读取切换取消旧请求，账户/权限限定快照，流/观察器/URL 随卸载撤销。分类不新增后台轮询；目录大小只按需计算。外观复用主题、强调/文字色、字号/字体、代码令牌、表面透明度、壁纸、模糊和减少动态效果；中心区使用有界的纵向文件滚动，宽表仅在有足够空间时提供表格内横向滚动，窄文件区改为名称/副信息/操作的竖向紧凑行，不出现横向表格滚动条。页头按实际中间栏宽度折行、压缩重复说明并截断长路径；窄栏下搜索占完整宽度，筛选、刷新、新建和上传按容器宽度对齐为四列或两列操作组。DockKit 的栏宽和开合状态按账户隔离保存在本机布局存储中；窄分栏、手机下两侧栏可通过面板内关闭按钮打开和收起，移动视口一次只展开一个浮层。

构建仅写根 dist/packages/client/ui-sidebar-files。[设计与开发提示词](../../../docs/development/file-resources.zh.md)。源码/类型/构建不能代替登录态浏览器、手机/短屏和帧时间验收。

## 小鱼共享工作入口（2026-10-14）

文件页全局导航的“应用”入口直接导航到 `/work`，由 Workbench 展示唯一应用清单和四栏布局，不打开紧凑应用弹层；房子仍返回来源工作区，文件与单根存储合同保持。

全局“最近会话”入口独立调用 Workbench 的跨页打开请求，进入 `/work` 后由 `ApplicationWorkspace` 展开并刷新同一会话 Dock；文件页不持有会话列表或展开状态。

设置页可向全局导航传入由 Workbench Settings 快照派生的可见应用项；应用显示/隐藏来自 `general.hiddenApplicationNavigationIds`，本包不另存清单或开关。

上传直接提交 File 原始字节，不再生成 Base64 字符串；远程下载和图片/PDF 预览从 Connection 取得短期 Blob。单文件沿用 3 MiB 上限和现有 20 MiB 批量上限，账户/权限切换后不再展示迟到的预览结果。

构建只写仓库根 dist/packages/client/ui-sidebar-files/；当前合同见 [开发提示词](../../../docs/development/xiaoyu-agent.zh.md)。构建、合成模型、浏览器与真实模型/节点验收分别报告。
