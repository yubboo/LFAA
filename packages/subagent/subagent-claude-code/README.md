# lfaa-subagent-claude-code

此包封装官方 `@anthropic-ai/claude-agent-sdk@0.3.310` 外部 Coding Agent driver、Anthropic Console API Key 凭据门面与 SDK 协议适配。凭据按 LFAA 账户保存在现有 `lfaa-credentials`/`lfaa-settings` 加密记录中；设置页保存前通过 Anthropic Models API 验证，状态接口只返回是否已配置及更新时间。未配置有效密钥时，工具准备阶段在外层审批和 SDK 启动前拒绝；执行器禁止复用本机 Claude Code 或 claude.ai 登录。Anthropic 官方 API Key 认证要求见 [Agent SDK overview](https://code.claude.com/docs/en/agent-sdk/overview)。

执行器解析当前账户加密凭据，真实 API Key 保留在 Host；每次 Run 在 `127.0.0.1` 临时端口启动固定 `/v1/messages` relay，SDK 子进程只收到 256 位随机 `ANTHROPIC_API_KEY` relay token 和本轮 `ANTHROPIC_BASE_URL`。relay 限制 POST、版本头、流式 JSON、请求/响应大小和单并发；`lfaa-llm` Owner 固定发送至 `https://api.anthropic.com/v1/messages`，拒绝重定向并流式转发。客户端断开、Run 取消、超时与 SDK 结束会中止上游并回收 listener；API Key 与 relay token 在错误边界脱敏。该 relay 隔离凭据，但没有 OS 级出站限制或 AppContainer loopback 证据；SDK 仍只在现有 `aiRuntime.executionSandboxMode=danger-full-access` 下启动。执行器设置独立临时 `CLAUDE_CONFIG_DIR` 并启用 Anthropic 支持的 `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1`（关闭遥测、错误报告、自动更新与反馈流量）；查询关闭后清理临时目录。SDK 使用 `tools: []` 关闭内置 Shell/文件工具，并只连接当前父 Run 提供的进程内 `lfaa` MCP server。MCP 按父 Run 当前继承范围原样公布 LFAA JSON Schema；handler 通过 `executeTool` 回到 Agent Loop 的共用 dispatch，重读能力、运行原 parser、评估真实工具风险、检查重复调用/预算并由唯一 Permission Owner 授权和执行。SDK `PreToolUse`/`canUseTool` 仅限制在本轮登记的 MCP 名称并完成协议衔接，不创建第二套泛化审批；工具 observation 由 MCP 以对应 SDK `tool_use_id` 返回。不得从 MCP handler 直接调用 Registry `tool.execute`。

外部运行仍要求本机 Host、当前 Session 的 AgentGit 目标、现有 `aiRuntime.executionSandboxMode=danger-full-access` 与父 Agent Loop dispatch；当前这不等于 LFAA OS Sandbox。锁定 SDK `spawnClaudeCodeProcess` 要求同步返回进程，而 LFAA `SandboxProvider.confine()` 是异步；Windows Agent AppContainer 目前以 `CapabilityCount=0` 启动，且未证明可访问 Host relay。通用 `internetClient` 能力会开放一般公网出站，不是 Anthropic 白名单；本地 relay 只隔离凭据且没有系统级域名 egress 约束。`tools: []` 隔离了 SDK 内置 Shell/文件动作，但不代表 SDK 进程或 LFAA 全部工具已获得 OS 隔离。SDK 终态 `modelUsage` 的分模型 token 已接入 Session 总量且有合成回归；真实 Anthropic 账户/Provider、跨平台取消、系统级公网出站、AppContainer relay 与 token streaming 仍未实测。SDK `costUSD` 是估算值，不作为账单或费用事实保存。Codex 外部 driver 仍因缺少共享工具桥而不可用。

Claude SDK 开启 `includePartialMessages` 后，只转发顶层 `stream_event/content_block_delta/text_delta`；thinking、工具输入 JSON 与嵌套子 Agent 文本不进入父 Run。文本先脱敏当前 API Key 和 relay token，再按最多 2048 字符或 72ms 合批，通过 Agent Loop 的瞬时 Run SSE 事件传给当前 Client；预览不写入 Session JSONL，断线重订阅不补发旧增量，最终回答仍以 SDK result 和父 Loop observation 为准。Client 每个活动最多保留 4096 字符预览、全局最多 8 项，并在 Run 终态或会话切换时清除；真实 Anthropic Provider 的端到端流式体验仍待现场验收。

定向回归：`apps/cli/tests/anthropic-messages-relay.test.mjs` 覆盖 LLM 固定 endpoint、relay 方法/路由/query/token/大小限制、重定向拒绝、错误脱敏、SSE、取消及 listener 回收；`apps/cli/tests/subagent-claude-sdk-mcp-isolation.test.mjs` 使用锁定版真实 SDK 通过 Host relay 连接本地假 Messages transport，检查 SDK 环境只含随机 token、真实账户 Key 只到固定 LLM endpoint，并覆盖 LFAA MCP Schema、PreToolUse、父进程 dispatch 和匹配 observation；`apps/cli/tests/subagent-agent-loop-permission-bridge.test.mjs` 使用真实 Agent Loop、Settings/Permission Owner、合成 Provider 和 test driver 检查外层委派与继承 Tool 的批准/拒绝。`apps/cli/tests/subagent-claude-sdk-permissions.test.mjs` 覆盖 Hook、凭据、Key 输出脱敏、非必要遥测关闭、取消和启动门禁；`subagent-external-workspace.test.mjs` 覆盖目标与运行模式。上述本地隔离回归不使用真实 Anthropic 账户/Key；OS Sandbox、API egress 和真实 Provider 仍未验收。
