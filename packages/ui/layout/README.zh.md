# LFAA 工作区布局

本包提供统一的三栏区域契约和浏览器 Shell，顺序为图标主导航、功能菜单、主工作区。侧栏包含参考图中的主导航入口、ChatGPT/Codex 模式菜单、活动与本地搜索、可折叠分组、项目创建和用户菜单。

手机底部导航仅显示「首页」「更多」和「用户菜单」。图像、定时任务、资料库、插件和其他应用从「更多」进入；平板和桌面点击竖栏的「插件」直接进入插件页，竖栏也提供固定图标的操作。

桌面工作区按扣除左一图标栏后的宽度计算拖拽边界。左二默认最多占 15%，手动最多可拉到 25%。右侧最多占 75%，中间至少保留 10% 且不小于 360px。向右扩宽左二时，中间和右栏一起右移，右栏到最小宽度后才压缩中间。向左扩宽右栏时只压缩中间，左二宽度和位置保持固定。刷新或缩放窗口时会按当前空间重新约束已保存的侧栏宽度。

项目名称、固定应用入口和外观选择保存在当前浏览器本地，不会上传。“站点”默认固定，可在“更多”菜单中固定或取消固定应用。最近列表只记录当前页面会话的导航，刷新后会清空。搜索范围是侧栏功能和本地项目；活动、置顶会话等没有数据时显示空状态。图像、定时任务、资料库、插件、站点、地图、GPT、代码审查和外部 Provider 入口目前只有导航状态页，服务未接入；ChatGPT/Codex 菜单仅切换展示模式。账户、邀请、智能伙伴服务尚未接入，用户菜单会明确标注。本包只管理共享布局和外观；业务包拥有自己的 Client UI，新增插槽时再按真实消费者定义公开契约。
