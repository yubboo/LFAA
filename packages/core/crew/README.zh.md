# @lfaa/crew

LFAA 的多智能体任务编排包：把目标拆成有依赖的任务，按拓扑序接力执行，上游交付通过结构验收后才作为下游输入。

## 工具

| 工具 | 权限 | 用途 |
| --- | --- | --- |
| `run_crew` | read | 接收目标与任务列表，串行执行并返回逐任务状态与最终交付 |

任务最多 6 个，每个任务必须给出 `description`（怎么做）与 `expectedOutput`（交付什么）。执行复用 `@lfaa/subagent` 的隔离子运行：只读、不递归派发，工作台会为每个任务展开独立标签。

## 行为契约

- 按 `dependsOn` 拓扑排序，同层保持声明顺序；环、重复 id、缺失依赖在开跑前就被拒绝。
- 只把上游 **accepted** 输出注入下游提示，不转发上游对话与思考过程。
- 交接前按 `expectedOutput` 做确定性与结构校验：最小长度、JSON 可解析、`必须包含：A、B` 逐项检查；失败带原因重试一次，仍失败则该任务 `failed`，依赖它的任务 `skipped`。
- 每个通过验收的交付写入 `run` 作用域记忆（`ownerId=runId`），执行结束归纳成一条 `team` 记忆后清理，运行细节不进入长期召回。

## 安装

```bash
pnpm add @lfaa/crew
```

包默认导出 Cordis 插件本体，注入 `tools` 与 `memory`；子智能体服务按需延迟获取，未装配时 `run_crew` 返回可读错误而不是让 Host 启动失败。
