# @lfaa/chat

[English](README.md) | 中文

## 摘要

LFAA 核心聊天与 Agent 工作台业务包，提供会话管理、流式思考/行动/检查步骤可视化与模型规则设置界面。

对话视图保留流式正文与可展开的活动记录；轨迹视图列出会话中保存的步骤及可用详情。工作台概览提供 Git 变更入口，行数统计为已跟踪文件相对 HEAD 的差异。

本包位于 `packages/core/chat`。

## 开发说明

输入栏可在空会话中保存模式，首条消息后锁定。已完成的活动保留在对话中。工具活动的「查看」按钮定位到对应轨迹步骤，文件变更行打开文件预览。概览和 Git 审查使用已跟踪文件相对 HEAD 的增删行数。

流式活动段用同一行承载思考、工具执行和结果。输入框下方可打开当前回复保存的文件变更，本轮记录和工作区 Git 差异均在对应文件行下展开。输入框支持从已保存的澄清卡回复。

选择媒体模型后，输入框把描述直接发给生成接口。对话内的生成图片可以下载、引用为缩略图，并在原生成设置可用时再次生图。跳过澄清会在当前浏览器会话内关闭该卡片并保留草稿。
媒体直连生图请求附带的图片会保存在用户消息引用中，重新加载聊天后仍会显示缩略图。引用会话内生成图片、以及发给对话模型的图片附件也会记录在用户消息上。
