# LFAA 系统提示词

`lfaa-system-prompt` 按稳定顺序组装现有 LFAA 系统消息：核心安全与回复要求、权限模式、当前 App 领域指引、已登记扩展、任务专属 Agent 指引和运行上下文。

Provider 配置和权限检查仍归设置中心与执行工具 Owner；领域提示词仍归对应领域包。本适配包不存储提示词，也不增加用户设置。

核心指引要求工作量与用户目标相称：简单问答可直接回答，操作仅收集当前决策缺少的信息，目标已满足即交付；恢复失败必须有新依据，避免近似搜索与无界扫描。指引由模型理解和选择工具，不增加关键词路由、强制业务流程或新的授权限制。

操作过程由模型简短说明下一步及关键发现，最后独立交付答案；普通工具调用不逐条生成套话。过程只描述实际事实，关键补充沿已有交互入口等待真实答案，不展示隐藏推理。简单回答不强制增加过程段落。此约定不改 Provider 参数、权限模式或业务步骤。
