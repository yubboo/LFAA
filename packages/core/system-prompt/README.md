# LFAA 系统提示词

`lfaa-system-prompt` 按稳定顺序组装现有 LFAA 系统消息：核心安全与回复要求、权限模式、界面来源上下文、已选择的 Agent 指引和运行上下文。App 不再触发 Minecraft/写作总控全文；方法通过目录/加载工具由模型按需选择。

Provider 配置和权限检查仍归设置中心与执行工具 Owner；领域提示词仍归对应领域包。本适配包不存储提示词，也不增加用户设置。

核心指引要求工作量与用户目标相称：简单问答可直接回答，操作仅收集当前决策缺少的信息，目标已满足即交付；恢复失败必须有新依据，避免近似搜索与无界扫描。指引由模型理解和选择工具，不增加关键词路由、强制业务流程或新的授权限制。

多步操作或较长等待的任务开始前，模型先在正常回复正文简要说明准备核实/处理什么；每有可验证的实质进展，再自然交代发现和下一步。没有新信息时不重复播报，普通工具调用与内部模型阶段由界面提供可展开记录，不展示隐藏推理。最终答复先回应用户关心的事，使用连贯、平实的用户语言；简单问答保持自然段，复杂内容再按可读性选择结构，不套用固定开场/收尾。真实状态、依据、错误、权限和不确定性仍须准确保留；这类风格要求不改 Provider 参数、权限模式或业务步骤。

## 人格核心组合（2026-10-26）

本包只负责组合，不持有身份正文。`lfaa-persona`（`packages/preset/persona`，小鱼核心）通过 `registerLfaaPersonaCore` 登记两段正文：身份与真实领域地图（order 250，排在核心指引之后、权限模式之前）和领域工作约定（order 19000，排在 Agent 指引之后、运行上下文之前）。同一进程只允许一处登记，重复登记或空身份正文失败关闭；插件卸载后回退为不注入，组合结果与既有部署一致。正文版本由内容 Owner 维护，本包不复制、不推断领域能力。
