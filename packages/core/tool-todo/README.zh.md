# @lfaa/tool-todo

LFAA 智能体的任务清单工具包，清单存储复用会话记录（`@lfaa/session`）。

## 工具

| 工具 | 权限 | 用途 |
| --- | --- | --- |
| `todo_write` | read | 用模型传入的完整清单替换当前会话的任务清单 |
| `todo_read` | read | 读取当前清单与各状态数量 |

`todo_write` 是**整表替换**，不是合并：没有出现在本次入参里的条目会被删除。入参先校验再落库——内容不能为空、内容不可重复、同一时刻最多一条 `in_progress`。条目缺省 `id` 时用去空白后的内容作为标识，保证同一条任务跨轮次还是同一个 key。

清单写在会话记录的 `todos` 字段里，刷新页面或重启 Host 之后仍在；`todo_read` 读的就是这份持久化数据，而不是插件内存缓存。

## 行为契约

工具描述本身就是行为指令：多步任务开始前先为每个具体步骤建一条、同一时刻只保留一条进行中、完成即标记 `completed`。智能体的进度提示里会重复同一条规则。

## 安装

```bash
pnpm add @lfaa/tool-todo
```

包默认导出 Cordis 插件本体，可由 Cordis Loader 直接装载；它注入 `tools` 与 `memory` 两个服务。
