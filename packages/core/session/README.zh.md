[English](README.md) | 中文

## 摘要

LFAA 会话领域：消息/步骤/指标契约、本地会话文件读写、标题生成与历史摘要。

本包位于 `packages/core/session`。

## 依赖

无 workspace 依赖。

## 开发说明

会话记录在重新加载和分叉时保留已验证的预设及模块列表。会话已有消息时拒绝修改预设。旧会话可缺省这两个字段。

助手消息可保存结构化澄清问题，以及含身份与状态的子运行步骤。
用户消息可保存会话范围内的图片附件引用，使聊天历史在重新加载后仍能恢复预览。
