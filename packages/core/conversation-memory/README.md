# LFAA 对话记忆

`lfaa-conversation-memory` 是 AI Work 个性化记忆的唯一数据 Owner。它只保存账户级、数量与长度有界的摘要，使用 SQLite `conversation_memories` 表并通过 revision 比对保护并发更新与删除。设置中心的认证接口支持查看、编辑和清空；编辑入口严格拒绝超限、重复或可识别的敏感数据。

记忆内容与 Session 历史、工具审批授权、Markdown 知识库及自定义指令分开。Agent Loop 负责在账户设置启用时决定读取、生成和注入时机；本包负责输入整理、持久化校验、账户隔离和清除。

记忆默认关闭。功能启用前的会话永不回填。成功完成的根级 AI Work 轮次才有资格生成；用过工具的轮次另由账户设置控制。主回答与用量持久化并发出完成事件后，后台才启动有界记忆整理；每账户同时最多一个，本机总并发最多四个。整理只接收本机已过滤的当前轮用户文本、助手最终自然语言回复与现有记忆，不接收原始工具参数/结果。过滤基于常见模式，不能保证识别所有敏感信息。写入采用 revision compare-and-set，编辑和删除都会阻止旧整理覆盖较新状态。

保存前，Agent Loop 的 Session 投影剥离 `<conversation-memory>` 注入块，不把记忆正文写入新的请求/尝试模型快照。清空记忆时，设置 API 先委托 Session Owner 重写该账户已有 JSONL 会话日志并重新计算完整性哈希链，再递增 revision 清空 SQLite 记忆；聊天原文保留。此操作针对活动数据目录中的权威日志，不触及独立备份副本。

SQLite schema version 43 创建账户外键、长度约束、递增 revision 与更新时间；数据随账户删除级联清除。
