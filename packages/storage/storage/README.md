# LFAA 存储枢纽

`lfaa-storage-hub` 是通用非会话存储的插件登记层。它管理具名后端和可挂载的数据形式，但不读写数据、不决定数据目录，也不拥有账户设置、Session 或其他领域数据。存储介质由领域 Owner 按数据类型选择，Hub 不接管语义。

每个后端插件在装配时注册自己的名称，并在卸载时用返回的 disposer 撤销注册。不同介质可以同时装配；领域插件根据自身配置选择后端。未知后端、重复注册、未挂载的数据形式会明确报错。

账户设置与应用偏好使用 `<LFAA_DATA_DIR>/users/<账户 SHA-256>/settings/settings.json` 原子持久化，Session 事件使用 JSONL，账户、权限、任务、Provider 密文及关系索引继续使用既有 SQLite。素材、工作流图和 Markdown 正文也进入账户隔离的文件目录；各领域包仍负责校验、索引和访问边界。JSON 后端继续供明确选择文件存储的插件使用。

本次没有新增或改变设置中心配置。各类别仍位于同一个既有 `LFAA_DATA_DIR`，用户级安装与项目/便携运行的根目录选择保持不变；具体路径和迁移恢复合同见 `docs/harness-storage.md`。
