# `lfaa-browser-use`

本机 Browser Owner：在受支持的 LFAA Windows/macOS 本机 Profile 中按需启动隔离的系统 Edge/Chrome 会话，提供有界页面观察、截图、导航与语义交互。它不读取系统浏览器 Profile，不继承用户 Cookie；隔离 Edge/Chrome 每个 LFAA 账户/会话使用独立 BrowserContext，关闭后销毁内存态页面与上下文。Electron Host 另登记 `lfaa-native-browser`：只通过受信主进程的 loopback CDP 发现当前 Electron 浏览器页，并按账户、LFAA Session 与前端明确选中的 Target 绑定；这个 Provider 不拥有也不关闭 Electron 原生页面的 Context。CDP 端点留在 Electron 主进程与 Control Plane 内，不交给 Renderer、Agent Tool 或远程网页。其专用网站 Session 不持久化 Cookie/缓存，应用结束即清理。远程 Web Host 不会获得本机浏览器工具。

Tabbit 是单独的个人浏览器适配器，通过当前账户安装目录中的稳定 LocalAgent CLI 创建有界任务；只有用户在浏览器工作区选中 Tabbit，或当前请求明确要求 Tabbit 时才读取标签摘要/连接所选标签。其他个人 Chrome/Edge Profile、Firefox 与其他 AI 浏览器尚无此 Browser Adapter；用户明确要求控制本地浏览器时，仍可使用已登记的通用 Windows CUA 工具，且该画面目前不镜像进本工作区。

模型通过 LFAA `lfaa_tools_list/load` 选择真实登记的 Browser 工具。账户设置 `browserUse.enabled`（默认关闭）控制 Agent 是否可发现这些工具；`browserUse.enabledProviderIds` 仅记录个人 Tabbit 的显式选择，不控制内置 LFAA 浏览器。`lfaa_browser_list_providers` 返回当前 Host 的真实可用状态；可用的原生 Chromium/隔离 Edge/Chrome 随 LFAA 自动提供，无需 Provider 连接设置。用户在右侧 LFAA Browser Dock 手动导航走 Browser Controller 的认证 `/browser/dock/*` 路由；Agent 开关开启后通过相同账户/Session/provider 复用同一个页面上下文。Agent 专用工具和 `/browser/sessions/*` API 继续复核 Agent 总开关、认证、校验与权限。隔离 Edge/Chrome 不要求开启电脑操控；Tabbit 个人会话仍须用户明确选择、接入并启用既有 `computerControl.enabled`。所有 Agent 动作仍走唯一 Permission Owner 与 `permissions.mode`，不在浏览器包建立第二套审批。

`browserUse.recordRecentSites`（默认开启）由 Settings Owner 按账户控制。Browser Owner 只记录 LFAA Browser Dock / Agent 实际访问的 HTTP(S) 站点与路径，去掉查询参数和片段，最多保存每账户 100 条；读取、写入和清除经认证的 Browser Controller 路由。关闭开关后停止写入并不返回已有记录；用户可在设置中心确认清除。记录不包含页面标题、正文、表单值、凭据、Cookie，也不扫描系统个人浏览器或 Tabbit Profile。

Agent Browser Tools 通过 `BrowserSessionManager.createRunAdapter` 绑定可信账户、LFAA Session、Agent Run 与取消信号；同一 Run 复用高层动作适配器，Agent Loop 的 `onRunDispose` 会使其失效并移除登记。适配器只委派现有 Browser Owner 导航、观察、点击、普通文本输入、受限按键、滚动和 Tabbit 操作，不返回 `Page`、CDP/WebSocket、进程或本机 Profile 句柄。LFAA 隔离页面的 Agent 工具默认返回有界正文、可访问控件、网址、标签和修订号等结构化数据，不在导航或操作后同步生成截图；图片只在有明确需要的观察路径上提供，避免把画面编码/传输时间叠加到 Agent 动作。长期隔离 BrowserContext 继续按账户/LFAA Session 归属，不因普通 Run 结束自动关闭；Run 取消沿既有操作路径取消并回收当前 BrowserContext。该内部适配器尚不运行第三方 Skill 脚本或 Web Access Proxy。`browserUse.showFullUrl` 仅控制客户端地址展示。

当前会话绑定本机工作区时，`lfaa_browser_open_workspace_file` 可将工作区内 HTML/HTM 交给 Project Files Owner 建立仅监听回环的短期只读服务，并在相同 Browser Session 中打开；相对资源从同一工作区根目录读取，路径越界、数据目录与远程 Daemon 项目均拒绝。服务随 Browser Session 关闭或过期回收，不启动 Shell/Python。同一工作区页面的显式导航会保留其只读服务；离开该地址后先关闭服务。LFAA 隔离 Edge/Chrome 会按右侧 Dock 的可见页面区调整当前页视口；Tabbit 个人会话保留用户浏览器自己的视口尺寸。Dock 人类输入通过真实 Page 键盘、受限快捷键、滚轮/触屏滚动以及有界鼠标拖动转发到同一 Session；用户手动输入不作为 Agent 填表工具，不读取或返回敏感字段值。隔离浏览器的导航在主文档提交后即返回，显示画面则在 DOM 首次出现有界可检测的文本或媒体内容时更新；仍为空白时保留上一帧并返回加载状态，不等待整页所有资源加载完成。被动 DOM 变化通知按每页 750ms 节流，限制动态网站反复触发整屏截图；明确导航阶段和用户动作仍立即唤醒 Dock 刷新。登录、网页授权及验证码需要用户在页面中手动完成，不尝试绕过；Agent Tools 读取结构化页面快照，不为每次动作同步生成用户画面。

由 `profileContext`、`lfaaTools` 装配；配套认证 API 由 `lfaa-api-browser-controller` 暴露给共享 Client。Chromium 启动使用系统已安装浏览器，不自动下载内核；Browser Dock 新标签挂载后可先启动已选中的可用 Edge/Chrome 进程，预热不创建账户 BrowserContext、页面或网站请求，后续导航复用该进程。导航仅接受 HTTP(S)，页面请求拒绝私网目标（当前会话工作区的只读 HTML 源仅放行完全相同的 Origin）；混合公网/非公网 DNS 答案整体拒绝，只有全部解析到非公网地址的显式本机导航可放行。阻止 Service Worker；会话有并发和空闲时限。工具发现与执行均复核 Agent Browser Use 开关和当前 Host 的真实可用性；只有 Tabbit 个人会话额外复核明确连接与电脑操控设置。页面更新等待会在断开客户端请求时清理等待器，Web 页面隐藏时不继续订阅。取消隔离浏览器操作时关闭 BrowserContext，取消 Tabbit 操作后在当前有限操作结束时发送 `finish` 并回收 CLI 会话。构建输出为仓库根 `dist/packages/browser-use/browser-use/`。
