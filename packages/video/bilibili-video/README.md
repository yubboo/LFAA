# `lfaa-video-bilibili-video`

Owns the read-only Bilibili public video source contract: strict BV URL parsing, public metadata and captions, sampled storyboard images, bounded audio retrieval, and Ark Agent Plan ASR protocol. It sends no login cookies, follows only allowlisted HTTPS CDN redirects, checks public DNS addresses, and keeps image/audio bytes in memory only. ASR is limited to 60 minutes and 96 MiB, uses FFmpeg from the host `PATH` to produce 16 kHz mono PCM, and is available only when the caller supplies the selected account key after Permission Owner authorization. This package owns no account, credential, settings, permission, session, or disk media data.

The provider runs in the Control Plane Node.js process and is registered by the Web/Desktop Bundle at `packages/bundle/web-app`. Its consumer is `packages/video/tool-bilibili-video`. The network safety implementation reuses `lfaa-web-fetch-http`'s public DNS resolver; API/CDN routing and media limits remain here. Both HTTP and Ark WebSocket operations accept caller cancellation and have fixed timeouts and response/body limits. Storyboard JPEGs are transient model input; the consumer persists only descriptive metadata. Build output is `dist/packages/video/bilibili-video/`.
