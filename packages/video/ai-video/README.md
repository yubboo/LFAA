# `lfaa-video-ai-video`

AI 漫剧项目、创作画布、媒体库、时间线与白模导演台的唯一 Owner。创作画布与通用 Workflow 定义、运行记录分开；项目文件保存剧本、角色/场景档案、镜头和连线、Provider 任务、媒体清单、时间线片段与 3D 白模/相机参数。镜头连接允许环路，因为这些是创作关系，不是执行 DAG。

每个项目位于 `<LFAA_DATA_DIR>/users/<账户 SHA-256>/projects/aivideo/<项目 UUID>/project.json`，只接受已认证账户和服务端校验的 UUID，不接受客户端路径。项目 JSON 通过现有 `atomicWrite` 原子替换，目录使用现有私有目录保护，写操作复用控制端写锁。当前格式版本为 6，兼容读取 v1–v5，旧项目新增字段采用安全默认值。每账户最多 20 个项目、项目 JSON 合计最多 4 MiB；每项目最多 64 个镜头、128 条连线、24 个角色、24 个场景和 100,000 个剧本字符；每个镜头最多关联 8 个角色和 1 个场景。更新要求匹配服务端 `updatedAt`，防止覆盖并发修改。

静帧镜头图像使用设置中心选择的 OpenAI 或豆包/火山方舟模型生成；当镜头关联的角色/场景档案含本机参考图时，LLM Owner 通过 OpenAI Images Edit 或 Ark Seedream 的官方参考图字段传入；没有图片的档案仍只作为文字提示。视频使用独立 Settings 视频账户/模型与参数，通过 LLM Provider Owner 创建 Ark Seedance 异步任务。项目存储真实服务商任务 ID/状态；应用运行期由本机服务继续轮询，打开工作区时也可恢复；完成视频从限定的火山方舟对象存储下载，校验 MP4、单片大小后保存到项目 `assets/`。运行中的任务不能伪装成取消成功；只有排队任务调用服务商取消 API。任务临时 URL 不持久化为成片，也不返回给浏览器。

角色/场景参考图支持认证上传、读取、替换和删除，限定 PNG/JPEG/WebP、单张 3 MiB、边长 8192 像素和总像素 2000 万；复用 Settings 既有文件头/尺寸解析。媒体库支持 PNG/JPEG/WebP、MP4/WebM、MP3/WAV/OGG 导入，文件只写项目 `assets/`，JSON 保存素材 ID/MIME/大小/名称/来源；认证读取支持 Range 流，删除前检查角色、场景、镜头及时间线引用。账户素材最多 2048 个文件、合计 2 GiB、单素材 128 MiB；图片上限 16 MiB。时间线有视频、音频、字幕轨，单轨不重叠、最多 256 个片段、最长 300 秒。浏览器按 MediaRecorder 的真实能力导出 MP4/WebM，限制 128 MiB，音轨源文件合计最多 32 MiB，成片回写项目媒体库。

白模导演台在同一项目保存最多 32 个角色/方块几何体及相机位置、角度、焦距和比例；共享工作区用 Canvas 透视投影绘制场景，白模取景可保存为镜头参考。手机设备取景只在用户点击后启动 `getUserMedia`，切页、隐藏窗口或卸载时停止设备轨道，拍摄帧通过认证 Owner 写入镜头素材。无法访问相机时显示真实错误。Agent 领域工具由 `packages/video/tool-ai-video` 负责，所有写入/计费操作沿用统一 Permission Owner。旧版 `storyboards.json` 在分项写入并回读验证后原子改名为迁移恢复副本。构建输出位于仓库根 `dist/packages/video/ai-video/`。
