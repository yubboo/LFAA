# LFAA 受管子进程接口

`lfaa-subprocess` 是本机/节点进程执行插件共用的服务合同，覆盖可执行文件解析、受管进程、标准输入输出与终端会话，并通过 `registerSubprocessProvider` 把唯一真实实现登记到 Cordis 宿主。每次请求都包含目标节点、目标操作系统、绝对工作目录、argv、标准流策略和进程树终止宽限期；不接受 Shell 命令字符串，也不隐式继承父进程环境。收集输出必须给出每个流的字节上限，终端排队输出也必须有界。

调用方负责结合现有设置、项目权限和工具审批决定是否可以执行，并通过 `AbortSignal` 传入超时/取消；提供方负责安全创建进程、过滤未显式允许的父环境变量、回报真实退出码并等待整个进程树终止。argv 最多 256 项、单项最多 32 KiB、合计最多 256 KiB；收集输出每流最多 16 MiB，终端队列也最多 16 MiB。远程目标身份由 Daemon Owner 校验，服务接口不替代远程认证。

当前 Daemon 的 `process-control.mjs` 仍专属于已有任务和 Minecraft 进程；通用本机/节点提供方、Shell 及 PTY 的真实接线按后续 P2 阶段完成，本包此处仅交付可构建、已核验的接口和请求校验。
