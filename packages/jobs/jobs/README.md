# 持久任务控制

`minecraft-queue.ts` 与 `ai-host-tasks.ts` 持有控制面任务事实，供手动面板和模型工具共用。节点领取任务后获得租约；过期租约不允许晚到心跳复活，不接收晚到完成，也不自动重放副作用。

AI 主机任务支持按账户取消、节点确认、增量输出与单调输出序列。排队取消确认未执行；运行取消只登记请求，节点通过下一次心跳接收，再在进程退出后报告结果。输出上限每个流 1 MiB，最终结果保留期沿用现有 24 小时合同。

Minecraft 实例的启动、停止、重启、配置、备份和控制台动作排队时共用实例互斥。重启安全停止后再启动；强制停止后拒绝自动启动。控制台送达事实不能冒充指令效果验证。执行结果未知时实例状态为 unknown，后续由真实节点观测恢复。

新增字段及任务种类由数据库版本 34 迁移，保留旧任务、日志和索引，不清空用户数据。API、权限、执行器和验证记录见 [执行控制合同](../../../docs/execution-control.md)。

Minecraft 数据库版本 35 在此基础上保留记录并增加多核心工件/执行方式。自动 provision、start、restart 的成功完成必须包含当次 serverReady 证据；PID 或进程创建不等于就绪。自动部署与实例共用持久队列，已确认失败仅允许显式恢复原工件，未知结果不重放。账户下载、安装、就绪和停服时限快照随任务下发，执行器不得用页面连接或硬编码成功结果代替真实运行状态。见 [Minecraft 领域合同](../../games/minecraft/README.md)。
