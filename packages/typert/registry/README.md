# Typert 运行注册表

`lfaa-typert-registry` 是 Cordis 插件服务，按命名空间和方法保存 Remote 执行定义，并提供注册、查询、列举与受校验的本地调用。贡献由插件 Fiber 持有；Fiber 卸载时注册项精确撤销。

注册表不会创建 HTTP/Socket 路由，也不持有身份、权限、账户/App/项目/节点范围或持久化。当前 `api/gateway` 适配器先验证 LFAA 登录会话，再由注册方法的 `authorize` 对真实调用方做方法级授权；业务范围仍由原业务 Owner 检查。

请求与响应在解析器前后都受有限 JSON 边界检查。重复方法、重复 ID、未授权调用、非法数据和关闭后的调用会失败关闭。当前只有账户自身读取这一方法经过网络与 Client 闭环验证。
