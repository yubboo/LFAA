# LFAA Capability Prompt

该包把 GitHub Markdown 提示词适配到账户设置 Owner 与通用能力安装目录。

- 搜索只返回仓库候选；检查固定 commit 与源码归档摘要，只读取一个 `.prompt.md` 或普通 `.md` 文本文件。
- 多文件仓库要求模型先从检查结果选择相对文件路径，再重新检查；不执行仓库脚本。
- 安装时重新下载固定 commit 并核对归档与所选文本 SHA-256，按账户、目标 App 和来源路径登记；同一来源不会静默覆盖。
- AI Work 通过只读目录/加载工具访问当前用户、当前 App 的已启用提示词。提示词内容作为不可信输入回到模型，不能扩展授权或产品工具。
- 每账户最多 16 条，每条最多 24 KiB UTF-8；支持停用、移除，不提供就地编辑和自动升级。
- `plugins.enabled` 仍是现有 AI Work 扩展总开关。安装不会修改它；服务端 Agent 工具同时校验逐条启用状态与 App 归属。
